# Codex 系列视觉风格

## 适用与使用

供采用 Codex 系列视觉识别的视频选读。策划时结合当前内容确定是否采用，在分镜中落实配色与材质，Remotion 实现沿用当前方案；构图、标题、演示对象和动画按内容设计。

画布、文字、声音等量化参数查 [质量规范 8.6](../../docs/VIDEO-PRODUCTION-RULES.md#86-教程片视觉与声音量化基线)，实际观看检查查该文档第 12 章。

## 配色与实现

现有配色实现见 [codex.ts](../../src/styles/codex.ts)。其中入口色的含义为：

| 代码字段 | 颜色 | 对应对象 |
| --- | --- | --- |
| `app` | 青绿色 `#39d7c2` | App 入口 |
| `cli` | 绿色 `#78dd6b` | CLI 入口 |
| `ide` | 紫色 `#ad88ff` | IDE 入口 |
| `web` | 蓝色 `#5da8ff` | Web 入口 |

`accent` 复用青绿色，`accentStrong` 复用紫色；`warning`、`danger` 分别提供警告与危险状态色，`text`、`muted`、`line`、`panel` 提供文字、边线和面板色。具体值以代码为准。

入口色在展示对应对象时使用；当前视频未涉及的入口无需补入画面。用于其他对象或状态时，在分镜中明确颜色含义，保持本条视频内一致。需要不同配色时可在当前视频实现中调整，不必修改共享配色文件。

## 背景与材质

现有 `codexBackground` 使用深色近黑底，叠加青绿色与蓝色环境光；`codexGridBackground` 提供细网格。面板使用深色半透明底、细边框和柔和阴影。环境光、网格和面板质感可按当前画面调整或取舍。
