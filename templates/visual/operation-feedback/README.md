# 操作环境与可见反馈

## 表达任务

在同一个科技软件工作区内，建立旧状态、停止、修改配置、执行操作，再用真实可辨认的数量变化回应操作。左侧为操作区，右侧为结果区，编辑期间窗口固定，结束保留完整结果画面。

中性示例：８项任务，先以２个工作位运行；停止后任务回到队列，修改并发配置为４，点击运行，先展开４个工作位，再分配４项任务并行推进。任务数量、工作位数量和等待数量保持一致。

## 使用入口

- `index.tsx`：`OperationFeedbackMotion`。
- `example.tsx`：`OperationFeedbackExample` 及 Composition 元数据；1920×1080、30fps、234帧／７．８秒。
- `artwork.ts`：逐帧状态、SVG与Canvas绘制。
- `scene.ts`：原创中性软件工作区造型。

组件无配置参数；通过修改代码中的配置、轨道、任务标识、布局及时间锚点改造。不要只修改画面文字而留下不一致的状态、轨道数量或等待队列。

## 视觉不变量

- 操作、应用状态和结果属于同一个软件环境；左侧较窄，右侧结果占主体面积。
- 灰蓝表示等待，青绿表示执行，琥珀色强调正在修改的值；文字和数量同步解释状态。
- 停止完成后才编辑；点击运行后才应用新配置；工作位展开完成后再分配任务。
- 并行工作轨道允许同时推进，配置修改和执行步骤保持顺序。
- 编辑与反馈期间窗口稳定；结束没有关闭、缩窄、上移或淡出，最后一帧保留完整结果。
- 不包含章节标题、字幕或声音；指针和点击反馈属于操作表达。

## 可调整项与限制

按当前内容改造文案、配置值、任务数量、轨道布局、配色和动作节奏。正式视频必须改为绑定当前冻结分镜与真实Timeline；示例７．８秒不作为生产默认时长。

本例停止会将任务重新入队，新运行从头开始，不表达断点续跑。进度条是中性动画，不代表实际性能、完成时间或速度提升。需要真实执行证据时，应消费当前资料中的真实状态。

不适用于必须详细阅读大量代码、需要独立窗口之间传递数据，或操作结果与并发任务无关的内容。结果只变颜色而不改变数量、配置未应用便提前改变结果、过多轨道导致字号过小，都会削弱表达。

## 实际验证范围

用户认可７．８秒独立Shot无声预览，要求移除收尾动画并保留完整最后画面，复看后明确要求入库。提取后的234帧状态及SVG一致，组件和绘制代码核对、定向严格TypeScript检查通过。

依赖浏览器Canvas 2D与SVG图片解码，无新增依赖或媒体素材。预览与Remotion共享绘制实现；未渲染MP4，Remotion实际输出、正式视频应用及跨视频验证待完成。独立Shot认可不能替代当前视频人工Gate。
