# 具象对象对比

## 表达任务

通过可辨认的储物盒与分区柜体，比较分开存放和集中组织。先建立旧对象，再让位给新对象，保留前后对照。符号代表中性文件、图片和代码类别，物体大小表达视觉主次，不代表容量或效率数据。

## 画面变化

- 三个有顶面、侧面和接触阴影的储物盒依次建立。
- 盒体缩小并移向左侧，双门柜进入右侧，两段动作末尾有重叠。默认时序中让位在1.65～2.8秒进行，柜体从2.55秒开始进入。
- 双门展开，露出木色内部和三个对应分区。
- 阅读后柜门合拢，柜体向右滑出；盒体错峰向左滑出，标签随对象离场。合门与滑出有重叠衔接，出场不降低透明度。

默认示例8.2秒，1920×1080、30fps、246帧；无章节标题、字幕或声音。二维SVG提供体积线索，不是实时三维模型。

## 使用入口

```tsx
<ObjectComparisonMotion
 labels={{separate:'分开存放',organized:'集中组织'}}
 timeScale={1}
/>
```

`labels`对应两组短标签，不能只换文字声称展示了其他对象或能力。`timeScale`由调用方传入正的有限数，整体缩放时间；组件没有自动校验该参数。完整示例的Composition帧数可采用`Math.round(8.2 * timeScale * fps)`。正式视频按用户确认的分镜与真实Timeline改造，需要独立调节动作或停留时修改实现。

示例Composition ID：`ObjectComparisonExample`，注册信息见 `example.tsx`。不修改通用Root或具体视频注册。

## 当前实现与改造边界

- 旧组让位后保留对照，柜体进入不遮挡旧组；三个符号与分区持续对应。
- 顶面、侧面受光及遮挡关系保持一致；门板按固定边展开，内部位于门板后方。
- 当前阅读时物体及标签保持稳定；柜门合拢、滑出与附属标签共同完成收尾。这是现有动作设计，可按当前内容改造。

可以调整短标签、颜色、材质和节奏。当前固定三个类别、三个分区及宽画幅构图；不同数量、不同对象、真实三维旋转或其他组织关系需要重新设计造型与布局，没有自动布局或任意柜体配置。

失败方式：仅换文案却沿用不匹配的物体；把面积差当成数据比例；门板穿透内部、标签脱离对象；移动期间遮挡比较对象；过短停留使分区对应不可辨认。
