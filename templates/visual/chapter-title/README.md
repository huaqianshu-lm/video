# 科技章节标题与风吹散出场

## 表达任务

为短章节建立清晰定位，阅读后从右到左将文字吹散退出。标题字形、词组比例和冷色亮面形成身份，光束辅助建立；示例「从输入到结果」不演示实际处理流程。

## 使用入口与输入

- `index.tsx`：`ChapterTitleMotion`。
- `example.tsx`：`ChapterTitleExample` 及元数据，1920×1080、30fps、153帧／５．１秒。
- `artwork.ts`：状态、字形碎片与SVG／Canvas绘制。
- `scene.ts`：字形、布局与背景；`glyphs.json` 保存六个示例字的矢量路径。
- `build-scene.mjs`：从字形路径及布局生成 `scene.ts`。
- `extract-glyphs.swift`：可选的macOS字形提取工具，使用系统CoreText读取字体文件；不安装字体或依赖。

组件无配置参数，按当前章节修改字形、字号、词组间距、颜色及时间锚点。文字是矢量路径，修改`aria-label`不会改变可见标题。换标题时需提供对应字形并更新`glyphs.json`、构建脚本中的布局和动画字符索引；当前示例为六字，不自动排版任意长度。改字数还需同步调整`artwork.ts`中的`offsets`、`glyphSources`和多处固定六字循环，以及构建脚本中的定位框、字符中心和强调分组；仅替换字形文件不能适配其他长度。

可用本地字体文件生成路径：先在 `extract-glyphs.swift` 修改标题及字号，编译后传入字体路径和目标 `glyphs.json` 路径，再运行 `node templates/visual/chapter-title/build-scene.mjs`。预览及渲染本身不依赖macOS、字体安装或网络；字形生成是改造时的独立步骤。

## 当前认可版设计

- 关键词比连接词大，同词内间距紧凑；完整标题归位后保持稳定阅读。
- 字形完整、薄侧边、冷白／浅蓝与薄荷绿亮面，未加入额外笔画切口或背景装饰。
- 字符小幅错位连续归位，当前没有弹跳；光束展开后局部亮点短暂增强。
- 出场从右到左触发；碎片来自原字形局部，保留笔画与颜色，向左漂移、扰动、旋转缩小并逐渐变淡。
- 未触发区域保持完整字形，不能提前显露网格；基线同步退去，最后碎片清零。
- 当前示例只展示一个风吹散出场，未连接其他场景，也未包含字幕或声音。

## 可调整项与失败方式

按当前内容调整字数、字形、强调词、间距、材质和节奏；上述构图、配色、归位动作和风吹散出场属于认可版样式，可按设计改造或与其他画面组合。正式视频按用户确认的分镜及真实Timeline安排时序，５．１秒不是生产默认时长。

适合简短章节标题，不适合长句、正文或持续阅读的信息。标题改造后须同步定位框、字符中心、碎片范围和消散触发跨度；只换字形却沿用错误外接范围会裁切笔画或残留字块。碎片过大像方块爆炸，过小或过多会影响SVG解码性能；风速过强、过早消散或阅读期晃动会破坏可读性。

示例保留标题背景至结束。正式片与下一章节的衔接需按本片画面另行设计和观看，不宣称当前出场适配整条视频。
