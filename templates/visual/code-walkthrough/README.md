# 代码走读

表达任务：建立代码结构，以连续入场和推近进入阅读位置；编辑器固定，行高亮滑向三处关键代码；高亮结束后连续拉回并退出。引导阅读，不展示执行结果或证明代码正确。

`artwork.ts` 提供唯一画面实现，`index.tsx` 提供 React／Remotion 组件，`example.tsx` 提供认可版中性代码示例及 Composition 参数。无章节标题、字幕和声音；文件名是编辑器对象标签。

## 使用

```tsx
import {CodeWalkthroughMotion} from './index';
import {exampleContent} from './example';

<CodeWalkthroughMotion content={exampleContent}/>
```

输入 `content`：`fileName`、`lines` 和 `focusLines`。每行由 `[TokenRole,string]` 片段组成，保留原始缩进；颜色角色为 `plain`、`keyword`、`name`、`string`、`number`。`focusLines` 为三个从零开始的行索引，需位于代码行范围内，按阅读顺序排列。文字转义后嵌入 SVG，不自动解析语法。

可选 `timing` 包含入场／推近、显现、高亮进入、两次移行、高亮退出、拉回／收起、淡出的起止秒数，字段见导出类型。以 Composition／Sequence 起点为零，读取实际 fps；正式视频按真实 Timeline 转换时间，不能直接沿用示例节奏。

示例 Composition ID：`CodeWalkthroughExample`，1920×1080、30fps、198帧／6.6秒。时长由使用方设置，不由组件固定。本模板不修改共享 Root 或注册具体生产视频。

## 视觉不变量与适用边界

- 入场位移和推近共用连续进度；拉回与收起共用连续进度，避免分段停顿。
- 高亮出现之前完成推近，高亮完全退出之后才开始拉回。整个逐行高亮阶段编辑器位置、缩放和代码坐标不变。
- 单条高亮背景与侧边标记连续滑动，文字明暗随焦点交接；非当前行仍保留上下文。
- 深蓝环境、细边代码窗、低饱和语法色与薄荷色焦点共同构成层次。颜色与造型在 artwork 中改造，不提供主题引擎。
- 当前按五行短代码布局，行距70px、字号32px；例中最长行仍留有右侧空间。更多行、长行或大字号必须改造窗口和排版并观看，不自动滚动、换行或缩字。
- 不适合全文代码阅读、多窗口切换、代码运行结果演示或用高亮代替必要解释。输入内容需由当前视频资料支持。
- 调整时间时保留逐行阅读空间，且高亮阶段必须落在入场／推近结束与拉回／退出开始之间；不得为了提速截断最后一行或让镜头跟随高亮。

6.6秒独立 Shot 无声交互预览已获用户认可并明确要求入库；认可版包含固定编辑器的逐行高亮和连续入出场。提取前后198帧 SVG 一致，定向严格类型检查通过，详细检查保存于本地候选资料。
