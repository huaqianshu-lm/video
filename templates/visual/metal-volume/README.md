# 实体金属循环主体

## 表达任务

用于需要实体材质与曲面体积的概念性科技主体。冷银表面、曲面浅槽、加工细纹及冷暖反射建立金属身份。不是产品实拍、真实硬件结构或能力数据；使用时需要当前内容支持这一造型。

## 画面与变化

深色环境中，球体位置及大小固定，倾斜浅槽和纹理随对象绕竖轴转动；槽线与旋转轴不重合，转动时曲率、遮挡和槽边明暗发生变化。世界光源固定，球体的主要反射区域保持稳定，不将高光贴在表面一起旋转。没有轨道、入场、离场、章节标题、字幕或声音。

默认24秒一周并持续按周期求值；这是缓慢转动时的闭合周期，不是正式视频的固定时长。

## 使用入口

```tsx
<MetalVolumeMotion/>
```

示例Composition ID：`MetalVolumeExample`，1920×1080、30fps、720帧。示例注册信息位于 `example.tsx`；无限循环由播放器开启，Composition 本身是一周期的有限时长。正式视频可以使用任意内容时长。

`artwork.ts` 使用 WebGL 绘制原创程序材质，网页认可版与模板保持相同片元着色器与渲染逻辑。`motion.ts` 提供 `angleAtFrame(frame,fps)`，周期为 `cycleSeconds`。当前固定单主体构图，不提供任意模型、贴图或数据输入；可按需要改造槽位、材质、光源和周期，改造后重新观看。

## 视觉不变量与失败方式

- 纹理与槽线依附对象坐标，光照依附世界坐标；不能让纹理停在屏幕上或让整个亮斑跟着表面转。
- 浅槽遵循球面曲率，背光面和柔和反射共同建立体积；外晕不能代替体积。
- 细纹保持克制，过密会产生摩尔纹，过强会像脏点；压缩及缩小后的表现仍需复查。
- 冷暖反射有主次，不能让全表面均匀发亮而失去金属反差。
- 槽轴与转轴重合时，运动可能难以辨认；速度过快会妨碍观察材质。

不适用：真实设备拆解、准确机械结构、网络连接关系、操作因果反馈及量化性能比较。槽数量、反射和转速不代表能力或运行状态。网络结构表达使用独立的 `network-volume`，两个模板不互相替换。

## 运行条件与实际验证范围

需要启用WebGL；不支持时明确报错，不静默替换为静态图。使用独立画布并保持1920×1080设计坐标，外层按视频尺寸缩放。显卡、驱动、浏览器实现和输出压缩可能影响细纹，实际帧率和远端渲染兼容尚未测量。

独立无声持续循环预览获用户画面认可，并明确要求入库。四个CPU材质参考状态已查看，循环角度边界闭合；提取后片元着色器、渲染逻辑和720帧角度与认可版核对，模板入口定向严格类型检查通过。CPU参考图与GPU输出没有声明逐像素一致；Agent未进行浏览器连续观看或自动化检查。
