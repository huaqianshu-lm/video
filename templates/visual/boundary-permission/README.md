# 边界与许可动效

## 表达任务

同一个操作主体在限定区域内行动，接近边界受到限制；许可请求与实际执行分开表达。另一个可独立使用的动作段展示区域内操作改变文件状态。主体画面不内置章节标题、音频、字幕或具体视频业务文案。

## 验证范围

26.808秒真实时间的独立场景交互预览已获用户画面质量认可，并明确要求收入模板库。本实现从该预览的原创SVG动效提取；对象、配色、关系和状态变化保留，文本改由输入提供。

当前只记录单场景预览认可。中性示例经过定向类型检查；中性内容的正常速度观看、Remotion运行时实际渲染、完整视频人工Gate及另一内容复用仍待验证。未标记跨视频验证。

## 入口与组合

- `index.tsx`：`BoundaryPermissionMotion`，使用Composition／Sequence的本地帧与当前fps。
- `artwork.ts`：本模板具体SVG画面，`renderBoundaryPermission`可用于独立交互预览。
- `example.tsx`：两个中性示例及对应Composition元数据；不自动注册或修改项目Root。

`BoundaryRequestExample`为10.5秒、315帧；`WithinScopeEffectExample`为6秒、180帧，均为30fps。这些只用于演示，不是生产默认时长。两者可分别注册为Composition，或按当前视频内容放入Sequence。

## 输入与时间

组件接收`events`和`content`。画面从本地帧0建立。所有事件时间都是当前Sequence的本地帧；实际视频使用共享`src/lib/timing.ts`从真实Cue／Segment解析，不使用示例时间代替。

| 事件 | 可见变化 |
| --- | --- |
| `write` | 主体移到文件旁，区域内写入 |
| `network` | 主体到边界，外部连接目标出现 |
| `enforce` | 边界明确截住连接 |
| `approval` | 许可通路和独立请求进入 |
| `claim` | 请求说明出现，不开启通路 |
| `closed` | 通路维持关闭／待审 |
| `reassure` | 两层控制的关系线建立 |
| `noPrompt` | 许可退为上下文，主体返回区域内 |
| `return` | 文件再次写入 |
| `damage` | 文件出现裂口与碎片 |
| `final` | 保留结果及简短总结 |

`content`提供区域、许可、待审和请求说明的标签，以及各阶段的`summaries`。总结应概括当前可见关系，不复制完整口播。`showPermission:false`用于独立区域内动作段。示例中未使用的事件显式设为`Number.POSITIVE_INFINITY`；这是组件中禁用动作的值，不写入Storyboard或Timeline JSON。

保持实际采用的事件顺序，按当前fps留足动作和阅读空间。请求在30fps下至少需72帧完成进入及移动；更紧的口播先简化动作或只选一个机制，不能强塞全部阶段。每次采用后仍需正常速度观看。

## 视觉不变量

- 命令主体、文件、许可请求有不同造型，身份可追踪。
- 实际执行主体留在区域内，外部移动的小纸片表示许可请求。
- 范围边界与许可通路分别承担职责，不能画成批准就一定安全。
- 深绿强调区域与主体，琥珀强调许可，朱红用于文件损坏。
- 原主体先让位再切焦点，结果态保留理解时间。

## 可调整项

文本、真实时间锚点、是否使用许可机制、动作段组合及Composition时长由调用者提供。当前造型以1920×1080为逻辑画布，字号、对象位置及配色可在`artwork.ts`按内容改造；没有另建通用布局引擎或主题系统。标题通过独立标题模板组合，字幕与音频在外层叠加。

## 不适用与失败方式

- 不用于真实软件界面证据、实际权限结果或数据比例演示。
- 不表示许可批准成功；需要成功路径时必须按当前资料另设计，不能仅把锁图标变色。
- 不适合长标签、密集信息或强塞完整口播。当前SVG短句不自动换行，内容变长须重新排版。
- 竖屏须重新构图，不能仅缩小横屏画面。
- 动作锚点过密会互相截断；停顿太长且没有新信息也不合格，不能添加无意义运动填时长。
- 对象标签、小纸片与命令身份混淆，或区域内损坏被误读成越界成功，均需返工。
- SVG字体与滤镜效果需在目标渲染环境复查，交互预览不能替代Remotion成片验收。
