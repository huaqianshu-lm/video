# 曲面网络循环主体

## 表达任务

用于概念性的科技网络主体：曲面连接、发光节点和倾斜轨道形成可持续观看的空间形象。不是实际产品界面、真实网络拓扑、能力数据或执行流程；具体视频需要为采用这一造型提供内容依据。

## 画面与变化

深蓝环境承托球面网络，点线随深度改变亮度、大小和疏密；曲面边缘压缩、固定照明和局部暖色节点提供体积。轨道前后段分层，绕行光点依据深度在主体前后出现。

第一帧即为完整主体，中心与尺度固定，球面匀速旋转、光点持续绕行。没有入场、压拢、离场、章节标题、字幕或声音。默认24秒球面一周、轨道光点两周，共用相位形成闭合周期；周期不是正式视频时长，画面函数可以接收持续递增的帧号。

## 使用入口

```tsx
<NetworkVolumeMotion cycleSeconds={24}/>
```

示例Composition ID：`NetworkVolumeExample`，1920×1080、30fps、720帧。将example.tsx的注册信息用于独立Composition；无限循环播放由预览播放器开启，Remotion示例本身是一周期的有限Composition。

`cycleSeconds`为正的有限数，控制球面一周与光点两周的共同周期；缩短时两者同步加速。正式片按冻结分镜与真实Timeline确定持续时间，不必以完整周期为单位。`renderNetworkVolume(frame,fps,cycleSeconds)`用于共享画面或逐帧求值。

## 视觉不变量与可调整项

- 名称、说明或额外界面如需叠加，应保持可读；不随球面一起旋转。
- 深度、点线亮度差、边缘压缩和轨道遮挡关系共同提供体积，不能只保留圆形裁切与外晕。
- 节点、连线、轮廓与环境分配不同亮度，外晕不淹没结构。
- 球面和轨道共享周期；更改运动后需重新确认边界，不能直接播放到末帧再跳回不同状态。

可调整周期；造型、投影、网格密度、材质与配色位于artwork.ts，改造后重新观看当前画面。当前为单主体、深色宽画幅和概念性网络，不提供任意拓扑或数据自动布局。

不适用：需要准确节点数／连接关系的网络图、硬件部署关系、需要因果反馈的操作演示、量化能力比较。发光不代表处理成功，节点数量、尺寸和速度不代表性能。

失败方式：背景与主体同样亮；网格过密失去结构；过强光晕遮住线网；旋转过快；轨道前后遮挡错误；周期不同导致循环跳变。大量SVG元素和滤镜的实际浏览器帧率尚未测量，不能据类型检查声明播放性能。

## 实际验证范围

原创静帧及完整主体持续循环的独立无声Shot预览均获用户画面认可，用户明确要求入库。候选网页与Remotion共用确定性SVG画面；提取720帧逐帧SVG一致，周期边界第0帧与第720帧一致，模板入口定向严格类型检查通过。代码校验不代替观看。
