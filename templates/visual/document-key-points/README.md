# 文档到要点

表达任务：文档先建立来源，再向左让位；对应原文高亮、连线和三项要点分步展开；收尾先收回关系线，再退出文档与结论。连线表示提炼对应，不表示执行因果。

目录：`artwork.ts` 为唯一主体实现，`index.tsx` 提供React／Remotion组件，`example.tsx` 提供已认可内容的无声示例及Composition参数。主体不包含场景标题、字幕或声音；文档名称属于对象身份。

## 使用

```tsx
import {DocumentKeyPointsMotion} from './index';
import {exampleContent} from './example';

<DocumentKeyPointsMotion content={exampleContent}/>
```

输入 `content`：文档名称、简短说明、页脚、三个原文项及其结论。每项包含 `label`、`source`、`title`、`detail`；所有文字转义后嵌入SVG。`timing`可选，字段见导出类型：以当前Composition／Sequence起点为零的秒数，安排入场、让位、三项建立、收线、文档退场及要点退场。组件读取运行时fps，生产应用应将真实Timeline锚点转为本地秒数，不复用示例时间当口播时间。

示例Composition ID：`DocumentKeyPointsExample`，1920×1080、30fps、324帧／10.8秒。时长属于示例，不由组件固定；本模板不修改共享Root或注册具体生产视频。

## 视觉不变量与适用边界

- 保留完整文档轮廓和原文定位，完成让位后才建立右侧重点。
- 原文先高亮，对应线建立后结论进入，说明略后补充；同一时刻只强调一项。
- 三项结论共用排版基线，保留阅读时间；收尾分别处理关系、来源和结果。
- 当前逻辑画布1920×1080，固定三项；原文建议不超过16个中文字符、结论不超过8个、说明不超过16个。字符数仅作布局提示，实际字体及混排须观看检查。
- 不支持自动换行、任意项目数或竖屏布局。长文案需改造排版，不自动缩字。颜色和造型在artwork中修改，不提供主题引擎。
- 修改timing时必须保留动作顺序及最后一项阅读空间；退场顺序有少量有意重叠，不能通过挤压时间制造对应线跳动。
- 不适合全文阅读、无原文依据的结论、必须保留所有细节的密集文档或互无对应的三条口号。

## 实际验证范围

10.8秒独立Shot无声交互预览已获用户动态画面认可并明确要求入库。共享画面代码提取后逐帧一致性及定向类型检查记录保存在本地候选资料中。

认可范围是当前示例的构图、展开与分层收尾；未执行Remotion成片渲染、正式视频Gate或跨视频验证。改变文字、时序、字体和画幅后仍需重新观看。
