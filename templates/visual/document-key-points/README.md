# 文档到要点

表达任务：文档先建立来源，再向左让位；对应原文高亮、连线和三项要点分步展开；收尾先收回关系线，再退出文档与结论。连线表示提炼对应，不表示执行因果。

目录：`artwork.ts` 为唯一主体实现，`index.tsx` 提供React／Remotion组件，`example.tsx` 提供已认可内容的无声示例及Composition参数。主体不包含场景标题、字幕或声音；文档名称属于对象身份。

## 使用

```tsx
import {DocumentKeyPointsMotion} from './index';
import {exampleContent} from './example';

<DocumentKeyPointsMotion content={exampleContent}/>
```

输入 `content`：`name`（文档名称）、`description`（简短说明）、`footer`（页脚）、`page`（页码）和`items`（三个原文项及其结论）。每项包含 `label`、`source`、`title`、`detail`；所有文字转义后嵌入SVG。

`timing`可选，以当前Composition／Sequence起点为零的秒数指定各阶段起点：

| 字段 | 当前实现中的作用 |
| --- | --- |
| `enter` | 文档入场 |
| `park` | 文档缩小并向左让位 |
| `items` | 三项依次展开的起点，按原文高亮、连线、结论及说明的内部时序推进 |
| `retract` | 关系线依次收回 |
| `paperExit` | 文档退场 |
| `pointExit` | 要点依次退场 |

省略`timing`时使用`artwork.ts`导出的`defaultTiming`，即示例时序。组件读取运行时fps，但不读取Timeline；生产应用由调用方将真实时间依据转换为本地秒数，关联规则见[分镜关联与时间映射规则](../../../docs/STORYBOARD-PRODUCTION-CONTRACT.md)。

`timing`只控制阶段起点，阶段内部的动画时长及错峰间隔写在`artwork.ts`中。例如每项以自身起点为零：高亮从0秒开始，连线从0.16秒开始并于0.68秒完成，结论从0.48秒进入，说明从0.8秒进入。结论进入与连线绘制有重叠。调整锚点后仍需核对内部动作及阅读空间；需要改变节奏时一并修改对应实现。

示例Composition ID：`DocumentKeyPointsExample`，1920×1080、30fps、324帧／10.8秒。时长属于示例，不由组件固定；本模板不修改共享Root或注册具体生产视频。

## 来源与结论的关系

- 文档来源与原文位置可辨认，每项结论与对应原文相符。
- 高亮、连线与结论的对应关系清楚，不让观众把提炼关系误读为执行因果。

## 当前实现与可调整项

- 当前画面保留文档轮廓，文档缩小向左让位后，在右侧逐项展开要点；三项共用排版基线，收尾依次启动收线、文档退场和要点退场，部分动作有意重叠。
- 当前逻辑画布1920×1080，类型和绘制逻辑固定三项，不支持自动换行。原文建议不超过16个中文字符、结论不超过8个、说明不超过16个，仅作当前布局提示，实际字体及混排须观看检查。
- 内容和阶段起点可通过参数调整；项目数量、构图、字号、颜色、造型及内部动作可在`artwork.ts`中改造。长文案需重新排版，竖屏需重新构图；这些是现有实现的适用条件，不是视频设计的固定限制。
- 修改时序时检查原文定位、连线与结论是否仍能对应，以及最后一项是否有必要的阅读时间。后续收线或退场过早，会打断尚未展开完整的内容。

## 不适用与失败方式

- 当前布局不适合全文阅读或必须保留所有细节的密集文档，需另行设计阅读方式。
- 结论缺少原文依据、三项互无对应关系，或连线指向错误，会使提炼关系失真。
- 长文字溢出、动作挤压导致关系线跳动或结论来不及阅读，需改造布局或时序。

## 实际验证范围

10.8秒独立Shot无声交互预览已获用户动态画面认可并明确要求入库。共享画面代码提取后逐帧一致性及定向类型检查记录保存在本地候选资料中。

认可范围是当前示例的构图、展开与分层收尾；Remotion成片渲染、完整视频观看／试听及用户确认、跨视频复用仍待验证。改变文字、时序、字体和画幅后仍需重新观看。
