# 对齐比较表

## 表达任务

用三列比较对象、三行共同指标展示差异。依靠同行对齐与逐行强调组织阅读，不把某一列暗示为优胜方案。示例内容为中性排版演示，不代表真实产品数据。

## 画面变化

三列错峰建立；三项指标逐行呈现，同时强调同一行的三个值；保留完整总览；列宽收成窄条并错峰上滑，指标标签向左离场。比较期间表格位置固定，收拢与离场连续衔接。

默认示例8秒，1920×1080、30fps、240帧；无章节标题、字幕或声音。

## 使用入口

`AlignedComparisonMotion` 接收 `data` 和可选正数 `timeScale`。

```tsx
<AlignedComparisonMotion data={exampleData} timeScale={1}/>
```

`data.names` 是三列名称，`data.rows` 是三行指标；`data.values` 按列组织，每列包含按指标顺序排列的三个值。三项数组均固定长度，使用短文本。示例组件与数据见 `example.tsx`，Composition ID：`AlignedComparisonExample`。

`timeScale`由调用方传入正的有限数，组件没有自动校验该参数。整体时间按该倍数缩放，完整示例的Composition帧数可采用`Math.round(8 * timeScale * fps)`。正式应用按用户确认的分镜及真实Timeline调整动作与阅读停留，需要分别调整时修改实现。

## 比较关系

- 同一指标使用相同口径，数值与对象、指标对应清楚；颜色和图标不暗示缺少依据的优劣。

## 当前实现与改造边界

- 名称、数值的横向位置与同指标的高度固定；一行的三列同时出现。
- 后一行建立时前一行保留；强调同行差异，不移动整张表格。
- 当前以绿、赭黄、蓝灰区分列身份；配色可按当前风格修改，必要含义由文字表达。
- 图标当前分别表示本地、云端、混合结构。更换比较对象时需要相应改造图标，不能只换名称造成语义冲突。
- 文字应保持完整可读，窄条收尾以裁切列宽完成，不压扁字形。

可改造名称、指标、数值、图标、配色、字号、位置、动作和收尾。实现固定三列、三行及横屏布局，没有任意数量自动排版；长说明、大量指标或竖屏需要重新设计。改变布局和动作后，仍须让同指标的值便于对应和比较。

失败方式：指标口径不同却强行对齐；颜色暗示未经依据的排名；长文案溢出；出现过快导致无法横向阅读；收尾提前打断比较。
