# 双球科技比较

## 表达任务

以实体金属与曲面网络的造型、表面和光照差异建立左右比较；金属球先建立并让位，网络主体随后建立，完整构图保持可读。暖金与青绿外晕、实体背光暗面帮助区分两种视觉身份。

## 使用

```tsx
import {MaterialComparisonMotion} from './index';
// 使用当前 Composition 的 frame 与 fps，按用户确认的分镜和真实 Timeline 改造。
<MaterialComparisonMotion />
```

示例 Composition ID：`MaterialComparisonExample`，1920×1080、30fps、264帧／8.8秒。组件没有外部输入或媒体资源；示例标签「金属表面」「网络结构」为中性对象说明，正式视频应按当前资料替换。示例时长不决定正式视频的时长。

## 当前实现

- 金属球与网络球左右对照，中心高度相同，标签共用基线；大小表达视觉主次，不代表数值或性能比例。
- 金属先完整建立，再完成让位，网络之后建立；标签随所属对象出现，比较阶段稳定。
- 金属浅槽、纹理旋转，光源与暗面位置固定；网络旋转与轨道光点保留曲面前后层关系。
- 外晕分宽柔光、较窄光带与边缘光，置于主体之后，不能覆盖点线、纹理或文字；金属暖金、网络青绿。
- 背光暗面保留实体表面结构。暗面叠层为屏幕空间视觉调校，不声明物理光照模拟。
- 完成态保留完整比较构图和主体细节运动，没有淡出；没有透光对象、章节标题、字幕或声音。

## 可调整项

在`artwork.ts`调整建立与让位时段、位置、大小、标签及网络旋转速度；金属旋转周期由共享的`metal-volume/motion.ts`中的`cycleSeconds`控制，改动会影响同库金属主体及其他调用者，需核对直接影响。在`lighting.ts`调整外晕色彩、半径、宽度和暗面参数，在`scene.ts`调整环境。

左右布局、建立顺序、配色和结束方式均属于当前设计，可按内容改造；同步调整外晕、阴影、标签与前后层关系，保持比较对象及其差异可辨认。正式使用按用户确认的分镜与当前真实Timeline安排时序。

## 实现与适用限制

`index.tsx` 为 React／Remotion 入口，`artwork.ts` 按帧计算，`lighting.ts` 提供光晕与暗面，`scene.ts` 是独立可共享的环境底稿。复用同库 `metal-volume/artwork.ts` 的原始材质绘制及 `network-volume/artwork.ts` 的曲面结构，不读取 `local/` 或具体视频目录。需要 Canvas 2D、WebGL 和 SVG 图像解码，无新依赖。

适合实体与连接结构的视觉比较。不能单靠球体、发光和大小表达能力、性能或真实硬件；内容需要具体操作、精确拓扑、比例数据或其他轮廓时重新设计。不适用于透光材质验证。

失败方式包括：强光晕盖住结构、暗面黑成一片、新对象进入时遮挡比较所需的旧对象、比较位置无意漂移、标签与对象分离，以及用材料差异替代真实内容差异。浏览器不支持WebGL时显式报错，不回退为静态图。

## 实际验证范围

用户认可8.8秒独立无声 Shot 双球版本并要求入库。提取后核对逐帧时序、SVG生成与绘制实现，定向类型检查；这是 Shot 预览认可与源码提取检查，不能代替 GPU 输出逐帧对照。Remotion 成片、正式视频应用与跨视频验证待完成，未渲染MP4。
