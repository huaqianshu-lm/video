# 保留上下文，展开对应细节

## 表达任务

低亮后景保留整体关系，选中一个对象，将它对应的细节展开为较亮前景。来源定位、连接线及相同片段让观众知道细节属于哪个对象。

中性示例用请求、缓存、计算组成链路；缓存节点展开为解释面板，显示已保存片段与当前请求的相同前缀逐项对应，新增部分另行处理。这是概念示意，不表示具体缓存算法或性能。

## 使用入口

- `index.tsx`：`ContextFocusMotion`。
- `example.tsx`：`ContextFocusExample` 和 Composition 元数据；1920×1080、30fps、186帧／６．２秒。
- `artwork.ts`：逐帧状态、SVG与Canvas绘制。
- `scene.ts`：原创中性链路及细节造型。

组件无配置参数，按内容修改来源对象、对应细节、文字、布局和时间锚点；不能只换文字而保留错误的对应关系。

## 视觉不变量

- 来源建立和选择完成后才展开细节；面板从来源位置展开，连接线维持归属。
- 前景出现时后景降低亮度，来源仍可辨认；前景展开完成后保持稳定供阅读。
- 两行片段都建立完成后才逐项对应，相同前缀对应完成后再显示新增内容与结果。
- 青色标出复用部分，斜纹和标签共同标出新增部分；颜色不独自证明优劣。
- 结束保留完整结果，无离场动画；不包含章节标题、字幕或声音。

## 可调整项与失败方式

可按当前内容调整对象数量、细节结构、前后景亮度、连接线、字号和节奏。正式视频按冻结分镜及真实Timeline改造，６．２秒不是生产默认时长。

适合解释整体中的一处概念、节点或局部结构；不适合必须同时阅读全部背景资料、没有明确来源归属，或要求比较多个同等重要对象的内容。

背景过亮会抢焦点，过暗会失去上下文；前景覆盖来源、连接线指错对象、对应片段不一致、移动期间出现大量阅读文字，都会削弱表达。新增部分单独标识不表示已展示其完整计算过程。

## 实际验证范围

原创静态画面及６．２秒独立Shot无声交互预览获用户认可并明确要求入库。提取186帧状态与SVG一致，组件／绘制源码核对及定向严格类型检查通过。

依赖浏览器Canvas 2D及SVG图片解码，无新增依赖或媒体素材。尚未渲染Remotion成片，正式视频应用与跨视频验证待完成；Shot认可不能替代当前视频人工Gate。
