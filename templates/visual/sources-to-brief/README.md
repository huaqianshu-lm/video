# 多源汇聚为简报

表达任务：三份独立输入沿对应路径依次汇入一个结果；对应内容分区生成，旧路径清理，结果居中确认后收起。不是执行流程、资料删除或任务成功演示。

目录结构：`artwork.ts`为按帧求值的主体画面，`index.tsx`提供React／Remotion组件，`example.tsx`提供已认可的中性内容和Composition参数。无章节标题、字幕或声音；结果名称属于对象身份。

## 使用

```tsx
import {SourcesToBriefMotion} from './index';
import {exampleContent} from './example';

<SourcesToBriefMotion content={exampleContent}/>
```

`content`包含`resultName`及固定三项`items`，各项提供`name`和`body`。文字转义后嵌入SVG，输入与结果使用同一文案及对应色签。

可选`timing`以当前Composition／Sequence起点为零的秒数指定阶段起点；省略时采用`artwork.ts`导出的`defaultTiming`，即示例时序。

| 字段 | 作用 |
| --- | --- |
| `inputs` | 三份输入各自入场 |
| `result` | 结果容器建立 |
| `paths` | 三条路径各自建立 |
| `travel` | 三份输入各自汇入 |
| `reveal` | 三个结果区块各自显现 |
| `clear` | 路径错峰清理 |
| `center` | 结果居中 |
| `seal`、`sealExit` | 完成标记出现及消失 |
| `exit` | 结果退场 |

组件读取当前fps，不读取Timeline；调用方负责从真实时间依据换算本地秒数，关联规则见[分镜关联与时间映射规则](../../../docs/STORYBOARD-PRODUCTION-CONTRACT.md)。`timing`控制阶段起点，内部动作时长及错峰间隔位于`artwork.ts`，需要改变节奏时一并核对。

示例Composition ID：`SourcesToBriefExample`。1920×1080、30fps、222帧／7.4秒。时长属于示例，组件不固定生产时长，也不注册共享Root。组件外层按容器大小缩放，保持16:9构图，避免固定SVG尺寸裁切。

## 来源与结果的关系

- 三份输入、三条路径和三个结果区块始终一一对应；来源色签保留到结果。
- 完成标记只表达整合结束；需要比较、分流或保留独立输入时，须相应设计来源与结果关系。

## 当前实现、可调整项与失败条件

- 资料签移动、缩小与正文淡出同时开始；正文先于移动结束淡出，各项抵达时开始显现对应结果区块。
- 当前依次汇入、清理路径、结果居中并收起。末项结果显现与路径清理有短暂重叠；这些是现有时序，可按内容改造。
- 暖纸底、不同纸张形态、细路径与轻接触阴影共同建立层次；颜色及造型可在主体实现中改造。
- 固定三项，逻辑画布1920×1080；标签建议2～4个中文字符，正文建议不超过12个，结果名称建议不超过6个。字符数是布局提示，混排和字体变化仍需观看。
- 不自动换行、缩字或适配任意项目数。密集资料、竖屏或需要保留所有输入的布局须另行设计。
- 调整布局、数量或时间时，同步修改来源、路径与结果区块。检查抵达与结果显现是否对应，以及末项是否有必要的阅读空间，避免路径过早消失或结果过早移动造成含义混乱。

## 实际验证范围

7.4秒独立Shot无声交互预览，修正播放器SVG适配后获用户认可并明确要求入库。认可范围为当前示例的构图、依次汇入、对应结果及居中收尾。

提取前后逐帧一致性和定向类型检查记录保存在本地候选资料中。Remotion成片渲染、完整视频观看／试听及用户确认、跨视频复用仍待验证；改造内容、时序、字体或画幅后仍须重新观看。
