# Video Narrative｜Output Styles

## 叙事目标与命题

同一个 Claude，换 output style 后可以换“节目”：能力和项目知识不变，回应的角色、语气和格式改变。观众需要从一个常见误区出发，最后能自己选择、创建并验证一个样式。

## 观众认知路径

1. 先看到错位：把“改简历”的需求交给默认工程师人格，问题不在项目知识，而在响应方式。
2. 建立边界：output style 改系统提示里的“怎么回应”，CLAUDE.md 管“项目知道什么”。
3. 认识选项：Default、Proactive、Explanatory、Learning 不是四个模型，而是四种工作台风格。
4. 解决操作坑：老的 `/output-style` 路径失效，现在从 `/config` 或 `outputStyle` 切换，且要 `/clear` 才生效。
5. 从使用走向创建：一个 Markdown 文件就能定义自定义样式，存放级别和 frontmatter 决定范围与行为。
6. 做关键取舍：`keep-coding-instructions` 取决于样式下是否仍然编程。
7. 看懂底层：样式会参与系统提示组装，并持续影响本次会话的回应。
8. 防止工具混用：把 output style、CLAUDE.md、临时追加、Subagent、Skill 放到同一张边界图中。
9. 亲手跑通：创建一个“先画图再解释”的样式，用 `/config`、`/clear` 和问题验证它确实改变了回应顺序。
10. 收束与承接：记住“方式归 output style，内容归 CLAUDE.md”，下一篇进入事件触发的 Hooks。

## 整体叙事结构与 Scene 顺序

### Scene 01｜默认工程师，不等于所有角色

用“改简历”与“拆函数、加测试”的错位制造问题，提出为什么 CLAUDE.md 不总能稳定解决回应方式。

### Scene 02｜改的是方式，不是知识

将同一位 Claude 拆成“能力／知识”与“角色／语气／格式”两层，明确 output style 作用在系统提示。

### Scene 03｜四档内置样式怎么选

用四张并列卡片展示 Default、Proactive、Explanatory、Learning 的差异和使用场景，并标出后两档响应更长。

### Scene 04｜切换入口已经变了

把已移除的 `/output-style` 变成旧入口，再把 `/config` 和 `outputStyle` 作为当前两条路径，避免观众照抄旧教程。

### Scene 05｜切完为什么没变化

用会话时间线演示“保存选择 → `/clear`／新会话 → 新系统提示生效”，把读取时机做成可见状态变化。

### Scene 06｜自定义样式就是一个 Markdown 文件

展示 `.md` 文件、frontmatter、正文，以及用户级、项目级、托管策略级三个存放级别。

### Scene 07｜`keep-coding-instructions` 的二分题

用“还在编程／完全不编程”的分支说明 `true` 与省略字段的选择，展示按反后工程指令与角色不匹配的后果。

### Scene 08｜样式如何进入系统提示

展示系统提示组装、内置工程指令的保留或移除、样式说明追加与会话提醒，并提示输入 token 和长响应的成本差异。

### Scene 09｜五种工具，各管一个抽屉

用功能矩阵对比 output style、CLAUDE.md、`--append-system-prompt`、Subagent、Skill，建立“方式／内容／一次性／独立任务／按需工作流”的选择直觉。

### Scene 10｜实操：建文件并选择样式

展示 `diagrams-first.md` 的 frontmatter 和正文，随后在 `/config` 中看到它；命令只作为教程画面，不执行。

### Scene 11｜实操：`/clear` 后验证差异

展示 `/clear`、提问“解释一下用户登录的请求是怎么从前端走到数据库的”，预期为 Mermaid 图先于文字；再显示切回 Default 的对照。

### Scene 12｜换方式，不换知识；下一篇 Hooks

汇总六个核心判断，最后才出现第 33 篇“钩子（Hooks）”预告，作为本片最后一个视觉事件。

## 叙事节奏

- Scene 01—03 先用错位、对照和选择建立概念，节奏由快到稳。
- Scene 04—08 进入设置和机制，使用路径、时间线、文件分层和系统提示组装降低抽象度。
- Scene 09—11 用矩阵和实操闭环验证“边界不是口号”。
- Scene 12 保留足够停留空间，先总结再展示预告，预告避开底部字幕和预览控件区域。
