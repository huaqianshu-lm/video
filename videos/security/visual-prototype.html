Scene 09 · Self Protection

安全自保清单：按信任程度对号入座

日常本机

✓关键操作写进 deny
✓批准前看一眼
✓不把陌生内容直接管道传入

真实敏感数据

✓开启沙箱
✓凭证目录加入 denyRead
✓定期检查权限

陌生代码

✓谨慎信任新仓库 / MCP
✓容器 / VM / 网页版云端
✓本机不裸跑
按场景选择边界，不要把所有代码当成同一种风险
