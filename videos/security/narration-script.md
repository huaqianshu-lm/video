# 安全与风险边界：到底该不该信任 AI 碰你的代码

## Scene 01｜你在信任谁？

用 Claude Code 时，真正要问的不是模型会不会自觉，而是你到底在信任谁。可以把安全想成三层防护：程序强制执行的边界，内置断路器和隔离，还有你自己的审查和克制。尤其要记住，权限规则是 Claude Code 这个程序强制执行的，不是模型自己讲道德。提示和 `CLAUDE.md` 可以影响它想做什么，但不能改变程序允许什么。

## Scene 02｜README 里藏着一封写给 AI 的诈骗邮件

提示注入，就是把陌生人写在内容里的话，伪装成你的命令。比如一个看似正常的 README，可能藏着一段指令，让 Claude 读取 `~/.ssh/id_rsa`，再把内容发到外部地址。README、issue、网页和依赖注释本来只是数据，但攻击者会故意让它们用“老板”的口吻对 AI 说话。模型一旦把数据当成指令，风险就从阅读项目变成了泄露凭证。

## Scene 03｜危险命令会经过几道拦截？

这条危险路径不会毫无阻拦地直通。命令黑名单可能先拦住 `curl`，上下文分析会检查它和你原本的任务是否相关，网络请求默认还需要批准，抓网页的内容会放进隔离的上下文窗口，可疑的命令注入也可能被再次拦下。但这些机制最后都会汇到同一个地方：你批准前的那一眼。只要闭眼点了同意，前面的拦截就失去了意义。

## Scene 04｜deny 挡住明枪，挡不住暗箭

敏感数据泄露还有一个很容易误判的边界。`deny: Read(./.env)` 可以拦住 Claude 的内置 `Read` 工具，却不一定拦得住 Bash 启动的 Python 或 Node 脚本。脚本自己打开文件时，绕过了 Claude 的文件工具，像从后门进屋。也就是说，`deny` 能挡住直接读取，但不能单独保证所有进程都碰不到敏感路径。

## Scene 05｜沙箱不是 deny 的同义词

沙箱解决的是另一层问题。它由操作系统限制 Bash 子进程能够访问的文件和网络，所以命令即使启动了，进程也可能被挡在边界外。这和工具层的 `deny` 不是一回事。不过沙箱也不是万能开关：它主要隔离 Bash，管不到内置文件工具、MCP server 和 Hook，而且默认仍可能读到 SSH 或 AWS 凭证，这些路径要额外放进 `denyRead`。

## Scene 06｜信任越低，隔离越要往外加

安全边界应该跟代码的可信度一起变化。自己写的代码或公司内部项目，可以用权限规则，按需要打开 Bash 沙箱。知名但没有逐行审查的开源项目，至少要用沙箱并封住凭证读取。完全陌生的仓库，最好放进容器、独立虚拟机，或者使用网页版云端。`--dangerously-skip-permissions` 这种全裸奔模式，只有在隔离环境里才有讨论空间，不能在本机或生产机器上直接开启。

## Scene 07｜官方写死的几条底线

Claude Code 还内置了一些断路器。删除根目录或主目录，即使在危险模式下仍然会提示；Linux 和 macOS 上用 root 或 sudo 启动全裸奔模式会被拒绝；`curl` 和 `wget` 默认会被拦截；匹配不到规则的命令默认先问你，这就是故障关闭。`auto` 模式还有后台分类器检查可疑操作。但这些是最后的底线，不是替你判断陌生内容的理由。

## Scene 08｜三分钟验证：绕道读密钥，沙箱能不能挡住？

原文给了一个很直观的练习。先在 `sandbox-demo` 里放一个假 `.env`，只配置 `Read(./.env)` 的 deny。直接让 Claude 读取时，它会被拦住。接着让 Python 子进程打开同一个文件，没开沙箱时，这条路径可能绕过去。再启用沙箱，把 `.env` 加进 `denyRead`，同一个子进程也会在操作系统层被挡住。这样就亲眼验证了：单层 deny 有洞，深度防御要把两层叠起来。

## Scene 09｜安全自保清单：按信任程度对号入座

日常本机开发，把 `git push`、删除操作和敏感文件写进 deny，批准命令前认真看一眼，也不要把陌生内容直接通过管道喂给 Claude。项目里有真实密钥，就开启沙箱，把凭证目录加入 `denyRead`，定期检查权限。碰到陌生仓库或第三方 MCP，不要无脑信任，优先用容器、虚拟机或网页版云端。可选的安全指导插件只能增加一层检查，不能代替完整方案。

## Scene 10｜安全不是开关，而是判断力

所以，这一篇真正要留下的不是某个安全开关，而是一种习惯：默认怀疑来路不明的内容，把每一次批准都当成真实的授权决定，批准前多看一眼。程序边界和隔离机制是安全带与气囊，最后那脚限速仍然要由你自己踩。下一篇是 `22「MCP：连接外部服务」`，我们会继续看 Claude 接上外部世界之后，信任边界会怎样变化。
