# Interface and Shortcuts 视频化 · 第四步：Narration Script

## Scene 01｜先认出你该盯的三块区域

你是不是也有过这种感觉：Claude Code 的窗口看着就一个输入框加几行输出，可真要控制它，却不知道眼睛和手该放哪儿。这一篇不教你怎么提需求，只做一件事：把界面看懂，把几个高频动作练进手里。先记住三块：最底下的输入框，告诉你当前上下文的状态行，以及决定它动手前问不问你的模式和权限提示。

## Scene 02｜高频快捷键是一张动作地图

快捷键不用一上来全背，可以先按动作记。`Esc` 和 `Ctrl+C` 负责控制正在发生的事，`Ctrl+D` 负责结束会话，`Shift+Tab` 负责切换权限模式。上箭头和下箭头翻命令历史，`Ctrl+R` 搜历史，`Ctrl+L` 重绘屏幕，`Ctrl+O` 切换详细转录。把这些键按“动作”而不是按“字母”记，才更容易变成肌肉记忆。

## Scene 03｜Esc、Ctrl+C、Ctrl+D 不要混用

先把最容易混的几个动作拆开。`Esc` 按一下，是踩刹车：Claude 停在当前进度，已经做完的部分保留。输入框为空时，连续按两下 `Esc`，才会打开回退菜单；如果输入框里还有文字，双击 `Esc` 的结果是清空这段文字并存进历史草稿。`Ctrl+C` 是清场，任务在跑时中断，没任务时第一次清输入，第二次才退出。`Ctrl+D` 则是直接退场，一下结束整个会话。

## Scene 04｜Shift+Tab 切换权限模式

再看 `Shift+Tab`。它不是换行，也不是发送，而是在权限模式之间循环。`default` 会在需要动手时询问，`acceptEdits` 会自动接受编辑，`plan` 只出方案不动手。你按下之后，盯着状态行，看模式提示有没有变化，就知道切换是否成功。某些不支持 VT 模式的旧 Windows 终端可能把这个动作设成 `Alt+M`，遇到不灵时记得这是终端差异。

## Scene 05｜四个输入前缀，四条入口

输入框开头的符号，也是在给请求分流。`@` 会触发文件路径补全，比如 `@src/auth.ts`，你是在精准点名一个文件。`!` 进入 Shell 模式，比如 `! git status`，命令直接在终端运行，输出还会回到对话上下文里。`/` 是命令和 Skill 的入口，`#` 和记忆有关，但不同版本的行为可能不同，这两个符号本篇只先认识，不展开。

## Scene 06｜Enter 默认发送，多行要换一种按法

输入长指令时还有一个高频坑：Enter 默认是发送，不是换行。最稳妥的习惯，是先输入反斜杠，再按 Enter，这个方式跨终端都能用。也可以试 `Ctrl+J`，或者在支持的终端里使用 `Shift+Enter`；macOS 还可以配置好 Option 键后用 `Option+Enter`。如果内置终端不支持 `Shift+Enter`，可以运行 `/terminal-setup`。指令长到不适合挤在小输入框里时，按 `Ctrl+G`，直接交给默认文本编辑器写。

## Scene 07｜六步把动作跑一遍

光看快捷键表，明天很容易忘。打开一个有文件的文件夹，启动 `claude`。然后输入 `! echo hello-shortcuts`，确认命令直接执行，输出也进入对话。清空输入框后按上箭头，确认刚才的命令能被调回；连续按几次 `Shift+Tab`，确认状态行里的模式在变化；输入两行文字，用反斜杠加 Enter 换行；最后按 `Ctrl+D`，确认回到普通终端。六步跑完，你练的就不只是按键，而是每个动作对应的结果。

## Scene 08｜先用熟默认，再考虑自定义

这些快捷键不是永远不能改。先用 `claude --version` 确认版本达到 v2.1.18 或更高，再运行 `/keybindings`，它会创建或打开 `~/.claude/keybindings.json`。不过给新手的建议很简单：先把默认配置用熟，明确感觉某个键每天都别扭了，再考虑重绑。`Ctrl+C`、`Ctrl+D` 这类保留快捷键是硬编码的，不能重新绑定。

## Scene 09｜把手放对地方

所以，这一篇的重点不是背一张孤立的快捷键表，而是形成一条判断链：先看输入框、状态行和模式提示，再选停止、回退、切模式或查历史的动作；需要输入内容时，用 `@` 点名文件，用 `!` 顺手跑命令，长内容用可靠的换行方式；最后看状态和输出，确认动作真的生效。等这些动作熟了，你和 Claude Code 的交互就会从鼠标键盘来回切，变成手不离键盘。下一篇，我们继续看怎么提问和给指令。
