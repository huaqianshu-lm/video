# Agent SDK 视频化 · 第五步：Narration Script

## Scene 01｜从用工具的人到造工具的人

前面你一直是在终端里使用 Claude Code：敲一句命令，看它读文件、改代码。但如果你想做一个自动审 PR 的机器人、一个每天晚上扫仓库的定时任务，或者给自己的产品加一个能干活的 AI，光坐在终端前就不够了。Agent SDK，就是把这件事交给你自己的程序。

## Scene 02｜SDK 搬走的是 Claude Code 内核

先给结论：Agent SDK 把 Claude Code 的内核做成了一个库。这里的内核，不只是模型回答你一句话，而是包括 Read、Write、Edit、Bash 这些内置工具，想、做、看循环的代理编排，以及它对上下文的管理。也就是说，你写几行代码，就能在自己的程序里调起一个和 CLI 同款的 Claude 代理。

## Scene 03｜同一个内核，两个入口

那它和 CLI 到底是什么关系？可以把它理解成同一个内核、两个入口。你人在终端前，边看边调，用的是 CLI；程序自动触发、批量运行、没人值守，用的是 Agent SDK。内核没换，提示词、工具和权限的思路也能迁移，变化的只是由谁按下启动按钮。

## Scene 04｜差别不在模型，在工具循环

Agent SDK 最容易和原始 API 混淆。Client SDK 给你的是模型响应，模型说想读哪个文件，工具怎么执行、结果怎么传回去，都要你自己写一个 while 循环。Agent SDK 则把这整段工具循环收进了 query。你只需要给任务，代理自己读、自己改、自己继续看结果。区别不在模型会不会说，而在谁负责把事情做完。

## Scene 05｜按项目语言选择入口

两套 Agent SDK 的功能是对齐的，按你项目本来使用的语言来选就行。TypeScript 安装的是 @anthropic-ai/claude-agent-sdk，需要 Node.js 18 以上；Python 安装 claude-agent-sdk，需要 Python 3.10 以上。无论选哪套，运行前都要准备 ANTHROPIC_API_KEY。安装包是入口，密钥才是让代理真正调用模型的凭证。

## Scene 06｜query() 是代理入口

最小入口就是 query。prompt 告诉代理要做什么，options 告诉它怎么做，最关键的 allowed_tools 决定它被允许使用哪些工具。query 返回的是消息流，所以 Python 用 async for，TypeScript 用 for await，边接收边看到它的思考、工具调用和最终结果。原始 API 里的那套编排，被这个入口藏在了后面。

## Scene 07｜权限决定代理能做什么

工具列表其实就是代理的工牌。只给 Read、Glob 和 Grep，它只能做只读分析；加上 Edit，它才有修改代码的能力；再加上 Bash，才可以运行命令。先按任务给最小权限，比一上来把所有工具都打开更容易判断代理到底能做什么。

## Scene 08｜先造一个会崩的 utils.py

现在用一个很小的例子把它跑起来。先建一个 my-agent 目录，安装 SDK，再准备一个 utils.py。这个文件里故意放两个边界问题：空列表求平均会除零，传入空用户时取姓名会报错。问题先摆在这里，代理才有明确的任务可以完成。

## Scene 09｜让代理读、改、再回报

接着写 agent.py。让 query 收到一句「检查 utils.py 里会导致崩溃的 bug，并修复它」，再给它 Read、Edit、Glob 三个工具，并用 acceptEdits 自动批准编辑。你不需要自己实现读取文件和提交修改的胶水代码，代理会把任务变成一串工具消息。

## Scene 10｜成功要落在文件里

运行 python agent.py 后，终端会流式显示它的工作过程：先读文件，再编辑文件，最后出现 Done: success。但到这里还不能只看一行成功提示。重新打开 utils.py，确认空列表和空用户的防御性处理真的写进文件。消息证明流程结束，文件变化才证明结果落地。

## Scene 11｜什么时候该用 SDK

所以，你不需要为了跟上潮流马上学 SDK。如果你只想在终端里让 Claude 写代码、改 bug、跑命令，CLI 就够了。只有当你想把重复流程自动化，做一个机器人、定时任务，或者把能操作项目文件的 AI 嵌进产品，SDK 才真正进入主场。先在本地用 SDK 做原型，等需要托管基础设施和会话，再考虑 Managed Agents。

## Scene 12｜把能力变成你能调用的零件

把全篇压缩成六句话：Agent SDK 搬来的是 Claude Code 的工具、代理循环和上下文管理；CLI 和 SDK 是同内核的两个入口；原始 API 的工具循环要自己写，query 会替你编排；prompt 决定任务，allowed_tools 决定权限；成功要看消息，也要看文件结果；是否上手取决于你有没有自动化或嵌产品的需求。下一篇「开发配置」，我们再处理 API 密钥、开发与生产环境，以及第三方模型供应商的配置。
