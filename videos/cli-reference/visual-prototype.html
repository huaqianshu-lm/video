Scene 03 · Sessions

最近还是指定：会话入口怎么选

-c · --continue
当前目录最近的对话
-r · --resume
按 ID 或名字恢复特定会话
--name login-refactor
让恢复列表不再只剩 UUID
维护与账户
claude updateclaude install stableclaude auth loginclaude auth status
-c 认最近，-r 点名恢复；update、install、auth 属于维护命令

Scene 06 · Control Surface

模型、权限、目录：给一次调用加边界

--model sonnet这一趟临时切换模型
--permission-mode plan启动时决定权限模式
--add-dir ../lib增加文件访问目录，不继承配置
--allowedTools Bash,Read,Edit预先放行需要的工具
--max-turns 3 · --max-budget-usd 5.00给无人值守脚本加保险丝
--dangerously-skip-permissions
隔离环境 · 慎用
参数越具体，脚本边界越清楚；危险开关不应成为真实项目默认路径
Scene 07 · Structured Output

从一大坨 JSON 取出真正要的字段

$ claude -p …
--output-format json
{
  "result": "…",
  "session_id": "…",
  "total_cost_usd": …
}
jq -r '.result' → 干净文本
session_id → --resume
total_cost_usd → 成本
JSON 让脚本拿到结果、会话 ID 和成本；jq 负责取字段

Scene 09 · Exit Codes

0 继续，非 0 停下处理

$ claude auth status
Logged in$ echo $?
0
$ claude auth status
Not logged in$ echo $?
1
0 → continue
／
1 → || → 未登录，终止
退出码是给脚本看的成绩单：0 表示成功，非 0 表示问题
Scene 10 · Reference Table

不用背：按用途查 CLI 标志

查，不背
分类代表标志用途
启动与会话-p · -c · -r · --name进入、继续、恢复
模型与权限--model · --permission-mode控制这一趟运行
目录与配置--add-dir · --settings · --bare决定加载边界
headless 输出与控制--output-format · --max-turns · --max-budget-usd脚本保险丝
杂项--version · --ide · --debug查版本、连接、排查
--help 不会列出每个标志；完整能力要回到 CLI 参考文档
Scene 11 · Practice Loop

四步跑通 headless

1claude -p "…"result → exit
2cat buggy.py | claude -pinput received
3--output-format json | jq -r '.result'clean text
4claude auth status · echo $?0 / 1
单次调用→管道输入→JSON + jq→退出码判断
四步串起来，就是把 Claude 塞进脚本和 CI 的自动化地基
