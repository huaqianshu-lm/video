# Claude Code 订阅套餐与计费视频化 · 第二步：Video Narrative

> 目标：让观众从“账单为什么变贵”走到“我知道怎么选、怎么验、怎么省”，最后承接下一集第一次实操。

## 1. 视频叙事目标

这条视频不是把套餐价格念一遍，而是完成一次成本认知变化：

```text
Claude Code 很贵
        ↓
先看清楚钱到底花在哪
        ↓
再根据自己的情况选付费路径
        ↓
买了套餐也要确认请求真的走对
        ↓
用命令和习惯控制上下文成本
        ↓
准备进入下一集的真实使用
```

核心问题是：

> **你不是在买一个“便宜套餐”，而是在选择一条可观察、可控制的模型使用路径。**

## 2. 观众状态变化

| 阶段 | 观众原本的疑问 | 视频给出的答案 |
|------|----------------|----------------|
| 开场 | “为什么一个工具能烧这么多钱？” | 工具免费，模型处理量按 token 产生成本 |
| 机制 | “问几次是不是就决定价格？” | 上下文、输入、输出和思考量更关键 |
| 选择 | “哪个套餐最划算？” | 按量、订阅、Coding Plan 是不同取舍 |
| 配置 | “买了 Coding Plan 就安全了吗？” | Base URL 和 Key 错了，可能走按量计费 |
| 验收 | “能启动是不是就成功？” | `/status`、额度和 Console 需要分别核对 |
| 优化 | “怎样让同样的任务少花钱？” | `/clear`、Sonnet、plan mode 和具体提示 |
| 行动 | “我现在该怎么开始？” | `/status → 小任务 → /usage → 上限` |
| 收束 | “下一步学什么？” | 下一集跑通第一个真实例子 |

## 4. 各段叙事设计

### 01 开场：账单为什么会失控

从“每天十几美元、月底几百美元”的官方文档数字和个人账单经历切入，但不把它说成所有人的必然成本。先让观众产生“我到底在为什么付钱”的疑问。

### 02 机制：token 是模型的计价单位

用出租车与里程建立直觉，再把输入、输出和上下文映射到真实请求。关键转折是：不是问了几个问题，而是每次塞进去多少内容、让模型输出多少。

### 03 选择：三条付费路径没有统一答案

先给三列对比，再根据“官方原生、固定支出、国内成本和网络”几个条件把选择权交还给观众。价格只作为变化中的参考，不在画面写死金额。

### 04 陷阱：买了套餐却没走套餐

把 Base URL 的 `coding` 与 `v3` 做成一条分流。观众先看到错误请求流向按量计费，再看到正确路径消耗套餐额度；最后补充 Key 也要使用套餐专属版本。

### 05 检查：三个命令各自负责什么

不要将命令做成孤立列表，而是演示一次“看明细、设上限、核配置”的职责分工。特别区分本地估算、官方计划限制和配置状态。

### 06 优化：真正省钱的是少带无效上下文

用同一个任务对比四个坏习惯和四个好习惯。视觉重点是上下文堆积被清除、模型档位被切换、错误返工被提前阻断、搜索范围被缩小。

### 07 行动：五分钟跑一遍最小闭环

把前面的知识收束为可执行检查：启动、`/status`、做小任务、`/usage`、官方计划设置上限。画面像终端操作清单逐项打勾，口播提醒 Coding Plan 用户以厂商控制台为准。

### 08 总结与下集预告

先收束三条结论：看懂计费、核对路径、控制上下文。随后把总结卡片退到背景，切换成独立的“下一集”卡片，明确预告下一篇 07「第一次使用：跑通第一个例子」，并给出“正式启动 Claude Code，跑通第一个真实项目”的期待。

## 5. 叙事节奏

- 前 30 秒快速建立“账单不透明”的问题，不立即讲价格表。
- 中段用三次结构性变化推进：计费单位、付费路径、错误分流。
- 后段从理解转向操作，命令和习惯必须给出可以照做的动作。
- 最后保留总结后的停留，再进入下集预告；预告不能和总结字幕抢同一位置。

## 6. 事实和时效边界

- 套餐价格、促销、额度和命令行为均以当前官方页面或厂商控制台为准。
- 画面中的厂商 URL 和 Key 前缀必须作为示例，并显示“以当前官方文档为准”的提醒。
- 不把源文档中的个人账单经历包装成普遍结果。

## 7. Gate 1 内部结论

- 叙事顺序遵循“问题 → 机制 → 选择 → 风险 → 检查 → 优化 → 行动 → 承接”。
- 每段只有一个主要认知任务，后续可映射到既有六类通用场景。
- 文章中的所有核心结论都有叙事位置，价格和厂商细节被限制在可更新的示例范围。
- 结尾预告已经成为叙事结构的一部分，并明确作为最后视觉事件实现。
