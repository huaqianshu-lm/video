# Claude Code「第一次使用」视频化 · 第一步：Content Analysis

> 来源：`source.md`，原始文档 `07-first-run.md` 的项目内副本。
>
> 本阶段目标：提取第一次使用 Claude Code 时真正需要完成的认知和动作，不把原文的重复总结、平台差异和教程说明全部搬进视频。

## 1. 核心命题

第一次使用 Claude Code，不需要先学会复杂命令；在一个可随时重建的玩具项目里，完成「进入项目目录 → 启动 → 先解释 → 再修改 → 看 diff 并批准 → 必要时回溯」这条最小闭环，就能获得安全的第一次成功体验。

视频最终要让观众记住：Claude Code 的第一次正确用法不是“把一个大项目交给 AI”，而是“给它一个小而明确的任务，同时保留人的确认权”。

## 2. 必须保留的信息

### A. 先用玩具项目降低风险

- 正式项目文件多、依赖杂，不适合第一次练习。
- `hello-claude` 是可重建的练习场，包含一个简单的 `main.py`。
- `mkdir` 和 `cd` 的作用要用画面直接展示，不需要展开命令行基础课。

### B. 工作区边界由启动目录决定

- 必须在 `hello-claude` 目录中运行 `claude`。
- 当前目录就是 Claude Code 读取项目文件的工作区。
- “把师傅领进要装修的房子”是原文的解释类比，可转译为画面中的目录边界，不必完整朗读。

### C. 第一次交互先读后改

- 用「解释 `main.py`」确认 Claude 读到了真实文件。
- 解释型任务是只读、低风险的试水步骤。
- 预期理解结果：`add(a, b)` 接收两个参数并返回相加结果。

### D. 修改必须经过 diff 和批准

- 让 Claude 给函数增加类型注解和基本错误处理。
- 画面必须展示旧行／新行的 diff，而不是直接展示“改完了”。
- 人看到 diff 后批准，改动才落盘；第一次不建议直接开启全部接受。
- 这是本片最重要的安全护栏，也是从“会聊天”进入“人机协作”的关键事件。

### E. 改错有回溯路径，但不等于 Git

- 可以直接说「改回去」。
- 可以使用 `/rewind`，或在输入框为空时连按两次 Esc 打开回溯菜单。
- Checkpoint 是本地撤销，Git 才是永久历史；本片只需建立边界，不展开 Git 教程。

### F. 最后把动作串成五分钟流程

- 建目录和文件。
- 在目录中启动 Claude。
- 解释代码。
- 请求修改并批准 diff。
- 退出后用 `cat main.py` 或 Windows 的 `type main.py` 检查结果。
- 最后一幕要留下“完成一次闭环”的成功感，并预告下一篇 VS Code 集成。

## 3. 认知关系

```text
害怕敲错
  ↓ 降低损失
玩具项目
  ↓ 确定上下文
项目目录启动
  ↓ 先做零风险确认
解释 main.py
  ↓ 进入真实协作
提出修改请求
  ↓ 保留人的判断权
查看 diff → 批准
  ↓ 出错仍可恢复
改回去 / /rewind
  ↓ 完成最小成功闭环
读回文件并确认结果
```

## 4. 可视觉化内容

- 终端路径从上级目录切换到 `hello-claude`。
- 文件树只有 `main.py`，突出小项目的可控边界。
- Claude 欢迎屏幕保留输入框、`/help`、`/resume` 三个新手识别点。
- 解释型请求只读文件并返回自然语言说明，文件保持不变。
- 修改型请求展示 `-`／`+` diff，随后出现批准选择。
- 批准后文件状态从“待修改”变成“已更新”。
- 回溯画面展示 `/rewind` 和 Checkpoint，并在旁边标注“本地撤销 ≠ Git 历史”。
- 五步流程作为收束路线图，下一集卡片为「08 · VS Code 集成」。

## 5. 可以弱化或删除的信息

- Mac、Linux、Windows 的完整建文件差异：保留“Windows 可用记事本”这一事实提示即可，视频不展示两套完整命令。
- 官方文档、安装登录前置篇章和 `EACCES` 权限报错：可用一条小字提示带过，不让它打断主线。
- `--dangerously-skip-permissions` 的命令名不作为画面主文案，避免把注意力引向本片未讲的权限模式。
- 原文多次“一句话总结”：视频只保留场景之间的自然转场和最后闭环总结。
- 详细表格不全部照搬，改为过程化 UI；表格中的“解释型／修改型／生成型”可在 Scene 05 作为辅助标签出现。

## 6. 事实边界与文字归属

- 本片所有命令、路径、文件名、提示语和状态文字均来自 `source.md` 或本分析：`mkdir hello-claude`、`cd hello-claude`、`claude`、`/help`、`/resume`、`/rewind`、`main.py`、`add`、`TypeError`、`VS Code 集成`。
- 不把 `claude-code-what-is` 的“Bug／ChatGPT／Copilot／Cursor”业务语义带入本片；本片只展示第一次使用的玩具项目。
- 不在画面中新增无法由当前 Source 支持的产品状态、版本号、成功指标或权限承诺。
- “成功”指本地教程闭环完成，不能扩写成代码质量或生产安全保证。
