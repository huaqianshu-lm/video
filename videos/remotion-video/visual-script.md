# Remotion 视频化 · 第五步：Visual Script

## 全局视觉原则

### 1. 画面不能只是重复口播

口播负责解释“为什么”和“适不适合”，画面负责展示帧如何变化、流程如何运行、工具边界如何分叉。

### 2. 统一使用“时间轴、画布、代码工作台”视觉语言

全片使用深色代码工作台、细线时间轴、蓝紫色主强调和绿色完成状态。翻页、连线、扫描、回环和状态替换都服务于理解，不引入与文章无关的产品 UI。

### 3. 一个 Scene 只表达一个视觉中心

每幕只保留一个主要动作：批量生成、帧变化、工具比较、代码流转、时间计算、动画对照、流程回环、反馈变化、终端状态、选择分叉、风险检查或总结收束。

### 4. 先展示变化，再显示术语

先让模板复制、翻页、元素移动或流程回环发生，再显示 `frame`、`interpolate()`、`spring()` 等词，避免把画面做成静态术语卡。

### 5. 命令只作文章示例展示

Scene 09 的终端顶部明确标记“文章中的示例命令 · 本次不执行”。原型没有网络请求、命令执行或外部依赖。

### 6. 原型交互只服务预览

上一幕、下一幕、自动播放、进度条和幕内字幕只用于静态原型浏览，不代表最终 MP4 的 Composition 内容。

## Scene 01｜视频也可以写

### 视觉目标

把“批量个性化视频”从一个抽象例子变成可见的数量变化。

### 主要画面

左侧是一张固定的 `年度总结模板`，右侧依次出现三张数据不同的输出卡：`播放时长`、`最常听的歌`、`排名`。输出卡从 1 张扩展为多个，模板外框保持不变。

### 动画

1. 模板卡出现。
2. 三组数据依次填入。
3. 输出卡复制成多个版本。
4. 模板和数据分离，数据标签轻微移动，突出可替换参数。

### 屏幕文字

```text
同一模板
不同数据
几千条视频
```

### Visual Type

`Process + Data Visualization`

## Scene 02｜一帧一帧的翻页书

### 视觉目标

用连续帧把 Remotion 的核心模型讲清楚。

### 画面结构

中央是一条横向时间轴，上方悬浮三张画面页：`第 0 帧`、`第 30 帧`、`第 60 帧`。同一个 `HELLO` 元素从左侧屏外移动到中央并略微放大。

### 动画

1. 三张静止画面页依次翻过。
2. 时间轴指针从 0 移到 30 再到 60。
3. 三张页连接成一条连续路径。
4. 下方出现 `React 画面`，指向每一页。

### 屏幕文字

```text
第 0 帧
第 30 帧
第 60 帧
React 画面
```

### Visual Type

`Concept Diagram + Motion Study`

## Scene 03｜剪辑、模板、代码三条路

### 视觉目标

让观众看到三类工具的工作方式和边界，而不是把 Remotion 包装成万能方案。

### 画面结构

三列轨道从左至右分别标记 `剪辑软件`、`在线模板`、`Remotion`。每列下方显示输入、动作和结果：实拍素材／拖素材／自由剪辑；现成模板／填内容／快速出片；参数／写代码／精确·批量·可复用。

### 动画

1. 三条轨道同时亮起。
2. 输入沿各自轨道移动到结果。
3. Remotion 轨道最后放大 `精确 · 批量 · 可复用`。
4. 实拍和一次性创意标签停在剪辑软件侧，不被 Remotion 吸走。

### 屏幕文字

```text
剪辑软件
在线模板
Remotion
精确 · 批量 · 可复用
```

### Visual Type

`Comparison`

## Scene 04｜框架提供可能，Claude 负责动手

2. Claude Code 生成短代码片段。
3. 代码流向 Remotion，再变成预览画面。
4. 预览结果回到人的判断节点。

`Connection Diagram + Task Routing`

## Scene 05｜帧与时间

### 视觉目标

建立“秒数、fps、总帧数”的换算直觉。

### 画面结构

上方是 `6 秒` 和 `30fps` 两个输入，下方是从 0 到 180 的时间轴。指针每移动 30 帧，旁边显示 1 秒刻度；`useCurrentFrame()` 作为读取指针的标签。

### 动画

1. `6 秒` 和 `30fps` 汇入公式。
2. 公式计算结果显示为 `180 帧`。
3. 指针沿时间轴移动，刻度逐个亮起。
4. `useCurrentFrame()` 读取当前指针位置。

### 屏幕文字

```text
总帧数 = 秒数 × fps
6 秒 × 30fps = 180 帧
useCurrentFrame()
```

### Visual Type

`Timeline Diagram`

## Scene 06｜插值与弹性

### 视觉目标

让两个动画函数通过运动差异被理解。

### 画面结构

左右两个小画布：左侧的圆点从 `A` 移到 `B` 并伴随透明度变化，右侧的 Logo 从小尺寸弹到正常尺寸。函数名贴近对应运动，而不是占据标题区。

### 动画

1. 左侧 A 点和 B 点出现，圆点平滑移动。
2. `interpolate()` 沿路径显示。
3. 右侧 Logo 快速进入、轻微超过目标、再回到目标。
4. `spring()` 在回弹停止后亮起。

### 屏幕文字

```text
interpolate()
A → B
spring()
弹一下，稳住
```

### Visual Type

`Motion Study + Code Annotation`

### 屏幕文字

## Scene 08｜预览才是调试现场

### 视觉目标

用前后状态变化展示自然语言反馈如何改变视频细节。

### 画面结构

左侧是预览窗口，中央是两条反馈气泡，右侧是一个简化代码参数区。初始状态文字快速飞入、绿色光晕过强；修改后文字慢一些、光晕减弱。

### 动画

1. 初始状态快速出现并用偏亮光晕标记。
2. 气泡依次显示“这个字飞太快了”“发光弱一点”。
3. 代码参数从短区间变成长区间，光晕值降低。
4. 预览重放修改后的状态。

### 屏幕文字

```text
这个字飞太快了
发光弱一点
预览 → 反馈 → 再预览
```

### Visual Type

`UI Simulation + State Change`

## 全片视觉类型／组件／动画标准

### 视觉类型

- `Process + Data Visualization`：批量输出和数据替换。
- `Concept Diagram`：翻页书、帧、工具职责。
- `Comparison`：三类视频工具和适用边界。
- `Connection Diagram`：需求、Claude Code、Remotion、预览、人。
- `Timeline Diagram`：fps、总帧数和时间。
- `Motion Study`：插值与弹性。
- `Process Diagram`：从空目录到渲染的工作流。
- `UI Simulation`：预览和自然语言反馈。
- `Terminal Simulation`：文章示例命令和预期状态。
- `Decision Diagram`：参数化模板与一次性艺术品。
- `Checklist`：成本与避坑。
- `SummaryScene`：最终判断收束。

### 原型组件

- `Stage`：固定 16:9 横屏画布。
- `Scene`：单幕容器和过渡。
- `Window`：IDE、预览和终端窗口外壳。
- `Timeline`：帧、秒数和流程进度。
- `Node`／`Arrow`：关系与流程节点。
- `CodeLine`：最小代码词和参数变化。
- `Status`：安装、预览、完成和警示状态。
- `Caption`：幕内短提示字幕。
- `Progress`：原型导航进度，不进入正式视频。

### 动画标准

- 信息动画优先：复制模板、翻页、时间轴移动、连线、状态替换、回环和分叉。
- 注意力动画适量：高亮当前节点、放大最终判断、减弱非当前路径。
- 装饰动画从简：只保留轻微光晕和细线流动，不使用粒子、复杂 3D 或无意义旋转。
- 所有延迟状态在正式实现时必须保证帧数不为负；本 HTML 原型只用 CSS 动画，不调用 `spring()`。
- 横屏主标题控制在 1～2 行；终端和字幕保留安全区，避免贴边和溢出。

## Gate 2 内部审查

- 12 个 Scene 已在 Scene Script、Narration Script、Visual Script 和 Prototype 中一一对应，顺序一致。
- `narration-script.md` 的 Scene 正文只有实际口播，没有视觉说明、制作备注、Gate 清单或命令执行指令。
- Visual Script 对每幕均定义了画面结构、动画顺序、屏幕文字和视觉类型；声音解释与画面演示互补。
- 原型中的标题、标签、状态、命令和卡片文案均可追溯到 `source.md` 或本资料对文章的结构化压缩；未复用其他视频的业务语义。
- Scene 09 的所有命令只在终端模拟器中展示，顶部明确本次不执行；未产生 TTS、音频、字幕、Timeline 或 Remotion 代码。
- 原型采用 16:9 横屏、深色教程风格、少量 CSS 动画和预览控件，未进入正式 Remotion 实现。
