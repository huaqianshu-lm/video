# Claude Code 综合实战视频化 · 第二步：Video Narrative

## 1. 视频叙事目标

这条视频不是复述文章章节，也不是展示一堆 Claude Code 功能。它要让观众理解：

> 真正的毕业设计，不是再学一个新功能，而是把已经学过的零件，按正确的时机组织成一条可跨会话、可验证、可恢复、可交付的工程流。

主认知变化：

~~~text
“我会用这些功能”
↓
“真实项目会让这些功能互相接力”
↓
“流程的价值在于把复杂工作拆开、验证、恢复并交付”
~~~

## 2. 叙事主线

1. 从孤立技巧到完整合奏：前 47 篇像一件件乐器，综合实战要看谁在什么时候进场。
2. 从直线到回路：中等项目会跨会话，验证后回到规划，不靠一个会话硬撑。
3. 从规矩到协作：CLAUDE.md、权限基线和 SPEC 先搭地基。
4. 从本地到外部：MCP 带来项目外上下文，但信任边界不能省。
5. 从单人到分工：subagent 负责隔离探索，新鲜上下文负责挑刺。
6. 从失败到恢复：检查点和 git 把改崩后的止损路径显性化。
7. 从「改好了」到交付：测试、真实功能、diff、review、commit，最后由人把守 push。
8. 从玩具到真实项目：真实项目不是多写几行代码，而是每个关键环节都留下可检查的状态。

## 3. Scene 结构

### Scene 01｜毕业设计不是新功能

用「零件合奏」开场：观众已经学过许多能力，但真正难的是让它们在同一个项目里按顺序协作。画面先呈现散落零件，再收拢为一支乐队和一条项目线。

### Scene 02｜中等项目是一条带回路的工程流

展示六个环节：立项 → 规划 → 接外部 → 分活 → 容错 → 交付，并让回路从验证返回规划。用一句话说明规模变大后，流程本身成为能力。

### Scene 03｜立项：先把规矩和退路立起来

把 todo-cli 的项目骨架、CLAUDE.md、权限基线、git 原点放在同一张工作台上，但视觉中心只放在「先定规矩、先留退路」。

### Scene 04｜规划：SPEC 让大活儿可以跨会话

从模糊需求进入采访和 SPEC，再切成会话 1 到会话 4。突出 SPEC 是文件化交接锚点，而不是依赖口头记忆。

### Scene 05｜接外部：MCP 把够不着的资料接进来

先展示复制粘贴的断点，再把文档、数据库、GitHub 接入项目。用信任检查和只读标记，表达「连接能力」和「安全边界」同时存在。

### Scene 06｜分活：隔离探索，保留主上下文

展示主会话派 subagent 去找 todos.json 的读写位置，只返回文件／函数摘要；随后新鲜上下文审查 diff。观众看到的是上下文分工，而不是更多角色名词。

### Scene 07｜容错：改崩时先干净退回

将「烂摊子上继续补丁」与「/rewind 或回稳定 commit」对比。轻档和重档只作为恢复选择，不展开操作教学。

### Scene 08｜真实项目：从计划到动手

把前半段能力压缩成一次真实操作：在 plan mode 里明确 todo-cli 的 add/list、数据文件和测试，再批准开始。画面承担「先规划后修改」的证明。

### Scene 09｜真实项目：验证和挑刺

展示 unittest 的 OK、真实 add/list 输出和 /code-review 的新鲜审查。核心转折是「Claude 说改好了」不是验收，跑出来、审出来才算证据。

### Scene 10｜交付：看范围、写 commit、守住 push

让改动从工作区进入 diff，再进入中文 commit；在 push 前停住，由人保留最后的远程发布判断。

### Scene 11｜玩具打法与真实打法的分水岭

将七个维度压缩成过程型对照：规矩、规划、会话、外部、质量、容错、交付。不是展示表格全文，而是让「省掉一步，后面加倍返工」的关系可见。

### Scene 12｜合奏完成，下一集预告

回收六棒与回路，给出「流程让你敢把活儿交得更大」的结论。最后预告下一篇「最佳实践」，作为系列的最后视觉事件。

## 4. 节奏和情绪

- Scene 01—02：建立问题与全景，节奏明快。
- Scene 03—06：逐步加深，画面从单个工作台扩展到协作网络。
- Scene 07：降低速度，给恢复机制一个清楚的停顿。
- Scene 08—10：重新加速，用真实输出和交付状态推进。
- Scene 11—12：压缩、总结、停留，最后预告卡片留出约 2～3 秒可读时间。

## 5. 叙事边界

- 文章中的 todo-cli 是示例项目，视频不声称本次真实执行过它。
- MCP、subagent 和命令只作为文章中的流程示例呈现。
- 不读取或引用下一篇「最佳实践」的正文。
