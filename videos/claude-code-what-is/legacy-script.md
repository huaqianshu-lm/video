## Goal

用一条入门短视频讲清楚 Claude Code 是什么、可以做什么、在什么情况下适合使用，以及它和 ChatGPT、Copilot、Cursor 这类工具的核心区别。

## Core Message

Claude Code 不是会写代码的聊天框，而是能进入项目、理解代码、修改文件、运行命令，并参与真实工程任务的 AI 编程搭档。

## Audience

这条视频给刚接触 Claude Code 的用户看，尤其是：

- 听过 Claude Code，但不知道它到底是什么的人。
- 用过 ChatGPT、Cursor 或 Copilot，但分不清它们和 Claude Code 区别的人。
- 想用 AI 辅助开发，但还不知道什么时候该用 Claude Code 的人。

## Outline

1. 开场困惑：很多人听过 Claude Code，但不知道它和 ChatGPT、Copilot、Cursor 差在哪。
2. 一句话定义：Claude Code 是能读项目、改文件、跑命令的 AI 编程搭档。
3. 运行形态：它核心是终端工具，但也有编辑器插件、桌面 App、网页和手机形态。
4. 它能做什么：理解项目、跨文件改代码、修 bug、补测试、写文档、跑验证。
5. 它不能做什么：不能替你拍板、不能保证 100% 正确、不能猜业务逻辑，必须人来把关。
6. 和其他工具的区别：ChatGPT 是顾问，Copilot 是智能输入法，Claude Code 是能动手的搭档。
7. 什么时候该用它：真实项目、多文件修改、修 bug、重构、补测试、持续迭代时更适合用。
8. 总结收束：人定方向，AI 负责执行和重复劳动；Claude Code 是协作工具，不是甩手掌柜。

## Voiceover Script

你是不是也经常听到别人说，Claude Code 很强？

有人说它能一句话重构项目，有人说它能自己修 bug、跑测试、改文档。

但如果你刚接触它，最容易冒出来的问题其实是：

**Claude Code 到底是什么？**

它和 ChatGPT 有什么区别？

和 Copilot、Cursor 这种 AI 编程工具又有什么区别？

它是不是只是一个会写代码的聊天框？

先给结论。

**Claude Code 是 Anthropic 官方推出的 AI 编程助手。**

更准确一点说，它是一个可以进入你真实代码项目里，帮你读代码、改文件、跑命令、做验证的 AI 编程搭档。

这和普通 AI 聊天最大的区别在于：

普通聊天工具更像一个顾问。

你要把代码复制给它，把报错粘贴给它，它给你建议，然后你再回到编辑器里自己修改。

但 Claude Code 更像一个坐在你旁边的搭档。

你可以直接告诉它：

「帮我看一下这个报错的根因，然后修掉。」

它会自己去读项目里的相关文件，分析问题，修改代码，必要时再运行检查命令，看结果对不对。

所以它不是只给你一段代码建议，而是可以参与完整的工程过程。

那它能做什么？

比如，帮你理解一个陌生项目；

帮你解释某个函数为什么这么写；

帮你跨文件修改代码；

帮你修 bug；

帮你补测试；

帮你清理 lint 报错；

也可以帮你写 README、release notes，甚至处理一些重复性的工程杂活。

一句话，它适合处理真实项目里的连续任务。

但是，这里有个边界一定要说清楚。

Claude Code 不是甩手掌柜。

它不能替你拍板技术决策，不能保证代码百分之百没有 bug，也不能猜中你没有说清楚的业务逻辑。

它给你的，是高质量候选方案，不是绝对正确答案。

所以正确的使用方式是：

**人负责方向、判断和验收，AI 负责分析、执行和重复劳动。**

最后，再用一个类比帮你彻底区分。

ChatGPT 更像顾问。

你问它，它给你建议。

Copilot 更像智能输入法。

你写代码时，它帮你补下一句。

而 Claude Code 更像能动手的搭档。

你说清楚目标，它可以自己读项目、改文件、跑命令，最后把结果交给你验收。

所以，如果你只是问一个概念，用普通聊天工具就够了。

但如果你面对的是一个真实代码项目，需要理解上下文、修改多个文件、跑检查、持续迭代，那 Claude Code 就更适合。

你只需要记住一句话：

**Claude Code 不是会写代码的聊天框，而是能进入项目一起干活的 AI 编程搭档。**

下一条，我们再正式看怎么安装和启动它。
