# Claude Code 桌面 app 视频化 · 第二步：Video Narrative

> 目标：不机械复述文章章节，而是让观众从“桌面 app 是简化版”走到“它适合并行和审阅，是同一引擎的另一种工作方式”。

## 1. 视频叙事目标

观众的认知变化：

```text
桌面 app 只是聊天客户端套壳
↓
真正的痛点是多个任务共用一个工作目录
↓
Desktop 用 worktree 把并行会话隔开
↓
集成终端、文件和 diff 又把审阅放回同一窗口
↓
它和 CLI、IDE 扩展共享同一底层能力，但主场不同
↓
按任务选择入口，而不是争论哪个入口“更正统”
```

## 2. 叙事起点和结论

### 起点

先击穿“给小白的简化版”这个判断，再把观众带进三个互不相干任务在终端里互相干扰的真实场景。

### 中段问题

桌面 app 到底解决了什么？答案不能停留在“界面更漂亮”，而要让观众看见三种具体变化：会话隔离、同目录操作、改动审阅。

### 结论

桌面 app 不是 CLI 的替代品。并行和可视化审阅选 Desktop，熟悉的编辑器选 IDE，脚本和自动化选 CLI；三者共享配置与底层能力。

## 3. 整体叙事结构

```text
01 先打掉“简化版”误解
↓
02 认准 Code：它到底连接什么
↓
03 安装门槛：平台、订阅和 Git
↓
04 三个会话为什么需要 worktree
↓
05 一个窗口里的终端与文件
↓
06 改动如何被看见、批注和复核
↓
07 Desktop、IDE、CLI 各自的主场
↓
08 跑通第一个本地会话并安全接受改动
↓
09 形成选择结论，预告 Web / 手机
```

## 4. 逐段叙事设计

### 第一段：先让观众怀疑“简化版”

用三个终端 tab 和三个互不相干任务制造混乱，再用桌面 app 的会话侧栏和 worktree 分裂形成第一个视觉反转。

### 第二段：先定义 Code，不展开 Chat 与 Cowork

把 Code、Chat、Cowork 放进同一窗口，突出只有 Code 能直接读写本地文件；随后用“同一引擎、不同外壳”完成产品定位。

### 第三段：把安装差异变成一条决策路径

先出现 macOS / Windows / Linux 三路，再依次标记付费订阅、Windows Git 和重启应用这两个容易卡住的关卡。

### 第四至六段：连续展示三个独有价值

- worktree：仓库分裂成互不污染的研究间。
- 集成工具：同一会话中的终端和文件编辑器指向同一工作目录。
- diff 审阅：改动从绿红文本变成可点、可批注、可自审的界面。

三段都用状态变化推进，避免连续做“标题加卡片”。

### 第七段：把选择题放在能力展示之后

先让观众看到 Desktop 的优势，再将 CLI、IDE 扩展和 Desktop 连接到各自任务，不制造“谁替代谁”的错误结论。

### 第八段：用最小会话验证安全闭环

选择 Local、项目文件夹、模型和询问权限，发送小任务，查看 diff 后再接受或拒绝；把“看清楚再点头”变成可视化动作。

### 第九段：收束并打开下一集

一句话总结三个入口的主场，补充 `/desktop` 会话迁移，然后给出“11 网页版与云端（Web / 手机）”预告卡片。

## 5. 叙事节奏

- Scene 01—03：快速建立误解、定义和门槛，信息密度较高但每幕只保留一个重点。
- Scene 04—06：全片核心演示段，分别用分裂、共享、变更三种动态机制。
- Scene 07—08：降低抽象度，先做选择，再走一遍最小操作闭环。
- Scene 09：保留足够停留时间，让入口判断和下一集预告都能读完。

## 6. 声音与视觉分工

| 叙事信息 | 声音负责 | 画面负责 |
|---|---|---|
| 桌面 app 不是简化版 | 解释误解为什么成立、又为什么过时 | 终端混乱与会话隔离的反差 |
| Code 选项卡 | 说明三种模式边界 | 选项卡与本地项目连接 |
| 三个核心价值 | 解释它们解决的工作问题 | worktree 分裂、同目录窗格、diff 状态 |
| 入口选择 | 给出按任务选择的判断 | 三路路由图和能力标签 |
| 上手闭环 | 说明安全操作顺序 | Local、项目、权限、diff、接受状态 |
| 下一集 | 说出预告主题 | 独立预告卡片 |

## 7. Gate 1 叙事审查结论

- 叙事不是文章章节的逐节搬运，核心转折从“并行混乱”开始。
- 每一段都推动“另一种工作方式”这一主命题，没有把功能列表当作主线。
- 三个独有价值均有独立视觉机制，避免重复同一种卡片表达。
- 平台限制和权限安全被保留，但没有抢走主线。
- 结尾包含 source 已明确给出的下一篇预告，未扩写下一篇内容。
- Gate 1 结论：通过，可进入 9 Scene Script。
