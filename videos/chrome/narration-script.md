# Chrome：让它操作浏览器：Narration Script

## Scene 01｜改完代码，为什么还要自己切浏览器

你改完登录表单，得自己打开页面点一遍；控制台报错了，得开 F12 把红字复制回来；设计稿还原完了，还得在浏览器里一像素一像素比。过去，代码和浏览器验证中间，总隔着一次手动切窗口。

## Scene 02｜Chrome 集成，就是借用你的真浏览器

Chrome 集成做的事很直接：让 Claude Code 借用你已经登录好的 Chrome 或 Edge。它会在浏览器里开一个新标签页，替你打开网页、点按钮、填表单、读页面，整个过程都在你看得见的窗口里发生。

这不是另起一个陌生浏览器，也不是偷偷在后台操作。你原本登录着的状态会被共享，所以 Claude 终于可以把改代码和在浏览器里验代码，放进同一个对话里。

## Scene 03｜MCP、Chrome、computer use，各有主场

但别把 Chrome 集成理解成“让 Claude 控制整台电脑”。处理外部任务时，优先选择最精准的路径：有接口的数据库、Jira 或 Slack，走 MCP；任务是网页操作，走 Chrome；只有原生应用、模拟器或者没有 API 的工具够不着时，才考虑 computer use。

所以 Chrome 的主场很明确：浏览器里的网页。它比整个桌面更窄，也正因为更窄，才更适合网页任务。

## Scene 04｜连接前，先过四道门

这个功能目前还是 beta，命令、前置版本和支持范围都可能随版本变化。现在要先对四项硬条件：浏览器用 Chrome 或 Edge，扩展版本至少是 1.0.36，Claude Code 至少是 2.0.73，套餐则必须是直接的 Anthropic Pro、Max、Team 或 Enterprise。

Brave、Arc 和其他 Chromium 浏览器目前不支持，WSL 也不支持。只通过 Bedrock、Vertex、Foundry 或 API key 访问 Claude，也不能直接走这条能力。门槛没对齐，后面的启动命令再正确也连不上。

## Scene 05｜扩展、--chrome、/chrome：三步接上

接入动作可以记成三步。先安装并启用 Claude in Chrome 扩展；启动新会话时加上 `--chrome`；如果已经在会话里，就输入 `/chrome`。

`/chrome` 不只是开关，还能检查连接状态、管理权限、重新连接扩展，以及选择已经连接的浏览器。网站级权限从扩展设置继承。默认启用虽然省一次命令，但浏览器工具会一直加载、增加上下文使用，所以更适合需要时再开。

## Scene 06｜六类网页活儿，都在同一条动作轨道上

接上之后，最常见的工作有六类：测本地网页、读控制台调试、批量填表单、在已登录的应用里写东西、从网页抽取结构化数据，以及录一段操作 GIF。

它们看起来不同，省下的却是同一段往返：不用自己切到浏览器手点，再把观察结果复制回终端。你只要说清要验证什么、填写什么、抽取什么，浏览器里的动作和结果就能回到当前对话。

## Scene 07｜真登录态，就是便利也是风险

这里必须停一下。Chrome 集成操作的不是用完即焚的沙箱，而是你真实的、登录着一切的浏览器。登录态像一串钥匙：邮箱、公司后台，甚至银行页面，只要你登录着，它就可能够得着。

还有第二类风险：网页内容来自外部，里面可能藏着写给 AI 看的提示注入。Claude 读取网页时，不能把页面上的每一句话都当成你真正下达的任务。共享登录态带来便利，也把信任边界一起带进来了。

## Scene 08｜四道闸：停手、可见、圈站点、留方向盘

官方已经给了几道护栏。遇到登录页或 CAPTCHA，它会停下来让你手动处理；操作发生在实时可见的 Chrome 窗口中；网站范围则可以在扩展设置里控制。

你自己还要守住三条底线：先看清这台浏览器登录了哪些敏感账号，把网站范围圈小；对陌生网页里的指令保持警惕；涉及下单、转账、删数据这类涉钱或不可逆操作，自己来，或者全程盯住每一步。浏览器里点下确认，后果就是真的。

## Scene 09｜最小实战：先确认扩展和版本

现在跑一个最小实战，只读官方文档站，不碰敏感账号。先到 `chrome://extensions` 确认扩展已启用，版本不低于 1.0.36；再在终端运行 `claude --version`，确认 Claude Code 不低于 2.0.73。

条件通过后，用 `claude --chrome` 启动，再用 `/chrome` 查看连接状态。先把连接本身验证清楚，再交给它真正的页面任务。

## Scene 10｜让 Chrome 真的动起来

连上以后，给它一条只读指令：打开 `code.claude.com/docs`，点搜索框，输入“hooks”，把出现的结果告诉我。

你应该看见 Chrome 弹出新标签页，自动导航、点击、输入，然后把搜索结果列回终端。浏览器真的动起来，结果也回来了，这条连接链路才算跑通。

## Scene 11｜连不上时，先查对话框和重新连接

第一次启用时，Chrome 可能需要重启，才能读到本机消息传递配置。如果页面中途没反应，先看看是不是 alert 或 confirm 对话框挡住了浏览器事件；手动关掉，再让它继续。

如果闲置太久后断连，就回到 `/chrome` 选择重新连接扩展程序。把这些恢复动作记住，连接失败时先按顺序排查，不要一上来就把问题归结为功能不可用。

## Scene 12｜从改代码到浏览器验证，再到下一集

这一篇真正接上的，是你天天在用的那个浏览器：网页任务走 Chrome，有接口的服务走 MCP，原生桌面才轮到 computer use；连接则是扩展、`--chrome`、`/chrome` 三步。

它能测本地应用、读控制台、填表单、操作已登录应用、扒数据和录 GIF，但你也要记住三件事：圈小网站权限，警惕提示注入，不可逆和涉钱操作自己把方向盘。

这样，Claude Code 就从本地代码助手走到浏览器验证，改代码和验结果可以在一个对话里完成。下一篇是 41「并行任务」：当一个会话不够快时，再看看怎样让多个任务同时铺开。
