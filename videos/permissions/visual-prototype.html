Scene 07 · Configuration

玩具放松，生产收紧

玩具 / 个人项目

{
　"defaultMode": "acceptEdits",
　"deny": ["rm -rf *", "git push *"]
}
可重建，优先提速

生产 / 公司项目

{
　"defaultMode": "default",
　"allow": ["git status *"],
　"deny": [".env", "git push *"]
}
真实影响，优先把关
--dangerously-skip-permissions　仅隔离环境
项目越接近生产，权限越要收紧
