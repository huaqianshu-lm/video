## 1. 核心命题

这篇文章真正要让观众理解的不是“如何在 VS Code 里多一个聊天面板”，而是：

> Claude Code 扩展和 CLI 使用同一个引擎、共享配置与可恢复的对话历史，但交互入口和能力边界不同；VS Code 扩展把改代码、审阅 diff、提供上下文和审阅计划变成了图形化工作流。

因此，视频需要同时解决两个认知问题：

1. 为什么安装后找不到 Spark 图标，以及怎样快速排查。
2. 为什么值得使用扩展：它把文件上下文、改动审阅和计划审阅放进了编辑器工作区，但并不替代 CLI。

## 2. 必须保留的信息

### A. 关系与边界

- 扩展不是 CLI 的替代品，而是外面的图形界面。
- 安装扩展时会顺带带上 CLI。
- 两者共享 ~/.claude/settings.json 配置。
- 对话历史可以主动恢复，但不是实时同步；可在终端用 claude --resume 接续。
- CLI 支持完整命令和 skills、完整 MCP server 配置、! bash 快捷键和 Tab 补全。
- 扩展原生提供并排 diff 和选中代码作为上下文；命令和 MCP 能力是子集或需通过 CLI 配置。

### B. 安装和图标排查

- VS Code 版本要求为 1.98.0 或更高。
- 应用市场搜索 Claude Code 时，发布者要认准 Anthropic。
- 也可以使用 vscode:extension/anthropic.claude-code 直装。
- Cursor 使用对应的 cursor: 链接；其他编辑器分支可从各自扩展视图或 Open VSX 安装。
- 官方兜底方案是在集成终端直接运行 claude。
- Spark 图标的关键条件：编辑器右上角入口只在打开具体文件时出现，光打开文件夹不够。
- 其他入口：活动栏 Spark、状态栏的 ✱ Claude Code、命令面板。
- 排查顺序：打开文件、确认版本、Developer: Reload Window、暂时禁用其他 AI 扩展、信任受限工作区。
- 首次打开面板需要登录并在浏览器完成授权；原文还说明从终端用 code . 启动可帮助继承环境变量。

### C. 三个图形界面核心能力

1. 并排 diff：红绿高亮增删，支持接受、拒绝，也可以在接受前直接手动修改建议。
2. 上下文输入：@ 模糊匹配文件或文件夹；直接选中代码后 Claude 自动看到选中内容；还支持带行号的引用、隐藏选中内容和 Shift 拖拽附件。
3. 计划审阅：Plan Mode 先生成 Markdown 计划，再由用户批准或添加内联批注后执行。

### D. 可操作的练习闭环

原文用一个最小 Python 文件演示完整路径：

- 创建 vscode-claude-demo 文件夹。
- 创建 demo.py，内容是 greet 函数和 print 调用。
- 用 code . 打开工作区。
- 打开 demo.py，从 Spark 入口登录。
- 选中 greet 函数，让它改成 f-string 并添加类型注解。
- 在 diff 中查看并接受改动。
- 切到 Plan Mode，为文件增加命令行参数支持，先审阅计划再执行。

### E. 快捷键和切换方式

- Cmd+Esc / Ctrl+Esc：编辑器与 Claude 之间切换焦点。
- Cmd+Shift+Esc / Ctrl+Shift+Esc：新选项卡打开对话。
- Option+K / Alt+K：插入 @ 提及引用。
- Cmd+Shift+T / Ctrl+Shift+T：重新打开会话。
- Cmd+N / Ctrl+N：开始新对话，但原文注明默认关闭。
- 集成终端可运行 claude 回到 CLI 风格；外部终端可运行 /ide 手动连接；也可设置 useTerminal。
- Bedrock、Vertex AI、Foundry 等第三方提供商需要按原文所述单独配置，不能在本片中扩展成配置教程。

### F. 系列结尾

- 本篇结尾要明确收束：扩展和 CLI 按工作类型切换，不需要二选一。
- 最后一个视觉事件加入下一篇“09 JetBrains 集成”的预告，且不额外创建场景组件。

## 3. 因果、对比和流程关系

### 因果关系

只打开文件夹 → 编辑器右上角 Spark 不出现 → 误以为扩展安装失败。

打开具体文件 → 右上角 Spark 出现；若仍不出现，再按版本、重载、扩展冲突和工作区信任逐层排查。

文件上下文不明确 → Claude 需要猜测；使用 @ 或选中代码 → 上下文更准确。

大改动直接自动接受 → 容易顺手改动多个文件；切换 Plan Mode → 先审阅方案，再允许执行。

### 对比关系

| 对比维度 | CLI | VS Code 扩展 |
| --- | --- | --- |
| 交互方式 | 终端窗口 | 编辑器内图形面板 |
| 命令和 skills | 全部 | 子集 |
| MCP 配置 | 完整 | 部分，或用 CLI 添加 |
| diff 与选中上下文 | 需连接 IDE | 原生 |
| ! bash 和 Tab 补全 | 支持 | 不支持 |
| 关系 | 同一后厨 | 同一后厨的另一扇窗口 |

### 流程关系

安装官方扩展 → 打开具体文件 → 登录 → 提供上下文 → 审阅 diff → Plan Mode 审阅 → 根据任务切换扩展或 CLI。
