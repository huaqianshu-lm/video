## 1. 核心命题

这篇内容真正要改变的认知不是“Claude Code 多了一个网页入口”，而是：

> **先看代码在哪台机器上跑，再选择入口：网页版把任务交给 Anthropic 云端沙箱，Remote Control 只把本地会话的控制权交给手机或浏览器。**

观众最后应该能回答三个问题：

1. 网页版为什么适合免安装、并行任务和本地没有克隆的 GitHub 仓库？
2. Remote Control 为什么不是把代码上传到云端，而是远程操控仍在本机运行的会话？
3. `--remote`、`--teleport`、`--remote-control` 和 deep-links 分别把会话往哪里移动？

## 2. 必须保留的信息

### A. 三个入口的执行边界

- 本地 CLI／桌面 app：代码和工具跑在用户自己的机器上。
- 网页版：从 `claude.ai/code` 进入，在 Anthropic 管理的云 VM 中运行；每个任务使用一次性隔离机器，并从 GitHub 仓库开始。
- Remote Control：会话和代码继续在用户本机运行，手机或任意浏览器只是远程控制窗口。
- 这条“代码在哪台机器上跑”的分界线决定了本地文件、配置、联网、断线和并行能力的差异。

### B. 网页版的价值和边界

- 免安装，云端预装常见开发工具；任务结束后把改动通过 GitHub 分支交付。
- 适合并行跑多个独立任务、本地没有克隆的仓库，以及不想配置本地环境的场景。
- 需要 GitHub 仓库；原文声称研究预览面向 Pro、Max、Team，以及具备相应席位的 Enterprise 用户。
- 会话可跨设备持久化，关闭网页后云端任务仍可继续。
- 云端只有仓库内的配置；本机的全局 CLAUDE.md、本地 MCP 和其他只存在电脑上的工具不会自动出现。
- 网页版只有“自动接受编辑”和“Plan”两种权限模式；任务描述必须具体，不能假设云端会逐项等待确认。

### C. Remote Control 的价值和前提

- 本地会话可以从手机、Claude app 或另一台浏览器继续查看和指挥。
- 本地文件系统、本地 MCP、工具和项目配置仍然可用；不等于云端执行。
- `claude remote-control` 启动服务器模式，终端提供会话 URL，按空格可显示二维码；已有会话可用 `/remote-control` 或 `/rc` 转为远程控制。
- 原文给出的前提：Claude Code v2.1.51 或更高、使用 claude.ai 账号登录而不是 API key、本地进程必须保持运行。
- 推送通知作为辅助能力保留，不抢主线。

### D. 相似命令和 deep-links

- `claude --remote "任务"`：从本地发起新的云会话，代码在 Anthropic 云 VM。
- `claude --teleport`：把云会话拉回本地继续，方向是云到本地，而且是单向迁移。
- `claude --remote-control`：开放本地会话给手机或网页，与云端无关。
- deep-links 用 `claude-cli://` 链接指定仓库和预填提示词；只选择目录并填入提示，不会在用户按回车前执行操作。

### E. 操作与访问门槛

- Remote Control 最小闭环是：查版本 → 启动服务器模式 → 空格显示二维码 → 手机扫码 → 手机发消息 → 电脑终端同步状态 → `Ctrl+C` 结束。
- 登录方式不对、关闭本地进程或网络无法访问 `claude.ai`，都会导致远程链路失败。
- 国内访问重点是浏览器、手机 app 和 Remote Control 到 `claude.ai` 的连接；云会话内部访问仓库和 npm 等网络走 Anthropic 的云基础设施。

## 3. 因果、对比和流程关系

### 因果关系

- 不想安装或本地没有仓库 → 网页版从 GitHub 克隆到一次性云 VM → 任务完成后交付分支。
- 需要本机文件、MCP 或本地配置 → 选择本地 CLI，而不是网页版。
- 本地任务需要换设备查看 → 启动 Remote Control → 手机作为控制窗口，本地进程继续执行。
- 网页版默认自动接受编辑 → 任务描述不具体会扩大改动范围 → 必须写清文件、行为和预期结果。
- 关闭 Remote Control 的本地进程 → 会话结束；它不是后台云任务。

### 对比关系

| 维度 | 网页版 | 本地 CLI／桌面 app | Remote Control |
|---|---|---|---|
| 代码跑在哪 | Anthropic 云 VM | 用户自己的机器 | 用户自己的机器 |
| 入口 | claude.ai／手机 app | 终端／桌面 UI | 手机／浏览器遥控本地会话 |
| 本地配置 | 不自动可见 | 可用 | 可用 |
| GitHub | 需要 | 不一定需要 | 不一定需要 |
| 断开界面 | 云端继续跑 | 终端关闭即停 | 本地进程关闭即停 |
| 适合场景 | 并行、免安装、远程仓库 | 本地文件和工具 | 换设备接着指挥本地任务 |

### 流程关系

```text
判断代码运行位置
↓
网页版：GitHub → 云 VM → 分支 / PR
本地会话：本机项目 → Remote Control → 手机窗口
↓
按任务选择入口，并写清权限边界
```
