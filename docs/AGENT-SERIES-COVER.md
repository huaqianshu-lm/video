# 系列选择与封面

## 用途与使用时机

本文规定系列选择、封面快照和片头时间衔接。策划时读取选择规则，实现和准备输入包时读取快照与时间规则，观看时核对封面与正文衔接。

整体流程、用户确认与完成态保护见[直接制作入口](DIRECT-VIDEO-PRODUCTION.md)，工具命令见[工具说明](../scripts/README.md)。

## 系列选择与封面快照

新视频开始时通过系列工具列出真实名称、标识、风格和封面状态，不按文件名推断归属。用户可以选择已有可用封面的系列，或选择 `none`，不添加片头。

没有合适系列时可创建；已有系列缺少封面时可补图，再选择。工具拒绝选择没有可用封面的系列，不能据此自动替用户选择 `none`。图片须有效且为 16:9；不覆盖已有系列封面，不修改含已完成成员的系列配置，封面新版本使用新系列标识。

选择结果保存到 `videos/<slug>/cover.json`，不重写已有系列成员关系。选择系列时，图片复制到 `public/local-assets/<slug>/cover/`，记录系列名称、标识、风格、快照路径、SHA-256 和展示帧数；选择 `none` 时记录无片头模式。原系列图片后续变化不影响本视频快照。

## 片头与正文时间

独立输入 Manifest 的 `entry.cover` 来自本视频快照，资源 ZIP 包含同一图片。统一入口通过 `VideoWithCover` 先展示封面，再将整个正文 Composition（含音频和字幕）置于同一 Sequence。总时长为封面帧数加正文时长；正文 Timeline／Cue／Segment 保持相对时间，整体偏移一次。

正文组件不再添加片头或自行累加封面偏移，正文配置不重复声明 `series.coverSrc`。统一入口会拒绝该配置重复声明；正文组件内部是否另加片头或偏移，仍须 Agent 核对。无封面输入不添加这一层片头，保持正文原有时间。

## 核对与变更

系列工具检查封面图片类型、文件大小、尺寸及 16:9 比例；输入包工具检查封面路径、展示帧数、SHA-256，以及包内图片和资源 ZIP 的字节一致性。Agent 核对用户选择、`cover.json`、分镜中的系列信息和输入包 `entry.cover` 一致；这些工具不自动核对全部选择与设计信息。

实际观看时确认显示的是本视频选定封面、展示时长合适，封面结束后正文画面、字幕和声音同步进入，且没有重复片头或重复延迟。观看、试听及记录方法见[质量规范第 12 章](VIDEO-PRODUCTION-RULES.md#12-gate-3-实际观看与试听)；打包与交付检查见[渲染交付基线](RENDER-DELIVERY-BASELINE.md)。实际验证范围见 [ROADMAP](../ROADMAP.md)。

`select` 仅支持首次保存，已有 `cover.json` 时拒绝覆盖，当前没有直接更换选项的工具命令。调整选择或快照时，按[直接制作入口的变更规则](DIRECT-VIDEO-PRODUCTION.md)处理。
