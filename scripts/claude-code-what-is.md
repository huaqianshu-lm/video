## Goal

用 60-90 秒解释 Claude Code 和普通聊天式 AI 工具的区别。

## Audience

已经听说过 ChatGPT、Cursor 或 Copilot，但还不理解 Claude Code 是什么的开发者和 AI 工具使用者。

## Core Message

Claude Code 不是一个聊天框，而是一个能进入项目、理解代码、修改文件、运行命令的 AI 编码搭档。
