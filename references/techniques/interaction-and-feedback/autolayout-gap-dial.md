# 间距调节驱动布局：把参数与几何关系拍清楚

这类镜头解释的是：改变同一个间距参数，哪些边界随之移动，哪些尺寸保持不变。它的价值在于连续展示因果，不是给数字配一排会移动的卡片。完成态应让观众看懂间距实际作用在哪里；运动中，数值、对象、测量线和容器始终能互相核对。

来源：[Shotcraft 原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/interaction/autolayout-gap-dial.md)／[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/autolayout-gap-dial.mp4)。本文为独立研究与原创应用设计，不是原卡译文。**原卡给定**指作者报告；**源码可见**指实现中的实际关系；**抽帧可见**仅支持对应静态画面；**制作推导**指根据这些关系设计的新镜头。原卡提及的 Framer 原片片段未取得，不把它与官方重设计 demo 混为一个观测对象。

## １．先判断是不是一个参数问题

适合解释同一参数与多个可见结果的确定关系，例如横向间距改变、内边距扩大、圆角变化、旋转角度或同一缩放参数。先固定单位、作用对象、布局约束和真正允许变化的范围，再设计动作。

| 当前内容 | 可以采用的镜头 | 不应误用成什么 |
|---|---|---|
| 自动布局中调节间距 | 同一组对象保持身份，间隙与容器随参数变化 | 让每个按钮各自飞行，最后碰巧到位 |
| 固定宽度容器内重新分配 | 保留容器边界，按实际规则表现伸缩、剩余空间或换行 | 抄用整排自由扩宽，伪造产品行为 |
| 参数带来离散切换 | 数值到实际阈值时发生换行、模式改变等真实结果 | 在不允许的小数状态之间编造连续布局 |
| 解释视觉机制 | 明示为布局示意，可放大观察对象，保留量值关系 | 用示意属性栏冒充某个真实软件界面 |
| 多个变量同时起作用 | 先拆开单变量，再说明必要的联动 | 一个拨盘同时改字重、颜色、尺寸、间距，无法归因 |

这不是普通的前后对比技法。前后画面可以展示差异，本技法还要让人看到差异如何由参数连续产生。也不是筛选：筛选改变的是候选集合，间距调节不应无故改变对象数量、顺序和文字内容。

## ２．样片的美术设计：读数、标尺与布局形成一个整体

**抽帧可见**：上方是大号间距读数和细小单位，中间是以固定指针读值的横向刻度尺，下方是一整排不等宽导航块。选择框围住整排，四个间隙下方各有测量标记。第一块采用浅色实体，其余采用深色表面。深色背景上有上方冷灰柔光、下方暖色余光及局部点阵，整个场景近正视。

这不是把控件截图贴到黑底上。画面的层级来自以下具体设计关系。

### ２．１　大读数的字形与版面

**源码可见**：数字用大尺寸轻字重无衬线，单位显著小于数字，二者按基线对齐；数字采用等宽数字特性、右对齐和预留宽度。眉题采用更小、更疏的字距，说明正在调节什么，而不与读数同等竞争。刻度附近的标签经过中心避让，不在指针处再压一个数字。

**制作推导**：大数字的轻重与背景对比要一起决定。细字重可减轻大面积数字的压迫，但不能以纤细到断笔为代价；在最终观看尺寸检查笔画、单位和数字间距。两位变三位时，不仅数字本身，连带单位和整组视觉重心也不能忽然跳位。预留实际最大值的宽度，固定单位位置，再检查 `8、12、104` 等不同字形组合；仅写 `tabular-nums` 并不能保证所选中文字体、数字字体和渲染回退都稳定。

若真实工具面板已有清楚的数值框，就让该数值框承担控制来源，不再叠一个海报级大读数。全片每个参数都变成大数字海报，会让真实操作退为陪衬。需要读具体属性时用局部取景，不能为了保留整页外观把控件缩成纹理。

### ２．２　不等宽主体与选择框

**源码可见**：五块的宽度分别为 252／206／278／268／220，高度为 120；块宽在调节中不变。圆角、顶部细高光和近远软影使它们像有厚薄关系的界面对象，而不是几行悬空白字。浅色第一块保持原有激活身份，不随每次数字跳动反复变色。

**制作推导**：不等宽来自真实文字和内边距需求，不是“不等宽必然高级”。如果实际产品的按钮等宽，就保留等宽；如果是中文导航，用实际标签定宽，检查长短词的左右内边距，不靠随意拉伸文字匹配英文外壳。按钮的内容不能随 gap 变宽，除非产品确实同时改变了尺寸规则。

选择框解释这是一组受共同布局约束的对象。其细描边应围住集合，不能逐个按钮再套同样强的框。八个手柄只适合观众认识的设计工具语境；普通教程可以换成更直接的集合边界和一处间距标记。不要让观众误以为正在缩放整个组。

### ２．３　颜色、表面与背景空间

**源码可见**：选择框采用近白，测量线、徽章、指针与运动中的读数采用同一暖金角色；背景为石墨黑灰，暗块以微弱边线和上沿高光从底面中分离。舞台柔光、地平线光带、暗角和颗粒在背景层，主体与文字在其上方独立绘制。没有证据表明这是物理三维渲染。

**制作推导**：先定义颜色的含义，再挑颜色。控制来源、测量对象和当前变化使用可追踪的强调色；已激活按钮的选中身份可以使用另一种稳定明暗，但不再为每个按钮分配一种高饱和色。背景的光用于分开区域，不能沿全部边缘加霓虹来“增加质感”。

主体下的柔光只能承托对象，不能亮到抹掉底边。点阵可帮助建立画布尺度，却不应与间隙测量的虚线混成一套强纹理。暂停看去掉光晕的画面：如果组边界、按钮表面和间距已无法辨认，应先修明暗与轮廓，不是继续叠效果。

### ２．４　负空间与最大展开态

**制作推导**：上方读数和下方对象之间留出的空隙，让观众能把“控制”和“结果”分开识别；下方测量标记还有独立的高度。它不是等待补卡片的空白。先排最大间距态，再检查最小间距与过冲态：最大态容易撞屏边，最小态容易让标记、圆角阴影和按钮边缘粘连。

背景、主标题和字幕不随每次拨数一起摇动。选择框变宽已经提供足够的整体变化；若摄影机也明显缩放，观众会难以判断按钮到底有没有变大。样片的极缓推近只能作为环境层面的微小变化，解释尺寸差异时可直接取消。

## ３．先把布局方程确定，再安排动作

**源码可见**：示例是“块宽固定、间距一致、整排保持居中、容器随内容扩宽”，不是固定容器内的平均分配。用舞台宽 `W`、块数 `n`、块宽 `wᵢ`、间距 `g` 表示：

```text
T(g) = Σwᵢ + (n − 1)g
left(g) = (W − T(g)) / 2
xᵢ(g) = left(g) + Σ(k<i)wₖ + ig
gapStartᵢ = xᵢ + wᵢ
gapEndᵢ   = xᵢ₊₁
badgeCenterᵢ = (gapStartᵢ + gapEndᵢ) / 2
```

每条测量线应从前一块的右边到后一块的左边；徽章在这个真实间隙的中心。不要从两个对象的中心量距离，再把读数叫作 gap。容器留白、选择框外扩和阴影均不计入间距。

五块总宽为 1224；`g=12` 时整排宽 1272，`g=104` 时宽 1640，对应左端从 324 移到 140。外侧向两边移动，正中间第三块位置保持不变，其余块按离中心的序号移动。对象不是等速整体平移。

**制作推导**：这组方程能直接揭示“只改间距”的约束。若实际布局左对齐，起点应保持固定，不采用居中补偿；若宽度固定，必须按产品真实规则处理压缩、溢出或换行。不要先套方程，再让产品含义迁就它。

### ３．１　数值同步不等于所有显示都毫无误差

**源码可见**：真实几何使用连续 `gap`，大读数与徽章则按 2 为步进显示。也就是说，位置与读数同源同帧，但显示值经过量化；总宽又单独四舍五入。中段可能无法用屏幕上的整数读数精确反推出整数总宽，这不是独立动画滞后一帧。

**制作推导**：真实参数如果只接受整数，就让合法整数同时驱动几何与读数；如果接受连续值但界面只显示近似值，则按真实界面精度表现。不能为了好看，数值显示 48，布局却独立缓动到另一个值，测量线再第三次追赶。

统一来源应至少包括：属性值、对象坐标、容器尺寸、框选边界、测量线端点、徽章位置、标尺偏移。强调色、读数脉冲和模糊是视觉反馈，可以由该值的速度派生，但不能反过来改变业务状态。

### ３．２　拨盘刻度不是另一条动画

**源码可见**：中心指针固定，刻度横向移动。某个刻度值 `u` 的横坐标为 `标尺中心 + (u − g) × 每单位屏幕距离`；两端渐隐，靠近中心的文字避开指针。刻度尺宽 760，每单位映射到 6.5 个设计像素，这与下方间隙实际宽度不是同一个缩放比。

**制作推导**：这种标尺是读值仪器，不是对下方间隙的原比例放大。要表现真实测量，用对象边界上的端点；要表现调节手感，才用固定针与滚动刻度。若两者同时存在，保持单位清楚，不能让观众误以为标尺的一小格就是画面上的一个像素。

## ４．动作链：什么先发生，什么可以重叠

以下帧号来自实现与样片定位，是研究坐标，不是教程固定时长。原片从第 0 帧到第 149 帧；边界第 150 帧不属于可见帧。

| 阶段 | 实现安排 | 导演上要保留的关系 |
|---|---|---|
| 建立对象 | 导航块依次上浮、选择框收拢；读数与标尺随后出现 | 先知道调节谁，再把注意力交给参数；不要全部仪表先抢满屏 |
| 预备 | 第 22—32 帧，间距 12 向 6 收回 | 仅适用于设计展示的蓄力；真实操作不允许无依据的反向改值 |
| 拉开 | 第 32—66 帧，间距 6 向 104 变化 | 数字、空隙、容器同源；中段能看出块宽没变 |
| 最大态 | 第 66—86 帧保留最大间距 | 给人确认关系和阅读终值的窗口，不同时更换文字内容 |
| 回程 | 第 86 帧开始使用弹簧向 12 返回 | 回程必须有叙事理由；真实用户未重置就不擅自恢复 |
| 收束 | 后段逐渐接近初始状态 | 读数显示稳定不代表全部几何精确静止；决定何时真正结束 |

**源码可见**：去程采用 `swift` 不对称缓入缓出，回程弹簧配置为 `damping=9、stiffness=80、mass=1.1`。当弹簧进度超过 1，只把超出部分乘 0.45，再映射回间距。它不是对整条回程统一减速，也不是简单把 gap 钳制为非负。

**制作推导**：对合法业务数值，应先确定允许范围与实际操作轨迹。可以给控件外壳一个独立、克制的按压或回弹反馈，但标签所声称的数值与实际对象仍须一致；不能把“弹性放到外观”理解成结果位置可以与测量标记脱开。若教学目标就是精确间距，直接落到终值并保持通常更清楚。

入场错峰只建立对象，不表示它们按先后接受参数。主调节段应共同响应，不能像发牌一样每个块晚几帧移动。对象的位移幅度不同已经构成自然层次，无需再给每块一种弹簧。

### ４．１　速度模糊为什么内外不同

由上述居中布局可得：`dxᵢ/dg = i − (n−1)/2`。五块对应系数为 `−2、−1、0、1、2`，因此中心块不因 gap 变化横移，外侧块最快。

**源码可见**：实现取前后半帧的 gap 差估算速度，各块按自身速度使用横向高斯模糊，强度封顶为 9。它是逐帧计算的方向模糊，并非真实快门积分。框选边界和测量线没有跟着套同样的模糊。

**制作推导**：中心块清楚、外侧短暂带动势，可以帮助读出“从中间展开”。给全排统一模糊会损失这个关系。最终需要读按钮文字时，先确保速度已低、模糊已退；如果真实长标签在中段完全失去身份，就减小模糊或改变观察节奏，不靠末态补救整个过程。

### ４．２　数值脉冲与颜色余温

**源码可见**：读数缩放由连续 gap 的相位及速度共同决定，幅度不超过约 6%；显示数字按 2 取整。脉冲不是监听“显示数字刚刚变化”的事件。暖色热度取近期约六帧的速度历史，运动停止后衰减。

**制作推导**：不要把脉冲极大值、数字跳变和声音 tick 默认当成完全相同的时刻。需要触感声音时，应按实际跨越的有效刻度设计；高速段不把跳过的全部整数硬补成一串噪声。颜色用于提示当前正在调节，停止后可以退回稳定文字色；不能把白色恢复解释成操作取消，也不能用金色冒充业务成功。

### ４．３　关键参数与几何细节保留表

下列为**当前可读实现的取值**，用于重建具体关系，不是建议所有教程采用的规格。更换画幅、字体、对象数量或实际产品布局后，先重算几何，再调运动。

| 部分 | 实现取值或关系 | 设计含义与改造限制 |
|---|---|---|
| 基准与行程 | 12→6→104→12，预备 10 帧、去程 34 帧、最大态 20 帧 | 保留先后关系；真实教学可删预备和回程，不虚构产品的数值范围 |
| 去程缓动 | `cubic-bezier(0.4,0,0.2,1)` | 函数需先从时间求曲线参数，不能把两个控制点的 Y 值直接当时间插值；原卡关于过快／过慢的感受不是统一帧数限制 |
| 回程映射 | `s'=s≤1?s:1+0.45(s−1)`；`g=104−92s'` | 只压缩超过目标后的过冲部分；合法范围要看实际极值，不能只看系数名称 |
| 读数与单位 | 数字 196、字重 300、字距 −0.05em；单位 60；数字最小占位宽 1.9em、右对齐 | 这是该画幅的比例关系；实际字体要检查三位数与单位的空间，不照搬系统回退 |
| 导航文字 | 字号 36；激活项字重 650，其余 520；块圆角 24 | 用重量和表面表达稳定身份；若字体不支持这些字重，需检查实际落在哪一档 |
| 选择框 | 组外留白 30；初始额外外扩 26，随后收拢；框线 2 | 左右外框与总宽同源，不能只缩放一张固定框图 |
| 选择框入场 | 第 4 帧起，弹簧 `damping=16、stiffness=140` | 属于集合建立，与参数调节不是同一运动 |
| 八个手柄 | 四角与四边中点；尺寸 16；第 `7+1.2i` 帧起，弹簧 `13／240` | 位置来自当前框边；它们的弹出不等于按钮缩放，也不是八次参数操作 |
| 测量纵向位置 | 测量线在块底下 74；延长线从块底下 34 开始，高 58；端刺高 16 | 两条延长线分别钉在相邻块边，测量线穿过它们；不能因块移动而留在旧位置 |
| 徽章 | 在间隙中心、测量线下 20；最小宽 64；入场起点 `14+2i`，历时 12 帧 | 徽章常比窄间隙本身更宽，所以必须检查最小态的外框，不把徽章宽当 gap |
| 读数步进与脉冲 | `shown=round(g/2)×2`；`pulse=1+0.06×abs(sin(πg/2))×min(1,abs(v)/1.2)` | 连续相位与离散读数不同；决定声音时另查实际显示变化，别把相位峰值误当咔哒事件 |
| 颜色余温 | 近七个速度样本取衰减最大值，速度归一化尺度 1.5；最后一个样本权重为 1/7 | 它是近期运动的提示，不是持久选中或完成状态 |
| 标尺 | 宽 760；每单位 6.5；每 2 单位一刻度、每 10 单位主刻度；两端约 150 范围内渐隐 | 保证固定指针可读，边缘不形成硬切；不要把该标尺当下方对象的真实等比例尺 |
| 表面与色彩 | 背景从 `#17181b` 到 `#0e0f11`、`#08080a`；主字 `#f4f4f2`；测量金 `#e4c58a` | 用于追溯样片的角色关系，不要求原创应用照搬黑金配色 |
| 阴影与推近 | 激活块软影高度参数 18，其余 12，强度系数 2.4；全局推近最多约 2.5% | 软影是两层 CSS 阴影计算，不是物体实测离地高度；微推近也会改变屏幕像素距离 |

入场时整组框选高度会收拢，但主调节阶段按钮中心 Y、高度与内部排版保持稳定。若画面让人感觉全部按钮一起被拉伸，先核对坐标父层和缩放，再考虑缓动，不能用更多弹簧补偿错误结构。

## ７．完整原创演绎：解释“间距变了，按钮没有变宽”

以下为**制作推导**，不是样片内容，也不是已经实现的组件。目标内容是横向布局中 `gap` 的作用；观众镜头前可能以为“拉松一排按钮”是把按钮拉宽，镜头后应能区分对象宽度、对象间隙和整组宽度。

### ７．１　先画完成态，不先画拨盘

完成态是一条具有实际用途的工具栏：项目、文档、资源库、设置。每项包含稳定图标和文字，四项保持顺序与各自宽度，组居中展开；其中一个间隙被清楚测量，其余间隙保留较弱的端点提示。右侧一个明确标为“布局示意”的属性区显示 `gap: 64px`，工具栏上方显示组宽变化，当前按钮的一条宽度标记保持原值。

这张结果画面要同时证明三件事：间隙增加、按钮宽度不变、总宽因此增加。它不是四张卡片陈列，也不需要做一个虚构的漂亮产品首页。实际教程讲某个工具时，改用有依据的真实界面和相应约束，示意属性区不能冒充该软件的真实控件。

**构图草案**：以 1920×1080 为设计画幅，工具栏组中心约在 `x=820、y=560`；主体画布占左侧大区域，右侧属性示意区与主体最大展开边界之间保持清楚空隙。上方短标题交代“间距”这一概念，不再出现比工具栏更抢眼的巨大动态数字。工具栏下方留给测量与一句短结论，最下方另外预留实际字幕区域。坐标用于说明初稿取景，实际按项目画幅、字幕与字体重新检查。

### ７．２　字体、材质和物体身份

**制作推导**：使用浅中性色画布、石墨色文字和一个用于测量的蓝色角色；按钮是哑光浅面与细边，活动项用更实的明暗区别，所有按钮共享光向、圆角语言和支撑关系。属性区靠清楚的行、标签与数值建立工具语义，不做厚重玻璃盒。不要把官方样片整套黑金外观直接换上中文。

标题承担概念名称，按钮标签承担对象身份，属性值承担控制来源，测量数字承担核对。按钮文字采用同一正文体系；数值可用匹配的等宽数字。检查中文图标间距、实际字面高度及宽度标记的避让，不能让数字为了对齐而压缩字体。

测量选在第二、第三项之间，靠近主体中央，避免迫使观众同时追四个高亮徽章。该间隙的端点与控制值使用同一蓝色，第二项按钮的宽度标记保持中性，落定后再短暂提高对比供核对。始终不变的对象提供参照，不需要全程闪动提醒“不变”。

### ７．３　先验证几何，再设计路径

**制作推导**：四项初稿宽度为 `224、192、256、208`，高度 104，总宽 880；选择 `gap: 16→64` 展示同一参数。组居中，宽度从 928 变到 1072；左端从 356 到 284，四项横坐标变化分别为 `−72、−24、+24、+72`。整个过程块宽、块高、文字与数量保持不变。

这些数值是原创示意的明确输入，不是假装测到了某个软件。它们证明这套初稿可以在主区域内展开：最大态最右端为 1356；再加选择边界与软影后，还要与右侧属性区、字幕及标题一起复查。实际文字撑不进按钮时，先按内容改宽，再重算全组，而不是缩字回迁就这组数值。

### ７．４　从建立到下一镜的完整动作

| 状态 | 画面与动作 | 当前应该看哪里／理解什么 |
|---|---|---|
| A．建立基准 | 工具栏先以完整使用态出现；属性区显示 16；当前按钮内容清楚 | 这是一组已有布局的实际对象，不是等待飞入的卡片 |
| B．指出作用范围 | 一次框选说明受控集合；中央间隙出现端点与 16 标记，按钮宽度标记暂弱 | 当前参数作用在对象之间，不在按钮内部 |
| C．明确触发 | 示意控制值开始改变；若对应真实工具则表现有依据的拖调／输入提交 | 观众能认出是什么触发了变化，不能提前让结果展开 |
| D．连续展开 | 四项从同一参数求位置，中央间隙端点随边界移动，容器同步变宽 | 关注一个间隙如何扩大，其他对象共同响应而不是依次接受命令 |
| E．稳定结果 | 数值与布局停在 64；不自动返回 16；按钮原宽标记提高对比 | 清楚看到“间隙变了，按钮没变宽” |
| F．核对整体 | 组宽标记显示 1072；只在必要时用短提示解释总宽增加 | 结果由多个间隙累积产生，不误读为字体或按钮缩放 |
| G．交给实际内容 | 临时测量退弱，保留工具栏及真实终值；根据下一段内容局部取景 | 镜头不结束在抽象数字上，而是进入改变后的布局使用态 |

如果下一镜讲内边距，先保持同一按钮和当前间距，再明确改换观察对象到按钮内部。不要在收尾同时偷偷恢复 gap、放大按钮、改变 padding，让两种概念混在一个高潮里。需要恢复基准来做比较时，应明确表现重置动作及理由；不能把样片的自动弹回当成必经收尾。

声音可给操作触发一次轻反馈，连续调节期间是否使用刻度声取决于旁白密度；结果停稳不必加“成功”提示音。实际停留与触发时间取真实口播和 Timeline，不预设五秒讲完。若旁白需要比较，优先给稳定核对时间，不把每个状态都加成同样长的动画。

### ７．５　必须审查运动中间，而不只看两个端点

**制作推导**：在展开中段检查第二、第三项之间的测量线是否真连在边界；选择框是否跟随同一布局；右侧属性区是否被最右按钮或模糊外扩侵入。按钮内文字不拉伸，图标与文字间距不变，第一活动项不因数字跳变改变选中状态。

最小态和最大态都要检查徽章外框；窄间隙装不下读数时，把徽章放在外侧固定高度，用延长线指回端点，不能直接把数字缩进缝里。纵向分层足够时，各徽章可以保持相同高度；如果仍互相遮挡，就减少重复标记，而不是让它们沿无关方向跳舞。

正常速度下，目光应从触发值进入中央间隙，再回到保持不变的按钮宽度；若观众一直盯着属性区跳数，就降低该区的脉冲和面积，把变化过程交还给主体。这里的“焦点清楚”要靠观看证明，不靠所有元素都来自同一变量证明。

## ８．常见失败与具体修正

| 实际失败画面 | 原因 | 修正 |
|---|---|---|
| 数字在动，按钮像另一套动画 | 坐标和读数分别缓动或有额外 CSS transition | 用一个合法参数计算全部几何，取消独立追赶 |
| 观众以为按钮变宽 | 全局缩放明显，或字体与块宽也在变化 | 固定块宽与字形；保留宽度参照，取消竞争的推近 |
| 最大态好看，中段撞属性区 | 只排起终点，没查外框、阴影和模糊范围 | 检查完整包围盒，重排主体范围和控制区 |
| 小间距时四个徽章挤成一条金条 | 把所有测量同权重堆上来 | 重点保留一段，弱化其余；读数外置并指回间隙 |
| 全部按钮同时发光，哪里都像选中 | 选择、测量和动作强调混用 | 稳定选中身份；只给受调参数及对应边界强调色 |
| 参数被改回去，教程含义反了 | 无条件照搬展示样片的回弹结构 | 按真实操作保留终值；只有明确重置才返回 |
| 显示值稳定，测量线仍轻晃 | 取整遮住弹簧残余，或几何未真正收束 | 检查连续值与边界；需要精确阅读时明确结束运动 |
| 动作流畅，但仍像卡片进场 | 没有比较不变量，也没给实际结果 | 先确定要揭示的参数关系与使用态，再反向排动作 |
| 截图布局无法跟参数变化 | 固定图片不能真实重排内部对象 | 按有依据的对象分层或机制示意设计，不拉伸整张截图假装布局变化 |
| 回弹超出合法范围或穿插 | 误信原卡近似值，没有查实际极值 | 依据合法范围重新设计轨迹；别让显示钳位掩盖错误几何 |

## ９．怎样判断这篇参考已被正确使用

这是具体镜头的检查问题，不增加制作 Gate，也不代替项目现有设计审查与实际观看。

| 检查项 | 需要看到的通过证据 | 失败时返回哪里 |
|---|---|---|
| 视觉叙事 | 观众能指出参数作用的边界，也能指出保持不变的对象属性 | 只记得数字跳动：重新设计内容目标和结果画面 |
| 静态设计 | 基准态与结果态均有明确主体、稳定文字角色、可辨表面和有用途的负空间 | 只是普通按钮加框：重做造型、比例和取景，不先加效果 |
| 因果与精度 | 实际值、对象、容器、测量和单位来自同一状态；量化范围有说明 | 数值与几何不符：修数据关系，不能靠模糊掩饰 |
| 中段构图 | 最大展开、最紧状态、极值和模糊外框均无关键遮挡，身份保持连续 | 只验起终点：补中段并改区域分配或轨迹 |
| 正常速度 | 操作、结果变化、核对依次可理解；不被重复脉冲和标尺带走注意 | 追不上或只看仪表：减少竞争，让主体接管 |
| 真实内容与声音 | 实际中文与最长标签可读；操作与真实 Timeline 对应；配声后仍听清旁白 | 占位素材成立、换内容失败：重新排版并观看／试听 |
| 镜头衔接 | 结果保持实际终值，接到下一步操作或必要比较 | 自动回弹后没有新认识：改收尾与下一镜关系 |
