# 点阵扩散与反向回波：传播几何必须有明确含义

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/ui-entrance/radial-wave.md)、[RadialWave](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/ui-entrance/radial-wave/RadialWave.tsx)、[radial-wave 官方样片](https://vincentwei1021.github.io/video-shotcraft/media/radial-wave.mp4)。下文区分原卡给定、准确实现、官方样片抽帧观察和原创制作推导；抽帧每条16幅，未完整正常速度观看、试听、运行上游或实现原创镜头。参数用于解释原例，不能直接作为当前视频默认值。

## 1．波纹可以解释传播，不能自行证明连接

17×9点阵先由中心向外点亮，再从外向内回波。适合引出范围、传播方向或一个有明确规则的节点模型；若只是品牌背景，可短用后退出。不能把点亮写成设备都已联网、数据已同步，除非真实状态有依据。第二波「回执」是视觉比喻，不等于真实协议回包。

## 2．暗底、点距与文字区先设计

480×270舞台中点径10、margin−5居中，列距约28.24、行距30，输出按4倍显示。常色#6c8cff，第二波高亮#b9f2ff与12px浅蓝晕，深底#0a0b10支撑亮度差。若前景还有标题，先留出真正的文字区或降低背景，不能把字压在最亮波前上。

百分比中心(c+.5)／COLS、(r+.5)／ROWS让点阵均匀，但距离使用列行索引hypot，不是屏幕像素；行列物理间距不同，屏幕波前会稍椭圆。换宽高或改成非均匀地图时，要按实际节点坐标重新算距离。波源改变需重算到所有节点的最大距离，不能只改中心而保留旧MAX_D。

## 3．第一波实际只轻微过冲

dist=hypot(c−8,r−4)／hypot(8,4)，每点w1=outCubic(seg(t,.35dist,.35dist+.18))。距离决定起点，单点窗口相同；最外点.53完成，原地常亮。scale=w1[1+.5sin(πw1)]，因为前面还乘w1，**最大约1.0431，发生在w1≈.858，并非1.5倍**。不能把乘数自身峰1.5当最终尺寸。

opacity=.25+.5w1+.25pulse2，但首帧scale0，所以未点亮点虽有.25opacity仍看不见；原卡「暗点交代规模」不对应起始几何。若需要未激活网格先存在，原创要明确给非零底尺度，而非只改透明度。

## 4．回波的亮头、硬阈值与末帧残留

w2的窗是.62+.25(1−dist)到再+.15，pulse2=sin(πw2)。外点先、中心后，额外scale=.8pulse2，回波峰比第一波更强。pulse2>.3时颜色与光晕硬切，不是平滑渐变；阈值附近可能见开关，需要正常速度观看，不以静帧高亮漂亮判断无跳。

t=f/113，中心第二窗.87～1.02，末帧只到13／15，pulse≈.4067、scale≈1.3254、opacity≈.8517，仍发浅蓝光。外圈早已恢复，末尾亮中心是原公式结果；若需干净落定应把全节点回波结束移到t≤1并留阅读窗，不是简单截图最后一帧宣布已静止。

抽帧见蓝点从中心成片，随后外缘亮蓝向中间收，113中心仍亮。动画没有真实传感或网络输入；点数153只是画面节点，不自动等于153台设备。

## 5．原创制作推导：解释一个种子怎样影响邻近区域

用图像选区扩展教学时，先画结果：真实图像上的种子点、受影响区域边界，以及范围外保留内容；下一镜改变半径，看边界怎样变化。点阵只是示意模型，最后必须进入图像，不让153圆点代替实际选区。

1. 建立图像和一个真实操作起点，附近采样点按图像坐标摆放，不强制全部排成规则网格。
2. 波从种子出发，颜色只表示距离层级，不能把距离相近误说成颜色相似或语义相同。
3. 主波到边界后锁定可读范围，回波若没有对应操作含义就删掉；需要回查时可用回波强调种子与范围的关系。
4. 点阵退为细参照，真实选区遮罩接管，图像主体与边界清楚；保留一个没被选中的邻近部位说明限制。
5. 下一镜调半径或阈值，只改变一个变量，看到实际范围变化。声音一条轻扩散即可，不能给153点逐一发声。

## 6．原创草图的美术与中段取景

选区扩展示例里，传播颜色只负责说明距离或处理阶段，原照片保持可辨，不把整图染蓝到看不见主体。种子可用一个比节点稍明确的中空标记，点阵比真正选区边界更弱。需要解释半径时，直接保留种子到边界的一段标尺；不用再叠十几圈同心圆，避免从教学退化成HUD装饰。

传播中段检查波前是否把人物轮廓或细线淹没；最终用真实选区边缘、半透明遮罩和一处未选中的近邻构成判断依据。调参数下一镜只改半径或阈值中的一个，并保持同一图像取景。若只靠蓝点大小变化看不出选区有何变化，就需要让真实像素结果接管，不能继续增加第二、第三道回波。

## 7．关键画面与失败诊断

| 状态 | 美术／几何检查 | 信息证据 |
|---|---|---|
| 种子建立 | 起点明确，背景不过亮 | 波有实际来源 |
| 扩散中段 | 距离窗形成可读波前 | 传播规则不含糊 |
| 边界落定 | 外围与内部区别清楚 | 范围不是无限覆盖 |
| 原图接管 | 点退次级、真实遮罩可读 | 模型与结果有映射 |
| 参数改变 | 同图同取景、只改一变量 | 观众看见具体后果 |

偏心波永不到角落就重算MAX_D；点互咬先查实际scale峰和点距；亮度跳变可用连续混色替代阈值；结尾仍亮要延长或重排回波窗。须审核正常速度传播、静态边界与真实内容映射，不以「看起来像系统」代替解释成功。
