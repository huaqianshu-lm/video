# 玻璃听写条：让光退给文字

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/interaction/glass-pill-dictation-typing.md)、[GlassPillDictationTyping](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/interaction/glass-pill-dictation-typing/GlassPillDictationTyping.tsx)、[glass-pill-dictation-typing 官方样片](https://vincentwei1021.github.io/video-shotcraft/media/glass-pill-dictation-typing.mp4)。下文区分原卡给定、准确实现、官方样片抽帧观察和原创制作推导；抽帧每条16幅，未完整正常速度观看、试听、运行上游或实现原创镜头。参数用于解释原例，不能直接作为当前视频默认值。

## 1. 一句输入是主事件

它适合一个安静的输入镜头：胶囊落位、文字出现、待命光逐渐退出。它不负责解释完整语音识别过程，源例匀速字符也不是真实听写时间戳。若当前功能没有语音输入，不应保留声波按钮暗示存在；可以提取材质与光让位的方法，改为真实文本输入。

## 2. 大负空间里的具体材质

原例暖沙日光，1240×132定宽胶囊横置中央，右端92px按钮，左端文字56px。背后暖色光心靠胶囊右段，玻璃才能把背光晕开；不是在透明白条外面加一圈glow就算磨砂。顶部白高光两端渐隐，底缘内暗边、上亮下暗的微体积与两层暖影建立厚度。

内嵌光由左透明到右浓：38%约.18、78%约.62、最右杏色约.95，文字落在更安静左侧，按钮处较亮。地面反光与背景太阳配合，光熄时整个局部空间一起安静下来。底部品牌仅是源例包装，教程应换必要提示或删掉，不为了填空造品牌条。

## 3. 定宽、时间和文字容量

胶囊scale1.25→1用20f snappy，透明前2f满，前14f模糊6→0；这读成靠近观众的实体落回，而非一个随文字长大的chip。光标f2先出现，文字从f8起，每字2f，f66–74撤光标；光退g=1−smooth(f10→72)。

| 通道 | 源例关系 | 当前内容应怎样重算 |
|---|---|---|
| 字符 | floor(clamp((f−8)/(len·2))·len+epsilon) | 精确TEXT按实际长度，实际源句28字，但换句不能只依据注释排时间 |
| 源码文案 | Cut a launch film for my app | 实际28个ASCII字符，约f64完整；换文案须以实际长度计算 |
| 光同步 | 内渐层、外glow60g、背景太阳、地面、按钮同g | 只有胶囊变暗环境不动，因果不明显 |
| 残留光 | 太阳最低仍有.15分量 | “退去”不等于全黑，保留环境余温 |
| 声波 | 5条基准30/16/24/13/20，加±2.4sin | 仍在呼吸，末段不是逐像素静止，也不代表真实音频幅度 |
| 文字宽 | 内宽扣左右padding、按钮、光标及间隔 | 不能用“句宽1.8倍”经验替代实际字形测量 |

真实听写应按音频分段/词边界设计显现，有修正回写时忠实保留，不能为了均匀美观伪造恒定识别速度。输入文本若长，选水平滚动、换行或缩短示例，由任务决定，不让字挤到按钮下面。

## 4. 官方画面观察

16帧可见胶囊尺寸基本不随输入改变，右侧暖光逐渐退成中性，句子最后完整留在条内，背景仍有暖余光。玻璃与背景发生真实视觉混合。抽帧不能代表实际听写延迟、正常速度阅读和声音，演示本身无音轨。

## 5. 原创制作推导：把一句检索请求交给真实结果

内容目标是“把问题写具体，才能核查返回内容”。先设计结果：输入条内有包含对象与条件的完整问题，下方是实际资料结果的一部分，关键条件在输入与结果中一一对应。不能输入一句话后只给“AI很强”的标题。

开场用暖光表示待输入，胶囊定宽，短请求按实际输入事件出现；若是文字键入就改成文本光标和真实键盘语义，不保留虚假的录音态。输入最后一个条件出现后，光退到中性，让观众真正阅读完整句。

提交是另一个明确事件：按钮按下，输入条上移给结果让空间，真实结果显示来源标题与匹配条件。下一镜进入其中一份原文，核查它是否满足问题里的时间或范围限制。胶囊退成定位层，光不再反复点亮争夺关注。

## 6. 失败修正与验收

- 玻璃像白板：查背光是否真的在后面、backdrop是否被合成边界隔开；不要只提高透明度。
- 打完最后字被按钮挡住：实测字体宽度和flex布局，扩容或改行，不按英文字符平均宽估中文。
- 光退不明显：用同g控制内光、环境与地面，降低外围无关暖光，不无节制增加饱和度。
- 文字完成但光标提前消失：从实际len和输入时序推结束，检查标点与组合字符；不照注释固定帧。
- 观众误以为正在录音：按钮形态、波形活性与状态文字一致，没有真实录音就换图形。

通过需有定宽形体、清楚的状态变化、完整句阅读与真实结果接棒。逐帧seek可重复只是技术条件，正常速度与听写真实性、声音均须具体实现验证。

## 原创镜头的关键画面调度

下表是上述原创应用的设计草图说明，不是已渲染关键帧，也不代表动态已验。以实际内容、字体与画幅重排，检查每个状态及状态之间的完整运动包络。

| 状态 | 画面安排 | 观看焦点与接棒 |
|---|---|---|
| 就绪 | 定宽玻璃条居中，暖光在右后方，文字左侧对比安静 | 按钮形态与真实输入方式一致 |
| 输入 | 文本显现，内光／环境／地面一起退，条宽不变 | 光让给句子，不额外加跳字与弹性缩宽 |
| 结果 | 完整请求稳定可读，再提交并给真实结果让空间 | 下一镜核查返回原文是否满足同一条件 |
