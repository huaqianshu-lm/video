# 同心圆背景中的手机与功能胶囊

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/effects/radial-ripple-phone-chips.md)、[RadialRipplePhoneChips](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/effects/radial-ripple-phone-chips/RadialRipplePhoneChips.tsx)、[radial-ripple-phone-chips 官方样片](https://vincentwei1021.github.io/video-shotcraft/media/radial-ripple-phone-chips.mp4)。下文区分原卡给定、准确实现、官方样片抽帧观察和原创制作推导；抽帧每条16幅，未完整正常速度观看、试听、运行上游或实现原创镜头。参数用于解释原例，不能直接作为当前视频默认值。

## 1. 产品全貌与操作教学的边界

用于建立“这是一个移动端界面，里面有持续内容”。手机、背景波纹、两侧胶囊各司其职。它适合短全貌或段落呼吸，不适合让观众在缩小手机里读长文或学细操作。屏幕自动滚动只能说明展示内容，不能单凭这一点宣称软件具备自动播放功能。

## 2. 先设计一张完整产品画面

原例暖沙底，大至出画的实色圆盘由外深内浅，手机居中430×900，占画高约83%；两侧白胶囊错开高度，左下品牌与留白平衡右侧胶囊。手机暖钛金属边12px、黑边9px、圆角70，侧键、岛形开口与斜反光共同建立硬件感，不用无限叠描边。

屏内不是灰骨架：标题、精选大图、不同封面列表、时长与进度、底部迷你播放条形成真实密度。屏幕上下渐隐属于内容视口，与固定状态栏和播放器分层。真实项目先选择能代表主题的一屏，不要以自动滚屏掩盖页面排版粗糙。

胶囊36px字配60px图标圆，文字应短且各指一项能被后续证明的内容。手机两边不是任意空位：改宽、改词长以后要检查圆盘边、主体边、字幕与胶囊的包络，不把标签挤到画外。

## 3. 原例动作和几何关系

| 通道 | 原例数据 | 关系与重设计 |
|---|---|---|
| 背景 | 2240/1760/1280/840直径，scale1±.06，相位差1.7rad | 是四块实色圆盘，不是四条描边圆；由大到小叠放 |
| 呼吸 | 全片约1.5周期 | 错相形成波感，实际并非水面流体模拟，不能用来解释物理波速 |
| 手机 | 0–26f下方90px升起 | 投影同步收紧，手机没有自身无缘由摇晃 |
| 列表 | t .08→.98，0→−560px线性 | 约152f滚动；教程要读内容时应改停留，不沿用自动滚动 |
| 胶囊 | 左37、右67起，spring13/190，scale.8→1并外移28px | 一枚是主提示，另一枚可更弱，不必相同戏份 |
| 悬浮 | ±8px，弹出后18f起24f渐入 | 避免刚落位就反向飘；末段仍活跃，不叫真静止 |

手机PX=(1920−PW)/2，胶囊按手机外缘加CHIP_GAP64定位；左胶囊用right属性时要换算画宽。真实长截图必须高于“视口高+滚动距离”，否则末段露底。固定迷你播放条不跟列表一起滚；阴影和反光属于手机本体，不跟feed移动。

若换成实际截图，状态栏、底部手势条与截取范围要一致，不能设备壳已有状态栏，截图里又出现第二套。字体最终尺寸按实际输出投影查，不依据手机内部fontSize直接判可读。

## 4. 官方抽帧观察

16帧可见大圆盘出画铺底、手机从下方就位、左右胶囊先后出现，列表一直上移，播放器固定在底部，末段品牌文字出现。画面没有完全停止：波纹、滚动和标签悬浮均继续，所以“hold”指稳定构图而非静帧。未正常速度观看，无法断言三层慢动作叠加后仍不分心。

## 5. 原创制作推导：从收藏全貌进入一条真实资料

目标是“收藏不是终点，找到并阅读原文才完成任务”。先做最终全貌：手机展示真实收藏列表，精选项是一份与口播相关的资料，左右胶囊分别写“按主题找”和“回到原文”。封面有真实视觉差异，不能全部同色占位块。

手机初建只慢滚到目标附近，背景波纹降低对比，主胶囊先出现说明分类入口。接着停止滚动，让该项标题真正被读到；第二胶囊只在进入原文的操作即将发生时出现，不同时给两条解释。若读窗不足，删背景运动而不是加速念完。

下一镜沿目标卡中心推近到正视可读屏幕，保留相同封面、标题和分类色，点击进入实际原文。手机外壳和波纹退到画外，知识解释由真实内容接管，不再维持产品海报全貌。

## 6. 失败修正与验收

- 圆盘像靶心压住手机：降低外圈反差、减少可见边数，主体亮暗仍居首。
- 末段列表露白：按实际内容总高重新计算滚动上限，不用底部渐隐掩空洞。
- 标签长词出框：改短语或重排左右高度，测实际字体宽度及弹簧过冲包络。
- 手机里什么都看不懂：全貌只负责识别与入口，另给可读近景；不能把正文缩进390px视口承担全部教学。
- 自动滚动与光标操作冲突：操作开始前停滚，固定目标位置再点击，避免光标追着入口跑。

合格应有能独立成立的全貌海报、清楚的主提示、真实列表内容与后续近景身份连续；动态、阅读与声音在原创成片另验。

## 原创镜头的关键画面调度

下表是上述原创应用的设计草图说明，不是已渲染关键帧，也不代表动态已验。以实际内容、字体与画幅重排，检查每个状态及状态之间的完整运动包络。

| 状态 | 画面安排 | 观看焦点与接棒 |
|---|---|---|
| 全貌 | 中央手机／暖圆盘／单条主胶囊，屏内精选项有真实封面 | 先认产品与内容，不读所有微字 |
| 找目标 | 列表滚到所需资料后停，另一胶囊再说明回查 | 背景慢运动不得抢目标标题 |
| 接管 | 同一封面和标题放大进入可读屏幕，外壳逐步退画 | 下一镜点击真实来源，产品海报不承担原文全文 |
