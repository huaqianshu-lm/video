# 图标收束与字标落位：从演出形态回到稳定身份

本镜先把较大的运动图形收成小图标，再由图标让位给名称，最后补一行低权重说明。设计重点是由强到弱、由图形到身份，而不是收尾再制造一轮复杂动作。最终图标、文字、间距与对齐本身必须成立，动画才有一个可信的终点。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/outro/logo-shrink-wordmark-lockup.md)、[LogoShrinkWordmarkLockup.tsx](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/outro/logo-shrink-wordmark-lockup/LogoShrinkWordmarkLockup.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/logo-shrink-wordmark-lockup.mp4)。另核对 [Motion](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Motion.tsx)、[Polish](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Polish.tsx) 与 [Brand](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Brand.tsx)。固定卡已核验，main实现、媒体分别研究，不宣称同版运行。

本文分**原卡给定、源码可见、抽帧可见、制作推导**。样片1920×1080、30fps、132帧、4.4秒，无音轨；查看16帧。未正常速度完整观看、运行上游、核验品牌手册或制作原创镜头。案例数值不替代 [质量规则8.6](../../../docs/VIDEO-PRODUCTION-RULES.md)。

## １．适用角色：最后认清是谁，不再展开新论点

| 任务 | 可采用 | 不应代替 |
|---|---|---|
| 片尾身份定妆 | 图标与名称的标准组合 | 内容结论和操作结果 |
| 章节从活动元素回到小标识 | 视觉母题收束，名称补齐 | 尚未解释的知识点 |
| 品牌／系列识别 | 有实际身份资源与使用依据 | 临时造一个品牌当真实系列 |
| 循环素材 | 需要另设计尾首关系 | 从完整字标直接跳回大环 |

**制作推导**：原卡是片尾语法，不要求教程每次结束都做品牌动画。若最后一个实际结果足以收束，就保留结果并用低权重身份，不抢最后的理解时间。名称、标志、标语各有角色，不能三者都做同样强的弹跳。

## ２．最终静态组合要先量清

### ２．１　设计坐标与完整宽度

**源码可见**：设计480×270，zoom放大4倍。图标基准30、标准标志32，字标字号22／700、15字符，`WORD_W=172`为代码记录的实测宽；图标到字标间距9。名义组合宽30＋9＋172＝211，输出844。

图标中心左移`−(30＋9＋172)／2＋15＝−90.5`设计px，即屏幕−362；终点中心x598。文字左缘相对画中线−66.5，输出x694；字标名义右缘1382，图标名义左538，整体居中。标准标志32比基准框30略大，其可见包络要另看，不因公式居中就假定光学中心完全正确。

**制作推导**：换名称、字体、字重或字号，重新测实际行宽。逐字flex会改变字偶间距，不能拿一整行字体测量值不经复核就固定172。中文四字与15个拉丁字符不是简单按字数缩放；全角标点、下行和留白都会改变视觉重量。

### ２．２　暗环境让最终身份安静地站住

背景从`#0d0f17`到`#05060a`，顶部略亮，紫色能量晕先大后小。字标浅白，标语冷紫`#9d94ff`，与前段霓虹同色域而不再加撞色。标语12.5设计px，即50px输出、600字重、2.6设计px字距，位于中心线下34设计px，即y676。

**抽帧可见**：结尾图标和名称为第一阅读层，紫色标语在下、较细较疏；四周深场留白明显，没有另加产品卡片或高亮按钮。原演示身份资源属于上游，不作为可直接迁用的本项目品牌。

**制作推导**：最终静帧先去掉动画与光晕，审查标志大小、文字基线、名称间距、标语行宽。每一项都清楚后再设计收束。品牌标准态应遵守真实资源，不用抖动、发光或变形修补标志本身的问题。

## ３．大环、白环、标志是三种形态，不是一个矢量变形

**源码可见**：开头两段对角圆弧，中心15／15、半径10.5、每段154°，圆端帽；外层6.5宽虚晕、3.4宽芯。随后加一整圈白环，radius10.5、stroke5.5、fill none；再交叉到标准标志。

原卡称“实心白O”，当前实际仍是白色描边环、内部透明，不是填满的白圆盘。三种资源主要靠透明度交接，没有逐顶点形状变换。描述为“环愈合后换标”比“环精确变形为标志”更准确。

大环外层缩放5.4→1，基准30框输出约648px；实际白管外包络约26.5×5.4×4＝572.4px。它在画面中央较大，但并未满屏。环境晕初始半径150设计px、直径1200输出px提供更大光场，不应把光晕尺寸说成环本体尺寸。

**制作推导**：用当前品牌自己的几何母题建立演出态；若标志无环形关系，不必强迫从O变来。可以从同源线条、裁切框、纸角或已有图形收束，但标准标志最终不能保留随意旋转与光效。

## ４．缩放与刹车：先主收束，再一次很小的余量

**源码可见**：t＝frame／131，主尺度在0.02→0.28用inOutCubic从5.4到1；另在0.26→0.37乘`1＋0.06sin(πp)`。主收束末尾与刹车有交叠，不是到1后才启动另一段弹簧。

环内层独立减速转150°，0→0.3结束；标准标志在外层，只随位置与尺度变化，不跟着环旋转。环在小尺寸下愈合，旋转逐渐不显眼，标志朝向从开始可见就保持标准。

**制作推导**：过冲用来说明停止惯性，但6%不是所有标志的默认。几何严格、文化克制的身份可以无回弹，保留减速即可。需要声音重音时选择真正的落定点，不把主收束到1、过冲峰值与完全回1都同时叫“落位帧”。

### ４．１　残影依据速度，而非全程留两圈

代码用当前尺度与前一帧尺度差生成trail，差值／0.35封顶1；仅trail＞0.02时绘前1、2帧尺度与角度的淡弧。ghost不画标准标志，避免片尾出现多重logo残像。

**制作推导**：残影是速度提示，不是增加图层数量。方向错误或静止仍拖影，会看成叠了三个坏资源。换帧率后前1／2帧对应的真实时间不同，应按目标播放检查，不用两张拷贝替代真实采样验证。

### ４．２　冲击波属于旧落点，图标随后让位

波在t0.28→0.46从直径32扩大到140设计px，边宽0.9→0.25，透明度退0；中心固定画面中央，不跟图标左移。图标0.34开始让位时，中心可能仍残留淡波，这可以读成原落点余波，而不是错位的描边。

若设计希望光环始终附着图标，就必须共享shift；若希望残留在落点，则保持世界位置并快速退。不能任意混搭，导致观众分不清光属于谁。

## ５．字标与标语的完整时间链

| 通道 | t区间 | 对应当前帧位置 |
|---|---|---|
| 主收束 | 0.02→0.28 | 2.62→36.68 |
| 白环愈合 | 0.10→0.28 | 13.1→36.68 |
| 标志交叉进入 | 0.24→0.32 | 31.44→41.92 |
| 刹车余量 | 0.26→0.37 | 34.06→48.47 |
| 图标左移 | 0.34→0.47 | 44.54→61.57 |
| 首字符 | 0.46→0.56 | 60.26→73.36 |
| 末字符 | 0.684→0.784 | 89.604→102.704 |
| 标语透明度 | 0.72→0.84 | 94.32→110.04 |
| 标语位置 | 0.72→0.86 | 94.32→112.66 |

字母每个0.10时长，以outCubic从8设计px水平偏移回0、模糊2.5→0、透明度0→1。错峰间隔0.24／15＝0.016，不是0.7之前全词已经完成；0.7之前只是全部起跑，末字符约103帧才完整。

标语是整行进入，比字标低一档，不再逐字抢戏。它在字标最后几字尚未结束时就开始，透明度111完整、位移113到位；113—131共19张完整组合保持，不是默认一秒以上。需要更长识别时间时延长尾部，不能把整个132帧都算品牌阅读。

**制作推导**：“换标时已缩到最终尺寸”也只是近似：标志从31.44起可见，主尺度到36.68才到1，之后还有刹车。若真实品牌不允许任何缩放交叉残影，应将标准资源的交接延到完成态，而不是只改文档说它早已静止。

## ６．关键帧观察与未验边界

实际查看0、8、18、30、36、42、48、60、64、78、90、103、110、113、124、131。

| 帧组 | 抽帧可见 | 审查重点 |
|---|---|---|
| 0—18 | 较大切口环与紫晕，环逐渐变小 | 光场与实体边界、旋转是否有目的 |
| 30—42 | 白环与标准标志交叉，冲击波起 | 有无两标重影、方向错误或突然跳形 |
| 48—64 | 小标志左移，首字开始 | 左移量与名称总体居中关系 |
| 78—103 | 字母滑入并变清晰 | 字距、逐字基线、末字是否拖太晚 |
| 110—131 | 标语完整、最终组合安静 | 名称与标语主次，实际读取窗口 |

本轮静帧能支持形态交接与最终布局观察，不能证明动态余量、残影和声音手感。颗粒放在设计层之外按原生输出绘制，若它随帧变化，核心身份静止也不等于全像素冻结。

## ７．原创演绎：引用定位符收成“查证方法”章节身份

以下为**制作推导**，未实现。教程已通过真实原句与结论关系讲完查证，本镜从已经出现的引用定位符收成章节身份，不临时制造一个真实品牌或新系列。

### ７．１　先确定标准态

身份组合采用自绘纸页角标和四字“查证方法”，暖白背景`#eeeae2`、深墨`#28372e`、绿`#3c7155`。角标只是章节示意图形，不冒充真实软件商标；如果实际项目已有身份资源，则替换为被选用的真实资源。

先排图标96×96、与标题间28，中文64px中黑、四字实际行宽测量后整体居中。副句“看原文，再下判断”30px，位于主组下48。图标不做发光，纸角细线与正文引用定位框共用绿色，保持内容关联。

### ７．２　完整导演链

| 阶段 | 画面 | 内容职责 |
|---|---|---|
| 前镜实际结果 | 原句、来源与结论的关系已经可核对 | 学习任务已完成 |
| 收束 | 同一引用定位框从原文旁回到中央，缩成纸角符号 | 保留“从材料来”的视觉身份 |
| 标准态交接 | 运动框与自绘角标在完全对齐时交接 | 从操作标记变成章节标记 |
| 让位 | 图标向左，标题整体出现 | 读清章节名，减少逐字等待 |
| 注脚 | 副句安静落位 | 提醒已经被证明的做法 |
| 下一镜／结尾 | 进入下一真实主题或保持结束 | 不新增未讲过的结论 |

原文定位框不是突然变成另一个无关品牌。收束前先撤掉临时连接线，保留来源身份直到关系读完；不能为了收尾漂亮提前删除证据。

### ７．３　布局与时长反推

若实测四字行宽256，主组宽96＋28＋256＝380，图标中心相对画心为−380／2＋48＝−142；最终图标左770、文字左894、右1150。若中文实排宽度不同，重新推导，不能继续沿用上游−90.5。

图标让位与标题出现可以轻微重叠，但标题完整之后才进入低权重副句。最后一项位移结束后留真正阅读段，期间不再环绕、扫描或呼吸。纸角纹理可以静态保留，阴影只服务与纸面背景区分，不把一个二维符号做成浮空金属。

收束音来自一次轻纸张折合／合页感，是否采用取决于实际风格；不要加发布成功音，章节身份不是软件状态。真实旁白、字体、图形、原创实现与正常速度观看均待验证。

## ８．失败诊断与通过条件

| 失败 | 修正 | 可观察的通过证据 |
|---|---|---|
| 名称改长后整组偏右 | 重测字宽并同算shift／行左缘 | 最终完整组合光学居中 |
| 标志跟大环继续转 | 分离演出环与标准资源层 | 标准标志方向始终正确 |
| 白O描述成实心但画面是环 | 按真实资源描述／重新设计 | 文档、形态与动作一致 |
| 停止后残影还挂着 | 按实际速度衰减并核末段 | 稳定身份没有多重轮廓 |
| 小图标过冲像果冻 | 降低余量或采用单段减速 | 停止服务收束，不再制造玩具感 |
| 标语跟主名称同样强 | 降字级、延后整行出现 | 第一眼先读身份，第二眼读注脚 |
| 声称0.7全词完成，最后字仍糊 | 区分启动与结束，按末字符算 | 名称完整后有足够阅读时间 |
| 片尾身份遮掉未读的实际结果 | 先完成真实结果阅读 | 教学认识成立后再进入收束 |

Storyboard需交代标准身份资源、完整态排印、收束母题、形态交接、组合宽度、最后完成通道及下一镜。静态、全速、声音与品牌规范分别核对；本文不宣称原创镜头或商用成片已验。
