# 三行霓虹词墙：让明暗轮唱组织持续运动

本镜用三行反向滚动的短词建立持续流动，再把亮度按相位轮流交给一行。字墙不是让观众同时读三段正文，而是复现已经理解的主题词，作为结尾余韵。它适合短词回顾和音乐段，不能替代教程结论，也不应让滚动词与长旁白争夺阅读。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/outro/neon-triple-marquee.md)、[NeonTripleMarquee.tsx](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/outro/neon-triple-marquee/NeonTripleMarquee.tsx)、[官方演示](https://vincentwei1021.github.io/video-shotcraft/media/neon-triple-marquee.mp4)，另读 [Polish](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Polish.tsx) 与 [Look](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Look.tsx)。固定卡已核验，main代码、当前媒体各自作为证据，不宣称同版执行。

本文分**原卡给定、源码可见、抽帧可见、制作推导**。样片1920×1080、30fps、150帧、5秒，无音轨，查看16帧。未正常速度完整观看、运行上游、取得原卡提到的ClickUp原片或实现原创镜头。案例数值不替代 [质量规则8.6](../../../docs/VIDEO-PRODUCTION-RULES.md)。

## １．先确认三词是不是观众已经知道的东西

| 使用任务 | 成立条件 | 常见错误 |
|---|---|---|
| 教程步骤的简短回顾 | 三词各自对应已经展示的动作 | 只喊三个抽象词，没有实际内容 |
| 主题余韵／结束铺垫 | 只读短词，音乐或留白为主 | 一边读长段旁白，一边追滚字 |
| 品牌调性表现 | 词、颜色与介质统一 | 为用三色霓虹硬改原有风格 |
| 数据／命令／细节解释 | 通常不适合 | 内容不停出画，无法回查 |

**制作推导**：三词是回顾索引，不是新知识。若在片尾第一次出现“验证”，此前却没有验证过程，词墙不能补足事实。最后是否需要这类高能余韵，按当前口播情绪决定，不照抄原卡“发布会规格”给所有教程加码。

## ２．静态美术：一面有承载体的词墙

### ２．１　字形和排版密度

**源码可见**：286px窄体、800字重，优先Avenir Next Condensed，回退DIN、Arial Narrow、Impact；三行顶28／318／608、行距290，只有很小的垂直余隙。整个墙面宽2900，居中超出1920视口，避免斜拍露边。

三行不是彩色实心大字。文字填色透明，以描边构成灯管；分隔用空心菱形，尺寸与笔画同属一层。词距以字号0.36倍加菱形占位组成，宽度需要实际测量。不同字体的窄度直接影响一个词在画面里出现几次，不能用字符数估计代替实排。

**抽帧可见**：三层大词几乎占满墙高，四边自然截字；亮行明显前出，暗行仍能辨结构。最终不再有标题或按钮，观众只记住三词。这样的裁切适合熟悉短词，不适合必须从头完整读的中文句子。

### ２．２　蓝黑砖墙与湿地面都是程序舞台

墙色`#0a0b14`，砖纹为300×120的SVG线条平铺，亮度只有4%白；不是实拍砖墙。三色分别冰青`#38d9ff`、洋红`#ff3d9a`、琥珀`#ffae34`，热芯用各自近白色。墙面溢光随亮行强度增减，使砖缝在受光区更可见。

墙脚y900，下方深色反光带与细接缝，仅最下行有翻转、3px模糊、渐隐的文字倒影；另外三行各有较弱到较强的地面色池。墙与地面都位于同一斜拍平面，并非真实互相垂直的三维地面；湿地面是一种图形舞台近似。

**制作推导**：若需要真实建筑空间，应另建墙／地面几何和反射投影，不能把这套平面镜像当物理正确。若只要风格化词墙，当前近似可用，但不要在文案中宣称实拍、真实灯光或真实反射。

## ３．霓虹不是一层发光描边

**源码可见**：每行分三组：

| 层 | 当前参数 | 视觉职责 |
|---|---|---|
| 暗态玻璃 | 6px描边，同色30%×glass | 不通电时仍保留三行结构 |
| 通电管体 | 6＋4lit，最多10px | 形成有厚度的彩色管 |
| 热芯 | 2＋1.8lit，最多3.8px | 近白细线提供热亮中心 |
| 管体辉光 | drop-shadow约3—9／14—36／40—90px | 近、中、宽三层溢光 |
| 墙面受光 | 弱基础光＋0.55lit | 把光源与承载墙关联 |

虽然注释有“双层辉光”的说法，当前filter实际连续串接三次drop-shadow。串联可能扩大明亮范围和成本，不等于三层物理光。地面反射用cheap分支省去大辉光，但仍有管体与热芯，不能把它写成只画一条线。

**制作推导**：暗态与亮态都要审查。暗态太低，另两行消失，只剩单行广告；亮态太强，字芯被泛光吞掉，三个词都像光带。先确定管宽和字内空间，再调辉光，别用90px软光掩盖字形错误。

## ４．无缝横滚：复用单位必须包括词、间隔和分隔符

单位宽`wordW＋2×GAP＋dotW`，dotW为字号0.42倍。副本各自绝对定位在i×unitW，偏移由frame×speed对unitW取模；上、下行向右，速度9px／帧，中行向左11px／帧。在30fps下，墙坐标速度为270／330px每秒，透视后的屏幕速度还随位置改变。

副本数量按`ceil(2900／unitW)＋3`，不是原卡表述的1920视口公式，因为需要覆盖更宽的斜拍墙。回绕时不是把一张图突然拉回原位，而是重复纹理在相同空间周期内置换。

### ４．１　测宽与字体加载决定是否真的无缝

**源码可见**：有DOM时用canvas测字宽，再加字数×字号×0.02近似字距；无DOM时按字数×字号×0.6估宽，结果写入Map缓存。没有等待字体就绪或在字体变化后自动清缓存的逻辑。

**制作推导**：真实渲染应在最终字体可用后测宽；回退字体测出的宽一旦被缓存，之后正确字体载入也可能继续错。完整单位还要计入末尾字距、菱形与外发光包络。至少检查一次回绕前、回绕帧、后一帧，不能只看中间流动。

如果只是五秒中没有走满一个单位，眼前没跳也不能证明循环无缝；需要对实际重复边界另做检查。不能为测试循环而覆盖正在使用的预览。

## ５．轮唱节奏：三行共用一个42帧时钟

### ５．１　稳定阶段的相位关系

18起计算每行相位：`((frame−18−14i) mod 42＋42) mod42`。每行持续窗口16帧，起点错14，所以几何时间槽有2帧交接。槽内开头点火系数0.6／0.25／1，升亮用1起3帧out曲线，最后5帧以exit退去。

**制作推导**：这里的“一亮两暗”是视觉主次目标，不是所有时刻严格只有一个图层非零。相位窗、升亮、灭灯和power共同决定实际亮度；开场和尾部还有独立闪光。要验证主次，读取最终lit并看片，不只画三根相差14的曲线。

### ５．２　上电与断电有独立门控

上电序列为0、1、0.15、0、0.9、0.6，六帧后保持1；三行从0／5／10起。12→18全局压低开场亮峰，随后进入轮唱。开场可能多行同时有弱光，不能把稳定轮唱规则硬解释成整个150帧都严格一行亮。

断电从124／130／136依次启动，序列1、0.2、0.85、0.1、0.5、0；最后一行到141已切断主电。关灯阶段另有killFlash，可能暂时与另一行尚在运行的脉冲重叠，这是收尾抖闪，不是主循环失相。

### ５．３　“熄灯hold”仍然滚动

暗态glass最终保留0.75，再乘玻璃层0.3，即颜色alpha约0.225，不是注释声称的0.6。最后一行暗态从140→148还在退弱，因此142—150的“熄灯保持”并非所有亮度早已固定。

词行位移始终用frame，关灯后仍滚。墙面rotateY−17°→−9°与scale1→1.05都用0→150缓动，输出到149；也没有冻结全部相机。正确描述是“通电光退出、暗管继续巡回”，不是静态结束海报。

**制作推导**：要清楚地结束，可让滚速在关灯前平滑归0，并在暗态稳定后留停留；要延续音乐余韵，可以保持暗管慢动，但文档和验收记录需一致。别用静帧截图证明尾部已经静止。

## ６．关键帧观察

实际查看0、5、10、18、24、32、46、60、88、116、124、130、136、141、144、149。

| 帧组 | 抽帧可见 | 审查重点 |
|---|---|---|
| 0—10 | 砖墙与三行依次点火，词从边缘经过 | 是否像故障闪屏，是否能认出三个熟悉词 |
| 18—60 | 青、粉、琥珀轮流成为亮行 | 轮唱方向、反向滚速与字间节奏 |
| 88、116 | 稳态继续，对向流动清楚 | 是否越看越嘈杂，辉光是否吞字 |
| 124—141 | 逐行断电，中间仍有短闪 | 关灯是否有次序，不是整组消失 |
| 144、149 | 暗管与砖墙保留 | 暗部压缩后能否看见结构，末态是否符合结束职责 |

原卡提到约7秒渲150帧是其环境记录，本篇未运行上游，不能当本项目性能保证。正常播放、回绕、频闪观感、字体可用性与音画节奏均待实际验证。

## ７．原创演绎：回顾“观察、比较、判断”三个已完成动作

以下为**制作推导**，未实现。前文确实展示了一组图像的观察、同条件对比与最后判断，本镜只做回顾。若前文没有完成这些步骤，先补内容，不靠词墙补步骤。

### ７．１　先排三个词与真实图像痕迹

将三词改为“观察”“比较”“判断”，优先用适合中文的厚实黑体轮廓，不能假设Impact能提供正确中文。单词先试200px，行距250，画面上下留更大空间；背景改灰蓝`#141b21`，灯色统一低饱和暖白，当前行以亮度和芯线宽度区分，保留低权重深青作边界。

每行旁只保留一个前文已出现的图像局部，例如观察用纹理、比较用同位置分割边、判断用实际选定结果。它们是静态内容痕迹，不再加三段视频同步播放。文字是当前焦点，真实图像证明回顾对应过什么。

### ７．２　完整调度与收尾

| 阶段 | 画面 | 认识 |
|---|---|---|
| 接前镜 | 实际判断结果仍可看清 | 结论有事实依据 |
| 第一行 | “观察”短距离经过，亮度接管 | 回忆先看具体细节 |
| 第二行 | “比较”反向经过，相同尺度对照痕迹保留 | 回忆比较要同条件 |
| 第三行 | “判断”进入主位 | 回忆结论来自前两步 |
| 结束 | 三词速度减到0，统一暖白而不全量强亮 | 三步关系可静态复述 |
| 下一镜／片尾 | 保留实际最终结果，低权重身份出现 | 学习结果先于装饰收场 |

这里不必42帧循环几遍，三个词各获得一次完整关注就可结束。词行方向可以借用，但读词时间由真实中文长度和旁白决定。若还在口播解释，直接采用稳定三行版面更合适，不强上持续跑马灯。

### ７．３　实现与声音验证

用实际中文字体测宽，给每个单位加入同样的图像片与间隔，计算复用宽度；图像片和词是一个整体，不各自漂移。若仅一次经过而非循环，删除不需要的取模机制，用明确起终点更易设计减速。

暗底材质可用轻纸纹或低对比平面，不一定砖墙。没有真实反射场景就不加湿地倒影。停留时撤掉高频点火，避免知识总结变成夜店灯牌；结束前让最后一行完整进入画内，不只留下半个字。

声音可以三次轻强调对应三个认识，但不机械一字一拍；第三次之后让人声完成结论，再收环境。原演示无音轨，不能照原卡的音乐段想象已经听过。实际字体、素材、原创实现和正常速度试听均待验证。

## ８．失败诊断与通过条件

| 失败 | 修正 | 可观察的通过证据 |
|---|---|---|
| 三行都强亮，像灯牌故障 | 检查最终lit与开关门控，压副行 | 全速有清楚的主行轮换 |
| 只做透明度，像普通彩描字 | 分开玻璃、管体、芯与墙受光 | 暗与亮有材质差别，字形仍清楚 |
| 回绕突然空一截／词距跳 | 字体就绪后测完整单位，加足副本 | 边界前后连续，无布局跳变 |
| 斜拍后远端中文挤成团 | 减倾角、减字数、改字重与行距 | 当前词完整可辨，不靠猜 |
| 说关灯静止，暗词仍滚 | 决定停止或持续余韵，调整真实状态 | 文档与实际运动一致 |
| 关灯后全黑，三行结构丢失 | 留低权重玻璃管与环境 | 暗部仍可识别词墙而非空屏 |
| 三词与前文没有对应 | 回到真实镜头和内容选择 | 每个词都能指回一个已展示动作 |
| 片尾抢走最终结论 | 减循环或采用稳定回顾 | 观众先记住知识，再记住风格 |

Storyboard要交代三词对应内容、字体、行距、单位宽、运动方向、亮度轮唱、真实关灯与停止时刻、声音和最终结果。静帧、回绕、全速与声音分别验收；本篇不宣称原创或商用成片已通过。
