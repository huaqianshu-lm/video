# 砂化与凝聚：让已读过的长句收束成一个判断

本镜先让完整文字失稳为颗粒状轮廓，再在最难辨认的阶段交接给更短、更重的文字，最后恢复清晰。它能表现“这些信息归结为这一点”，不能证明系统真的提取或压缩了内容。文字语义必须先成立，砂化只能负责一次收束。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/outro/grain-dissolve.md)、[GrainDissolve.tsx](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/outro/grain-dissolve/GrainDissolve.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/grain-dissolve.mp4)，另核对 [Motion](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Motion.tsx)、[Polish](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Polish.tsx)、[Brand](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Brand.tsx)。原卡固定版本已核验，main代码与媒体分别研究，不宣称同版执行。

本文分**原卡给定、源码可见、抽帧可见、制作推导**。样片1920×1080、30fps、60帧、2秒，无音轨；查看16帧。未正常速度完整观看、运行上游或实现原创镜头。参数用于解释案例，不替代 [质量规则8.6](../../../docs/VIDEO-PRODUCTION-RULES.md)。

## １．镜头角色：收束，不是让观众重新读长段

| 内容条件 | 可采用 | 需要另做的部分 |
|---|---|---|
| 长句已经在前镜被读懂 | 由长句回到短结论 | 保留结论所依赖的事实 |
| 品牌发布已被实际确认 | 从宣告收束到身份 | 不凭时间动画生成上线事实 |
| 教观众选中并提取文本 | 只能作为明确的设计示意 | 真实选择、实际命令与结果证据 |
| 第一次展示陌生长句 | 不宜用2秒完整效果代替阅读 | 先留稳定清晰的读取窗口 |

**制作推导**：原演示开场干净字到约8帧即开始砂化，只有约0.27秒。它可以接已经建立的发布句，不能独自承担首次读完长句的任务。换成长中文更不能照搬2秒，首先把阅读与动效分开。

与普通淡出换词的区别，是颗粒化打断旧轮廓，再将焦点交给更强的新轮廓；与真实粒子字变形的区别，是大部分效果来自图像滤镜和两层文字交叉，而非每粒对应一个字形采样点。

## ２．完整静态画面：一句话到一个更强的视觉中心

### ２．１　实际尺寸要乘viewBox比例

**源码可见**：SVG viewBox640×360，直接输出1920×1080，1单位等于3输出px。长句字号26即78px，终字44即132px；原卡数值中的26／44不是最终输出像素。两者分别基线y191／198，即573／594，字面中心并非完全重合。

选区框左128、顶148、宽384、高62，输出384／444／1152／186。长句带大致覆盖x140—500，四角HUD则在88／552、96／264，左右中线短划在52—76、564—588。内容落在中心宽带，周围有明显暗部，不是满屏白颗粒。

**抽帧可见**：开头为带花括号的整句，中段形成横向白砂带和选区，最后是更粗、更大的小写字标。最终字标比长句更强，但常驻HUD仍在四周；“选区撤掉”不等于所有辅助结构都消失。

**制作推导**：长句和短结论先各做静态排版。它们的共同视觉中心应按实际字面修正，不只看text-anchor。英文基线换中文后位置、光学重心与字宽不同，字号和粒子落点范围都要重新测。最终结论无光晕时也应有完整字形和留白。

### ２．２　冷白光与暗场建立层次

环境`#0a0b0e`，背景柔光在中上、暗角0.6；常驻括角深灰、圆点更亮，辅助线弱于文字。主体浅灰白，最终纯白，滤镜bloom偏冷蓝，只有一个主色域。

紧光和宽光在同一滤镜链内从处理后的字形生成。紧光标准差1.2＋1.6glow，输出约3.6—8.4px；宽光5＋6glow，输出约15—33px。颜色矩阵分别控制蓝白色与透明度，最后与核心合并。它们不是额外复制一团居中径向白斑。

**制作推导**：若用暖纸／墨字，应重新设计介质。黑墨散开不应继续发冷白光；粉尘、烟、油墨和数字噪声有不同尺度与边缘。保留“失稳—交接—凝固”的动作关系，材质按内容改，不靠一套SVG滤镜包打所有场景。

## ３．滤镜链实际做了什么

### ３．１　纹理置换，不是真实碎字粒子模拟

**源码可见**：fractalNoise两层噪声作为位移图，频率0.9＋0.4burst；文字先经过位移，再1.1burst(1−lock)模糊，再合成紧、宽bloom。位移系数52burst(1−lock)，数值在viewBox坐标中，峰值尺度相当于156输出px；按位移图通道范围，实际单轴偏移还由噪声值相对0.5决定，不能把156当每点必走距离。

频率高意味着细碎轮廓，低频更像整片被扭曲。52不是“粒子速度”，1.1不是最终屏幕1.1px。把设计坐标参数直接搬进原生1920 SVG会得到另一种粒度。

### ３．２　seed不是每帧都变

时间t＝frame／59，seed＝floor(46t)。整个输出seed0—46，有47个状态，部分相邻输出帧复用同一噪声；变化约23次／秒，非每帧一幅新图。固定公式确保不同渲染可复现，不等于每粒有连续速度。

**制作推导**：改变总帧数却保留46，噪声更换速度会随时长改变。要保同样手感，应按目标时间设计seed更新率，再正常播放检查跳变；不要把提高seed频率误当增加真实物理细节。字形已经恢复后，seed即使变化，位移为0便不再改变核心轮廓。

### ３．３　150粒游离砂只是辅助运动

额外砂粒有固定种子初位、外吹方向、终点和微错峰。起点随机分布在长句带，终点随机落在短标带，**不是从字形像素提取，也没有保证落到真实笔画内**。粒子在归拢后熄灭，真正完整字形由另一层文字恢复。

它们用inQuart吸回，末段加速；抖动与seed节奏同源。图像置换提供密集细砂，游离圆点提供可见的向心流动，两者缺一时观感不同。不能把演示描述成“所有旧字颗粒精确重组为新字”。

## ４．选区框与文字交换如何交接

框随burst从20%横向展开到满宽；斜纹34单位间隔、45°方向，四角为错位5×5方块。撤场0.55→0.64时缩回一部分并降透明度，不是缩成一个点；0.64之后不再渲染。

长句opacity1−cond，短标opacitycond，共用同一滤镜组。cond0.60→0.71用inOutCubic，把换文字放在最不清楚的砂化阶段；新字还以1.06逐渐压实到1。它是有遮蔽的文字交叉，不是字体拓扑变形。

**制作推导**：两句必须指向同一主题，且长句到短句的逻辑真实。选区含义会让人联想到“提取／编辑”，若视频不讲选区或文字工具，可以去掉框，只保留语义收束。不能因为原效果有选区，就暗示真实软件正在执行提取。

## ５．完整时序与余波

| 通道 | t区间 | 按59帧归一化换算 |
|---|---|---|
| 砂化建立 | 0.13→0.28 | 约7.67→16.52 |
| 选区撤场 | 0.55→0.64 | 约32.45→37.76 |
| 长短文字交叉 | 0.60→0.71 | 约35.40→41.89 |
| 置换凝固 | 0.68→0.90 | 约40.12→53.10 |
| 游离砂渐灭 | 0.66→0.80 | 约38.94→47.20 |
| 光痕结束 | 到0.92 | 约54.28 |
| 辉光回落 | 0.88→1 | 约51.92→59 |

**源码可见**：文字交叉与凝固有交叠，不是换字全部结束才开始恢复轮廓。短标在整数42已完全替换，位移要到54才归0，细光痕55才结束，辉光直到最后帧59还在回落。

glow＝burst×0.3＋cond×0.7−settle×0.45，最终是0.55，不是0.45；0.45是扣减项。峰值附近先有更强光，再留下柔光。不能把原卡“回落0.45”误读为最终亮度。

**制作推导**：2秒成片几乎没有严格稳定的完整终态阅读段。短品牌已熟悉时可作结束重音，新的知识结论必须延长清晰终态。结尾若要完全静置，需要让滤镜、粒子、光痕和背景时间都符合意图，不能只锁定文字opacity。

## ６．关键帧观察与可审查范围

实际查看0、7、8、12、17、25、32、35、38、40、42、47、48、54、55、59。

| 帧组 | 抽帧可见 | 审查重点 |
|---|---|---|
| 0、7 | 整句清晰，外围HUD较弱 | 是否早已读过；首次阅读时间是否不足 |
| 8—17 | 字边失稳成细砂，选区展开 | 粒度是否细腻，是否只是模糊文字 |
| 25—38 | 横向噪点带、选区逐渐退出 | 中段是否只有无意义等待，旧轮廓是否仍可辨 |
| 40—48 | 短字标成为主体但仍有砂化软边 | 换字是否露双行，重心是否跳 |
| 54、55、59 | 字体清晰，辉光趋弱 | 最终字形和实际阅读是否成立 |

本篇不认证正常速度下换字完全不可见，也不认证不同浏览器滤镜性能。使用真实字体和目标渲染环境后再查位移边界、filter裁切、压缩噪点和音画卡点。

## ７．原创演绎：从例子回到“名称不等于格式”

以下为**制作推导**，未实现。教程前文已通过真实文件说明名称与扩展名的区别；本镜只收束认识，不凭砂化发明文件已经转换格式。

### ７．１　先排清楚结论画面

前镜保留一个真实文件名和扩展名局部，观众已看懂差别。收束画面用暖深灰`#1a1916`、纸白`#eee9df`、浅铜`#b79a71`的低饱和语言；中央“名称不等于格式”先用80px中文中黑实排，关键词“格式”可用细铜色下划线，不配霓虹HUD。

旧句“改名字，并不自动改变文件内容”只在前镜读过后进入短暂失稳，不要求本镜从头再读。两句均保留正确含义，不换成夸张的“格式已转换”。颗粒只沿文本附近薄带出现，最终结论比旧句更简洁、更清晰。

### ７．２　完整调度

| 阶段 | 画面 | 认识与证据 |
|---|---|---|
| 接前镜 | 同一真实文件名与扩展名还在 | 结论有具体对象 |
| 收束准备 | 已读旧句稳定，文件小标退到角落 | 从例子回到判断 |
| 失稳 | 文字边缘短暂颗粒化，不放选区手柄 | 不冒充软件正在提取 |
| 凝聚 | 新结论在同一光学中心建立 | 字数减少，语义保持 |
| 阅读 | 颗粒与光痕全撤，清晰字形固定 | 允许完整读一次 |
| 下一镜／结尾 | 进入实际“查看格式”的正确方法，或结束章节 | 不把动画当文件转换结果 |

如果前文并未证明名称与内容差异，应先补真实例子，不以更好看的结论补证据。若整片在这里结束，保留真实文件身份的小型提醒即可，不强行变成品牌口号。

### ７．３　按中文重新设计空间与时间

中文8—12字的轮廓、笔画密度和字宽与15个拉丁字符不同，先测字框再定滤镜扩展。原案例最高156输出px位移可能毁掉汉字识别，可以降低到只扰动字边；参数要通过中段帧观察重新确定，不能把52当默认。

游离砂终点若不是按新字形采样，就让它们在结论清楚之前灭掉，不宣称精准重组。两句共用字面中心，必要时分别调整基线；用完整字体创建最终字，不在结尾用另一字体“补清晰”。背景装饰为零也可成立，重点是结论本身有准确内容和良好排版。

先让最后一个位移、砂粒、光效全部结束，再给新结论稳定读取窗口，时长按真实旁白。一次轻收束音足够，不为每粒配音；配音应完整说出知识结论，不能只靠画面闪一瞬。当前没有真实素材、字体实排、声音或原创实现验证。

## ８．失败诊断与通过条件

| 失败画面 | 修正 | 可观察的通过证据 |
|---|---|---|
| 一开始就砂化，旧句来不及读 | 将阅读放前镜或延长起始态 | 观众知道被收束的是什么 |
| 颗粒像大块抖动／糊字 | 核viewBox倍率、噪声频率、位移和模糊 | 中段有细碎边缘而非整块扭曲 |
| 长短词重心跳位 | 用实际字框重排基线和中心 | 交叉时主体不突然上下／左右跳 |
| 说全部粒子成字，但砂只随机落带 | 明确滤镜交叉机制，或真按字形采样 | 描述与实际方法一致 |
| 接管后框还在像未完成编辑 | 提前撤临时选区，区分常驻HUD | 清晰结果有明确终态 |
| 最终辉光糊掉笔画 | 降bloom、核核心字形与压缩 | 无光效时与有光效时都可读 |
| 没有清晰终态阅读时间 | 从最后光效结束之后重排停留 | 正常播放能读完整短结论 |
| 变化暗示实际提取／转换成功 | 补真实过程，调整标签与旁白 | 视觉收束不产生虚构产品状态 |

Storyboard应交代长句已被理解的依据、短句逻辑、字形中心、滤镜坐标、选区语义、凝固后的稳定时间与后续真实操作。静帧、全速、声音、性能和真实内容分别验收；本文不宣称商用成片已通过。
