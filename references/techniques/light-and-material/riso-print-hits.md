# 双色套印错位与归准

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/effects/riso-print-hits.md)、[RisoMisregistrationHit](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/effects/riso-print-hits/RisoMisregistrationHit.tsx)、[misregistration-hit 官方样片](https://vincentwei1021.github.io/video-shotcraft/media/misregistration-hit.mp4)。下文区分原卡给定、准确实现、官方样片抽帧观察和原创制作推导；抽帧每条16幅，未完整正常速度观看、试听、运行上游或实现原创镜头。参数用于解释原例，不能直接作为当前视频默认值。

## 1. 介质决定冲击语言

这是一种印刷版的命中强调：同一标题分成两块油墨印版，错位震荡后突然套准。适合纸墨、海报或印刷主题；不应用于真实软件故障诊断，避免观众以为输出真的失真。它与RGB色散最大的区别在于纸上正片叠底的混色和局部印版，不是把全屏分离红绿蓝。

## 2. 海报本身怎样成立

原例再生纸#f3eee2，粉#ff4fa3与蓝#1f5fc4，左对齐300px超粗两行大标题，右侧半调太阳提供第二个大形。顶部细版记、底部三栏小信息与横线构成印刷网格；四角套准标维持稳定参照。字形、网点和纸纹已经足够丰富，不需额外玻璃高光。

标题只用两版同字形multiply叠加，重合后深紫、分开后粉蓝边可辨。原文说“互补色最好”是选色建议，实际这组并非严格色轮互补；应以分离时可辨、重合后足够深、纸面反差合理为准，不能机械求180°色相。背景太阳和信息栏始终套准，只有标题会错，介质语义因此明确。

半调不是均匀点阵：按到圆心的距离算tone=1−d^2.4，点半径随√tone变化，边缘点渐小。点网格与输出分辨率应一起检查，过细会摩尔纹；不能只在放大的静帧看纹理。

## 3. 撞入、分版、硬套准

准确实现120f，20–28f标题从右侧加速撞停，28–71两版反向震荡，72硬套准，72–76短缩放脉冲和印章，之后为阅读段。纸面、版记先在场，太阳0–16擦入，给动作一个稳定世界。

| 参数 | 原例关系 | 不能误用之处 |
|---|---|---|
| 位移 | 单版AX20/AY8，反向双版 | 总分离约40/16，不是单版40；需按新标题实际大小重算 |
| 震荡 | A·cos(2πt/18)·exp(−t/60) | 包络与瞬时cos值不同，“约11px”是近似残量，不能说每帧固定残差 |
| 归准 | f72直接设0 | 保留可见残差到这一拍，才读成套准；不是渐淡到无 |
| 句号 | scale1.03→1约4f，圆章1.5→1 | 印章应有实际语义，不能给未审核内容盖“通过” |
| 取景 | 标题基线和印版原点一致 | 两版字距、字重、抗锯齿方式不同会永远套不准 |

原例负字距使F与T笔画接近，单字margin再收.01em消发丝缝；这是该英文词的光学校正，不可整段中文一律压字距。源码尾段仍极缓推近，称稳定海报即可，不夸为全段逐像素不变。

## 4. 官方帧观察

16帧可见粉色太阳、蓝色版记先成立，标题撞进后露出粉蓝双边，随后硬回成深色标题并出现圆章。页面只有标题错位，背景稳定。等距帧不足以证明8f撞入或硬归准那一下的手感，纸张与印刷拟音未验证。

## 5. 原创制作推导：解释为什么两层图像要对齐

内容目标是讲“比较前后图时应保持同一取景”。先做最终画面：同一照片的前后两层在真实轮廓上配准，一旁有固定取景标记。若讲真实印刷，可用真实双色版样本；若只是类比，则明确双色标题是开场比喻，不能把它当真实配准算法输出。

开头短标题用两版错位表达“不对齐”，右侧换成与主题有关的真实轮廓小图，不搬原太阳。归准时固定四角标保持位置，标题合一；随即标题退到小节位置，真实前后图接管。两图先以同尺度叠合展示重影，再对齐同一主体边缘，留足观察窗口。

下一镜保持同一裁切和缩放，用分割线查看处理前后的实际差异。观众应把“不对齐会误判”落实到图像观察，而不是记住一段粉蓝抖字。

## 6. 失败修正与通过条件

- 错位读作阴影：增加两色可辨性与相反位移，检查总分离相对字高的比例，不盲加模糊。
- 变成屏幕故障：只错标题印版、使用multiply、保留稳定纸底；不要screen叠整屏。
- 套准仍有毛边：查两版排版与字体加载，先静态叠合验证，再调运动。
- 全画面纸纹闪烁：用固定随机纹理，检查缩放取样，别每帧换颗粒种子。
- 印章暗示已审核：换成描述动作的中性标记，审核结论必须来自实际证据。

设计通过应有完整海报构图、可辨分版、明确归准和后续真实对齐示例。正常速度检查冲击是否过长、字能否读完，声音与原创实现另验，源例次数限制不作为项目新默认。

## 原创镜头的关键画面调度

下表是上述原创应用的设计草图说明，不是已渲染关键帧，也不代表动态已验。以实际内容、字体与画幅重排，检查每个状态及状态之间的完整运动包络。

| 状态 | 画面安排 | 观看焦点与接棒 |
|---|---|---|
| 印刷底 | 纸纹固定、取景标稳定、真实主题轮廓在右侧 | 两色与原纸对比成立，非全屏RGB故障 |
| 错位 | 短标题的双色版反向分离，背景保持配准 | 眼睛追同一字形而非更多装饰 |
| 归准 | 标题合一后，真实前后照片以同取景叠合 | 固定标记帮助判断对齐，不盖无依据审核章 |
