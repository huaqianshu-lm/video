# 四角准星收拢点名

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/effects/fui-hud-moves.md)、[ReticleLockOn](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/effects/fui-hud-moves/ReticleLockOn.tsx)、[reticle-lock-on 官方样片](https://vincentwei1021.github.io/video-shotcraft/media/reticle-lock-on.mp4)。下文区分原卡给定、准确实现、官方样片抽帧观察和原创制作推导；抽帧每条16幅，未完整正常速度观看、试听、运行上游或实现原创镜头。参数用于解释原例，不能直接作为当前视频默认值。

## 1. 点名之后必须有事可看

它让观众从整页中找到一个目标，适合画面仍在流动时点名。不是分析算法证明，也不是检测成功标志。准星落定后应出现可辨认的数据、操作或变化；若只是框住一张普通卡再切走，观众只学会“看这里”，没有获得知识。

## 2. 目标、角标与版面层级

原例是六块图表的浅色dashboard，目标为首排中卡。四个强调色L角以白衬描边从复杂底图中分离，中心细十字提供方向，锁定后外部仅轻压暗，目标仍保留原内容。顶部标签用深色胶囊、状态点、卡名与等宽编号组合，既不是红箭头，也不应扩成遮住原表头的横幅。

角标应在目标外留呼吸距。原例bbox(808,108,524,454)，PAD16，ARM58、THICK5。正文、角标、标签分别承担内容、指向、命名三个角色：只有角标使用强调色，表格本身不需要整体发光。标签靠近目标但避开上方窗口栏，缩小画幅时先查空间，不把标签挤成不可读细条。

## 3. 实现关系与卡片概述差别

原卡说“咬合帧标签同帧”，准确实现有意晚2f：锁定46，标签48–58；应以具体版本说明其跟随，而不能在评审时把2f差直接判为bug。目标高也已从旧425修正为真实454，否则下角咬不住。

| 通道 | 准确实现 | 如何重新设计 |
|---|---|---|
| 飞入 | f14–24，整框由右下(1100,620)移到目标 | 不是四角各从四方向扑入；方向选择要避免越过正在读的字 |
| 收缩 | f20–40从2.2到.94，40–46回1 | 与飞入重叠4f，消除到位再缩的机械停顿 |
| 咬合 | f46后角标额外向内6px再回，4f左右 | 只是一次确认，不能持续脉冲 |
| 目标受光 | 锁定后3f亮到.55，10f收至.28 | 裁进真实圆角；不能拿罩层盖掉数据对比 |
| 聚焦 | 外围暗约.10，整体相机1→1.035 | 仍保留其他卡作为空间参照，不变成孤立PPT卡 |
| 四角 | 目标中心±半宽高，sx/sy镜像 | 改bbox需四角共用，不能分别手调到“差不多” |

整体框移动与框大小是两个通道，目标自身不跟着四角弹。若目标也在运动，bbox应随它的同一变换计算；固定屏幕坐标会让准星滑离。速度拖影只用于飞入，锁定后边缘应清楚。

## 4. 官方抽帧观察

16幅帧可见全页静立，角标从右下大范围移进，随后收拢到中卡，上方深标签出现，末态目标周围较暗。四角没有成为完整厚边框。抽帧能验证目标选择与末态几何，不能证明10f飞入的体感，也不能确认声响与锁定同步。

## 5. 原创制作推导：在真实表格里找到单位

内容目标是“看数值前先核对这一列的单位”。先设计最终画面：真实表格顶部的单位和下面两行数字同框，四角只围住单位所在的表头区，不框整张表。单位文字必须可读，必要时先取局部镜头而非在整页上画巨大准星。

建立时保留相邻列，让观众知道为什么可能混淆。光标不同时飞入；四角收拢完成后，表头下第一行对应值轻微提高对比。标签写具体单位，例如“单位：千元”，且必须来自真实表格，不能用通用“LOCKED”代替解释。原例中心十字若挡住字，删除或改放外侧刻线。

接着让单位和数字的对应关系成立：同一列用细短连接或局部背景，而非一连串扫描特效。下一镜保持这列的空间位置，展示换算后的实际值和换算依据。准星可以退去，表头身份仍保留。

## 6. 失败修正与通过条件

- 角标扑进来后框错区域：测真实bbox及所有祖先缩放，叠合锁定帧的四角与目标边界。
- 看着像军事模板：减少刻线和编号，只保留有用途的四角；若当前美术不容纳该语汇，改安静指示。
- 锁定瞬间数字被闪白淹没：减受光峰值或改局部细边，优先保留真实信息对比。
- 标签与卡名重复，却没解释内容：标签应给单位、条件或关键差异，不再复述卡标题。
- 运动目标跑出准星：把目标与角标放在同一世界，或使用同一投影更新；不能靠加大框掩盖漂移。

设计证据应包括目标为何值得看、锁定时的边界、标签不遮挡、后续真实信息。每次使用承担不同任务；不把原卡次数和毫秒当本项目强制默认。动态、声音与完整阅读仍待实际成片检验。

## 原创镜头的关键画面调度

下表是上述原创应用的设计草图说明，不是已渲染关键帧，也不代表动态已验。以实际内容、字体与画幅重排，检查每个状态及状态之间的完整运动包络。

| 状态 | 画面安排 | 观看焦点与接棒 |
|---|---|---|
| 定位前 | 真实表格保留相邻列与列名，单位在可读尺度 | 观众知道几个候选，四角暂未成为主角 |
| 收拢 | 角标从空白方向进入，只围表头单位，标签避开数字 | 唯一主运动是框收拢，光标不抢同一拍 |
| 解释 | 单位与首行数值形成一组，邻列仍是空间参照 | 标签说具体单位，后续换算有依据 |
