# 流动、定格与圈注：停下的是现场，继续的是解释

## 1．镜头要解决什么

连续流动能建立“还有很多内容”，但不能让人看清某个对象。定格圈注把同一对象从流中留下来，解释为什么值得注意，再让它带着一枚可追踪的标记回到集合。重点不是停顿本身，而是**停住之后给出有根据的认识，解冻之后保留这次认识的归属**。

适合评审、过程讲解与素材检视。若原对象完全不需要运动，直接给清晰近景可能更有效；若运动包含需真实判断的行为，如碰撞、运动轨迹或软件响应速度，冻结后的演示不能冒充原始实时表现。教程中的暂停是讲解层操作，不应伪装成产品功能。

来源：[固定版本原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/rhythm/speed-ramp-freeze.md)、[FreezeAnnotateReal.tsx](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/rhythm/speed-ramp-freeze/FreezeAnnotateReal.tsx)、[官方 freeze-annotate 演示](https://vincentwei1021.github.io/video-shotcraft/media/freeze-annotate.mp4)。卡名是技法组，实际样片名不是 `speed-ramp-freeze.mp4`。读取了纹理布局以及 `SpeedBlur`、`velocity`、`TextReveal` 等辅助实现。

原卡给定、源码可见、抽帧可见与后文制作推导分别理解。本次已查看 158 帧／30fps 演示中的 0、30、44、45、49、55、64、73、89、96、104、111、112、123、134、157 帧；未正常速度观看、未试听、未运行源工程，原创部分尚未实现。圈注不是上游系统里真实保存的评论操作。

## 2．先设计暂停后的完整画面

原例采用冷白展台与钴蓝马克笔，重点卡片为白底文字卡。定格后的构图有三层：中央清晰对象，左右退弱的同类，右上批注。左上时间码和外围取景角说明“现在进入讲解暂停”。没有把每个空位都放上说明卡。

| 主体 | 第 5 索引位对齐画面中心，目标纹理 `card9.png` | 通过文件身份选对象，不能只依赖随机序号 |

Stage 主光在 0.5／0.1，底部填光在 0.5／1.0，horizon=0.86。接地带位于目标卡下方，低对比冷灰椭圆渐变。柔光和阴影围绕同一明暗关系服务清晰度，不把白卡照成没有边界的白块。

抽帧可见：初段两侧卡片有横向拖影；f55 目标独立清晰，旁卡退弱；f64 圈基本完成，f73 箭头与批注正在建立；f89／96 圈、署名和完整批注同时存在；f111 主要墨迹已退，蓝色图钉留在卡角；f134／157 目标卡位于左侧，下一卡居中。中段构图不只检查圈有没有画完，也要检查箭头、卡标题与批注之间有无遮挡的视线路径。

## 3．时间重映射：不要把定格写成慢慢刹车

源动画是 26px／源帧的匀速左移。输出帧 f 映射为源时间 s，轨道位置 `x=offset−26s`。f≤45 时 s=f；45 之后至 112，s 固定 45；随后用五次 smootherstep 在 22 张输出帧里前进一张卡的距离。

设 `u=clamp((f−112)/22,0,1)`，`S(u)=6u⁵−15u⁴+10u³`，则解冻段 `s=45+(652/26)S(u)`。端点速度为零，既从静止启动，也落定静止；不是一直加速离开。

几个量需要按实际算：

- 暂停状态标签覆盖 f45–111，共 67 张输出帧；f112 已显示 LIVE，但几何还在起点，随后开始前进。
- 652／26≈25.08 个源帧，在 22 输出帧里完成，平均源时间斜率约 1.14；峰值斜率约 2.14，画面峰值速度约 55.57px／输出帧。
- 这个解冻只多推进一张卡，**没有追回暂停消耗的全部 67 帧源时间**。“补偿”是视觉节奏与这一段行程的加速，不是严格恢复实时位置。
- 终点目标卡中心 x=960−652=308，卡左缘约 8；下一卡中心为 960。图钉仍属于原卡，不可留在原屏幕坐标。

`velocity` 用前后半帧位置差估计速度。冻结时强制模糊速度为零；其他时刻先扣除 8px／帧，再将余量交给 `SpeedBlur`。该工具以速度方向旋转滤镜坐标，再做单轴高斯模糊；amount=0.3、max=26，标准差低于 0.35 时不挂滤镜。因此“低于 8 就无模糊”只是近似，实际还有工具自身阈值。初段约 (26−8)×0.3=5.4px 标准差。

冻结对象应锐利。不能只把位置停住而保留固定 blur，也不要用多张跨时间纹理叠加造成界面文字染色。新场景若换成真实视频，应同时暂停视频纹理与依赖它的主体运动；只冻外壳、卡内内容继续播放属于另一种表达，必须说明。

## 4．标注的手势、重叠与回收

| 时段 | 源码实际动作 | 设计注意 |
|---|---|---|
| 45–49 | 白闪按 4f 渐退，峰值透明度 0.7 | 原卡／注释写 3f，代码持续到 49 归零；不能直接把两者当一致 |
| 45–55 | 主卡抬起，邻卡退弱；四角用弹簧进入 | 不是所有画面层都冻结，解释层继续动 |
| 54–64 | 10f 描圈 | 先给清晰对象，再落笔；不要圈住模糊内容 |
| 64–70／70–73 | 弧线箭杆，再两翼箭头 | 笔迹指向目标卡右上边缘，箭头方向由曲线末端切线求得 |
| 66–86 | 三词批注错峰上升，每词 14f、间隔 3f | 实际最后词结束 86，不是注释的 78；箭头与文字有重叠 |
| 78–88／84–96 | 下划线、署名显露 | 下划线开始时文字仍在进，不另误排成完全串行 |
| 96–103 | 圈、批注、署名完整且未开始淡出 | 真正全部信息同时满态只有约 8f，原卡长暂停不等于长完整阅读 |
| 104–112 | 墨迹与四角退场；图钉弹入 | 图钉与旧圈短暂共存，把“已评论”交给卡片 |
| 104–116 | 主体抬起／邻卡退弱的 focus 还原 | 比墨迹退场晚 4f，解冻初段仍有轻微恢复 |
| 112–134／134–157 | 解冻移一格，再保留末态 | 末态 24f 是几何保持；Stage 纹理等需另核查，不称绝对像素静止 |

超椭圆不是标准椭圆。x／y 以 cos／sin 的带符号 2／3 次方求轮廓，分别放大到卡片半宽的 1.2×1.03、半高的 1.22×1.03；中心是目标抬起后的中心。路径从 −2.3 弧度开始，画 1.08 圈，沿程收半径 4%，再整体转 −3°，形成有重叠而不机械闭合的圈。

路径用 `pathLength=1` 统一描画进度。静态 seed=11 的噪声位移 scale=6 给边缘粗糙感，**不是每帧随机抖动**。如果将 seed 逐帧更新，笔迹会在读字阶段沸腾，破坏“圈已经画在纸上”的感觉。圈、箭头和下划线共用笔触体系，但批注文字保持清晰。

圈没有贴着卡片边缘，而是留出笔宽与抬起空间。换尺寸后应重新求中心和外包络，尤其检查圈最左／右与邻卡是否误连；不能只按旧 RX／RY 套一张长条图。

## 5．原例的状态不能直接当产品事实

卡片纹理来自上游页面截图；原例的“Ship this first.”、“Marco · design review”及图钉是演示叙事，没有证据说明实际评论被保存到业务系统。教程要说“评论已保存”，应有真实保存结果与同一对象身份的证据，否则写“讲解标记”。

时间码的源码基数为 `30×72`，f0 显示约 `00:01:12:00`，暂停为 `00:01:13:15`；并非注释写的从 `00:00:01:12` 开始。f134 后映射源时间固定，LIVE 标签仍存在但时间码也停在终点。原例提供的是视频演示状态，不是严格真实播放器。底部“0 FPS”表示源画面保持；输出文件仍是 30fps，讲解层还在动。新的教程最好写“画面已暂停”，避免误导。

## 6．原创演绎：在联系表里选出对焦合格的照片

**内容输入。** 使用同一次拍摄的真实照片与原始分辨率，解释“缩略图看着清楚，放大后主体眼睛未必合焦”。先核对实际素材，不能用几张随机图库照片假装一组连续拍摄。此处只给待实现设计，不预设哪张合格。

**先决定结束画面。** 左侧保留带标记的真实候选，右侧为同一照片眼睛部位的 1:1 裁切；两者用细线对应。结论落到可见的睫毛／眼缘细节，不是悬浮一句“这张更好”。下一镜接另一候选的同部位，进行相同倍率比较。

**美术。** 深灰中性检查台减少照片明暗判断偏差；照片用极细浅灰边界，不把原图调成冷蓝。标记只用暖橙，批注用近白。大幅照片占中央，文件名和序号在边缘固定，以等宽样式保持身份；结果阶段右侧裁切窗给足面积，不用几枚小卡并排。外框、线宽与字重统一，禁止把原例钴蓝大圈、白闪、头像、所有取景角一并搬来。

**镜头链。**

1. 联系表横向移动只用于建立同组照片。每张底部保留实际文件尾号，运动中不要求观众读 EXIF。
2. 候选在中央停止，左上切“讲解暂停”。暂停源照片和轨道；若图像本身静态，只需冻轨道，不虚构视频帧号。旁白此时提出“先看眼睛”。
3. 整张照片轻提起，其他照片仅退弱。圈线只圈实际对焦部位，不能圈整个卡就声称解释了对焦。若主体太小，先放大明确部位，再画圈。
4. 在右侧从同一原图提取 1:1 裁切，保留边缘锐度，不用插值锐化制造更清楚的结果。连接线从原图眼部到裁切窗，两个位置由同一原图矩形变换得到。
5. 批注按实际情况写“眼缘清晰”或“焦点落在后方”，短句与证据并存。旁白需要多少阅读时间，就保留多少；不能把圈、箭头、署名做完才剩八帧阅读。
6. 圈和临时连接线淡出，候选角落留下“待比较”标记，而不是“已选中”。轨道再走一格，将下一候选居中；前一个标记随原照片移动。下一镜以同倍率裁切比较，之后才决定保留谁。

**坐标与焦点。** 原图若为 6000×4000，显示在 900×600，眼部原图矩形为 400×300，则缩略图中只占 60×45。这个区域不适合承担细节辨认，需在裁切窗显示真实 400×300 或明确标出的倍率。实际区域必须来自素材测量；上述数值只演示变换关系。画圈与裁切窗不能分别估计眼睛位置。

**声音与时间。** 暂停可配一个轻短提示，圈线只在落笔时配短摩擦声；解冻时恢复移动声床即可。拟音属于输出时间，不跟冻结源时间重复触发。完整速度观看要检查旁白说到“眼缘”时，对应裁切已经可辨，声效不盖住语音。这些是待验设计，不是原样片已经具备的声音证据。

## 7．失败诊断与验收

| 失败 | 具体修正 | 通过画面 |
|---|---|---|
| 停了仍看不清 | 冻结时撤方向模糊，换足够分辨率原图；必要时先近景 | 圈内关键细节是真实纹理，不靠文字代说 |
| 圈完就走 | 从口播与结论字数倒推完整结果态停留，前移署名或移除无用装饰 | 完整证据与短结论有共同阅读窗口 |
| 解冻后标记飘在空中 | 标记挂到对象局部坐标，与轨道共享映射 | 原卡移左，标记仍贴原卡角，下一卡不继承 |
| 停顿像卡死 | 清晰暂停状态加一次克制反馈；不要持续闪烁 | 观众能分清素材停、解释层继续 |
| 快流卡片叠成脏带 | 核查实际速度模糊和节距；优先减速而非增强 glow | 移动轮廓可跟踪，冻结瞬间没有前卡残影 |
| 以标记冒充已保存评论 | 提供真实保存证据，或改名为讲解标记 | 画面状态与产品实际行为一致 |

至少检查运动前／冻结瞬间／完整解释态／解冻中段／下一对象落定。前后对象身份、裁切配准和标记归属都通过后，再正常速度看一次并配口播试听；若静态画面漂亮而实际播放读不完，返回时间分配修改。原卡时长、弹簧和圈线速度不直接成为当前项目默认参数。

相关选择：[作画拍数切换](sakuga-timing-shift.md) 改变姿势更新频率；本篇暂停源时间、继续解释层。两者回答的问题不同，别把“操纵时间”本身当作必须出现的卖点。
