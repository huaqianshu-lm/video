# 列表步进与主题联动：一个时钟组织字、色与场

本镜把一串不同气质的词送进固定阅读位置，每次到站同时改变胶囊、背景和字体。它的清楚来自“同一位置、一次一个词、变化之间有停靠”，不来自换色越多越热闹。音乐段可以连续打拍，口播教程则要让每个词承担实际内容，不能用五次换肤代替解释。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/rhythm/beat-step-list-theme-cycle.md)、[BeatStepListThemeCycle.tsx](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/rhythm/beat-step-list-theme-cycle/BeatStepListThemeCycle.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/beat-step-list-theme-cycle.mp4)，另核对 [Polish](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Polish.tsx)、[Look](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Look.tsx)、[Brand](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Brand.tsx)。固定卡已核验，main代码与媒体各自研究，不宣称同版执行。

本文分**原卡给定、源码可见、抽帧可见、制作推导**。样片1920×1080、30fps、140帧、约4.67秒，无音轨；查看16帧。未正常速度完整观看、试听、运行上游、取得Bear原片或实现原创镜头。案例参数不替代 [质量规则8.6](../../../docs/VIDEO-PRODUCTION-RULES.md)。

## １．选型与职责

| 内容任务 | 可用方式 | 不宜方式 |
|---|---|---|
| 展示多种视觉气质 | 同一命题中改变字形、色与场 | 换几个色就宣称产品支持主题 |
| 复习几种已有类别 | 每次固定焦点，旁边有对应实例 | 只读类名没有真实内容 |
| 音乐段形成短密度峰 | 一组明确拍点，切后归还停留 | 全片一直每0.6秒换词 |
| 具体教程说明 | 放慢每个停靠，允许另镜解释 | 要求观众从快滚列表读长句 |

与 [单次主题切换](../interaction-and-feedback/theme-switch-moves.md) 的分工在于：后者用同一真实内容证明一次变更，这里强调连续多套气质的节奏。与 [选项轮换](../interaction-and-feedback/picker-carousel-feature-cycle.md) 的共同点是固定焦点，但本镜把字、胶囊、场色、角落状态绑定同一时钟。

## ２．先排一个完整句子，而非两组独立元素

### ２．１　左边稳定，右边变化

**源码可见**：固定前缀132px／300字重，右对齐在x428—898；间隔34后，胶囊左932、中心行y520、高156。列表字号132、行距176，文字左996；左右边距64／76。词不同，胶囊宽随实际字宽改变，左边界固定，避免前缀随每拍来回晃。

五词实际字宽记录425／384／540／376／352，胶囊对应565／524／680／516／492。最宽词右缘1612，最短右缘1424；整句不是每一态都严格居中，而是按中位宽560预留位置，稳定阅读支点。

**抽帧可见**：细体前缀与粗体选中词形成强字重对比，选中词坐在有厚度的亮胶囊中，邻行在上下作为列表线索。左侧不再加解释卡，整幅首先被读成一句话。

### ２．２　五套主题不只是五个随机颜色

| 词态 | 胶囊／背景 | 选中字体 | 美术意图 |
|---|---|---|---|
| modern | 骨白`#ece6da`／深棕`#15120f` | 无衬线700 | 中性清楚 |
| playful | 橙`#ff8a3d`／深梅`#1d0e17` | 圆体700 | 圆润、活泼 |
| expressive | 紫`#9d8aff`／深靛`#0f0d25` | 衬线600斜体 | 线条与姿态变化 |
| bold | 绿`#38d690`／深青`#06181a` | 几何700、全大写 | 更强轮廓与字距 |
| yours. | 黄`#ffd43b`／深海军蓝`#0f1834` | 无衬线800 | 最后一态明确收口 |

**制作推导**：颜色、形体、语义相互支持，不要为了“多气质”把每套都配成高饱和撞色。相邻背景保持相近暗度，可以让换色清楚却不每拍闪白。真实中文字体要检查缺字、斜体效果和宽度，不能假设系统圆体栈在每台环境都一致。

## ３．一个时钟怎样生成四次到站

**源码可见**：30／48／66／84起四拍，拍长18，30fps下约100BPM；每拍只用头6帧步进，其后列表位置保持。归一化x钳0—1后，`snap＝1−(1−x)^3.2`，初段迅速推进、后段停靠。

同一step控制列表`−step×176`，同一tInBeat控制胶囊宽和RGB颜色插值；胶囊形变也从这一进度派生。两个列表必须用同一位移，不各挂一个稍有不同的spring。

### ３．１　同一时钟不等于所有东西同帧完成

整数beat在拍头立刻切换，左下主题名`now.name`和色票选择也立刻变；但颜色／列表仍在6帧内过渡，角落计数滚动也跟tInBeat。30帧时中心仍是旧词modern，左下已写Tangerine，这是代码实际安排，不能称所有语义状态同步完成。

**制作推导**：如果角落信息需要严格对应当前已读词，可在到站后更新，或明确过渡中的“下一主题”身份。不要只因它们都调用clock就认为不存在领先／滞后。

### ３．２　列表停了，光晕和相机仍在动

拍头6帧结束后，hit＝exp(−sinceBeat／3.2)仍继续退；第6帧约0.153，之后的高光／辉光仍有尾部。全场0→140持续慢推3%，颗粒也独立。原卡“其余12帧完全静置”准确范围是主要步进位置与颜色，不是全场每个像素。

**制作推导**：到站阅读需要安静时，把残余高光收掉，或明确只是轻微余波。不能在12帧内叠新的标题、粒子与图表动作，再说列表已经停了所以不影响读词。

## ４．固定胶囊作为透镜：字色由空间边界决定

**源码可见**：胶囊外绘一份统一无衬线、暗白列表；胶囊里再绘同词表与同位置的副本，使用每词对应字体和深色字。胶囊overflow hidden，词只有穿过亮面区域时才显露选中造型，不按整数beat直接把远处新词改黑。

两层有相同row高与基准左缘，但并非所有时刻逐像素同形：外层按距离缩放、内层不缩；主题可换圆体／衬线甚至大小写；胶囊的sx／sy还作用在内层文字。所谓“重合”主要指行位置与语义身份，而不是不同字体轮廓完全一样。

入场外层还带40px的回位偏移、内层没有，0—22期间也有意存在差异。要做精确的“同字形变色透镜”，应让字体、缩放、位移与父形变全部一致，再只通过mask换色；要保留本例的主题字形变化，则审查边界是否产生难读的拼接。

### ４．１　胶囊形变是拍点，别让字变成果冻

sy随进度从1.14到0.96再回1，sx0.97→1.01→1，支点在左中。每个拍头从前一态1直接进入sy1.14，不是连续预备再压缩。6帧里完成，亮度与同色晕同时增加后退。

表面有顶边2px白内光、底部轻暗影、近接触影与同色远影；顶45%另盖一层柔高光。它是圆润有厚度的阅读面，不是平色药丸。换成严肃编辑排版时可以减形变和晕，保留固定停靠即可。

### ４．２　外围字如何退让

相邻行白色透明度约42%，更远每行降15%，并逐渐缩小、虚化；顶部300、底部330的渐变羽化用当前bg实时生成，防止换背景后露出旧色矩形。词表上下各垫两行，所以最后到yours.下方仍有timeless／quiet，列表不会突然断尾。

**制作推导**：不必用无意义单词充数。若真只有四个类别，到最后可明确让列表结束，或改为不暗示无限延伸的稳定选择器；虚构类别不是解决断尾的通用办法。上下邻居的身份和数量应符合内容。

## ５．时序核对与真正的终态

| 通道 | 当前实际时序 | 与概括的区别 |
|---|---|---|
| 胶囊展开 | 2→18 | 不是0—16全完 |
| 列表进入 | 4→22 | 铺垫30帧包含入场，完整静置约22—29 |
| 四次步进 | 30→36、48→54、66→72、84→90 | 每次过渡6帧 |
| 主题计数／色票 | 拍头已选新态，部分随6帧过渡 | 离散身份与几何过程分开 |
| 末句 | 90起，4词、间3、各16 | 115才全完整 |
| 全套完整内容 | 115—139共25张 | 不等于注释96起的44帧完整海报 |
| 相机 | 0→140慢推3% | 末输出139仍未到数值终点 |

**制作推导**：新口号若有阅读任务，至少从最后词完整之后安排停留。把拍数、每拍时长和总duration分开改；只改BEAT_LEN会改变拍点，但末句和总时长仍需重新核对。实际音轨的拍点可以不完全等间隔，不能用100BPM推算取代声音实听。

## ６．关键帧观察

实际查看0、16、22、29、30、33、36、48、51、54、66、69、84、90、115、139。

| 帧组 | 抽帧可见 | 制作应判断 |
|---|---|---|
| 0—29 | 胶囊与词表进入，modern停靠 | 首次读词是否有足够建立时间 |
| 30、33、36 | 从骨白到橙、列表送入playful | 透镜边界、字形与角落状态是否协调 |
| 48—69 | 紫斜体与绿大写依次接管 | 最宽词有无贴边，形变是否伤阅读 |
| 84、90 | 最后黄／深蓝态，yours.到站 | 列表下方是否仍合理 |
| 115、139 | 完整末句和最终主题 | 真实读完时间与声音是否够 |

媒体无音轨，不能认证拍点与鼓点相合。本篇只核视觉状态和代码关系，未做字体可用性、全速手感和原创实现验证。

## ７．原创演绎：在一张排版中找到标题、正文和注释

以下为**制作推导**，未实现。教程讲同一页面不同文字角色，采用固定阅读位置切换角色名，同时让真实页面对应区域接棒，不只换三种背景。

### ７．１　先设计真实完成画面

使用一张原创的阅读活动海报：左上日期，中央主标题，下方两段正文与页脚来源。近白纸面`#f1eee6`、主字`#253329`，只用深绿强调。画面左侧约560宽为“先看”＋三角色列表，右侧约1000宽为完整海报；最终三种角色都能在同一页中定位。

角色名用56px中黑，固定胶囊高84、宽按最长实际词测量；不要沿用132px英文与发光厚面。海报中的标题可初试64px、正文32px、注释22px，字形、行距和字重共同形成层级；具体以实际文案与输出尺寸重排，不能把字号本身当设计成立。

### ７．２　完整调度

| 阶段 | 画面动作 | 新认识 |
|---|---|---|
| 建立页面 | 海报完整、三个角色都在真实位置 | 同一页有不同阅读职责 |
| 标题到站 | 左侧“标题”进入焦点，右侧主标题边缘轻定位 | 大字先建立主题 |
| 正文到站 | 同一时钟让列表、定位区域和取景转向正文 | 正文负责解释，不是副标题 |
| 注释到站 | 定位来源和补充说明，保留页内位置 | 小字承担可追溯信息 |
| 回看整体 | 临时定位撤去，三类关系清楚 | 层级来自共同排版，不是三次换色 |
| 下一镜 | 修改一处真正失衡的版面并对比 | 将角色认识用于具体设计 |

每个停靠按旁白留充分阅读，不强制18帧换一次。三通道借用为角色名、页面定位和观看距离同源，背景不需要每次换新主题。字表可以就三项，末尾明确结束，不填无关词。

### ７．３　实现与验收

海报区域坐标、角色名和对应内容从同一角色数据生成，取景锚点直接指向实际字框。若海报源宽1600显示1000，比例0.625，源正文32只剩20px；需要读正文时另推近，不要求全景同时阅读全部文本。

左侧胶囊里的文字与外层采用相同字体／尺度，避免主题换字体引起边界拼接；形变可减到几乎无感，只保留到站。右侧材料始终同一页，不能每切一类就更换一张恰好排得好的新海报。

声音每个角色可有一次很轻提示，解释段让人声主导。最终实际版面、中文字体、原创实现、正常速度观看与试听均待验证。只有关键帧和文字规格，不能声明层级教学已通过。

## ８．失败诊断与合格判据

| 失败 | 修正 | 可观察的通过证据 |
|---|---|---|
| 列表、胶囊、背景各走各的 | 共用时钟，明确各派生曲线 | 新词到站与场态有一致节奏 |
| 新词未进胶囊已变黑 | 几何裁切副本，不按整数拍改远处字 | 字色变化发生在真实边界内 |
| 说逐像素重合实际字形拼裂 | 统一字形变换，或承认主题字体变化并调边界 | 中段不会读成断字 |
| 最宽词贴边／最短词空半条 | 实测当前字体字宽，共用宽度进度 | 每态左右留白合理 |
| 角落新名字领先中心旧词 | 分开过渡态／到站态语义 | 辅助信息与观众正在读的对象一致 |
| 声称12帧全静但光晕仍退 | 明确位置保持与余波 | 审核记录符合实际运动 |
| 换色热闹，没有内容差异 | 加真实实例与后续解释 | 每次到站带来可复述的新认识 |
| 末句只留25帧却写长hold | 从末词完整重排 | 正常速度能读完最终结论 |

Storyboard需交代固定句式、每次变化的内容、真实字体与宽度、同源时钟、透镜边界、到站读取与下一镜。静态、全速、声音、真实内容各自核验；本文不宣称原创或商用成片已通过。
