# 透视甩入、重砸与冲击传导

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/effects/slam-entrance-moves.md)、[ImpactBurstKit](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/effects/slam-entrance-moves/ImpactBurstKit.tsx)、[KanadaPerspectiveSnap](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/effects/slam-entrance-moves/KanadaPerspectiveSnap.tsx)、[ScoreSlam](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/effects/slam-entrance-moves/ScoreSlam.tsx)、[kanada-perspective-snap 官方样片](https://vincentwei1021.github.io/video-shotcraft/media/kanada-perspective-snap.mp4)、[score-slam 官方样片](https://vincentwei1021.github.io/video-shotcraft/media/score-slam.mp4)、[impact-burst-kit 官方样片](https://vincentwei1021.github.io/video-shotcraft/media/impact-burst-kit.mp4)。下文区分原卡给定、准确实现、官方样片抽帧观察和原创制作推导；抽帧每条16幅，未完整正常速度观看、试听、运行上游或实现原创镜头。参数用于解释原例，不能直接作为当前视频默认值。

## 1. 根据动作语义选一式

A透视甩入说“它来了”，B重砸说“这一项有分量”，C传导说“这一事件影响周围”。不是三个力度叠加包。教程中若没有需要被强调的真实结果，就不该用砸入替代内容。数字、比分和受影响对象都应有依据，不能从示例宣传片移植成事实。

## 2. 三种美术与结果画面

A是紫黑城市首映卡：左图有落日、楼群剪影和水面亮纹，右侧白色斜体片名、短规格和观看入口；背景超大低对比字条退到上缘。大图与标题形成重心，卡边圆角和长斜影让甩入有实体感。

B是石墨黑体育比分展台：上方远处灯点、中央横向黑卡、左右队徽和大数字，少量金色给终场状态和庆祝碎片。数字比队名更醒目，但队名仍决定数字含义。若移用到数据教程，应保留指标名称、单位和口径，不能只留下巨大的3比2。

C为亮场三列规格页，中间空槽先给主卡位置，左右白卡已站稳，中卡深蓝使它即使静止也为主角。数字、说明、特性和按钮有明确字阶，冲击环只是短暂包络。邻卡被推开是画面传导比喻，不代表真实业务参数会变化。

## 3. A：位置、透视与姿态分开收束

原例f2–20、18f行程，x−1350→0，透视约260→1800、rotate3d约62°→0、scale1.8→1。位置用snappy，姿态用bezier(.62,0,.3,1)并在16f窗口内变化；所谓“晚收”指曲线前段保持扭曲更久，不是起止时间必然更晚。源码的16f姿态和18f位移不能被误写成姿态结束在位移之后。

最后几帧rotateY过到+6°再spring回平，48道集中线约9f退出，7条身后速度线配按x速度的拖影(.2×速度、≤26px)。影子随姿态收正。内容晚一点落位形成跟随，但真正要读的卡内字应在稳定后清楚。

## 4. B：砸落的主次和扩散

f0–9近镜头悬停，scale2.75→2.6带模糊与半透，9–15六帧加速砸到.965再回1。原卡ease-in quad是概述，源码使用自定义贝塞尔，不是严格t²。

| 层 | 原例数据 | 审查重点 |
|---|---|---|
| 冲击环 | 直径120→1500，约16f | 扩散用out-cubic，消散按独立时间，别刚扩开就没了 |
| 碎片 | 14片金箔／玻璃、16道火花 | 向外并下坠、旋转、翻面，不是黑方块喷射 |
| 震源 | 18px短衰减，偏竖向 | 与卡接触同一事件，一镜只有一个主要震源 |
| 数字跟随 | 晚3/6f二次落地 | 不抢主接触，且不暗示比分在动画中真实增长 |
| 读窗 | 余波结束后保留完整卡片 | f15落地不等于此后全部可读 |

## 5. C：冲击波到邻居才产生响应

主卡16–22f砸进槽，邻卡此前已稳定。环半径100→1100、16f out-cubic；原例中心距约514，解1−(1−u)^3=(514−100)/1000得u≈.163，约2.6f，取落点后3f触发邻卡。改间距、环曲线或半径必须重算，不沿用+3。

邻卡外推34px、rotate±3.5°，cos(t/2)·exp(−t/8)衰减，40f后钳0；推开瞬间按速度给拖影。这个包络t0立即跃到1，是有意冲量近似，不是位置连续弹簧模拟。若实拍质感要求更连续，应改速度冲量积分或短上升包络后再衰减。

## 6. 官方观察与原创制作推导

三式各16帧。A能见大透视进场与紫黑图文卡，B能见近景模糊到清晰比分、环与金箔，C能见左右卡先立、中卡落入和邻卡偏移。抽帧不足以验证6f加速、相位和音爆。

原创内容可讲“一处正文样式修改影响哪些段落”。先做真实文档末态：选中段落为主，其他使用同一样式的段落有清楚身份。用A引出一个真实样式设置面板，最终必须能操作。若讲一项重要检查结果，可用B局部砸定结果，但不使用无关比分。

C的传导只能明确作为关系示意：真实样式改动后，影响范围由相同样式ID确定，外推幅度只作强调，不能让不相关段落也被波及。主事件一次发生，其他段落按关系点亮并回到原位。下一镜保持文档正视，检查真实字号、行距和例外段落，证明影响范围。

## 7. 失败修正和合格判据

- A像平面滑入：检查中段透视姿态，不能全通道同曲线过早拍平。
- B像慢放下：先查落地前加速，再查接触反馈；不能只增加碎片和震屏。
- C全版同时抖：按传播距离解触发时刻，让邻卡先稳住再回应。
- 环在亮底消失：选有反差的强调色并加弱压力盘，不能一律白芯外发光。
- 动作结束仍无法读数字：收净碎片、余震和模糊，按真实内容另给读窗。

通过应有完整主画面、清楚的一个震源、准确响应对象、实际信息结果和下一镜。正常速度、声音与原创成片待验证，原卡全片次数限制不迁为本项目强制默认。
