# 作画拍数切换：让姿势的更新频率成为表达

## 1．用途与证据边界

这个镜头让同一主体先以可辨认的姿势跳步移动，再逐帧冲刺落位。观众感到变化的来源既有姿势更新频率，也有轨迹、速度与姿态的变化。适合解释逐帧动画、强调一次有意的节奏转折，或让具有手绘语言的主体完成一次动作；不适合把普通软件滚动故意做卡，再声称产品更流畅。

来源是 Shotcraft 的 [sakuga-timing-shift 原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/rhythm/sakuga-timing-shift.md)、[SakugaTimingShift.tsx](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/rhythm/sakuga-timing-shift/SakugaTimingShift.tsx) 与 [官方演示](https://vincentwei1021.github.io/video-shotcraft/media/sakuga-timing-shift.mp4)。相关美术来自 `Look`、`Polish`、`Brand` 辅助文件。

**原卡给定**的是一拍三／一拍一、纸面与摄影表、冲击帧及速度线。**源码可见**的是以下尺寸、采样、时间链和材质关系。**抽帧可见**的是纸面、卡片姿态与切换点的状态。**制作推导**是后面的原创教学镜头。原片为 30fps、150 帧；已查看 0、2、3、24、45、47、48、49、50、56、68、74、80、108、110、149 帧，未正常速度观看、未试听、未运行上游工程，也未实现原创设计。

输出始终是 30fps。一拍三指一个绘制姿势占用三张输出帧，并不把文件变成 10fps。初段有 16 个姿势；后段另换了折返运动，不能据此宣称这是“只改变拍数”的控制实验。

## 2．先让一张作画纸成立

画幅 1920×1080。暖白纸不是任意加一层噪点：顶部三个定位孔、淡蓝安全框和中心十字、底部摄影表共同说明这是动画制作的观察台。主卡则使用墨线、平涂和硬边影色，与作画纸属于同一套语言。

| 画面部分 | 源码具体做法 | 导演作用与改造边界 |
|---|---|---|
| 背景 | paper look，主光位于归一化坐标 0.45／0.2，grain 0.06 | 浅亮环境承托墨色轮廓；不加另一套玻璃反光 |
| 定位孔 | 顶边 y=34；中孔 100×34，两侧 34×34，间隔 330 | 提供物理纸张线索；内凹阴影不能比主体轮廓更重 |
| 构图线 | 外框 110、110，1700×860；内框 260、190，1400×700，蓝色低透明虚线 | 表示制作辅助线，保持低层级，不能与真实路径混淆 |
| 主卡 | 600×360，y=330，圆角 30，5px 墨边 | 横向移动需要上下净空；底部摄影表不贴到卡脚 |
| 卡内字 | 品牌 32，元信息 22；数字 160／900，红色 fps 为 120；副句 38 | 大数字提供清晰体块；元信息是纹理，不承担教程结论 |
| 影色 | 无模糊的实色复制块，位于卡片右下 | 与墨线、平涂一致；不能再叠大面积柔软悬浮阴影 |
| 左上标注 | x=150、y=120，112 粗斜体 ON 3s／ON 1s；日文 40；说明 36 | 先读状态，再看运动。红色集中在切换后的 1s 与强调线 |
| 摄影表 | x=213、y=826，30 格，每格 44×64，格间 6，总宽 1494 | 把“保持一张画”变成可见机制，不只口头宣告帧率 |

开头卡在左侧，中央虚线槽预告落点，右侧保留运动空间；到最右姿态时卡片右缘为 1780，仍在画幅内。最终 x=660，主体居中，左右空间恢复均衡。角标与摄影表分处上下，不追着主体跑。

抽帧中，f45 与 f47 的卡片位置和姿势相同，f48／49 为墨底集中线，f50 回到浅纸并出现向右延伸的速度线，f80 后卡片居中。f108、110、149 仍保留摄影表和辅助线，不是品牌结尾黑场。

## 3．一拍三需要冻结整副姿势

f<48 使用 `q=floor(f/3)×3`，位置在 q=0→45 时从 x=140 线性到 1180。q 共取 0、3……45，共 16 个姿势；总程 1040 分为 15 次位置跃迁，每步约 69.33px。源码旧注释的“65px”不准确。

不只 x 使用 q，摆角、跳高和形变都由同一个姿势编号控制：

- 摆角为 `sin(q×0.7)×5°`。
- 偶数姿势上跳 −18px，横向 0.97、纵向 1.035；奇数上跳 −2px，横向 1.035、纵向 0.97。
- 变换支点在卡片底部中心。靠底支点的轻摆更像纸片落脚，若改成绕屏幕中心转会变成轨道运动。
- 硬影偏移随跳高取 18 或 10，再有纵向高度补偿；影子跟随姿势更新，不能卡片停三帧、阴影却逐帧游动。

这组设计让每张姿势有“画过一次”的变化。单纯对平移取整而保持完美矩形，容易像播放器掉帧。原卡提出最小步幅等经验，适用的是其画幅和卡片；改为小图标时，应判断输出中姿势能否辨认，不把 30px 当全项目硬门槛。

有意保持的范围必须写清。卡片姿势可一拍三，而角标、摄影表播放头是别的驱动；这不等于整画面每三帧才刷新一次。需要纯粹的拍数比较时，保持范围应该更严格，见原创示例。

## 4．切换、冲刺与落位的完整关系

| 输出帧 | 实际关系 | 应检查的画面 |
|---|---|---|
| 0–13 | 卡片已有，角标 0→14 上浮显露；摄影表 4→20 入场 | 初段并非完整空纸；讲解开始前重要标签应已可读 |
| 0–47 | 16 张三帧保持的姿势，右行 | 每次位移和姿势共同更新，停留时不漂 |
| 48–49 | 标注直接变 ON 1s，墨底与 64 条放射楔形线出现 | 集中线焦点跟随卡片，不固定屏幕中心；主体仍在前景 |
| 48–68 | x=1180→620，四次方 ease-out 折返 | 源码在 48 已计算新轨迹，冲击帧下也继续移动，不等到 50 才启动 |
| 68–74 | 620→660，以 inOutCubic 回到中心 | 40px 过冲不是另一个目标；回弹不超过摄影表区域 |
| 72／75／80 | 横向 1／0.92／1，纵向 1／1.07／1 | 挤压与回弹重叠；旧注释 0.9／1.08 与实际不同 |
| 74–149 | 整体相机朝 1.02 缓推，支点 50%／46% | 卡片落位不等于全画面静止 |
| 108／110 | 角标沸腾先冻结，播放头后停在第 21 格 | 两个停止时刻不同，不写成 108 后所有东西停止 |

冲刺形变来自速度差分：`v=abs(pos2(f)−pos2(f−1))`，`s=min(v/60,1)`；横向 `1+0.3s`，纵向 `1−0.1s`。速度越高，卡片越扁长，停下恢复。f48 的差分为零，f49 已很大，但两帧都属于冲击帧，因此速度线条件未开启。

九条横向楔形速度线只在非一拍三、非冲击且 s>0.08 时挂载；长度按速度缩放，y 和长度另有确定性变化。卡向左冲，线留在右后方。若换为右行，必须换线的起止方向；不能把原坐标原封保留。速度低于阈值直接移除，避免落定后还像在疾行。

冲击帧把背景变墨色，集中线用纸色，卡片影块变红。它是一次明确的视觉标点，不是白闪掩盖所有接缝的通用方法。卡片从 f47 的姿态跳到 f48 的 −4° 与新形变，需核查这一帧差异是否被观众读作动作强调；抽帧只能确认状态，不能代替正常播放判断闪动强度。

## 5．摄影表怎样真正支持解释

摄影表 30 格代表一秒。在一拍三状态，格位 0、3、6……27 写原画号 **1–10**，其他格画沿用竖线；不是旧注释所说把 ①④⑦当作显示编号。切成一拍一后，全部格位写 1–30。红色播放头按 `min(f,110)%30` 循环，f110 后固定在余数 20。

右上抬头另记 A01→A16，然后 B01→B27；B 编号在 f74 后封顶。这里是该段姿势计数，不等于右下摄影表始终实际展示了全部 27 张姿势。若教程要解释具体姿势复用，必须建立“时间格→姿势编号→主体”的真实映射，不借一个装饰摄影表冒充数据。

角标沸腾每四帧更新：位移约 ±2.5px、角度 ±1°，下划线控制点约 ±4px；f108 封顶。切换标注还有 f48／51／58 的 1→1.25→1 放大。这些都只是辅助强调，不能与主体抢读。摄影表的 17px 数字在完整视频中很小，适合作为制作纹理；若数字本身承担知识点，应另切近景，重新排印。

## 6．原创演绎：为什么同一张画会出现三次

**真实内容目标。** 解释动画时间格与姿势复用的区别。观众镜头前以为“30 帧就要画 30 张”，镜头后能指出哪三格用了同一姿势。此设计是待实现教学方案，不是已经完成的样片。

**先设计可读的结果。** 画面下部保留 12 个大时间格；上部只有一只自绘纸鸟与一条细基线。结束时格子 1–3 共用姿势 A、4–6 共用 B，标签只写“同一姿势，占用三帧”。不使用原品牌卡，也不让复杂角色细节淹没“重复”的证据。

**美术与构图。** 米白底上，纸鸟以两个折面构成：近翼墨蓝、远翼浅蓝，鸟嘴一小段暖橙；折线与外轮廓采用不同粗细，眼睛位置固定，便于跟踪身份。鸟在上半画幅水平飞行，摄影表在下三分之一，说明文字靠左，与飞行方向形成留白。背景不画满定位孔、编号和多重安全框；纸鸟折面已经建立手工感。时间格用等宽数字，知识点用清晰中文黑体，避免把日文动画术语直接当作理解前提。

**动作链由内容倒推。**

1. 先展示姿势 A 的鸟与时间格 1；下方放大该格内的小缩略图。先让观众认出姿势，而非一开始高速飞过。
2. 播放头从格 1 到 2、3，鸟的 x、翼角、尾巴与影子全部保持，三个格内出现同一 A 缩略图。第 4 格换 B 时，鸟的位置和翼姿一起更新。只显示必要的四个姿势，给旁白留清楚的观察窗口。
3. 对同一组原始逐帧姿势再演示一拍一。保持输出帧率、总时长、轨迹端点、相机和配色一致；采样由每三帧取一次改为每帧取值。不能用三倍速度折返和全画面冲击来冒充单变量比较。
4. 比较结束后停在一组相邻格，淡化其余，明确画出格 1–3 共同引用 A 的细线。线连接的是姿势对象，不是三个互不相关的新图片。
5. 下一镜把时间格扩为局部近景，示范把某一姿势多保持两格怎样改变停顿。沿用同一只鸟与 A 编号，观众不用重新建立身份。

**实现约束。** 原始姿势库需先真正设计翼部节奏，再对同一库采样。若只有用正弦函数摆翅的程序图形，应如实说是采样演示，不声称展示了手绘动画生产。缩略图、主鸟与编号引用同一姿势数据；播放器头不能与图像使用不同时间。位置保持但影子持续飘移、翅膀补间或眼睛随机跳动，都会破坏“一张画保持三帧”的解释。

**可用变体。** 若目的是情绪转折而非比较知识，可保留一次快速冲刺与短暂反相；先让纸鸟看见目标，再改变拍数与姿态。此时旁白描述“顿挫转为冲刺”，不再宣称唯一变化是绘制频率。

## 7．失败、修正与通过证据

| 失败画面 | 先查什么 | 修改后怎样判断 |
|---|---|---|
| 像掉帧 | 只有 x 量化，姿态无差异；步幅在输出中过小 | 连续三帧主体姿态相同，下一姿势有可认差异；正常播放能读出有意节奏 |
| 表说保持，鸟仍动 | 翅、尾、影子或相机未用同一采样时间 | 同一时间格组内主体各部件保持一致；必要时固定相机以排除干扰 |
| 切换只是变快 | 轨迹、速度与拍数一起改，标注没有解释 | 控制比较版本只改采样；表格能指出哪组姿势被复用 |
| 卡落定仍有高速感 | 速度线无条件存在、形变未回正 | 低速线撤走，轮廓恢复，影色回到接触关系 |
| 手工感变成乱抖 | 多层各自沸腾，幅度相加 | 主体身份稳定，辅助抖动不影响字形识别，知识点出现时可停止 |
| 最后还读不清表 | 数字沿用原 17px，观众看不到复用关系 | 切到实际可读近景；无旁白也能匹配 A 与三个时间格 |

文档研究通过的依据是来源、关键帧与机制能相互对应。原创镜头仍需验：起点／换拍前后／落位／结果五组画面，正常速度检查顿挫是否有意、冲击是否过强，配口播检查阅读时间，并确认下一镜继续解释同一对象。不得以导出 30fps、姿势编号正确或效果参数相同，替代实际视觉验收。

与 [三级跳切推近](rhythm-interrupt-moves.md) 的区别是，这里改变姿势采样；前者改变观察距离。两种时间与注意力手段应按内容择用，不因参考库有两篇就同时堆在一个动作上。
