# 行内容嵌入页面：把飞行终点做成真正的布局位置

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/ui-entrance/row-embed.md)、[RowEmbed](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/ui-entrance/row-embed/RowEmbed.tsx)、[row-embed 官方样片](https://vincentwei1021.github.io/video-shotcraft/media/row-embed.mp4)。下文区分原卡给定、准确实现、官方样片抽帧观察和原创制作推导；抽帧每条16幅，未完整正常速度观看、试听、运行上游或实现原创镜头。参数用于解释原例，不能直接作为当前视频默认值。

## 1．「嵌入」必须有一个可辨的槽位

行从上方降下、X倾角收平，在真实页面位置交给烤入截图，底边一缝短亮。适合解释资料、元数据或结果进入列表，不适合让所有文本长期悬浮在页面上。若终点只是遮在原行上方，观众读到的是贴纸，不是结构形成。先设计最终页面中每行的作用，再设计飞行。

## 2．美术从真实页面和取景出发

原例暖纸#f9f6f1，行内容来自整页截图的负偏移取样，保持字体、间距和边界与原位完全一致。飞行片backgroundSize固定1920×DETAIL_H、position为−r.x／−r.y；素材尺寸改动必须同步坐标与取样比例，不能把CSS重绘行和截图行混搭。

空槽先用真实底色补丁盖住原行，再画极淡虚线与接触影。补丁不是一块随意白板：应只覆盖该行所需范围，保留页面固有分隔线。若背景不是纯色，必须取得干净底图或可配准底层，不能继续用同色矩形掩盖纹理。

镜头CY500→740、zoom1.12→1.25、X960，页面铺满画幅。端点写在68，但文件末帧67，实际最后一帧未必到精确终值。关键行在运镜过程中都应保持可读区域，不切半行；信息行优先正视，不为立体感全局斜拍。

## 3．五行飞行、触地与原位交棒

cue12／22／31／39／46，间隔10／9／8／7递减；每行12帧飞，末行58触地。air=1−Bezier(.5,0,.8,.75)，起步缓、终点仍带速度，末端斜率.25／.2=1.25，由触地后的短回弹吸收。Y−120air、X倾16air，scale1.06→.995，再4帧回1。

入场前3帧opacity0→1；纵向模糊由air相邻半帧差计算，封顶3.2，触地立即归0。槽位接触影在靠近时收紧，落后3帧淡净；飞行片到land+4卸载，补丁land～land+2退，所以短暂两层同图重合是有意交棒，必须检查缩放.995阶段是否出现双字边。

## 4．底缝不是四边选中光

land～land+5底边2px缝从中心向两端扩，land～land+2保持亮、到land+8淡净；末行66收尾，剩余只有67这一末帧，无法自动得到长保持。原实现缝是页面空间独立div，虽然宽度不超过行宽，7px box-shadow未被父行圆角裁切；不能把原卡「光效已裁进承载圆角」视作代码已保证。

缝只强调接触，颜色应比正文弱，不能让每行像新选择状态。源例还有颗粒和暗角，末态不是全像素静止。抽帧见行依次落在真列表、镜头并行向下、最后原文完整；它不证明新增内容来自实际执行或已保存。

## 5．原创制作推导：把表单资料形成可用的结果列表

先定结果：三行真实资料按标题、类型、更新时间组成列表，字段列对齐，下一镜选一行打开详情验证内容。不是三条说明从空中落下后就宣称结构化完成。

1. 先排最终行，最长标题不撞类型和时间。列宽来自真实数据，缺失字段明确显示未知，不编值补齐。
2. 空槽保留列标题和行边界，第一行飞入时让观众看出哪个字段归哪列；其他行可更轻跟随。
3. 同一行的文字作为整体降下，X倾收平只在飞行段存在；落到平面后文字按原生尺寸读取。
4. 接触缝和数字反馈共用触地事件。若没有计数需求就不额外添加仪表；底光在真实圆角内收净。
5. 结果保留阅读窗，再进入选中行详情。下一镜核对标题和实际字段，显示内容如何被组织，而非只展示列表外壳。

## 6．原创草图的美术与中段取景

真实字段行先按内容排宽：标题列承载主要辨认信息，类型、更新时间使用较窄固定列。缺失值的占位要明确且弱于正文，不用漂亮数字补齐。飞行片的底色、字形和分隔线来自同一页面，圆角只属于承载行，不能把整个表格每个单元格都改成独立漂浮小卡。

末行进入时最容易把上行遮住，检查最大倾角和−120位移下的包络，必要时让主行先示范、其他行减少角度。交棒完成后底缝退出，真实表格的线条与字体承担结构；如果还需要常驻四边光，说明原版面本身层级不足。打开详情下一镜时，标题、类型和更新时间要与列表一致，不能只保留一个相同颜色块。

## 7．关键画面与失败判据

| 状态 | 画面审查 | 通过依据 |
|---|---|---|
| 空槽 | 背景、分隔线、列头正确 | 没有原行先透出 |
| 飞行中段 | 字体与截图同源、倾角不裁字 | 行像同一内容被安放 |
| 接触帧 | 缝在底边、接触影收紧 | 不是四边选中框 |
| 交棒两帧 | 临时片与底图几何一致 | 不出现双字和尺寸跳 |
| 真实列表 | 完整字段和阅读距离 | 能接下一次操作 |

失败修正：槽位底色错就重取干净底；文字接触时跳变先查取样坐标和scale；底光出圆角则给承载层真正裁切；行已落完仍慢慢摇页，应收镜并留阅读。声音可只给段落进入和主行一次轻落，不逐行长pop。须正常速度核对重量、交棒和阅读，不能只看最后截图没有错位。
