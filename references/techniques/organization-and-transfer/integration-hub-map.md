# 翻面中枢与两拍接入：先换视图，再说明真实连接

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/ui-entrance/integration-hub-map.md)、[IntegrationHubMap](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/ui-entrance/integration-hub-map/IntegrationHubMap.tsx)、[integration-hub-map 官方样片](https://vincentwei1021.github.io/video-shotcraft/media/integration-hub-map.mp4)。下文区分原卡给定、准确实现、官方样片抽帧观察和原创制作推导；抽帧每条16幅，未完整正常速度观看、试听、运行上游或实现原创镜头。参数用于解释原例，不能直接作为当前视频默认值。

## 1．翻面表达视角变化，光管表达什么必须另定

旧页快翻180°，背面成为中枢，五个图标同时出现、随后五管齐连。适合从单项内容转入同一系统的多源关系；若没有实际接入，不应把图标和循环脉冲说成已经连接成功。旧页与新页最好有共同对象身份，否则它只是一次炫目的换页。

## 2．美术：亮色工作区成为暗场唯一的阅读面

面板820×520，前面是有标题、元信息、字段和段落的文档，背面是分栏工作区；白面顶沿、细边、近接触影、远软影与冷紫环境光分开。近景zoom2.05退到1，用布局级CSS zoom保持字的栅格化尺度，但实际截图自身分辨率仍要够，不能声称zoom自动修复低清图。

五个112×112瓷贴围绕中枢，圆角28、内部高光和弱底影统一，图标本体是输入类型，不再是第三方应用标志。光管彩色、白热芯、前沿与彗尾有主次；若每条彩虹都压过面板，观众只看灯不看关系。背景霓虹矩形属于氛围，不得误画成额外节点。

## 3．实际切点与两拍时间

翻面14～49，outCubic，90°在14+35(1−2^(−1/3))≈21.22，而非旧注释28。bloom19／21／23／27为0／1／.25／0，峰值对侧棱，但并没有保证全画面不透明遮盖。双面各隐藏背面，背页转180°保持正字；不能用过亮闪白掩盖背页镜像。

五图标统一52起13帧显、五管62起9帧长完，确实两拍，**管开始时图标尚在最后3帧显露**。mapIn34～60还管整个星图可见度，不能只看单图标曲线。71后流动脉冲逐渐进，面板呼吸持续到末帧；相机推拉至96，早于此不能称最终布局完全固定。

## 4．同帧接通与真实路径长度

五路从不同方向接入中枢边沿。管长len是预设近似值，直线也有240与实际236的差别；含Q曲线的路径应重新测或纯函数采样。9帧齐达表示按自身长度归一，不能同时承诺五路恒定同屏速度。

渐变用userSpaceOnUse，每管独立ID，避免水平／垂直线bbox为0导致滤镜或渐变失效。输送dashoffset每帧−4.6、相位i×37，周期74；亮头7与拖尾26分层。方向来自路径起终点，换路线要核对数据到底流向中枢还是反向。循环亮斑是示意流动，不是真实传输包。

抽帧可见初始正文、侧棱、背面工作区、图标先于光管建立、尾部彩管输送。原例工作区字较密，在最终远景更适合全貌，不能同时要求阅读七行详细状态。

## 5．原创制作推导：一篇文章怎样关联原文、图片与注释

先画结果：文章主体占中间，外侧三种真实资料各有名称和引用入口，关系明确；下一镜打开一个引用核对原句。连接表达引用或关联，不冒充上传、授权或审核成功。

1. 从真实文章局部建立对象，翻面后仍保留相同标题／标识，让观众知道进入的是它的资料关系视图。
2. 外侧只放当前确实存在的三类资料，位置按内容关系分配，不为凑五路添加假来源。
3. 图标齐现建立整体范围，下一拍连到文章中实际支持的位置。若各来源作用差别大，应先讲一条主关系，再用较弱齐连收束，明确这是原创节奏改造。
4. 脉冲只在解释「信息进入」时短暂使用；最终静帧仍应有清楚的资料名称、引用标记与关系，不靠灯流说明一切。
5. 下一镜打开对应原句与图片，检查支持范围。旁白说到来源时可有轻接通声，不能让五声重击盖字。

## 6．原创草图的美术与中段取景

文章关系图的线条不必五色彩虹。来源类型已靠图标和名称区分时，可统一为一条弱色系，仅当前引用用强调色；这比每路争亮更容易追踪。中间文章需要能读到标题和一个具体论点，外侧资料节点的名称不要长到压进面板。路线绕开正文，接收端在引用标记或资料入口，别把线直接插进一个大logo。

翻面前后保留同一文章标题、来源标识或选中段落，至少一个锚在两面都能认出。若前面是文章、背面是所有资料的全局工作台，观众可能以为换了任务，应补明确的所属关系。最终关闭光管流动后，仍应能沿静态线找到哪份资料支持哪句论点；做不到时先重画结构，不加更多脉冲。

## 7．关键画面、失败与验收

| 状态 | 构图审查 | 通过依据 |
|---|---|---|
| 正文近景 | 题目与对象身份可读 | 翻面前知道在看什么 |
| 侧棱 | 面板轮廓、背面朝向正确 | 没有镜像或突然换对象 |
| 图标齐现 | 环绕留白不压正文 | 来源类型清楚 |
| 光管半长 | 方向、遮挡、接入点可信 | 不是随意接logo中心 |
| 完整关系 | 线退为次级，正文成为结果 | 关闭脉冲仍能读懂 |

管线消失先查坐标域、渐变ID和零bbox；翻面停顿先查单调曲线而非加速度拼接；尾部太亮就减氛围与芯光，不把主面板压黑；无真实关系就改文案或取消接通状态。须正常速度审核两拍是否分清、正文是否有阅读时间，代码齐帧不等于观感齐整。
