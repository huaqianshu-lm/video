# 时间错峰与数值梯度：同一索引怎样组织不同幅度

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/ui-entrance/value-stagger-gradient.md)、[ValueStaggerGradient](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/ui-entrance/value-stagger-gradient/ValueStaggerGradient.tsx)、[value-stagger-gradient 官方样片](https://vincentwei1021.github.io/video-shotcraft/media/value-stagger-gradient.mp4)。下文区分原卡给定、准确实现、官方样片抽帧观察和原创制作推导；抽帧每条16幅，未完整正常速度观看、试听、运行上游或实现原创镜头。参数用于解释原例，不能直接作为当前视频默认值。

## 1．先区分技法示范和真实数据图

十六根柱从左到右形成高度、色相、位移和模糊梯度，再由中心向外脉冲。它适合讲参数映射或视觉节奏，不能未经改造当成真实销量、频谱或性能。高度由索引预设，第二拍又改变高度，若观众以为柱高是数据，就会被误导。真实图表应保留数据长度，改用独立描边或亮度讲状态。

## 2．暗场中一条斜坡，比十六个独立色块更重要

480×270设计舞台以CSS zoom输出，基线Y196，柱宽3.4%，X=8+5.4i%；末柱右沿92.4%。高度92→32，色相200→320，构成蓝到紫红的单向斜坡。材质由上沿高光、左侧34%弱反射、深浅渐变、低强度晕与45%高的地面渐隐反光组成；不能把每柱都做成不同材质。

上方316×22代码条、9.5字输出约38px，只适合短参数展示。教程若不是讲代码，换成与内容有关的短语，不能原封保留anime.js字符串当产品界面。代码显示scale梯度，但实现用height生长以保圆角，二者表达关系要说清，别让字幕变成实际调用证据。

## 3．第一拍：同一进度驱动显形，属性起值各不相同

staggerVal把i/(N−1)映射到端值，可加ease；N≤1时返回起值。hMax92→32、hue200→320预算；动态Y46→14、blur8→2。每根e=outCubic(seg(t,.06+.02i,.28+.02i))，opacity=e、Y=(1−e)y0、height=hMax e、blur=(1−e)b0。

这里「时间错峰」和「数值梯度」两件事同时发生，不能只保留delay而声称学会全部。底部锚定height而非scaleY，圆角不被纵向压扁。16柱0.3归一化总延迟约44.7输出帧，单柱.22约32.78，存在一大片并行，不是每根做完才轮下一根。

## 4．第二拍：中心原点与幅度都要按实际偶数阵列计算

C7.5，distC=|i−7.5|/7.5，w窗.56+.13distC到.74+.13distC；amp=.06+.36(1−distC)，pulse=sin(πw)。因为16根没有dist0的柱，最近中心两根dist=1/15，**最大amp=.396而非.42**，启动.568667，约84.73帧；最外延迟.13×149=19.37帧，不是原卡「约4帧」。

末柱第一拍.58结束，中心脉冲.568667已经启动，两拍少量重叠。代码条在.502～.542切换，共5.96帧；它先换语句再迎接脉冲，不表示真实代码执行。端点.87完，约129.63帧，留下约20帧几何稳定，但颗粒继续动，不能叫像素静止。

distC在N1会除零，改柱数须连中心与百分比布局一起算。抽帧见先左高右低逐渐铺开，再中央鼓动向两端，尾部回到斜坡。它能证明参数图形关系，不能证明任意外部数据随之改变。

## 5．原创制作推导：用可见样本解释动画延迟与幅度的区别

教学内容就是两个变量：何时开始、移动多远。结果先画成同一批标记的两组受控对照，旁边只列当前改变的参数；下一镜在真实界面只调整其中一个。

1. 第一组固定所有标记的位移和大小，只改变起点，让观众先识别时间错峰。颜色保持统一，避免混淆。
2. 第二组保持同样起点，改各标记行程，明确这是幅度梯度。使用相同数量和观察距离，不同时换构图。
3. 再组合两个变量，主对象完整示范，余下跟随形成节奏。若换中心原点，标出几何中心在两项之间，不能硬指某一柱为唯一中心。
4. 最终静帧给出起点、终点和当前参数，不让高饱和装饰抢走教学标签。
5. 下一镜真实调整一个界面组件，看到延迟或幅度变化。声效只给参数切换与一次整体结束，不逐根敲音。

## 6．原创草图的美术与中段取景

受控动画教学可以用同样大小的几何标记，起点和终点各有一条弱参照线，标签只写正在改变的变量。先让时间不同但行程相同，再让行程不同但起点相同；这样观众能指出区别，不被蓝紫色、倒影和代码同时分散。组合阶段再引入色相与材质，且明确它们是视觉编码，不是新的数据变量。

中心传播使用偶数对象时，中轴落在中间两项之间，可用一条细轴而不是把某一项染成唯一中心。若改为真实数据柱，第二拍不要改变柱高，可让上沿短标记或边框脉冲，数值仍保持原位。最终画面保留参数、结果和一个可比较样本，正常速度观看时即使不暂停，也应能说出到底变的是时机还是幅度。

## 7．关键画面、失败与合格依据

| 状态 | 构图／机制检查 | 信息证据 |
|---|---|---|
| 受控时间组 | 同行程、不同起点 | 能区分先后 |
| 受控幅度组 | 同起点、不同距离 | 能区分大小 |
| 中心传播 | 中轴和对称关系清楚 | 不是整排乱弹 |
| 最终图 | 参数与状态一致 | 去掉代码也能说明变化 |
| 实际应用 | 只改一个参数 | 有可观察结果 |

若被误读数据增长，要加单位说明或改图形载体；中心波看不出先查真实传播19帧而非复述4帧；端柱溢出要重排百分比；入场和第二拍糊在一起要重算最后完成点。正常速度阅读和口播对照须另验，不能把十六根流畅柱等同设计表达已通过。
