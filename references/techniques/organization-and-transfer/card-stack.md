# 成摞、展扇与抽卡：先交代集合，再选择真正的主体

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/ui-entrance/card-stack.md)、[CardStack](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/ui-entrance/card-stack/CardStack.tsx)、[card-stack 官方样片](https://vincentwei1021.github.io/video-shotcraft/media/card-stack.mp4)。下文区分原卡给定、准确实现、官方样片抽帧观察和原创制作推导；抽帧每条16幅，未完整正常速度观看、试听、运行上游或实现原创镜头。参数用于解释原例，不能直接作为当前视频默认值。

## 1．先决定扇面最后要让人读到什么

此法适合从一组候选中引出一个具体对象，不适合逐张教学或比较九项复杂字段。原例是九种镜头配方的封面；它让人辨认种类和主角，不证明配方实际可运行。教程必须在抽卡之后进入真实对象。先画完整扇面与被抽出的卡，再倒推堆叠、展开和机位，不能先发九张空卡再寻找文案。

## 2．静态设计：同一纸张家族里只留一个重色主角

实现采用瓷白背景、墨字、钴蓝重点，卡320×440，中心在(960,610)。封面约占上部256高，底部用32px卡名与等宽元信息分层；圆角22、内高光和两层软影使它像薄卡，不是厚塑料盒。中心卡才用钴蓝实底，其余图形以灰、浅蓝和青绿控制重量。真实截图若各自高饱和，先统一容器和裁切，不把所有卡都染成重点。

眉题停在屏幕网格，标题居中置于扇面上方。展开时相机退到0.88，留出两端斜角；不能只算卡中心，必须算旋转后的四角。展开轴在卡高130%处，落在下缘之外，形成手腕扇柄；改成中心轴会变风车。中间抽卡向上72px，标题需给它的最大上冲留空。

## 3．入场和展开是两套时钟

每卡起点`2+stagger(i,9,40,EASE.out)`，跨度40帧，先疏后密；各自弹簧damping13、stiffness150，Y820→0，交替±9°飞行倾角随位移消失。垂直差分速度决定模糊，封顶10px。源卡把落座压低写成5px，但实现把九个sin脉冲相加，重叠期总压低可能超过5，不能当整摞恒定最大值。

62～72帧整摞收紧2%，68起共享展开弹簧damping20、stiffness95。两窗相叠，不是严格等预备结束才展开。每卡k=i−4，目标X=138k、角度6.5k；首末角差是8×6.5=52°，不是9×6.5。Z=i×2、zIndex=i保持，避免中途换顶牌。这里主要靠叠压和影子，不能把16px深差当真实厚板。

| 阶段 | 实际关系 | 观看任务 |
|---|---|---|
| 2～42依次起跳 | 每卡独立弹簧，末卡仍需收敛 | 读出一摞的数量，不读全部小字 |
| 64～106相机退远 | 与68起展扇重叠 | 外沿不出画，中段不挤成锯齿 |
| 102～120中心抽卡 | 描边104起，扫光108～130 | 只把注意力交给这一张 |
| 标题106起 | 5词、gap3、each18，最后词到136 | 原卡所谓122后hold不等于完整标题静止 |
| 122～150慢推 | 还叠1.017倍推近 | 尾部有活性，不能宣称全锁死 |

抽帧可见堆叠中只露顶牌、展开后九种封面、尾部钴蓝卡形成主角。文字完整时间仍以实现核对，16幅间隔图不能证明快速入场都清楚。

## 4．原创制作推导：九张照片如何进入一张封面的选择

目标不是「照片很多」，而是说明从同一组候选中选一张适合横版标题的照片。先设计结果：主照片保留主体，标题落在真实负空间，旁边保留小型候选索引。下一镜进入实际裁切，证明为何选它。

1. 从真实候选中选有不同构图意义的缩略图，卡面只保留短名称与一个辨认线索，不塞拍摄参数表。
2. 成摞建立共同集合。数量标注必须来自真实列表，素材重复不得算成更多样本。
3. 展扇先让人看到主体方向与负空间差别。中心主角由设计选择决定；若它不在中心，可重新排序并说明排序，不能让zIndex跳变冒充抽取。
4. 主角沿自身轴抽出时，其他卡保持弱上下文。一次轻落位声可强调选择，不给九张等重撞击。
5. 同一照片扩大为真正封面，标题在可用空区落定，再进入裁切框。此步才完成信息变化，扇面本身只是建立候选。

## 5．原创草图的美术与中段取景

扇面里的照片不要都裁成同样的脸部特写：有的呈现主体靠左、有的呈现主体靠右、有的主体居中，差别来自真实候选。卡名只标辨认身份，比较理由放在主角抽出后的完整照片中。扇面共同纸边用弱冷灰，照片保留真实色彩；中心主角可以用一条强调边，不必把整张照片染钴蓝。两端斜卡应露出至少一个能辨认的主体线索，不能只剩白色卡角。

抽卡中段最容易坏的是标题、卡顶和候选之间形成三块同重的亮区。先让上方标题收成一句短目的，主照片升出时保持视线方向的空区，旁卡只留轮廓。照片铺成封面后，原候选可收为窄索引，标题真正放进画面中；验收时遮去所有边框和扫光，仍应看得出选中这张的构图理由。

## 6．原创关键画面与验收

| 关键画面 | 构图和焦点 | 必须看见的内容 |
|---|---|---|
| 初始顶牌 | 集合集中，留上方标题空间 | 一张真实照片而非空白底 |
| 半展扇 | 斜边间距有节奏，主角颜色不过早抢夺 | 候选身份保持，端卡不裁主体 |
| 完整扇面 | 首末角包络与阴影完整 | 主角与其他项的差别可辨 |
| 抽卡中段 | 主照片离开重叠区但不撞标题 | 没有换图或临时浮出另一张 |
| 真实封面 | 照片成为画面，扇面退为上下文 | 能指出标题为何放在这里 |

失败修正：展开时还在大幅弹跳，就重排入场／预备／展开窗；端卡出画就检查旋转包络和机位，而非只缩小文字；主角抽出仍被右卡盖住，应设计真实遮挡和更明确的取景；扇面好看却没有选择理由，要回到候选差异与最终封面。静帧需分别审核半展开和最终封面，再以正常速度、真实口播与声效验证焦点交接，不能用弹簧参数正确代替审美通过。
