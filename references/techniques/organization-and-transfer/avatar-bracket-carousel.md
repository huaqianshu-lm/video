# 对焦框角色轮换：固定一个位置，逐个解释职责

## 1．一张头像不等于一份能力证明

四角对焦框固定在句中，圆盘头像沿垂直队列切换，标签同步，邻项退弱。适合说明角色、观察视角或预设选项；不能因为换了导演／剪辑／声音图标，就声称工具已完成这些工作。角色标签必须接到各自的实际输入、动作或产物。

## 2．焦点框、头像和标签分工明确

480×270设计坐标放大4倍，固定92方框、58圆盘、76步距；两侧34px／700字、gap22。框是唯一明显靛蓝，圆盘四阶中性灰，左上受光、半像素细边、内高光与两层影，白色26px线性图标。它是角色象征，不是照片头像。

四角3.2线宽、固定92viewBox，开场从外14px收拢；框内地光只托焦点。标签78×20、10px字，深色面压在下方邻盘上，透明度衰减比头像更陡，避免两条角色标签同时叠读。换成中文需实测标签宽，不能把四字职责硬挤成10px装饰。

头像不被92框裁切，只有外舞台overflow限制；上下邻项仍存在，是队列提示。原例全句居中，不保证框中心正好在屏幕中心，左右文字不等宽会偏；换句子先看框与阅读轴，不机械设「几何正中」。

## 3．一个距离驱动四个属性

pos为三段spring和，d=|k−pos|；scale=max(.5,1−.38d)、opacity=max(0,1−.62d)、blur=min(3,2.4d)、Y=(k−pos)×76。头像入场另乘enter，并从下12px回位；两种进度各有职责，不能把入场淡入叠到每次轮换而令中心突然消失。

标签opacity=max(0,1−2.2d)，支持区d<.4545；两个相邻标签支持区总宽.909<1，中间有小空档，不是两条一直交叉半透明。标签Y=(k−pos)×14，比头像慢，且裁在小chip内。圆盘轻微纵向拉伸由pos半帧差驱动，最大8%，不独立随机震动。

框脉冲使用每次切换后.1窗的sin包络，最大7%；头像移动窗.14，**两者窗口不同，脉冲峰在.05而非整个头像行程的时间中点.07**。实际感受应看正常速度，不凭「中点达峰」注释认定严格同步。

## 4．实际时间和未完全归整数的末态

t=f/155；三次切换.24～.38、.46～.60、.68～.82，对应37.2～58.9、71.3～93、105.4～127.1帧。框入场.03～.17到26.35帧；左右词分别.0～.13和.035～.165，不是所有内容第一帧已在。

四个头像enter末项.11～.21，32.55帧才完成，原卡概述「.15建立」偏早；它当前距初次切换仅.03≈4.65帧。增加头像时需重算，不只加切换数组。

辅助E.spring并非Remotion物理弹簧，而是`1−exp(−6u)cos(7.7u)`。u1值约.999619824，所以三段最终pos≈2.998859473，**不严格等于3**；中心头像略偏约.0867设计像素，标签透明度略低于1。它不继续振荡，但若需要精确末态应明确将端点设1并检查接点，不把近似称作精确配准。vel的dt写死1/155，改composition时长时应同步。

## 5．原创演绎：同一份作业由三种检查视角接力

**目标与结果。** 教观众分别检查内容、画面和声音，不把职责混成一个「已完成」。先设计最终态：同一份真实作业、当前检查视角、具体问题位置与实际结果；下一镜修一个已发现问题。没有实际音轨检查就不能让声音角色显示通过。

**美术。** 图标用文稿、取景框、声波同一套线性系统；中性圆盘与单一焦点色保持原理，去掉上游摄制组品牌句。角色名称是讲解标签，检查状态另列，不能角色切到哪里就自动打勾。

1. 先展示同一作业的身份和本次要检查的问题；第一视角「内容」进入框，画面显示真实一段文字与可核对来源。
2. 切到「画面」时，框固定、标签接力，实际作业的一个镜头接管主画幅，指出具体层级／裁切问题，而非只换图标。
3. 切到「声音」时，使用实际音频和时间位置，完整播放必要片段；没有试听就保留待验，不配伪波形冒充。
4. 最后焦点从角色框转到一个实际问题清单，按严重性有主次，保留三种检查的不同证据范围。
5. 下一镜执行对应修正并复看该处，验证问题是否解决。角色轮换只组织视角，不替代验收。

此设计尚未实现。可用轻切换声支持三拍，实际声音片段播放时撤拟音，避免把讲解声效当待检查素材。

## 6．原创三视角检查的关键画面

| 状态 | 对焦框中的职责 | 主内容必须展示 |
|---|---|---|
| 作业建立 | 暂不宣布任何检查通过 | 同一作业名称和本次范围 |
| 内容视角 | 文稿图标与清楚标签 | 一条真实表述与来源关系 |
| 画面视角 | 取景图标，邻角色退弱 | 一个具体构图／阅读问题 |
| 声音视角 | 声波图标，标签唯一 | 实际音轨与真实播放范围 |
| 修正接棒 | 角色框退到次级 | 问题位置和真实修正结果 |

草案尚未实现。可选一份明确的教学作业，内容问题是遗漏限定词、画面问题是标签被裁、声音问题必须来自实际试听后发现，不能为了凑三个角色编造。三个问题有严重性差异时，先解决主问题，其余简洁记录，不按角色数量平均分时。对焦框只组织观察位置，真实画面和音轨需要自己的观看空间；不要把所有证据也塞进58px圆盘，再靠大标签宣布已检查。

## 7．失败与通过判据

| 失败 | 修正 | 可观察通过 |
|---|---|---|
| 框跟着头像一起走 | 框独立固定，头像用pos | 同一观察位置连续切角色 |
| 标签两个叠读 | 保留更陡距离衰减和裁切 | 任何时刻当前标签唯一清楚 |
| 灰头像糊成色块 | 降模糊／调材质，保图标轮廓 | 邻项可感、中心可辨，强调色不乱 |
| 改时长后拉伸失准 | 统一useT和速度dt，检查端点 | 停稳没有额外smear，末态配准符合预期 |
| 换角色等于假通过 | 将职责与真实结果分开，保留待验 | 每一结论有相应资料／观看／试听证据 |

验收最初入场、三次中段、标签空档、末态与真实作业接棒；再正常速度、实际内容和声音验证。不能把角色数量当设计成熟度或工具能力覆盖数。
