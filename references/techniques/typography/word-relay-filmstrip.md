# 证据胶片与动词接力：让每一次换词都有内容对应

## 1．左边的画面必须真能支持右边的词

左列页面步进，右侧固定主体名词和原位动词；每次动词变化，对应一张新的内容页。这比纯词轮换多了一层可核查关系，但只有页面确实展示对应操作／结果时才是证据。原例的分镜、构建日志和评审页都是程序绘制，不能当真实任务成功或用户认可的事实。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/typography/word-relay-filmstrip.md)、[WordRelayFilmstrip](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/typography/word-relay-filmstrip/WordRelayFilmstrip.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/word-relay-filmstrip.mp4)。原卡提及Perplexity原片，本篇未重新取得原片；源码可见准确版式与时序，抽帧可见180帧的16幅阶段。原创为制作推导；未正常速度观看、试听、运行上游或原创实现。

## 2．编辑排版感来自图文尺度与共同中线

左卡940×530、left100、焦点top275，中点Y540；卡距105，步距635。右词两行各154高、top386，总中心也540；140px衬线，主体名次级灰直立、动词近白斜体、句点金色。两者共用相机中心(960,540)，所以整体scale1→1.02时中线仍一致。

金引线从卡右缘+14到词前40，即1054～1156，中心Y540；不是把长线穿到字里。序号在词块上，32px注脚在下，职责不同。截图应是真实允许展示的内容，正文细节用于证明对象而非要求逐字读完；关键证据需要另开近景。

邻卡按距离压暗、缩至0.94、blur最多3；亮卡焦点本身仍有4%暗罩，并非注释「绝对全亮」。明暗相间有助读出步进，但不能为交替效果伪造黑色页面或压坏真实截图；可以在统一框架／背景上区分邻项，让真实内容保持准确。

## 3．步进、接词与焦点不是完全同时结束

三窗16～34、66～84、114～132，每次scroll增加635；窗口外位置函数不动，但全局相机仍在缓推，视觉上不是所有像素零位移。每卡top=275+i×635−scroll，用同一step算距离与景深，卡、暗罩、模糊共同改变，不能各写一条独立补间。

新动词切点+7开始，逐字符16帧、gap1.2，句点也算字符。frames和builds各6字母＋句点，满态分别46.2／96.2，即47／97起；ships5字母＋句点，到143。胶片已在34／84／132停稳，新词仍继续升起，**不符合原卡「滚动终点＝新词落稳」**。

旧词在下一切点前10帧先灰化，到切点起8帧上升退出；因此第二次灰化56开始，胶片66才启动。旧词66～74退，新词73起，DOM有1帧重叠，新词起始在裁切线下；是否可见叠字仍需逐帧／正常速度检查，不能凭「先出后进」文字保证绝无重影。

引线切点起6帧收回，+10起16帧重画，所以分别42／92／140完整，不是胶片停下立即满线。注脚新词+6起14帧，分别43／93／141完整。全镜能完整看见最后词和注脚从143起，尾段37帧；背景仍呼吸、颗粒持续。

抽帧24胶片运动中、36新页稳而词未满，72第二换页中，84新页稳、动词仍升，131第三页已接近中心，143末词完整。这些错峰让视线先接图再接词，但如果当前内容需要读细字，应延长图片停留或拆近景。

## 4．证据页本身怎样设计

示意分镜页用标题、正文、shot list和小图注建立文档感；构建页有路径、阶段、日志、真实格式般的汇总；评审页有文件树、diff、检查和评论。这些细节让页面可信，但**程序写出的通过／approved不等于真实通过／认可**。邻卡还含示意医学与销售页，只是装饰上下文，不应误当本教程业务证据。

原创材料先按叙事选择三张真正相关的页面，保留同一项目／对象身份、时间和版本；必要时遮去无关信息，但不删掉会改变结论的字段。图像与动词不一致时，宁改词或换素材，不用金线强行关联。

## 5．原创演绎：同一篇文章的来源、整理与核对

**目标。** 让观众理解一份研究资料如何支持一篇文章。先设计结果：三张真实资料分别承担「查找」「整理」「核对」，最后回到文章中的一个论点；下一镜打开来源核实。不是展示三份漂亮假文档和三个能力词。

**美术。** 左列保留真实页面风格，外框统一；右侧中文动词简短、主名词是当前文章，使用合适中文衬线／正文对照，不强行英式斜体。焦点图与词块共同中心固定，注脚说明真实文件／章节，而非虚构成功编号。

1. 第一页是实际原资料，主要引用局部可读，动词指「查找」；先解释一项，其余做简洁跟随。
2. 同一对象进入整理页，步进只发生在换词窗口，图片到位后具体条目可认；来源身份保留。
3. 第三页是核对记录或实际原文定位，动词不能写「已验证」除非确有证据。缺口仍列待核，不为了结尾抹掉。
4. 胶片停住，放大一个关键论点和对应出处，右侧大词退出成为小标签，把阅读权交给内容。
5. 下一镜打开来源或文章位置核对准确性，说明哪些结论可支持，哪些须修改。

此演绎尚未实现。可让每次635步进配轻机械触感，文字进入不用逐字同响；口播阅读时保持停稳，正常速度与声音需实际审核。

## 6．原创资料到论点的关键画面

| 状态 | 左侧证据画面 | 右侧说明 |
|---|---|---|
| 来源 | 真实资料的一段可读局部与出处 | 「查找」及具体文件身份 |
| 整理 | 实际提取的条目，保留来源标记 | 「整理」说明实际变成什么 |
| 核对 | 原句定位／核对记录，缺口如实保留 | 不把待核写成已验证 |
| 论点近景 | 一句文章论点与对应证据并置 | 大动词退为次级标签 |
| 打开来源 | 同一出处和段落接管 | 解释证据支持的范围 |

草案尚未实现。三张资料若风格相同，不必为黑白交替强行把其中一张反色；可以用统一的暗邻卡与亮焦点边界，让步进从位置和清晰度读出。每张卡先审其内部版心：标题与重点段落可认、出处可找、无关侧栏不过度占空间。证据卡所占画幅应与其内容复杂度相称，密集原文需要更大局部，而不是永远固定940×530。右词只能说明实际发生的动作，不能用「证明」一词替代核查。

## 7．失败与通过证据

| 失败 | 修正 | 可观察通过 |
|---|---|---|
| 左列一直滚，读不清证据 | 只在换词窗步进，必要时延长停留 | 每个观点都有明确静态内容可看 |
| 图文中线不齐 | 以卡中点和两行总盒计算，检查相机后输出 | 两侧是一个严谨组合，非上下漂 |
| 新旧动词叠成怪词 | 查73／74等接点、裁切和字母延迟 | 正常速度能认出单一当前词 |
| 只看到小字页面，无法验证 | 选择关键局部或加近景 | 至少一条真实证据可读、可回查 |
| 示意通过被当实际认可 | 换真实状态并标清证据范围 | 画面与任务事实一致，不虚构评论或批准 |

验收每个焦点静帧、三次步进中段、动词完整点、图文连线及最后证据近景；再正常速度配口播验证。
