# 三词与三种几何接力：形状要解释词义，结果要证明主张

## 1．几何是比喻，不是论证本身

三个比较级短词分别配转环、相扣圆和金属扫光，形成持续推进的段落。适合简短价值回顾或几何概念引导，不适合替代真实收益证明。转得快只能表现速度感，不能证明工具更快；圆相扣也不能证明实际系统协同更紧密。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/typography/word-relay-geometry.md)、[WordRelayGeometry](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/typography/word-relay-geometry/WordRelayGeometry.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/word-relay-geometry.mp4)。原卡给定一词一几何，源码可见分层、交点和时间链，抽帧可见180帧的16幅阶段；原创为制作推导。未正常速度观看、试听、运行上游或原创实现。

## 2．共用舞台，保留一词一形的主次

石墨近单色暗场、230px／800主词、40px副句；几何白线约0.42透明度，弱于字。词在(960,500)，副句一般低210，第二段低246避开圆底；眉题、三段进度是次级纹理，不能要求观众读其小字来理解主张。

文字轮廓、填充、金属层共用padding上.08em、左右.1、下.28，防止下伸笔画／斜体外伸被mask裁坏。前两词2px轮廓先到，填充后用±7%柔边扫入，轮廓留0.2；最后词保留独特材质变化，不能三段都同样强扫光，导致无主次。

换中文先设计三个具体且平行的概念，实测字宽与圆的关系；不能靠副句写「更好」来补足抽象主词。主字、几何、注释分别控制阅读权，几何不遮掉关键汉字内白。

## 3．第一段：速度来自相对运动

2～16词去虚入场，12～30填充；主环r400、外刻度r452共120格，0～22从.4长至1。主环先额外转160°减速，之后仍0.9°／帧；刻度−.35°／帧；16段彗星弧7.5°／帧。三者相对速度建立运动感，不必再加相机震动。

52～62词缩至.86、退焦12、加速淡出；新词56起，重叠6帧。抽帧60能看到新旧词明显并存，**原例并不是完全不叠字**。这是其转场取舍，实际中文若读成混词，可减重叠、分开取景或先撤旧字，不把叠影当高级必需。

## 4．第二段：交点必须随圆的几何更新

三圆实际r218，中心−gap／0／+gap，58／64／70起各22帧描满，最后92；92～106 gap340→300。相邻圆交点在x=±gap/2，y=±sqrt(218²−(gap/2)²)，因此收拢时交点会移动，铆钉必须从同一gap算，不能放四个固定光点。

四点100／102／103／105起各10帧出现；最后点到115才完整，112已经开始旧词退出。圆线亮度脉冲100～112，108～120开始回收trim；这意味着某些铆钉尚在长、圆已开始退，不能说106起所有几何都稳定。

同样要分清集合图和实际关联：三圆相交只有抽象关系，真实流程／来源图需要保留对象与连接含义。不是给任意系统画三个相交圆就解释了协作。

## 5．第三段：金属到白色的完整收束

116～130新词入，120～130金属层建立；镀铬是亮顶—暗腰—亮底，不是一条平面灰渐变。124～148窄香槟高光以300%背景扫过，146～158收成纯白；辉光脉冲到168，舞台光脉冲到172；脚下光带146～168展开。

全段相机1→1.025、尘点和舞台呼吸持续，没有全静态尾帧。抽帧131看金属字，155副句仍进入，167大部分完整、179最终文案清楚；是否能读完仍需正常速度检查。

## 6．原创演绎：用真实排版解释「分开、关联、统一」

**目标。** 教观众把同一段真实信息组织成有层次的画面。先设计最终版面：标题、正文、注释与一个实际图例，明确阅读顺序；下一镜真实修改间距或对齐。三个词应对应真实设计动作，而不是空泛更快更强。

**美术。** 中性纸面或深色工作台均可，但三段统一字体、强调色和同一份内容。第一段用真实分组边界代替转环，第二段用有含义的对齐线／关联代替泛三圆，第三段统一版式后撤辅助线；不必强套金属材质。

1. 「分开」段显示真实内容的组间间距，变化由同一布局参数驱动，不让标题转圈代替分组。
2. 「关联」段跟踪一个主组与对应图例，线条端点来自真实对象，其他关系简洁跟随，避免满屏同重光点。
3. 「统一」段显示完整结果，排版节奏和字色一致，正文仍有可读细节；最终无动画也要成立。
4. 回看同一份内容的前后关系，单位、文字与数据不变，变化仅在组织方法。
5. 下一镜实际调整一个参数，观察边界条件，例如间距过大导致关联断裂，说明方法适用范围。

此演绎未实现。若本内容本来是几何教学，可保留真实圆交点与公式；若只是教程章节回顾，应减少修辞层，把时间交给真实画面。三段声音主次依叙事决定，最后确认可独享一次轻重音，未做实际试听。

## 7．原创三步组织的关键画面

| 状态 | 正向画面要求 | 几何的职责 |
|---|---|---|
| 未组织内容 | 同一段真实文本和图例，问题位置清楚 | 不先用装饰遮掉原状 |
| 分开 | 相关内容形成可识别组，组内外间距不同 | 边界指出实际分组 |
| 关联 | 一个主组与对应图例有清楚指向 | 端点来自对象，线不穿字 |
| 统一 | 字体、颜色、对齐与留白成为一套版面 | 临时辅助图形退去 |
| 参数验证 | 真实修改一个间距或对齐设置 | 看结果是否维持关系 |

草案尚未实现。主例可采用一段正文配一个图例，把注释从正文中分出来，再用实际引用符号建立关联，最后统一标题层级。不是三张互不相关的漂亮页面，也不把第三张故意做得更亮来宣布胜利。静态验收可遮去三个动作词，看画面自身能否讲清分组、关联和统一；若遮去文字就只剩三个不同圆形，应重做内容载体。动态验收看主对象全程身份和位置是否可追，避免每段重新生成另一套素材。

## 8．失败与验收

| 失败 | 修正 | 通过证据 |
|---|---|---|
| 三段只换字像PPT | 每段有真实关系变化和同一内容连续性 | 词与图互相解释，非几何装饰菜单 |
| 新旧字叠成不可读 | 重审交接6帧，撤或移动旧字 | 正常速度当前概念唯一清楚 |
| 铆钉脱离交点 | 与gap和R共用公式 | 全收拢过程点都在真实交点上 |
| 金属层退白时发灰 | 检查两层合成与完整字形留白 | 材质连续，边缘和下伸部不漏底 |
| 宣称22帧结果却副句还动 | 从175等实际完成点重新留阅读 | 完整内容与下一镜衔接充分 |
| 比喻被当性能证明 | 提供真实测试／结果或改具体叙事 | 观众能区分修辞与事实依据 |

验收三段静态美术、两次交接、四点运动、金属转白、全部副句与下一镜；再正常速度配口播和真实内容验证。相关 [空心字点亮](outline-word-fill.md) 是单次确认，本篇是三段接力，不需要在同一段再叠一次独立点亮镜头。
