# 双词对峙合拢：把最后一次位移留给揭晓

## 1．轮换是铺垫，合拢才是主事件

左侧固定标签、右侧硬切词列，最后一词停稳后仅一次相向合拢。适合已建立语义的章节回扣、命名或分类揭晓；不适合第一次讲八个陌生概念，也不能把极短轮换当功能说明。需要记住的词应在别处获得实际内容与阅读时间。

## 2．小字与大留白形成规格清单的语气

冷黑底、极淡顶光，42px／500等宽，字距3；左词次级灰，右词近白；没有大面积彩光或巨字冲击。左缘618、右缘1302，左右屏边距同618，但不代表两个字块视觉重量自动相等。右词从右锚，长短变化只改变其左缘；不能把每词中心都居中再假称固定。

最终短句宽按ADV=0.6×42+3=28.2估算，19字符得535.8，终点左692.1、右1227.9。两侧各移74.1。**这是字步近似，不是实际测量**：字体回退、最后字距和中文全角宽度都可能造成缝差。实际制作可测宽或采用确定字格；比例字体并非原则上不能做，只是不能继续用这条简式。

副句同字号斜体、低一级灰，左对齐最终短句，不给额外上移动作；留白要按真实观看尺寸核查，手机上42输出像素可能不足以承担关键教程信息。

## 3．准确时间与最后一次运动

初始8帧只有背景；轮换时长16／12／9／8／7／8／10／12，共82，从8到90。最后词90起，100开始合拢，136完成；154～158副句快速淡入，158～179留22帧完整副句。

轮换期间两锚点不收缩，只有切词瞬间一帧提亮；不是一边换一边逐步靠近。右词实际很长时，需先核对其左缘是否撞上左标签，不能为了保固定锚点任由重叠。若内容需要逐项说明，应减少项数或拆镜，而不是加速硬切。

合拢36帧inOutCubic，左右速度相反，SpeedBlur上限4；左词在前80%合拢阶段逐渐提亮，说明两半开始成为一个整体。背景柔光约130～154进入，与主运动尾部重叠；颗粒持续，所以「合拢定格」不代表整图静止。

抽帧84仍是倒数特性词，95出现最终名称但未动，119途中，143合拢后尚无副句，155副句在淡入。它把空间位移作为揭晓，其他动作都应让位，不能最后再盖章、弹跳或冲白增加第二个结尾。

## 4．原创演绎：把几项观察收成一个有依据的类别名称

**目标。** 教观众由已观察的共同特征识别一个概念。先设计结果：类别名与一张实际对象／示意图，保留能支持归类的特征标记；下一镜处理一个边界例。不是先闪一串形容词，再硬说这就是结论。

**美术。** 左标签可以是「共同点」，右侧只轮换前文确已展示的短特征；最终名称保证语法能与左侧自然合句，否则重写标签，不机械保留NEW。中文按实际字体测量，亮度统一，背景留白只托住思考，不制造空洞。

1. 前镜已经逐一展示特征证据，本镜用简短轮换回顾；如果观众尚未看过，先做内容镜头。
2. 左右位置固定，让观众预测仍会换词；词长超范围就缩短表述或重设版心，保留事实限定。
3. 最后类别名停稳，唯一一次合拢使分类结论成立，配色从次级到主色表达归属。
4. 对应真实对象接管画面，特征标记与类别一一对应；副句说明判定边界，不写泛品牌口号。
5. 下一镜展示一个不完全满足条件的例子，说明哪些特征必要、哪些不充分，避免把动画合拢当逻辑证明。

此演绎未实现。可用很轻的切词声建立节奏，合拢只用一个连贯滑动声或无声，不能每词都重击。正常速度需检查是否读得完中文短语。

## 5．原创归类镜头的关键状态

| 状态 | 具体内容 | 焦点安排 |
|---|---|---|
| 证据已建立 | 前镜展示过的对象与特征 | 不把尚未解释的新词塞进回顾 |
| 固定列举 | 左标签弱、右短特征强，共用基线 | 位置稳定，观众只跟当前特征 |
| 最后名称 | 名称完整停住，不立即移动 | 先意识到词不再换 |
| 唯一合拢 | 名称与标签形成语法完整的一句 | 只用一个连续动作宣布关系 |
| 实物接棒 | 真对象与特征标记并置，再看边界例 | 归类来自内容而非位移 |

尚未实现的教学草案可以讲三种图像适配方式：前镜先解释原图是否裁切、是否留空、比例是否改变，再用短词回顾并收成具体模式名。若特征不能唯一判断类别，不能用合拢强行宣布答案，应保留条件或安排对照。中文标签与最终名称必须成句，排版不能为保左三个字而产生病句。满态除了查空格，还看主副行的光学左轴、字面灰度与周围负空间，避免小字漂在一大片无意义黑底上。

## 6．失败、修正与通过证据

| 失败 | 修正 | 通过时看到 |
|---|---|---|
| 轮换期间两边渐近 | 将位移仅绑定最后合拢进度 | 观众先认出稳定列举，最后运动才有揭晓意义 |
| 长词压到左标签 | 实测最宽词、重排边距与字号 | 每个状态无重叠，左右锚仍清楚 |
| 合拢有缝／叠字 | 测实际字宽或固定字格，查最终空格 | 短句自然成形，视觉中心正确 |
| 小字像另一个标题飞入 | 零位移短淡入，降低权重 | 结论是唯一连续主动作，副句补充边界 |
| 分类只有漂亮字，没有依据 | 保留前文证据与真实对象 | 能解释为何归类，也能说出限制 |

检查最宽词、最后词停稳、合拢中段、最终间隙、副句完整和下一镜。文档研究未替代原片测量、真实中文实现与完整观看。
