# 字符坠落与集体归正：让标题有重量，也有句号

## 1．轻松语气的身份亮相

有效变体letter-drop-physics：字符依次加速落下、两次衰减弹跳、歪着站定，再集体归正。它适合轻松开场或一次标题连接，不适合严肃错误提示、精密数据解释，也不该让整段口播每字都砸落。它没有字符互碰模拟，不应把独立轨迹包装成真实刚体系统。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/typography/type-entrance-moves.md)、[LetterDropPhysics](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/typography/type-entrance-moves/LetterDropPhysics.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/letter-drop-physics.mp4)。原卡给定重力与归正，源码可见接触／形变／影子，抽帧可见150帧样片16幅阶段；原创为制作推导。未正常速度观看、试听、运行上游或原创实现。

## 2．先设计地面和字形接触

176px／800黑字，浅背景与极淡下方台面，地面Y600；两条低对比明暗线提供接触参照，不画厚舞台。每字有自然字宽的隐藏占位，运动层只transform，避免下落时整行重排。接触影随离地高度变大、变虚、变淡，落地收紧，不是全程相同的一团椭圆。

BASE=round(176×.886)=156，行盒顶444；这是当前字体实测比例，不是通用基线。带下伸部的字母、中文标点或不同字体需逐字校接地点。原例按歪角抬起`sin|θ|×48`，48固定半宽近似，不是每字真实宽度；宽字／窄字的角点可能仍穿地，必须看实际字形轮廓。

最终词位于地面上方，36px副句在Y670；主字、地面、接触影、说明四者的重量有主次。换成中文短题，要保证字面底部不被误当几何矩形底，否则「悬空」或「插地」一眼可见。

## 3．起跳、重力与两次回弹

起点`4+36[1−(1−i/(n−1))^1.5]`，九字首4、末40，间隔先疏后密；只有一字时分母n−1为0，改词必须单独处理。下落24帧：y=−720+720(t/24)²；一跳16帧高216、二跳8帧高64.8，均用4u(1−u)抛物线。三次触地在局部24／40／48，不是三个弹跳。

末字40起，64首次着地、80一跳落地、88二跳落地；触地挤压最多再16帧到104。歪角在首次着地后6帧形成，固定随机±6°，一直保留到归正。下落速度驱动10%拉伸，接触时Y挤压、X膨胀；公式并非严格面积守恒，不能称为真实体积不变。

模糊层外扩200，方向只Y，下落amount.26、弹跳.12、上限16。外扩让拖影不被字盒切平；镜头保持稳定，不能再叠全局震动来冒充落地重量。

## 4．归正与真实完整态

108～110先集体撑6%，110～116收尺寸，110～118归旋转且轻过冲。副句114～132进入，所以原卡「116～150真静止」不成立：至少到132副句才完整，外层Grain还在变化。132～149只有18帧完整副句，应按实际字量扩展。

抽帧40仍有字在天上，60／70多个字处于不同弹跳，99字基本站住但歪斜，119副句刚显，139完整。多字同时弹会分散视线，若内容较长应选择一个主字／组负责完整机制，其余减弱跟随，或改为更低能量入场。

## 5．原创演绎：让「对齐」概念进入真实版面检查

**目标。** 用一次轻松标题引出基线对齐，再展示真实文本／图标为何对不齐。先画最终版面：相邻文字和图标、真实基线／视觉底边、一个具体错位；下一镜实际改align-items或偏移并核对。不能只让「对齐」两字站直就结束教学。

**美术。** 中文短题采用当前教程字体，地面线可延续成后续基线辅助线。影子只支持落地，正文进入就撤物理质感；实际界面保持真实字形，不为示范把图标故意压扁。

1. 短题少量字符落下，起终点都在安全范围，观众先知道章节主题。
2. 字符歪站后统一归正，强调「共同基准」，不暗示软件已自动排齐所有元素。
3. 镜头转到真实排版，地面线变成基线标记，指出文字盒与字形轮廓不是同一个边界。
4. 一个主对象真实调整，其余保持，展示改动前后差异；不让所有元素同时飞散重组。
5. 下一镜查看小尺寸、不同字形和另一行文本，说明一次参数不能保证所有视觉对齐。

此设计未实现。落地声可按主字三次接触做衰减，其他字轻跟随，不把九字27次接触都同响播放；依据实际轨迹求接触帧，再正常速度试听。

## 6．原创基线教学的关键画面

| 状态 | 画面要画出什么 | 观看重点 |
|---|---|---|
| 坠落建立 | 少量短题字进入同一地面，背景安静 | 主题与重量感 |
| 歪站 | 字与地面的真实接触，影子不离地 | 角度与共同基准的差别 |
| 集体归正 | 同时回正，地面线仍清楚 | 把「共同基准」变为句号 |
| 真实排版 | 一行文字与图标，真实基线／盒边分层标记 | 为什么盒底齐而字面未必齐 |
| 参数修正 | 只调一个对象或参数，结果可对照 | 从隐喻进入可执行方法 |

尚未实现的教学草案可以用一个中文标签和一个线性图标，先显示真实盒边，再叠基线，说明二者并非同一位置。标题里的落地影在正文开始时撤掉，避免把平面UI图标也拍成重物；同一条地面线可连续变为基线辅助，不需要再加一个大转场。真实修正前后保留相同字体、字重与观看比例，只改变对齐参数，才能判断改善来自哪里。多字长标题改为短语或拆镜，不把弹跳规模当画面丰富度。

## 7．失败与通过证据

| 失败 | 修正 | 通过时看到 |
|---|---|---|
| 字穿地／悬空 | 实测字形接地点、基线和旋转角点 | 每次接触可信，歪站也不插进台面 |
| 像果冻跳不停 | 限两次衰减跳，重查触地形变包络 | 一跳高、二跳低，最后明确站住 |
| 影子跟着字一起升 | 影子留地面，尺寸／虚实随高度 | 字和地面的距离可感，非贴纸拖影 |
| 116就切走副句 | 从132完整点留阅读，必要时减字 | 主题、说明都可读，再进入实际教学 |
| 动效有趣却没解释对齐 | 接真实基线与参数结果 | 观众理解基准关系而非只看弹跳 |

验收首次接触、两次跳峰、最后站姿、集体归正、副句完整和真实版面；正常速度、声音与多字体接触分别验证。
