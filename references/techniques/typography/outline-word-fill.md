# 空心字瞬时点亮：尺寸落定之后，再做一次确认

## 1．点亮承担重音，内容承担结论

空心短词先急收，虚线环慢慢收拢、两侧线内伸，之后一帧变为实心。适合明确的确认或章节重音；不适合把未经验证的「更快」当真实产品结论。原例左右的一周／四小时是示意，不能直接作为本项目收益数据。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/typography/outline-word-fill.md)、[OutlineWordFill](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/typography/outline-word-fill/OutlineWordFill.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/outline-word-fill.mp4)。原卡给定两次落定，源码可见轮廓与硬切，抽帧可见90帧样片16幅阶段；原创为制作推导。未正常速度观看、试听、运行上游或原创实现。

## 2．制图语言要有层次，不能满屏等亮HUD

原例暖黑、余烬橙，220px／500静态无衬线词，2px暖灰轮廓。细线与中等字重留下内白，实心点亮后仍是同一字形。字体轮廓重叠可能在描边时暴露内部接缝，应实际检查所选字库，不笼统断言某平台字体都不能用。

主环半径410、dash22／18，内圈72格刻度、每30°长刻度，四个套准标记；左右水平线dash14／12，停在圆外28。侧读数30等宽、主字220形成尺度差。内圈透明度低，只提供仪表纹理，不承担第二焦点。换长中文词时同步改字宽、环半径、侧线端点与读数位置；不能仅缩字体到细字。

静帧应能辨认主词、比较读数与辅助说明。没有可信比较时，应撤左右数字，把空间交给真正的确认依据，而非保留两个漂亮但没意义的数。

## 3．两次落定与实际保持时间

| 帧 | 准确机制 | 导演判断 |
|---|---|---|
| 2～13 | 词scale3.2→1，2～8淡入，速度差驱动失焦 | 短促尺寸落定，不把字大部分时间糊在脸前 |
| 8～52 | 环scale2.8→1，8～18淡入 | 慢收与字急收形成快慢对照 |
| 28～46 | 侧线伸至522与1398，读数进入 | 线停圆外，不切进字里 |
| 44～53 | 暖灰轮廓变亮橙白 | 预热给54硬切以动机 |
| 54 | outline0、solid1，同帧变色／光脉冲 | 没有几帧渐变填充，是明确材质确认 |
| 54～62／68 | 字辉光8帧退，冲击环14帧退 | 不是永久强光字 |
| 56～70、59～73 | 眉题、说明分别进入 | 73才全部完整，非原卡70 |
| 73～89 | 主要文字完整 | 只有17帧完整尾段，还须按真实字量留阅读 |

主圈并非54帧立刻锁死：54前0.22°/帧，54后还用14帧滑过6°；内圈始终−0.14°/帧。整体慢推、尘点与颗粒继续，不能把54后36帧称为全静止。光脉冲后Stage还保留+0.15亮度，不完全回旧强度。

两层字共享字体、字号与位置，outline层仍占布局，solid绝对叠放。若改字体时两层fallback不同，会点亮跳形；满态需撤不必要的临时滤镜，同时保留确有意图的弱晕。抽帧53空心、59已实心，硬切准确性由源码支持，仍应补看53／54逐帧与正常速度。

## 4．原创演绎：把一个真实检查结果确认为「一致」

**目标。** 教观众核对导出文件是否与设定尺寸一致。先设计最后画面：设置宽高、实际文件宽高、明确的单位与匹配关系；下一镜打开图片检查内容和裁切。只有实际读取数据匹配才给「一致」，不是动画播到54就默认通过。

**美术。** 中心短词「一致」，两侧改为设置／实际，采用相同单位和读数层级。背景中性深色，暖色仅点亮结果；环可以变为轻量尺寸框或核对范围，不为HUD感保留72根无用刻度。

1. 展示真实设置和实际属性，说明正在比较哪个量，不能把文件大小与像素尺寸混为一谈。
2. 两侧读数先清楚，中心短词空心作为待确认状态；需要读取时保留真实等待，不伪造检查。
3. 证据一致后才硬切实心，同时用明确但克制标记连接两个对应值；不靠庆祝光遮住单位。
4. 让观众看到对应关系，若不一致就改成真实差异提示，不能用同一庆祝结尾。
5. 下一镜打开同一文件，检查主体与裁切，说明尺寸相同不代表画面内容必然正确。

此设计未实现。声音可在实际确认帧给一记短开关音，频谱与口播避让；原样片无音轨，不宣称已听出「钉子感」。

## 5．原创核对镜头的关键画面

| 状态 | 内容与排版 | 视觉主次 |
|---|---|---|
| 设定与实际建立 | 相同单位、相同字段顺序，两端清楚标「设置／实际」 | 先读值与口径 |
| 待确认 | 中间空心短词，外环或尺寸框只托住关系 | 几何弱于真实数据 |
| 确认瞬间 | 真实结果取得后才变实心，清楚保留两端值 | 一次重音，不遮单位 |
| 完整结果 | 中心词与依据保持，辅助解释出现 | 说明确认了什么 |
| 内容复核 | 打开同一导出图像，主体与边界可见 | 尺寸一致之外再检查内容 |

尚未实现的教学草案可以预设导出1280×720，并用实际生成文件的属性核对；这里只给构图意图，不声称已经生成或测量该文件。两端宽高必须同时显示，不能只取一个1280就宣称匹配。若结果为1280×800，中心应如实显示不一致，点亮的确认修辞也应改为问题提示。原例Faster的制图环可以简化成对应宽高的框边，让几何具有解释作用，而不是无论核对什么都套一个圆。

## 6．失败与验收

| 失败 | 修正 | 通过证据 |
|---|---|---|
| 空心字内部出现多余交叉线 | 检查真实字体轮廓，换合适字形或路径 | 外轮廓与内白干净，非描出重叠构造线 |
| 实心时词跳宽 | 两层同源字体与位置，等待字体就绪 | 只改变材质，身份和基线连续 |
| 确认后环还动却记静止 | 按实际68／73等完成点记录 | 主词可读，持续动作有意且不分散 |
| 光太强看不见读数 | 减脉冲、保清晰本体，检查最亮帧 | 确认瞬间仍知道确认了什么 |
| 有结论无依据 | 接入真实设置与文件属性 | 对应值可核查，下一镜继续验证内容 |

验收字急收、中环、侧线满态、53／54硬切、说明完整、实际结果与下一镜；正常速度、真实数据、声音各自验证。
