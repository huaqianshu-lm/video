# 大字距同步描画：让一个词作为整体显形

本镜的观看体验是“整词一起长出来”，而不是一个字接一个字被打出。字的位置固定、所有字符共享同一时间进度，细笔画逐渐补足，背景为字形让出安静区域。它适合短题字与身份收束，不适合大段正文，也不能用笔画显形代替知识解释。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/opening/letterspace-materialize.md)、[LetterspaceMaterialize.tsx](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/opening/letterspace-materialize/LetterspaceMaterialize.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/letterspace-materialize.mp4)、[缓动与视觉工具](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Polish.tsx)。固定原卡与main实现分开核对，不宣称代码和媒体已同版运行。

本文分**原卡给定、源码可见、抽帧可见、制作推导**。样片1920×1080、30fps、105帧、3.5秒，无音轨；查看16张精确帧。未正常速度完整观看、运行上游或实现原创镜头；未取得原卡提到的Superhuman原片。参数仅解释案例，实际制作遵循 [质量规则8.6](../../../docs/VIDEO-PRODUCTION-RULES.md)。

## １．适用角色：短题字需要静谧，不承担整段解释

| 使用问题 | 可以采用 | 不宜采用 |
|---|---|---|
| 品牌或短章节名出现 | 名称本身值得读一次，随后接实际内容 | 为普通正文每句都描笔画 |
| 从忙碌操作进入结果回看 | 用低能量的一次显形收束注意力 | 与多个闪光、弹跳、相机急推并发 |
| 介绍手写、字形或路径 | 显形过程本身与内容有关 | 把现成字体双轮廓描边当手写笔顺 |
| 教界面操作 | 只作短连接 | 观众看完题字仍不知道发生了什么 |

**制作推导**：两项核心条件是整词时间统一与字形连续生长。视觉上同时开始，不要求每一条笔画具有相同物理速度；长字形可更快，短字形可更慢，让同一词的视觉收笔协调。必须先决定是“单线骨架”“轮廓描边”还是“真实笔画填充”，三者的画面语言和实现都不同。

## ２．完成态先设计：字形、负空间、山与水

### ２．１　整词以轮廓节奏形成主体

**源码可见**：字标是15字符的小写词，包括连接号，使用13种自绘骨架字形。每个字符有独立宽度，统一64高视框，基线59、x高22、升部5。整体放大1.3，字行高83.2，笔画反向缩放后屏幕仍5.5px，字间固定30px。

按当前字形宽度合计542，整行显示宽为542×1.3＋14×30＝1124.6，横向居中时左397.7。不是15个同宽字框，也不是CSS的普通0.6em字距。30／83.2约0.361，若以小写实际字身高度48.1为参照又不同；不能把原卡约0.6em与当前数值混为一种定义。

字标行中心在y470，字框上缘428.4；主水天线y640。实际字形不顶满视框，中文或大写替换后需重做光学中心，不能只保留同一div顶边。连接号、i、t等窄字在大字距中提供节奏，不能把整词强制排成等宽棋盘。

**抽帧可见**：结尾细浅字位于紫灰天空和霞光之间，暗山脊在其下方，倒影更低、更暗。字标没有罩一块黑卡，靠背景亮度控制与轮廓完整性获得阅读。字体是几何小写，不是通用系统字体；实现别处换字体不会自动得到本镜字形。

### ２．２　背景不是一张暮色照片

**源码可见**：天空从`#17153a`到`#8a5878`再压回暗部，地平线附近有横向铺出画外的宽霞光。两条程序山脊由固定正弦叠加，远山偏亮偏紫、1.2px虚化、75%透明；近山`#271f43`较深、轮廓较实，构成大气透视。

水面自y640开始，顶部接霞光倒映，底部逐渐压到`#0d0b1a`。22条短横波光按深度分布，越靠前整体越宽，位置和透明度按缓慢正弦变化。2px水天线只在中段较亮，两边淡出；它不是横贯画框的硬白线。

**制作推导**：真实空镜应先挑一个适合放字的负空间，而不是先生成任意美景再盖文字。山形不要穿过最细的必读笔画；水面高光不应比题字更亮。若素材有船、人或太阳运动，它们可能比字更吸睛，需要换片段、改取景或将显形延后，不以压暗整幅粗暴解决。

### ２．３　反射是一套平面近似

字标倒影围绕y640镜像：倒影框顶`1280−470−41.6＝768.4`，scaleY−1，12%透明、2.4px模糊，再用渐隐mask压低远端。它共用文字进度，不能主字未写完而倒影已完整。

倒影没有真实波浪折射，也不随近层推近共同变换，属于视觉近似。要拍真实水面或反光桌面，应让反射遵守实际平面与观看位置；没有反射载体时不要为了多一层就加一排镜像字。

## ３．同步描画机制与多子路径的关键限制

### ３．１　单一连续路径怎样显形

**源码可见**：所有字符共享`e＝ramp(frame,16,52,bezier(0.5,0,0.3,1))`。SVG使用`pathLength=1`、`strokeDasharray=1`、`strokeDashoffset=1−e`；e≤0时不绘path，避免首帧圆端帽残点。

对于一条连续子路径，归一化使同一个e对应其总长比例，长短不同的字符都可以在68达到完整。字符本身不平移、不错峰，不靠遮罩依次显示上半／下半。圆端帽和圆转角帮助保持细笔画的柔和，但锐角字形要重新检查收口。

### ３．２　同一个path里有多个M，不等于笔顺串行

原卡及注释把i的点、t／f横笔等安排在路径末尾，称其按顺序写出。需要区分路径数据顺序与dash实际语义：SVG规范规定，每条子路径开始时会重新开始虚线模式。因此一个path中用多个M分开的笔画，不会仅因写在末尾就等待前一笔结束。[SVG 2描边规则](https://www.w3.org/TR/SVG/painting.html#StrokeDashing)。

**源码与规范推导**：当前i的主竖线37、点线0.5，总长37.5；共享进度下点会很早完整，主竖线在e约37／37.5时完整。t的竖51、横20，分别在e约0.718和0.282就可覆盖整段。不能据共享e写成“所有字符每一笔都精确到68才齐收”。这属于规范与路径推导，尚未通过本地浏览器执行验证。

**制作推导**：若要求真正逐笔串写，将各笔拆成独立路径，按同一字符的累计长度分配进度。设当前字符总长L，第j笔起始累计长Cj、长度Lj，则该笔进度为`clamp((e×L−Cj)／Lj)`；各字符仍共享e，就能同起同收，同时保留自己的笔顺。若目标是所有笔并行结晶，就明确采用并行笔进度，不声称手写笔顺。

### ３．３　中文不能把轮廓直接当骨架

现成字体转路径通常得到实心字形的外轮廓，描出来是双线边缘。汉字的横竖撇捺还涉及笔顺、交叠和粗细，不能从拉丁13字形库自动补出来。先选“几何单线题字”还是“毛笔／钢笔笔触”，再决定手绘中心线、描边遮罩或分笔填充。

如果为了精确字形使用完整填充字配合笔画mask，mask只控制显露，不参与最终字形；交叉处不能提前漏出下一笔，也不能用过粗遮罩把邻笔一起刷亮。中间帧必须仍像正在写，而不是分块擦除黑纸。

## ４．时序、光晕与所谓静置

| 通道 | 当前实际时序 | 核对意义 |
|---|---|---|
| 开场无字 | 0—16，16时e仍0 | 首次非零在17，背景已在慢动 |
| 描画 | 16→68 | 52帧进度，不是每字52再依次叠加 |
| 蓄亮 | 52.4→68 | 收笔前30%进入，不是最后瞬间硬闪 |
| 光晕回落 | 68→82 | 字形完整后还有亮度与光晕变化 |
| 霞光升亮 | 42→94 | 比收笔更晚完成 |
| 背景慢推 | 0→105 | 远层最多2%，近层3.5%，最后输出104 |
| 字形完整展示 | 68—104共37张 | 只能称字形保持，不能称全画面静止 |
| 霞光完成后 | 94—104共11张 | 水光、背景与颗粒仍可能变化 |

**源码可见**：文字自身不位移，光晕半径由5到15再回5，亮度透明度由0.3到0.68再回0.3；背景远近慢推围绕水天线缩放，不能把3.5%称整场统一3%。水光持续往复漂移，背景不是静态图。

**制作推导**：要的是静谧，不一定要绝对冻结；但必须说清实际在动什么。旁白读名时，水面细动可以维持环境，若正逢重要定义则停掉额外光晕和高光变化。文字完整后的阅读时间从68算，视觉完全稳定另算，不能混用。

## ５．关键帧与画面审查

实际查看0、15、16、20、28、36、44、52、60、67、68、75、82、94、100、104。

| 关键状态 | 抽帧可见 | 应据此判断 |
|---|---|---|
| 0、15、16 | 程序山水已存在，字尚未出现 | 背景本身有层次，字区是否干净 |
| 20、28 | 多个字同时出现短笔，整词有平行节奏 | 是否像描画，短笔是否过早完成 |
| 36、44 | 字形逐渐可辨，山水与反射不抢主位 | 中途仍可辨笔画方向，非分区硬揭示 |
| 52、60、67 | 字趋完整，光晕较强 | 细线是否糊、连字符与圆碗是否完整 |
| 68、75、82 | 字形不再增长，光晕退回 | 读名窗口不被新动作打断 |
| 94、100、104 | 最终山水题字 | 小尺寸观看时是否仍能读，压缩后是否有色带 |

抽帧不能证明同步显形的全速手感，SVG规范推导不能替代具体引擎观察。实际实现要放大检查点与短横、再正常播放看整词，不能只核68帧全字是否齐。

## ６．原创演绎：题字“来处”接到原文证据

以下为**制作推导**，未实现。教程章节要说明“结论要能回到材料中的原句”。题字只负责建立章节身份，后续必须有一条真实原句与结论的对应，不把题字当完整解释。

### ６．１　先设计静态题字画面

选用已获许可的真实书桌／资料工作台照片，浅木纹在下方、柔和侧窗光在右侧，中上部留较暗、纹理较少的区域。禁止让几何山水暗示这个教学主题必须用暮色风景；环境应来自读资料的真实情境。

题字“来处”采用自绘单线几何字，两字各约132×132，间距64，总宽328，置于画面x796附近、光学中心y440；线宽先试6px、暖白`#f3eee3`，无彩色外发光。副句“让结论回到原文”30px，置y580，保持独立阅读层。实际字框、重心和笔画交叉要以手绘路径与最终画面实排，当前只给设计规格。

两字各自拥有有序笔画与累计长度，统一e在同一时段推进。字与字同步开始、同步完成，字内按真实笔顺；不让短笔在全词起步时全部闪满。固定完整字形的轮廓，mask只揭示，避免画完后突然换成另一套字体。

### ６．２　完整调度与内容接棒

| 阶段 | 画面与动作 | 内容职责 |
|---|---|---|
| 接前镜 | 前镜真实材料页退出，保留桌面与纸张质感 | 从实际资料进入章节 |
| 起笔 | “来”“处”同时开始，字内依序显形 | 建立短题字身份 |
| 收笔 | 线宽与颜色保持，轻微亮度回落即可 | 让观众读完整章名 |
| 阅读 | 副句完整，所有新增动作停止 | 宣布本章要解决的问题 |
| 交棒 | 题字降为角落小章标，真实材料页进入正视阅读 | 场景从氛围变成证据 |
| 下一镜 | 定位一条确实存在的原句及其结论引用 | 用内容证明“来处” |

题字到章标的转接可参照 [标题让位](../../examples/title-to-section-label.md)，但须重新排中文缩移终点。题字描画结束与缩移开始之间留完整读取时间，正文不能在每笔未完时就同时飞入。

### ６．３　版面、素材与时长重新推导

若真实桌面图片宽3840映射到1920，则场景倍率0.5；进入证据页时，资料页应使用独立清晰素材，不从背景照片中的小纸页不断放大。章标缩小后的最细线宽要重设，不能把6px乘0.25变为难读1.5px后仍宣称清楚。

先为两字绘制关键笔画25%、50%、75%、100%的静帧，审查交叉处、转角和字间重心，再接时间。显形时间按口播和笔画复杂度决定，不沿用英文52帧。阅读段从“来处”与副句都完整后开始，后续页内字数另配阅读时间。

不为每一笔配一个音效。可用一层很轻的笔触底声，收笔结束即退，进入原文讲解时由人声接管；没有声音资产与试听时不写“听感已通过”。真实资料、照片、字形路径、原创实现和连贯观看目前都待验证。

## ７．失败诊断与通过条件

| 失败 | 修正方向 | 可观察的通过证据 |
|---|---|---|
| 看起来是双线描边 | 重新选择骨架或分笔填充 | 字形像中心线生长，最终造型一致 |
| 短横／点在起步即完整 | 检查多M子路径，按累计长度分配 | 字内先后符合选定的描画方式 |
| 各字先后起笔像打字机 | 共用词级进度，去每字延迟 | 全词并行进入，同一阶段收束 |
| 远景很美但细字读不清 | 重选字区、对比、字重与背景纹理 | 静帧不依赖大光晕也能读 |
| 倒影与主字不同步 | 同源路径和同一进度 | 每个中段主字与反射身份一致 |
| 37帧被误写全画面冻结 | 分开字形、光晕、霞光和背景 | 文档描述与实际慢动相符 |
| 描完后换实心字体跳形 | 统一最终字形，或精确重合交接 | 完成态没有笔画位置／粗细突变 |
| 题字后仍是抽象口号 | 先完成真实证据接棒镜头 | 下一镜能定位实际原句与结论 |

Storyboard应明确短题字的职责、字形来源、同步方式、子笔画顺序、字区负空间、最后完成通道、阅读时间和接棒内容。关键帧、SVG行为、正常速度与声音各自核验；本篇不宣称已得到商用题字镜头。
