# 自适应胶囊轮换：让句子接受词宽变化

## 1．与固定词槽的区别先说清

中间深色胶囊滚动换词，宽度随词长平滑变化，两侧句干自然移开／收拢。适合枚举同一种句法位置上的对象或角色；如果句干需要像坐标尺一样固定，就选固定槽方案。轮换文字只能说明讲了哪些项，不能自动证明软件已处理它们。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/typography/pill-chip-slot-cycle-handled.md)、[准确实现](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/typography/pill-chip-slot-cycle-handled/PillChipSlotCycleHandled.tsx)、[Motion坐标与时间](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/_fixtures/Motion.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/pill-chip-slot-cycle-handled.mp4)。原卡给定宽度响应，源码可见测量和幽灵项，抽帧可见150帧的16幅阶段；原创为制作推导。未正常速度观看、试听、运行上游或原创实现。

## 2．胶囊材质与句法层级

480×270设计坐标，在1920输出放大4倍。两侧30px／800＝输出120，胶囊内22px／700＝88，图标18＝72；胶囊高48＝192，左右外距14＝56。深色面#1a1c24、白字、下软影，浅底#fbfbfd。它是句中徽章，不是整幅应用界面。

四词长度接近，胶囊宽度为实测词宽+74设计像素，额外空间容纳图标、间距和内边。两侧flex:none，不被压扁；整个句子flex居中，因此宽度变化时两侧都在移动。若只想让右侧动，应改为左锚布局，这是另一种设计，不是本卡原行为。

上下幽灵项只保留前后邻词，灰字基础透明度0.13，提示有一列可滚动内容。它们不是需要逐条阅读的第二份列表；对比不足时可去掉，而不是加深到三行同样重要。

## 3．位置、宽度与幽灵的时间关系

`t=f/149`，三次窗为.25～.37、.47～.59、.69～.81。实际连续边界是37.25～55.13、70.03～87.91、102.81～120.69帧，第一完整新词分别从56／88／121帧起；不能简单用150×百分比写成精确整数。

pos为三窗inOutCubic的和，列Y=−48pos；胶囊宽在floor(pos)与下一词实测宽之间按小数插值。两者共用pos，滚到哪里就有相应宽度。改成独立CSS transition会依赖播放历史，跳帧预览可能不同，应继续用纯时间函数。

幽灵基准上−38、下58，半速roll=(pos−round(pos))×48×.5，滚动中更淡、落定更清晰。在pos半整数处，邻词文本和roll会跳换；其最低opacity是0.052，**不是完全不可见**。若真实素材或放大后能察觉，就改为邻项连续交叉淡出，不能因为注释说「不可察」就不验。

## 4．测量与画幅改造

隐藏span挂载后用offsetWidth量一次，未显式等待webfont，也没有delayRender。length×13仅兜底，不保证首帧精确；制作时应等待当前字体就绪，测量图标和词的实际组合，或固定经验证的宽度。系统emoji跨平台外观、变体选择符和宽度不同，可换自有同系列SVG。

DesignStage默认按输出宽度缩放，固定480×270，不自动适配任意纵横比。竖屏需要重新构图，让句干与胶囊分行或缩短文本，而非把横版硬缩到中间。胶囊完整态、最大宽与切换中段都要测。

抽帧40仍是第一轮过程、79第二次滚动有两行裁边、109第三次滚动，129以后最后词稳定。源码没有额外相机／纹理时间源，末段主要几何确实保持；是否像素恒定未做全帧比较，不代替正常速度观看。

## 5．原创演绎：一句话里的三种真实排序依据

**目标。** 说明同一文件集合可以按名称、日期或大小查看，最后停在本次要用的一种。先设计结果：真实列表、当前排序标识、一个可核对的文件顺序；下一镜实际切换并观察顺序，而不是只写「全部搞定」。

**美术。** 句子改为具体语义「按［名称／日期／大小］查看」，胶囊用同一套排序图标，采用中文实测宽度。列表是内容主角，词槽只在上沿作为讲解标签；阴影轻于原例，避免徽章像大按钮抢画面。

1. 先建立真实同一集合与当前排序；明确词槽是讲解标识，还是实际可操作控件。
2. 每换词都同步给对应真实排序结果，先一个主要切换充分解释，其余简洁跟随；不沿用原例固定18帧硬赶操作。
3. 胶囊宽度和列位置同源，左右标签自然响应，但列表自身固定，便于观察对象重排。
4. 最后选择日期并保留实际升／降序符号，定位一份文件；不能用「日期」两个字替代方向说明。
5. 下一镜打开该文件并核对日期来源，使变化有实际结果。

此设计未实现。切换可配三次轻滚动／贴合声，响度不盖住排序依据；官方样片无音轨，需实际试听。

## 6．原创排序教学的关键状态

| 状态 | 主画面内容 | 词槽职责 |
|---|---|---|
| 集合建立 | 同一批真实文件，名称和属性可辨 | 说明当前按什么查看 |
| 名称排序 | 一个主文件和邻项的顺序清楚 | 胶囊只标当前依据 |
| 切换中段 | 列表按真实规则重排，文件身份连续 | 文字移动与宽度共用pos |
| 日期落定 | 升降序符号、日期列和目标文件相邻 | 不把「日期」误当完整排序条件 |
| 打开文件 | 文件内容和属性对应 | 槽位退成小标签或撤去 |

草案尚未实现。可使用三份自建教学文件，名称、修改日期与大小刻意各有不同顺序，明确它们是示例；这样一次切换就能看出真实排序关系，而不必飞二十行。主文件保留同一强调，其他行只跟随重排，不能给每行同样大弹簧。胶囊在讲解区、真实排序标识在应用区，二者应同义但不混成同一个控件；幽灵项只提示可切换选项，不代表列表中还有隐形文件。

## 7．失败与验收

| 失败 | 修正 | 通过证据 |
|---|---|---|
| 宽度突然跳、文字被切 | 等字体就绪再测，共用pos插值 | 切换全程留边合理，末态不挤字 |
| 两侧被压缩 | flex:none并核对句子总宽 | 字形不变形，只发生位置响应 |
| 幽灵在半拍跳字明显 | 降权或连续混合，查最低opacity | 邻项只提示列表，不成为第二焦点 |
| 中文或emoji撑破胶囊 | 测实际组合，使用确定图标 | 各平台输出在当前环境可控，图标风格统一 |
| 只换词，没有对应结果 | 衔接真实排序和打开行为 | 能看出依据、顺序和具体文件 |

验收最宽／最窄词、两次半整数、中段裁切、最终结果与下一镜，再正常速度配口播检查。与 [句尾胶囊轮换](pill-slot-cycle.md) 相比，本篇允许句干移动，不可混淆稳定支点。
