# 固定句干与句尾胶囊：枚举之后如何得到完整句子

## 1．先确定枚举是不是同一种句法

固定句干后依次换六个动词短语，最后胶囊退出、结论补齐并居中。适合已讲过的能力回顾或少量同类动作；六个功能词本身不构成六份证据，不能凭最后一句「全能」推断实际支持范围。教程应把各词接到真实操作／结果，或只列本段真正解释的几项。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/typography/pill-slot-cycle.md)、[PillSlotCycle](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/typography/pill-slot-cycle/PillSlotCycle.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/pill-slot-cycle.mp4)。Notion商业原片仅为原卡的出处说明，本篇未重验。源码可见锚点、滚筒与收束，抽帧可见200帧的16幅阶段；原创为制作推导。未正常速度观看、试听、运行上游或原创实现。

## 2．美术与固定阅读轴

浅柔光底，句干96／800，left300固定；胶囊正文64／700，白面渐变、细边、顶部内高光、两层软影。图标统一34px线性SVG，置于62方块、浅强调色底，避免系统符号风格混杂。正文是动词短语，不能在同一轮里混入长段落与单字。

句干与胶囊间距36，最后结论词改成普通词距18。列举期位置不受当前胶囊宽影响；源码用当前pill的隐藏占位决定槽宽，宽度在换词时可直接变，不是平滑自适应插值。固定句干能掩护重心变化，但不能声称整个槽宽连续。短语长度差太大时，先改文案／布局，再考虑额外宽度动画。

整体行在y540垂直居中，靠flex对齐；句干入场0～12有上移、淡入、失焦。只有入场结束后才称其「钉住」，不是从首帧就纹丝不动。

## 3．每拍的进出与材质跟随

六拍起点12／33／54／75／96／117，每拍21；新pill前8帧从+120到0、rotateX−38→0、scale.94→1，减速落槽。旧pill7帧向−130加速退出、rotateX0→34、scale1→.94。新旧方向同为向上，但曲线相反，不能两者都ease-out造成软交叉。

竖向模糊由位移半帧差驱动，入上限14、出12，只有Y轴；满态滤镜不挂。阴影随lift提高而扩大变软，材质与飞行距离呼应；用全屏各向同性blur会把边、字与阴影一起糊成块。透视1400给轻滚筒，不应把整词转到不可辨认才落地。

固定SVG滤镜ID为psc-in等，多实例同场可能重名，原创复用应实例化ID并核对引用，不能直接把两份源组件拼进同一页面。

## 4．最后不是48帧全静止

138开始最后胶囊7帧退出，结论14帧从+90以back1.4落位，到152。整行居中实际从150开始、用26帧到176，和结论末2帧重叠；不是完全落定后才移动。176～199才有24帧几何保持，背景仍有颗粒。原卡「48帧完整句hold」包括了26帧居中，不可误当48帧静止。

结论96／800与句干一致，临时margin−18把36槽距还原成18普通词距。最终宽度通过隐藏句测量，首次布局读一次、没有等webfont；换字体需字体就绪后量。当前示意结论无真实结果检查，不能把它作为功能承诺证据。

抽帧13首pill仍模糊，66第三项清晰，119末pill正在进入，146结论已出现但尚在位移，172仍接近居中收尾。正常速度下短语能否读完取决于语言和字长，不能按21帧普遍保证。

## 5．原创演绎：同一照片的三个实际导出用途

**目标与结果。** 教观众为预览、文章和归档选择对应导出条件。先画最终态：三个真实输出文件及用途、尺寸／格式，主对象是本次选择的那一份；下一镜打开它检查。胶囊文字只枚举用途，不伪称一次操作自动生成全部。

**美术。** 固定句干为具体对象，如「这张照片用于」，槽内是平行短语，最终句不泛化成「全部搞定」，而是落到当前实际选择。背景中性，图标同系；结果画面使用真实图片与属性，而非六张宣传卡。

1. 先建立同一原图，说明不同用途改变哪些真实要求。
2. 第一用途作为主示例，槽位换词时下方实际参数与图片同步；其余简洁跟随，但保留单位和格式。
3. 三项展示后最后槽退出，完整句落成「选择文章用图」等真实决策；先确保结论语法自然，必要时重写句干。
4. 整行轻移到结果上沿，文件本体获得主画幅。没有需要就省去独立居中动作，把时间给结果阅读。
5. 下一镜打开真实导出文件，比较尺寸和清晰度；与目标不符则返修，不能以动画结论盖过去。

此设计未实现。声音可用同类轻贴合音，主示例充分、其余递减；不要把每个词当同样响的击打。完成口播正常速度试听后再判断节奏。

## 6．原创导出用途的取景与焦点

| 状态 | 具体画面 | 可核查关系 |
|---|---|---|
| 原图 | 一个真实主体、源文件身份和必要属性 | 所有用途来自同一张图 |
| 主用途讲解 | 当前词槽＋真实尺寸／格式，图像占主空间 | 文字与输出条件对应 |
| 后续用途 | 词槽保持阅读轴，简洁切到对应真实结果 | 不把三个用途变成三份无关素材 |
| 选择收束 | 完整句说明当前选哪份，文件从次级转主角 | 决策由用途条件支持 |
| 打开结果 | 实际图像、像素尺寸和所需细节可见 | 输出不是只存在于宣传文案 |

草案尚未实现。预览、文章、归档的真实规格由当前任务决定，参考不预设文件一定应更小或更清楚。三种文件可保持相同视觉主体，让差异来自真实尺寸／格式，而非换成三张更好看的图。完整句居中若打断当前图像的阅读轴，可以直接转为上沿结果标签；使用参考的动作目的，比原样保留26帧居中更重要。

## 7．失败与验收

| 失败 | 修正 | 通过证据 |
|---|---|---|
| 句干每拍左右跳 | left固定，不随pill居中 | 六拍共用一个稳定阅读起点 |
| 新旧pill同重叠很久 | 进出分曲线，缩换位窗，检查遮挡 | 读到当前短语，知道旧项已离开 |
| 满态仍模糊 | 速度差归零后撤滤镜 | 字、图标和细边清楚 |
| 结论突然像新标题 | 同字体字号字重与普通词距 | 看成同一句话补完，不是再开一页 |
| 最后居中吃掉结果时间 | 按176完整点留时间，必要时撤居中 | 结论与真实输出能被理解 |

检查固定句干、最短／最长pill、中段同屏、收束138～152、居中150～176和实际文件；正常速度、真实内容与声音独立验收。
