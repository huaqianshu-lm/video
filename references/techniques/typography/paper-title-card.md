# 纸面章节字卡：用一句具体话给下一镜铺路

## 1．只负责路标，不代替内容

逐词压印的一句话、一个强调词、一条短线，随后退出。适合作为章节连接或高密度内容后的换气；不是所有功能前都强制插字卡，也不能全片靠纸卡解释。句子应告诉观众下一镜具体看什么，之后立刻由实际内容兑现。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/typography/paper-title-card.md)、[PaperTitleCard](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/typography/paper-title-card/PaperTitleCard.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/paper-title-card.mp4)。原卡给定压印和呼吸位，源码可见排版／计数／淡出，抽帧可见55帧的16个状态；原创为制作推导。未正常速度观看、试听、运行上游或原创实现；原例12镜头为示意。

## 2．先做一张能独立站住的排版

暖白低彩纸面、中心偏上暖光；116px／600衬线，行高1.14，字距−0.012em，版心最多1500。flex换行，指定第三词后强制断行，避免下行孤词。仅一个收益／动作词用琥珀斜体，不让每个名词都有强调色。

220×6短线位于标题下38，副行再隔34、26px等宽大写，字距0.12em。短线是中心收束符号，不紧贴关键词，因此与 [手绘下划线](marker-underline-title.md) 作用不同。中文要选适合当前内容的字体与语义分组，不能强制斜体，也不为两行差不多长删掉事实限定。

纸光是图形渐变，不是真纸压印物性。所谓压印感来自scale1.28→1、失焦7→0和opacity同进度，而非真实凹陷、阴影或墨扩散；若要实体印刷质感，需要另做美术证据，不以命名代替画面。

## 3．词数、数字与退场必须一起算

八词delay4+4i，每词9帧。最后词32起，到41完整；强调词28～37。下线16～34，副行10～22，数字第1位12～34、第2位16～38。结论不是所有东西等标题写完再出现，而是多个层次重叠。

55帧总长，47开始8帧淡出，完整正文只有41～46这6个无淡出帧。前词虽已读过，换长中文句或加副行后仍要重算，不能把1.8秒作为所有章节固定时长。`最后词=4+4(n−1)+9`，再从退场点倒推实际阅读。

数字列重复0～9两遍，位移(10+target)×行高，tabular-nums和固定裁切保证不跳高；它只是滚动到一个写定数字，不是实际统计。数字应在淡出前完整且留读数时间，长数字每位再延4帧会迅速吃掉尾段。

整张AbsoluteFill连底一起淡出，所以最终底色取决于下方场景；单独演示抽帧50／54变暗，不能误写成纸面自身曝光降低。f54透明度仍为1/8，f55才数学归0，但不在本片输出中；接下一镜时要明确外层合成，避免一帧残字或黑闪。

## 4．原创演绎：引导观众去看一次真实来源定位

**目标。** 连接「提出结论」与「回到原文检查」。先设计下一幅真实内容：原文局部、目标句和出处；本字卡只说具体动作，例如「把结论／放回原文」。终态不是另一句价值口号。

**美术。** 中文两行按语义断开，强调仅给「原文」，字体和后续资料的纸面呼应。副行若没有必要数字就省略，不虚构「已查12份资料」。版心留足负空间，短线可作为进入原文标记的颜色预告，但不要把它错认成已划在原文上的线。

1. 前镜结论完整停留后，再出现字卡；不是在观众还读图表时抢进一句话。
2. 各短语压印，全文和标点在退出前有足够阅读时间；长句缩短为明确动作，而不是压快到读不清。
3. 字卡纸底与原文纸面配准或用清楚切换，退场时原文已经在位，不让整张卡淡到黑再重新淡入白页。
4. 原文目标段落成为主角，原字卡缩为章名或彻底退出，避免两句同等大标题并存。
5. 下一镜定位并阅读具体原句，说明是否支持前结论。若不支持，就展示修正，不预设「查证成功」。

这是尚未实现的演绎。可统一使用轻过渡声或完全由口播连句，不机械照搬源模板四个固定帧音效。声音、完整速度和真实内容需后续实际验证。

## 5．原创章节连接的关键帧

| 状态 | 画面内容 | 与前后镜的关系 |
|---|---|---|
| 前镜结论 | 论点与已有证据完成阅读 | 不用字卡抢走未读结果 |
| 章题形成 | 「把结论／放回原文」按两组语义排，强调只给原文 | 说明下一步具体动作 |
| 章题满态 | 字形、短线、留白独立成立；无必要数字就不放 | 只做路标，不制造数据 |
| 原文接管 | 原文纸面与章题底色协调，段落成为主焦点 | 同一任务连续进入验证 |
| 定位近景 | 真实目标句和上下文可读 | 兑现「回到原文」的承诺 |

草案尚未实现。该句若在真实字体下只能排成三行，先看是否需要改短语，不为了强行两行而把「原文」缩成小字。满态应从最后语义组完成点计算，短线可以提早开始但不可被当作阅读结束命令。退场既要看字卡本身opacity，也要看下一层原文有没有提前透出造成双读；最终合成中原文必须稳定可读，而非一张好看纸卡溶进另一张密字纸卡。

## 6．失败与通过证据

| 失败 | 修正 | 通过时看到 |
|---|---|---|
| 两行孤词、标点掉行 | 明确语义组和强制断行，测最终宽 | 句子按意义读，版面重心稳定 |
| 数字没滚完就退 | 从淡出帧倒推各位完成点 | 数值完整可读，不在最后一刻猜数字 |
| 单卡好看，片子像PPT | 减少使用、让真实内容接棒 | 字卡只是连接，主体镜头有操作和结果 |
| 淡出变成黑闪 | 检查下层场景和切点合成 | 纸面自然交接，没有意外暗帧／残字 |
| 引导句泛泛而谈 | 写具体动作／对象，匹配下一镜 | 观众知道接下来要观察什么，并实际看见 |

验收完整排版、最后词与数值、47前阅读段、淡出与下一镜合成；再正常速度配口播看是否真有换气作用。原卡的固定50～55帧、每功能前字卡是其作品方案，不升级为本项目通用规则。
