# 首词缩回组句：让阅读顺序沿着一个支点展开

## 1．从一个概念进入完整主张

首词先大幅占据中心，随后缩回并落到整句的自身位置，后续词推入；主句上移、副句填入，再以短推近交给下一镜。适合短概念引入与章节连接，不宜把长段口播塞进一行，也不能把末尾crash当独立片尾。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/typography/lead-word-zoom-assemble.md)、[准确实现](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/typography/lead-word-zoom-assemble/LeadWordZoomAssemble.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/lead-word-zoom-assemble.mp4)。原卡给定支点与编舞，源码可见布局测量和时间函数，抽帧可见84帧的16幅阶段；原创为制作推导。未正常速度观看、试听、运行上游或原创实现。

## 2．两词排版和克制背景先成立

原句只有两词，最终96px／600、−0.03em，第二词靛蓝，第一词墨色。背景浅灰网格般柔光：左上靛蓝、右下极淡暖色、中心亮面，无需真实卡片与厚重材质。副句34／400灰色，整句站在大面积负空间中。

首词初始2.3倍，到12帧2.438倍，其字形和宽度要足以读清而非被截掉关键尾部。原卡说「两侧略溢出」并非所有字体和词都会发生，应实测。中文先选短语义组，确定字号、断行和强调词；不可把未经排版的十几个字都放大2.3。

最后静帧应看主句与副句的距离、字色主次、整行居中和基线；背景再美也救不了过长的一行。强调只给一个有意义的词，不必照用品牌名。

## 3．支点怎么保证首词身份稳定

先测整行宽W、首词中心位置c与基线b，`leadRatio=c/W`；整行居中时向右补`W(0.5−leadRatio)`，把首词送到屏幕中线。缩放origin横向放首词中心、纵向放基线，故缩小时首词的基线位置不被盒中心拉走。

组件delayRender后在挂载时读offsetWidth、offsetLeft；零尺寸inline-block尺读offsetTop作基线，metrics准备好才显示。不应只用「字号×0.8」估算。但源码仍有fallback，并且没显式等待document.fonts.ready；换网络字体必须保证字体加载完成后再测，避免先量回退字体。测量所得也不是跨环境永恒常量。

各词inline-block，词间空格放在块外。实际改为语义短语或中文时，空格与标点应按内容重排，不能用隐藏空格修布局后丢失真实文本。

## 4．动作曲线与完整时间

| 帧 | 实际变化 | 设计检查 |
|---|---|---|
| 0～6 | 首词透明度0→1、约8px屏幕失焦退出 | 第0帧没有首词，不能写「一开始整词可见」 |
| 0～12 | scale2.3→2.438 | 是继续推近，不是完全hold |
| 12～24 | 加法缩回到1，同ZOOM_EASE | 幅度和速度受12帧窗口影响 |
| 12～36 | 整行横移归位 | 虽同曲线，持续时间不同，不是同一p；允许位置长尾 |
| 18～30 | 第二词从右0.5em推入，18～20淡入 | 两词原例不证明更多词自动适配 |
| 32～46 | 主行上移56，副行同步入场 | 和横移末4帧重叠，别出现空位后再补副句 |
| 46～71 | 主副排版保持 | 背景颗粒仍变化 |
| 72～83 | scale1→1.2、blur0→9、opacity1→.45 | 转场前半，必须设计下一镜接法 |

相加两段scale保证数值连续，不自动证明任意替换曲线后速度连续；应查窗口边界的导数／逐帧差。缩回失焦用scale半帧差×10、上限3.5，和首词入场失焦相加，满态撤去。它只是速度感近似，不是物理快门。

抽帧11首词大、22第二词已入场、33副句很淡、44主副已接近完成、77开始糊、83明显失焦。下一镜若忽然清晰静态全景，前半crash可能断裂，应预先设计相同主对象或明确切点。

## 5．原创演绎：从「范围」进入真实选区与结果

**目标。** 教观众先确定操作范围，再执行修改。先画最终态：真实编辑器中一个连续选区，边界与当前作用对象可见，下一镜执行格式修改并核对范围外内容没变。不是把「范围」缩成一行口号后换页。

**美术。** 首词「范围」在中性浅底占中心，整句补成具体原则；强调给「先确定」或主概念之一。最终编辑器沿用同一左轴和强调色，选区不加玻璃卡边或彩虹光。文字字体与实际中文界面风格一致。

1. 让主概念独占一拍，但保证完整字形；测首短语中心和基线，不能按英文字宽估算。
2. 缩回同时补齐原则句，后词从自身槽侧进入；词数增多时重算最后完成点，不挤掉阅读。
3. 上移让真实编辑器出现，原句成为小标签；内容接棒比副标题逐词花样更重要。
4. 若使用末尾推近，让推近支点对准同一实际选区；下一镜以对应观察距离接住，再清楚展示边界。没有连续对象就取消crash。
5. 执行真实修改，显示范围内变化与范围外对照，说明原则的实际后果。

声音可在主概念收束与内容接管给轻微节奏，不给每个词等响冲击。此设计未实现，真实字体测量、正常速度和声音待验。

## 6．原创「范围」镜头的空间调度

| 状态 | 正向画面设计 | 仍保留的身份 |
|---|---|---|
| 首词占场 | 两字大但完整，负空间包围它，不把副句挤在边角 | 主概念与字体轮廓 |
| 收缩半程 | 首词基线稳定，后短语从自身槽位推进 | 同一个词，没有另画替身 |
| 主副满态 | 具体原则句清楚，副句只说明当前任务 | 强调色不扩散到整行 |
| 选区接棒 | 真实编辑器成为主体，上沿保留小章名 | 同一对象与作用范围 |
| 结果核对 | 范围内格式变化、范围外保持，必要时局部近景 | 改动对象和结果对应 |

尚未实现的草案可用一段明确教学文字，只选第二句并修改字重，显示第一、第三句未变。选区的颜色和章题强调色可同色相，但语义要区分：章题是讲解，蓝色选区是实际状态。尾部推近如保留，应先把选区置于稳定支点，再让下一镜接住；不能先对整句中心crash，下一镜却突然从无关工具栏开始。静态满态看主副字形、行距与上下负空间，动态中段看阅读轴是否被横移和上移共同拉散。

## 7．失败与验收

| 失败 | 修正 | 通过时看到 |
|---|---|---|
| 缩回时基线飘动 | 正确测量并设首词中心／基线origin | 同一首词身份稳定，非上下漂移 |
| 字体加载后突然跳宽 | 字体就绪后测，检查跨环境 | 首帧和后续布局一致，无错误大字闪帧 |
| 词粘成一团 | 词块外保留正确分隔，实测标点 | 终态可读，词距与语义一致 |
| 先缩再另滑一拍 | 重查共享曲线及时间重叠 | 看成一次组句，长尾有目的 |
| 尾部推糊后硬断 | 设计下一镜或撤crash | 连续进入实际内容，非动画没播完 |

检查最大词、缩回中段、横移尾段、主副满态、crash最后帧和下一镜第一帧；补做真实字体、正常速度及口播审核。
