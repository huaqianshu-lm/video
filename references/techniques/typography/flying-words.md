# 词语纵深隧道：让信息氛围退在主内容之后

## 1．适用边界：背景，不是能力证明

22个词从远处向观众接近，中心固定标题保持阅读焦点。适合短暂建立主题范围、资料丰富度或穿行感；不适合解释每个词的具体含义，更不能把飞过的能力词当产品已支持的证据。需要观众记住的内容应停留、展开并由实际结果接管。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/typography/flying-words.md)、[FlyingWords](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/typography/flying-words/FlyingWords.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/flying-words.mp4)。原卡给定词云角色，源码可见投影和生命周期，抽帧可见180帧的16幅状态；原创为制作推导。未正常速度观看、试听、运行上游或原创实现；循环接缝尚未动态验证。

## 2．静态中心与三层纵深共同组织画面

中心112px标题、30px等宽眉题，后有1520×520径向暗幕。飞词使用64～120px基础字号，三阶冷白，6个衬线斜体、4个电光蓝强调；不是每词都发光。10道扁椭圆环建立隧道壁，56条尘线提供速度参照，词只承担可偶尔辨认的内容纹理。深蓝黑空间和中心冷光形成远端焦点。

中心词的压暗按椭圆位置计算，不是碰到标题才突然隐藏。设计时应实查当前标题实际包络，长中文句可能超出原椭圆；加暗幕也不能掩盖前景字本身排版拥挤。中间标题在不播放时仍要清楚、宽度合理，不能靠背后大量运动衬出「高级」。

## 3．投影、生命曲线与速度细节

P4400，z从−7000到+3200，尺度`s=P/(P−z)`，从约0.386到3.667。**z>0只表示越过舞台原点，不是越过相机平面**；相机平面在z=P，原例始终未到奇点。原卡把正值解释为穿过相机不严谨，可感的擦身来自投影放大、向外散开和出画。

黄金角约2.39996弧度加固定扰动，半径330～990、Y压到0.6；散开d=0.5+1.35u。每词`u=(2f/180+i/22)%1`，身份和随机参数固定。OP在u0／.25／.6／.85／1为0／1／.5／.2／0，中段退弱，近端退场，避免处处满亮。

方向尾迹按当前与上一u的位置差，六层text-shadow向−v排列；各偏移除以s，使外层缩放后的屏幕长度合理。远端u<.22失焦，近端u>.86失焦到约8.4屏幕像素量级；不会靠把所有词永久模糊来制造层次。尘线使用2.6帧跨度位置差，但用同一个当前roll，故是近似速度参照，不是完整历史轨迹。

源码按低透明度条件返回null，**不是原卡所说全部22词全程不增删DOM**。词相位／运动仍确定，不应把节点常驻当不可违背条件。主要审查随机是否固定、时间是否可重放及视觉是否连续。

## 4．循环成立的范围要拆开

词、环、尘线各自取模，滚转±2.5°用sin(2πt)，中心光呼吸sin(4πt)，在t1与t0回到相同参数。但Stage有自身呼吸／Grain等时间源，**整数CYCLES不是整幅输出无缝的唯一充分条件**。要做循环背景，还应锁定或周期化舞台噪声，比较f180与f0，并检查179→0的速度，不要求179和0像素相等。

180帧中无安排停留，每词90帧一轮。抽帧可见很多词在边缘被裁、中心标题始终稳定；这支持氛围层定位，不支持「每个词都读清」。若需要讲22项内容，应另做有逻辑的分类与实际案例。

## 5．原创演绎：从阅读线索进入一份真实资料

**目标。** 开头说明研究涉及哪些观察维度，随后进入一条实际证据。先设计结果：一份可阅读原文、一条具体问题和定位标记；下一镜读该段内容。词表只来自实际研究维度，不能塞与内容无关的流行词。

**美术。** 中文关键词用短语和真实字体测量，不按「汉字固定两倍英文」缩字。中心一句短问题，背景词亮度低一档，强调仅给当前准备深入的维度。可减去环和尘线，让资料语气更安静；纵深不需要总是表现为科幻空间。

1. 中心提出一个能被资料回答的问题，周围维度词低对比掠过，只承担范围感。
2. 选定一个主维度，其他词继续退弱，不能让五个同重飞词同时压住问题。
3. 主维度停止作为氛围，在合理阅读位置保留；从其后出现真实资料局部，保持语义连续。
4. 隧道撤去，资料占主画幅，显示原句与出处，而不是留一整屏高速词云加口播。
5. 下一镜定位证据并解释它支持什么、不支持什么。视觉收束由研究内容决定，不由循环刚好播完决定。

若制作循环待机背景，可独立使用本技法；若用于教程，必须设计退出和结果，不能永远循环。声音建议低密度气流或无拟音，正文进入即退；样片无声，正常速度和声画关系待验。

## 6．原创「从范围到证据」的关键画面

| 状态 | 视觉主次 | 空间约束 |
|---|---|---|
| 问题建立 | 中心一个短问题，背景只给相关维度词 | 主句之外保留呼吸空间，不把词云挤成边框 |
| 范围流动 | 一次只让少数近词可辨，其余低亮度 | 词的最长包络不穿过主句关键词 |
| 选定维度 | 一个词清楚停靠，其他维度继续退弱 | 不能四个词同时停在中心 |
| 资料出现 | 真实段落在同一阅读轴展开，词变小标签 | 隧道光不继续染色原文 |
| 证据解释 | 原句、出处与限定条件清楚 | 背景流线和无关词全部退出 |

草案尚未实现。研究维度可来自当前文章实际使用的「定义、条件、来源、限制」等短词，但只有确实用到才放入；少于22词时重新分配相位和留白，不复制同义词凑密度。一个长中文词在近端的屏幕宽度会乘s，必须看最宽时的真实轮廓；用出画和退弱解决，不把主句也一起缩小让路。选定维度后可以停止循环并直接进入资料，不必等待两圈结束，剪辑时间由信息目标决定。

## 7．失败、修正与通过证据

| 失败 | 修正 | 通过时看到 |
|---|---|---|
| 所有词从中心爆出来 | 保持椭圆铺位和避中心半径 | 有远近通道，中心主句不被穿破 |
| 近词巨大遮住标题 | 生命曲线退弱、空间压暗与近端出画协同 | 前景始终可读，背景仍有深度 |
| 词像静态贴图放大 | 叠位置散开、投影与速度尾迹 | 方向和速度相互支持，不只scale循环 |
| 循环接缝闪一下 | 审查全部时间源，不只CYCLES | f180与f0参数／输出符合预期，179→0运动连续 |
| 词很多却没讲任何内容 | 选择一项进入实际证据 | 观众获得具体认识，背景只负责引导 |

检查最大近词、中心遮挡、边缘裁切、循环边界和退出后的真实资料；静帧、正常速度、阅读与声音分别验收。
