# 表盘数字交接：让一个读数成为句子的起点

## 1．量程感不是数据证据

九个等大数字沿弧扫过，5到弧顶后直接迁入标题首槽，其余退去。核心是**同一数字从仪表读数转为语句的一部分**。适合真实数量、经过证实的时长或教学示意；不等距数字在等角刻度上并不构成真实线性仪表，更不能用「45扫到5」证明性能提高。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/typography/countdown-arc-scatter.md)、[CountdownArcScatter](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/typography/countdown-arc-scatter/CountdownArcScatter.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/countdown-arc-scatter.mp4)。原卡给定交接意图，源码可见极坐标／槽位／速度，抽帧可见100帧的16个阶段；原创为制作推导。未正常速度观看、试听、运行上游或原创实现；5分钟安装未经本篇实测。

## 2．仪表美术与最终句子一起设计

暖白纸、墨色112px／700数字、朱红读数标。数字等大等字重、tabular-nums，沿半径700的弧切向旋转；圆心(960,1150)，弧顶450。内侧小刻度、外侧半径800发丝弧与顶部三角形成量程外观，红指针以盘转角0.35倍跟随，避免整组像一张贴图。

最终标题150px，数值与词同一字重，只有末词染朱红；下方34px等宽命令行和顶部刊头为次级信息。原例弧可见宽约1315.6，约占画宽68.5%。标题不是居中数字再随意补句：估算总宽985.5，左缘467.25，首槽0.6em＝90，中心512.25；5从弧顶迁到这个位置。

换中文先测整句字宽和单位，不把数字、量词拆成无关元素。大数字必须有单位和口径，不能把「5」独立保留而把「分钟」缩成无法读的小字。

## 3．同一数字的完整路径

盘角0～5从96°后吸到99°，随后弹簧d12／k60趋向0。第i数字位置角`(i−6)×24+rot`，x=cx+Rsin、y=cy−Rcos，自转同角度。5在i6，终角0，正好弧顶；换主角索引要一起重设。

可见度`clamp((70−|角|)/22)`，不依赖硬矩形遮罩。32～52同一h把5的位置混到首槽，字号112→150、自转回正；其来源位置仍受盘角函数驱动，不是从一个固定起点直线飞过去。其他数字28～44仅失焦淡出，无额外散飞，给主对象让路。

方向模糊用数字屏幕位置的半帧差分，amount0.16、max14；非主数字退场blur另加到6。主数字不应在落位后继续挂速度拖影。标题首槽只留空，不再生成第二个5；否则会有重影、粗细变化或落位瞬间替换。

| 帧 | 动作 | 检查 |
|---|---|---|
| 0～5 | 盘面预备，顶部信息0～14建立 | 第一帧虽有数字，顶部并未全部出现 |
| 5起 | 大角度扫停 | 回弹峰和衰减按实帧，不把注释当精准停止点 |
| 28～44 | 非主数字、内刻度和指针退去 | 主对象路径不被同时飞散分流 |
| 32～52 | 5迁入标题首槽 | 最后落点、字重、字面中心与句子对齐 |
| 42～66 | 三词重叠进入 | 数字先到，但句子在其落位中已开始形成 |
| 64～76 | 末词变强调色 | 是语义落点，不是每词依次变色 |
| 62～78 | 命令行进入 | 78后才是完整信息；尾部22帧仍要按真实字量判断 |

外弧最终只留35%透明度，成为读数记忆，不再像活仪表。抽帧33其他数字淡去、40主数在路上、53句子成形、79完整。没有正常速度观看，不能断言扫停与落位两拍已清楚。

## 4．原创演绎：把可核查的筛选结果变成一句结论

**目标。** 解释一个真实集合筛选后剩几项，而非虚构耗时降低。先设计最后结果：数字与「项符合条件」组成完整句，旁边保留真实筛选条件与对应列表；下一镜打开其中一项核对条件。没有实际数据时使用明确标注的教学示例。

**美术。** 中性纸面，数字为墨色，强调只给筛选条件或最终数量之一。若要保留弧，刻度应对应真实计数范围；不将45、35等随意数列伪装成统计过程。最终列表比命令行更重要，预留其版心与实际阅读距离。

1. 先显示真实原集合和条件，执行筛选或展示已验证结果。
2. 弧形数字仅作为讲解组织，主角为真实最终数量；如需表达精确变化，用真实范围和合理刻度，或直接取消盘转。
3. 其余数淡去，主数迁到结果句首槽，单位同步保持可读，不能在飞行中变成另一个数。
4. 句子落定时，真实结果列表接管主画面，保留条件和总数；少量对象有主次，不把全部条目同重播放。
5. 下一镜核查一个具体结果，说明为什么符合；遇到例外或不确定条件如实保留。

声音可把扫停与落位做成相邻但不同音色的轻拍，先依据实际帧决定间隔；不能把固定32／52帧写成通用音乐点。

## 5．原创计数结论的关键状态

| 状态 | 静帧应有的信息 | 运动怎样服务它 |
|---|---|---|
| 集合建立 | 真实条件、总范围和一项具体对象 | 先认清正在数什么 |
| 数字观察 | 数列／刻度的含义明确，单位不消失 | 盘转只组织观看，不伪装逐项计算 |
| 主数迁移 | 主数仍带同一语义，结果句为它留准确槽位 | 身份连续，其他数字只退弱 |
| 结果满态 | 「数量＋单位＋条件」与真实列表对应 | 先读结论，再看其中一项 |
| 下一镜 | 打开具体结果，条件与字段可核对 | 结论有真实内容支撑 |

原创草案尚未实现。若使用明确的教学集合，可以先准备十项可逐项核查的样本，其中五项满足一个单一条件；画面标为教学示例，不能把这个数量说成真实用户数据。最终五项可按有意义顺序组织，主对象稍大并保留身份，其余降权，不能又飞成五张同样重要的卡。标题数字与列表计数共用实际集合长度；当条件变化时，两者同帧更新，避免先显示5而列表仍有6项。计数结论需要保留条件口径，不能只留下大号5。

## 6．失败与验收

| 失败 | 修改 | 通过证据 |
|---|---|---|
| 主数停不到弧顶 | 重设主角索引和零角 | 停止后读数与顶部标记同轴 |
| 落进句子后重复一个数 | 首槽只占位，飞行主体保持身份 | 全程只有一个主数，落位粗细无跳变 |
| 末词出现后整句偏一边 | 实测最终文字宽，而非只改估算em | 整句视觉居中，数字与单位间距合理 |
| 数字很多却没有可信结论 | 用真实集合／口径，展示结果 | 数量能逐项核查，不靠表盘造可信感 |
| 只余22帧却塞长说明 | 缩句或延长结果段 | 正常速度下能理解结论并接下一镜 |

检查初始弧、最大速度、主数交接中段、首槽满态、结果列表与下一镜；静态构图、真实内容、正常速度和声音分别验收。
