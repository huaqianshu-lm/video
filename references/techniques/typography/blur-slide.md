# 逐词虚焦收敛：让标题服从语义与版式

## 1．它负责轻声引入，不负责制造内容

标题按词从微小上移、虚焦和透明中收敛，副标题在主标题结束前跟进。适合已有明确内容的章题、引导句；不适合用来代替操作、比较或结果。全片若每镜只是同样的两行字浮现，曲线再细也仍是文字翻页。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/typography/blur-slide.md)、[BlurSlide](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/typography/blur-slide/BlurSlide.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/blur-slide.mp4)。原卡给定三通道同源，源码可见实际词数和排版，抽帧可见120帧的16个等距阶段。原创为制作推导；未正常速度观看、试听、运行上游或原创实现。

## 2．静态画面先靠字体、尺度和留白成立

原例暖纸墨字，左网格168。刊头24、朱红眉题30、两行衬线主字170／400、副句无衬线46／400。主副字号比约3.70，字体家族和尺度共同区分，不能只把副题透明度降低。主字起点x162做视觉补偿，眉题与副句x168几何对齐；基线比盒子左缘更重要。

两行y384／556，主角词cinematic为斜体朱红，只有它更晚落定且带字距收拢。右后景760px刊号只用约4.5%墨色，向左缓漂24；它不是可读信息，不能放重要数字。刊头固定，主体绕(168,560)缓推到1.03，形成轻微层次。新内容若要展示真实照片，后景刊号可撤，不应强迫每篇都有巨数字。

用中文时按语义分3～5组，例如「先保留／原始信息」，而非把每个汉字各做一个弹入。先定断行和标点归属，测量最终宽度；`split(' ')`不会自动理解中文。必要的说明不能伪装成低对比装饰小字。

## 3．三通道同一个p，主次不靠排队

每词`p=ramp(f,start,dur,EASE.out)`，透明度p、Y位移(1−p)dy、模糊(1−p)B。主标题dy64、blur18，副题dy26、blur9；同一进度使清晰度和位置同步。最后主角词字距0.03→−0.025em也绑定p。分开启动会出现位置已到但字仍糊的悬空感。

词距由flex gap产生，**源码主标题0.24em、副0.26em**，不是原卡概述的0.32em。模糊达p≥0.999就撤滤镜，避免满态仍挂微小采样。中文字体边界和标点需要另查，英文的em留空不能直接当中文词距标准。

| 内容 | 实际时间 | 应理解的关系 |
|---|---|---|
| 眉题 | 4～22 | 先给语境，不用与大字同幅运动 |
| 首行三词 | 10／14／18起，每词22，到40 | 观众读成一句，不是三次同重事件 |
| 次行两词 | 26起22，30起30，到60 | 主角词最后清楚并获得颜色焦点 |
| 副句 | 34起，9词、gap2.4、each20，到73.2 | 原卡写9词正确，80是概括保持点；34～60与标题重叠 |
| 刊脚线与页码 | 72～98 | 内容完成后还有版面闭合动作 |
| 主体慢推 | 0～119 | 80后并非全画面静止 |

最后完整时间通式为`start+(n−1)gap+dur`，不是gap×n；再加阅读预算才是可切走的时间。副句原文「Shot recipes and camera moves, crafted by your agent.」有9词。抽帧40第二行尚糊，56副句尾词在收敛，79正文完整但刊脚仍在画。

## 4．原创演绎：标题让位给照片中真正的裁切边界

**目标与结果。** 章题说明「先保留主体，再调整边界」，接下来让观众在真实照片上辨认保留与舍弃。先设计结果画面：照片主体占主区域，裁切框与原图范围清楚，章名降为稳定小标签；下一镜实际移动一条框边。

**美术。** 标题用两行中文，强调只给「主体」；副句只补充当前问题，不重复口播。纸面颜色可与照片背景衔接，主字的左轴延伸到后续图像注释；不保留上游刊头和07装饰。关键照片在标题段可作为低对比局部存在，但不同时要求读其小标签。

1. 先排静态完整标题，确认强调词在最后收敛时仍在合理行宽内。
2. 三个语义组按同一p体系出现，副句小幅跟进。实际口播决定起点，不把固定帧数当默认。
3. 标题完整后保留读句时间，再沿左轴缩成章节标识；背景照片同时获得完整取景，不只是出现三张解释卡。
4. 裁切框围住真实主体，标出一个需要保留的关键部位。只有此时才出现操作说明。
5. 下一镜真实调整边界，看到主体被保留／切掉的具体后果；标题不再承担全部解释。

无须给每个词配点击声。可让一句口播带动阅读，转入照片时安排一个轻声交接；声音和正常速度仍待制作验证。

## 5．原创标题与照片如何占同一张画面

| 关键状态 | 排版与焦点 | 衔接依据 |
|---|---|---|
| 主句先读 | 左轴固定，第一短语墨色，第二行的主概念有唯一强调 | 先理解原则，不抢照片细节 |
| 主副重叠 | 副句靠近标题块下方，幅度更小；右侧照片只作为弱背景 | 大字最后词清楚时，说明已经跟上 |
| 章名降格 | 主句收成上沿标签，照片扩大到主要画幅 | 同一左轴保留章节身份 |
| 照片解释 | 主体与裁切边界清楚，标签退到次级，标记只指一个位置 | 信息变化来自图像，不来自又出现三段文字 |

这是未实现的排镜草案。中文标题可按「先保留主体／再调整边界」两行排，强调主词需与口播要点一致，不把每个短语都染色。照片若主体朝右，保留其视线方向空间，让文字占相反一侧；主体在中央时可先用纯标题，再以明确连接进入全图，不硬把标题叠在人脸上。审查标题最后词最大宽、缩成章名后的可读尺寸及照片接棒时的图文重心，不能只看透明度归1。

## 6．失败、修正与验收

| 失败 | 修改 | 通过证据 |
|---|---|---|
| 中文逐字蹦，像字幕机 | 人工语义分组，重定行宽 | 观众按短语理解，不逐字追踪 |
| 主副一样大幅浮动 | 减副题位移和模糊，保持固定阅读轴 | 主词是焦点，副句支持而不抢拍 |
| 字距变化挤出右边 | 检查最终与运动中最大宽度 | 标点完整、行尾不撞装饰和安全边 |
| 标题到位还发糊 | 共享p，满态撤滤镜 | 最终字形清楚，位置与合焦同时结束 |
| 只有一句漂亮口号 | 让实际内容接棒，设计下一镜 | 视频展示了可观察的内容变化 |

验收起始版式、主角半清晰帧、主副重叠、最后词与刊脚完成、真实内容接棒；再按正常速度和口播审核。原卡所谓「默认解」是选型建议，不意味着所有片都必须使用。相关 [大标题变节标签](../../examples/title-to-section-label.md) 负责后续阅读权交接。
