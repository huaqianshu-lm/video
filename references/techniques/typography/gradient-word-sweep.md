# 关键词充能：把一处文字重音做出光的层次

## 1．只有一个词获得重音

白色标语中一个词被左到右染亮，波前最强、后方回落；完成后少量细闪电点缀。适合确有能量语义的短连接镜头，不适合解释任意教程结论。真实能力或改善须由后续画面证明，渐变和闪电不能替代证据。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/typography/gradient-word-sweep.md)、[GradientWordSweep](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/typography/gradient-word-sweep/GradientWordSweep.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/gradient-word-sweep.mp4)。原卡提及ClickUp来源，本篇未重新取得该商业原片；研究证据为准确组件和105帧官方演示的16幅抽帧。源码可见分层和排期，抽帧可见美术，原创为制作推导；未正常速度观看、试听、运行上游或原创实现。

## 2．先审无光排版，再审光

近黑带微紫底，92px／700斜体，两行中心排版、行高1.28、字距−1px。关键词之外是同等清楚的白字，但没有彩光和闪电；主次来自局部材质差异，不是把其他词压得看不见。背景大暗角与细颗粒托住主体，不出现独立移动星点。

关键词四层关系是环境大光、字形大晕、中晕、近核，再叠清晰渐变本体。原实现环境0.55、字形大晕0.55、中晕0.62、近核0.72再乘glowLvl；不能把这些opacity当最终亮度或通用阈值，层叠、混合、背景与字重都影响实际观感。字体内白和字间隙在峰值仍应辨认。

渐变从青蓝经紫粉到琥珀，有单向色序。清晰本体裁在字形，辉光允许溢出；波前亮核也保持字符形状，不变成一颗沿线跑的白星。

## 3．揭示、尾迹与防止方框光

关键词先有白字底，再有同样字形的渐变层；12～30帧out-quad揭示，宽度0→100%。刚揭开的前沿附近有约34%词宽尾迹，越靠前越亮；30～40退回稳态。填色不是逐字符硬换色，也不是整词同时亮起。

模糊层放进四周外扩90px的Halo盒，mask色标用`90+(盒宽−180)×比例`换回字坐标。若直接在文字盒上裁blur46，会把溢光切成矩形；若外扩了盒却仍按盒百分比扫，前沿会错位。清晰层用clipPath，发光层用软mask，两者职责不同。

闪电路径在700×240局部SVG内固定生成，换关键词长度必须重排，不能假设它自动跟实际字间隙连接。长弧三层6／2.4／1.4px，短弧更细，紫红色而非纯白粗电弧。

## 4．实际排期和保持口径

两行0～14、4～18进入；填色12已启动，与第二行入场重叠。闪电绝对起点35／45／55／66／76／85／89，生命3～4帧，末次89～91，92起无闪电。源码事件间隔末两次只有4帧，**注释「≥9帧」不成立**；同屏最多一道与事件间隔是两件事。

填完后glowLvl仍逐帧读固定噪声，闪电时额外增亮；整组慢推到1.025，颗粒变化。因此92～104不是全图静止，只是没有新闪电。抽帧35、55、76可见细弧，97以后仍有渐变字与柔光。闪光是否过密、是否抢口播尚待正常速度判断。

## 5．原创演绎：用一个「启用」重音进入实际参数结果

**目标。** 解释一个真实功能开关如何改变当前结果。先设计最后画面：开关状态、同一素材、实际产生的差异，下一镜查看该差异的细节。只有功能和结果已经核对，才可用充能词表达章节重音；不让闪电充当真实软件反馈。

**美术。** 简短中文句，强调词选择与内容一致的动作，如「启用」；主标题不过分倾斜，正文和参数为稳定直立字体。彩光只在章节连接中短暂使用，进入实际界面便撤去。真实照片、代码或图表用自己的色彩，不整体染紫。

1. 先说明准备启用哪个参数，展示当前未启用的真实状态。
2. 连接句中只让动作词接受快速染色；辅助词保持静态，不逐字再配三层动画。
3. 关键词完成时，取景接到真实开关所在位置；开关点击与结果变化按真实行为展示，不用闪电遮掉过程。
4. 真实结果占主画幅，明确指出变化位置；若无可观察变化，保留事实并检查条件，不宣布成功。
5. 下一镜放大同一位置的细节，说明效果和适用限制。能量镜头只负责引导，论证由真实内容承担。

本设计未实现。声音可以只给填色末端一次轻重音，零星电弧不必每次配响；先保证口播清楚，再做正常速度试听。

## 6．原创关键词到真实结果的画面表

| 状态 | 美术与内容安排 | 焦点交接 |
|---|---|---|
| 参数未启用 | 实际界面和同一素材，状态读数明确 | 先知道准备改什么 |
| 连接短句 | 一个动作词有彩色材质，其余白字安静 | 只为内容转折建立重音 |
| 半扫 | 波前亮、后方有颜色但较弱，保留字形内白 | 视线跟一次方向，不追独立光点 |
| 操作接管 | 真正开关被操作，字卡退为小标签或撤去 | 让真实因果可见 |
| 结果近景 | 同一素材具体变化被指出，参数状态仍可查 | 观众能验证，而非听口号 |

草案尚未实现。若选择图像锐化之类有局部结果的教学，真实素材的同一纹理位置应保持配准，展示实际参数；充能镜头不参与前后质量比较，比较时须撤光和风格层。若内容只是开关布局变化，应以界面状态为结果，不把闪电暗示成性能提升。峰值静帧要看词边、内腔和周围白字是否均有层次；大光圈若吞掉白字，即使关键词很亮也未通过美术检查。

## 7．失败与通过证据

| 失败 | 修正 | 可观察通过 |
|---|---|---|
| 彩光外沿是矩形 | 外扩光盒并换算mask坐标 | 光柔和衰减，没有被裁平的边 |
| 像进度条给字上色 | 缩短扫充、强化波前与后方差异 | 看出一次快速注入，而非慢慢加载 |
| 全词糊成一团 | 降环境／中晕，保持清晰本体和内白 | 每个字轮廓仍辨认，光只增强重音 |
| 闪电飞在字外无归属 | 按真实字形重排路径、减事件 | 细弧与关键词有关，不像背景故障 |
| 充能结束仍无实际内容 | 衔接真实开关与结果 | 观众理解功能变化，非只记住口号 |

验收无光静帧、半扫、波前峰、最大光晕、最后闪电及实际结果；再正常速度配口播审核。源项目个别审美判例可借鉴，但不自动升级为本项目强制参数。
