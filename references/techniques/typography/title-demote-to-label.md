# 标题降为节标签：整卡双变体与跨章节接棒

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/typography/title-demote-to-label.md)、[TitleDemoteToLabel](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/typography/title-demote-to-label/TitleDemoteToLabel.tsx)、[title-demote-to-label 官方样片](https://vincentwei1021.github.io/video-shotcraft/media/title-demote-to-label.mp4)。下文区分原卡给定、准确实现、官方样片抽帧观察和原创制作推导；抽帧每条16幅，未完整正常速度观看、试听、运行上游或实现原创镜头。参数用于解释原例，不能直接作为当前视频默认值。

## 1. 与已认可案例的分工

完整标题美术、负空间、连续缩移、正文接棒与原创应用继续见[标题变节标签案例](../../examples/title-to-section-label.md)。本篇补整卡A/B的选择、文本选区变体和多节让位，不把完整案例重写成简版。标题动作只负责章节连接，正文中的操作、图像或证据必须接管，不能整片循环“大字缩小、三卡出现”。

## 2. 两种开场与同一终点网格

A直接显影短标题，B在显影后先表现文本被选中再撤选。B适合编辑器、文档或文字操作有意义的场景；非文字产品为了好看加选择色块，会产生错误功能暗示。两式都落到左上固定槽，旧标签让位，新的正文区沿同一左边距展开。

原例暖纸白底、深墨超粗无衬线、朱红句点与编号。220px标题字距收紧，30px等宽眉题较疏；终点scale.22约48.4px，但实际有效字形高度还受字体与祖先变换影响。中文需要重新选择可用字体、字重和行长，不能直接照搬英文负字距。右上页码与底部元信息只属演示包装，不是教程章节的必备。

## 3. 选区不是一块跟着飞的色板

B以两条百分比通道构造选择：on用10f把宽度0→100%，off用8f使左缘0→100%，宽度=max(0,on×100−off×100)。因此撤除像从左边让开，不是整体淡掉；插入光标跟选区右缘，结束后一起收净。选区层位于字下方，字本身不变形。

准确实现B reveal118、select.on136/off156、demote166；选区到164附近退净，之后才缩移。换标题长度后，不该用固定10f就假称完成真实拖选；这是设计性示意。若需要展示真实编辑操作，光标按实际文字选择边界运动，不能让背景色块代替交互。

## 4. 连续降格与多节交接

| 环节 | 原例关系 | 导演检查 |
|---|---|---|
| 缩移 | 26f，bezier(.6,0,.18,1)，(960,540)→(216,196) | 同一曲线驱动位置与尺度，不先缩再移 |
| 原点 | left center，translateX从−50%同步归0 | 防终点偏移半字宽；真实标题bbox要重测 |
| 前缀 | demote+20起12f擦入01/ | 终点为编号留缩进，不在飞行中穿过标题 |
| 内容 | A at48，B at178；各子块另有6/8/10等偏移 | “开始生长+12”是容器基准，首个可见子项更晚，不能据概述推精确读窗 |
| 旧标签 | f166起16f，上移68、缩至.7、变灰 | 旧章仍作定位，不能压新标签或累积十行 |
| A退出 | f112起12f，实际上移50px | 原卡概述写12f退场，不应误解成只移12px |

全长246f是两式串播，不是单一章节模板。A标题reveal0/demote36，B单段更长有选区；可读站稳时间要从最后一个字显影完成后算，不从第一字出现算。字幕、光标或弹窗不要在标题路径同一位置争焦点；正文可在落点下方接棒，并不意味着全画面不能有任何次级变化。

## 5. 样片观察与正文内容角色

16幅等距帧可见A中心标题变标签，下面三类卡并非同款复制：浅卡、深底衬线引语和波形卡形成明暗与字体对照。B则出现脚本文本、句内选区、引线与旁注条目，是具体位置到解释的对应。波形是函数生成装饰，不当作实测音频。

抽帧能确认两章共享舞台、旧标签上移，新选区撤去后缩移；不证明每个字完整站稳多久，也不代表正常速度节奏或原例声音。已有完整案例的证据边界继续保留。

## 6. 原创制作推导：选中一句话后解释它的条件

内容目标是“引用不能漏掉限制词”。先做终态：真实原文的一句与其上下文同框，限制词在原文位置，侧注说明该条件影响哪一项判断。章节标签短写“核对条件”，不把整句缩成小字。

若本节本来要教文本选择，用B：短标题选区作编辑语汇提示，撤净再让位；正文随后直接是同一份真实文档，光标选中那句并保留上下文。若文本选择没有教学价值，用A，省掉选区表演，把时间给原句阅读。

正文引线从真实限制词外侧出发，连接到一幅受条件影响的结果图，非一张泛泛总结卡。下一镜保持相同限制词，展示有条件与无条件时两种结果为何不同。若还需下一章，旧标签退成一行定位后退出，不让角落堆成章节历史墙。

## 7. 失败诊断与通过证据

- 选区跟标题飞成脏色条：检查off结束与demote起点，确保先退净，再开始缩移。
- 标签终点偏半个词：核对left-center原点和百分比补偿是否同步归零，不补手写像素碰巧对齐。
- 站稳时间算多了：从末字可读帧计，真实长标题重算，不套短英文36f。
- 多节左上角堆满：设置一个当前槽和有限旧定位，超过容量及时撤旧，不无限上移小字。
- 动画顺滑但仍像PPT：让正文展示实际原文、操作或关系变化，标题不承担全部解释。

通过设计须能指出短标题与正文具体内容的联系、双态排版、撤选干净、跨章节不碰撞及真实接棒。原例参数为研究依据，不改项目默认；正常速度、声音与原创实现仍未验。
