# 手绘下划线：让一笔标记有明确的阅读对象

## 1．先读标题，再强调一个词

标题站稳后，一条贴近关键词字底的干笔线快速划出。它用手绘与印刷字的材质差异指示重点，适合题目、原句或术语标注；不是标题下面任意增加一根装饰分隔线。强调之后必须进入内容解释，不能用「new」之类泛词替代实际变化。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/typography/marker-underline-title.md)、[MarkerUnderlineTitle](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/typography/marker-underline-title/MarkerUnderlineTitle.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/marker-underline-title.mp4)。原卡提及Notion原片，本篇未重新验证原商业视频；已核对准确实现和75帧样片16幅抽帧。源码可见笔形、滤镜与时机，抽帧可见图文位置；原创为制作推导。未正常速度观看、试听、运行上游或原创实现。

## 2．美术：字底关系比噪声更重要

118px／700、两行居中、行高1.12、负字距；关键词斜体，其余直立。浅纸面只有柔光、轻暗角与细纹。第二行是112标志与品牌字，不是正文；当前教程应换成有内容的副句或直接接实际画面，不默认保留上游署名。

笔画位于关键词局部盒left−12、bottom−20，SVG252×44；这不是相对字形最低轮廓的精确距离。字体下伸部、斜体外伸与标点可能改变视觉间隙，换词应看实际渲染。线太远变分隔线，太近碰字变涂黑；最好先画静态满笔与标题的关系，再设计揭示。

原例左低右高跟随词的斜势，正体中文不必强加同样斜角。中段略饱满、两端收窄，墨色#1b1916、0.94、multiply；不会靠粗边光体现手绘。笔画再粗糙，也不该覆盖字底的关键笔画。

## 3．轮廓、飞白与揭示分开控制

笔画不是均匀stroke，而是40段上下轮廓合成闭合形状。中轴从约19向10px上斜，叠低频缓波和固定微扰；宽度由14加中段6，再收细首尾。这样裁切推进时保留原笔形的粗细，而不是矩形条渐长。

干笔滤镜固定seed：低频位移1.8造成轻微毛边，高频纵向噪声经alpha阈值与轮廓相交形成细碎飞白。噪声只改变墨层，不改变标题；噪声seed不能逐帧变，否则划完还像信号故障。filter边界外扩，避免毛边被裁直。

32～42用矩形裁切从左到右，进度再经`1−(1−t)^2.2`，前快后缓。原卡泛称SVG描画，准确实现不是dashoffset；若直接换dashoffset到填充多边形，不会得到相同效果。裁切末端超过轮廓6px，减少收笔漏出。

## 4．完整节奏与保持范围

第一行0～22，第二行4～26；32起笔，所以相对全标题落定后6帧，符合「先读后强调」。42划完，至74共有33输出帧；整组仍缓推1→1.015，背景颗粒变化，不能叫整图像素静止。原卡「总1～1.5秒」与当前75帧2.5秒不是同一个时长口径。

抽帧25标题已清楚但无划线，35正在出现，40接近满笔，45以后保持。16幅图看不到每一个起收笔瞬间，正常速度是否一气呵成待验。将标题改长时，不应保留32固定起笔；按最后语义组完成点重新留间隔。

## 5．原创演绎：在原句里指出一个会改变理解的限定词

**信息目标。** 教观众阅读条件限定，例如「仅在本地」中的「仅」。先设计结果：真实原句、上下文和一个限定词，下一镜展示该限定对实际操作的影响。不是孤立放大一个词然后宣布重要。

**美术。** 采用实际文档字形，标记色与正文形成足够反差但不抢字。限定词保持直立，不为套斜线强改字体。下划线按真实行框定位，多行句子分行处理，不能一条斜线扫过两行空隙。

1. 先呈现真实完整句与必要来源，口播读到限定关系，给观众理解时间。
2. 原句保持稳定，短笔从限定词下方划出；笔迹只强调其范围，不暗示已经完成事实核查。
3. 略扩观察距离，显示限定词如何约束整句，保留原句不被总结卡替换。
4. 接到真实操作场景，演示该条件下发生什么；若比较条件外行为，保持同任务和明确边界。
5. 下一镜回看原句，解释哪个结果与限定吻合、哪些仍需验证。标记服务理解，结论来自证据。

此演绎尚未实现。可配一次轻划笔声，长度贴合实际笔画，而非从标题入场一直刷到下一镜；口播优先。

## 6．原创限定词教学的关键画面

| 状态 | 画面安排 | 必须能回答的问题 |
|---|---|---|
| 原句 | 完整句子、必要上下文和出处，字形直立清楚 | 这句话到底说了什么 |
| 单词强调 | 一笔贴字底，其他区域保持安静 | 标的是哪个限定，而非整句都重要 |
| 关系解释 | 限定词和受其约束的对象有轻连线／局部框 | 限定作用于谁 |
| 实际条件 | 真实界面／结果显示条件内外的差异 | 限定会带来什么后果 |
| 回看 | 同一原句保留，事实与文字对应 | 哪个结论已验证，哪个仍待核 |

草案尚未实现。可用明确标注的教学句「此操作只修改选中段落」；「只」与「选中段落」不是两个同等重音，先标限制，再让实际选区解释其作用。文字居左且下方留足一笔的空间，手绘线不伸到下一词或把逗号划成笔迹。多行句子中不要把第二行整体移上来迁就划线，应按真实行框标注，并保留能看懂限制的完整短语。材质只在笔迹上，原文不加随机粗糙滤镜。

## 7．失败与通过证据

| 失败 | 修正 | 通过时看到 |
|---|---|---|
| 像CSS分隔线 | 贴近目标字底、轮廓变宽、适量毛边 | 不看动画也知道强调哪个词 |
| 笔迹盖住下伸部 | 按真实字形重定位与缩宽 | 文字完整，标记有材质但不破坏阅读 |
| 划完还随机抖 | 固定种子，撤时间噪声 | 满笔稳定，不像故障 |
| 标题没读完就划 | 按真实最后词完成时间延后 | 先获得句义，再感到强调 |
| 标出重点却没有解释 | 接实际条件与结果镜头 | 能说出限定关系和它的后果 |

验收无标记标题、半笔、收笔、最终字底距离、正文解释和下一镜；再正常速度配口播看节奏。与 [逐词虚焦收敛](blur-slide.md) 可先后使用，但不让标题入场、笔迹与正文指示同时争一个焦点。
