# 裸词滚轮：让同一句中的对象清楚接力

## 1．固定词槽与自适应徽章不同

句干固定，句尾三行高视窗内四个对象依次滚过，中心清楚着色、上下邻项退弱。适合平行对象或已解释用途的短回顾；不适合首次讲四个陌生功能。末词若作为结论，应有真实包含关系，不能把「每一种」当未经证实的全能承诺。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/typography/vertical-word-roll-blur-cycle.md)、[准确实现](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/typography/vertical-word-roll-blur-cycle/VerticalWordRollBlurCycle.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/vertical-word-roll-blur-cycle.mp4)。原卡给定滚筒语法，源码可见距离、速度和退场，抽帧可见150帧的16幅阶段；原创为制作推导。未正常速度观看、试听、运行上游或原创实现。

## 2．裸词是句子的一部分

480×270设计坐标放大4倍，句干与滚词同30px／800、−.5字距；输出约120px。浅底、墨色句干、靛蓝中心词，未读邻词灰。与深色胶囊不同，这里没有徽章面、图标或厚阴影，主次来自位置、清晰度和颜色。

词槽固定190宽、132高，露三行；每行44，间距是句法结构的一部分。最宽词需完整，最短词也不能孤立在大片空白里。固定槽宽让外层flex中心不变，句干因而稳定；改为自适应宽后必须重新选择锚点，不能沿用「句干固定」的结论。

中文应用先测最长短语、标点和行高。改竖屏需重构句法与版心；DesignStage只按宽缩放固定横版设计，不会自动适配画幅。

## 3．位置、清晰度与色彩共用距离

三窗.16～.27、.36～.47、.56～.67，t=f/149，对应23.84～40.23、53.64～70.03、83.44～99.83帧。每窗约16.39帧，p为三段`0.7outQuint+0.3outBack`之和，前快后慢、有轻回摆；不是每段独立覆盖前一段。

整列Y=44−44p，中心行永远是第二行；各词d=|i−p|。距离模糊中心0、邻行3、远端最多5设计像素，另叠速度模糊最多4；SVG只Y轴，横向笔画保留。离中心越远还最多压扁14%，视窗上下软mask辅助滚筒曲面感。

opacity中心1，邻行.35，更远最低.1；色彩按`clamp(1−2.4d)`从灰到靛蓝，d<.4167开始着色。**不是只有完全落定瞬间才上色，也不是滚动中全灰**；接近中心就逐渐染色。实际制作要看半拍是否同时两词有颜色，避免误读两个都被选中。

DT固定为.5/(150−1)，而useT读取当前composition时长；若只改变composition duration不改常量，速度模糊的半帧近似就错。复用应统一取当前时长，或明确维持150帧。滤镜ID按索引固定，多实例要隔离。

## 4．尾词与退场并非彻底归零

末词约100起完整，.9开始淡出，即134.1，到.985即146.765完成。源码opacity为`1−seg×.999`，终值**0.001**，没有真正归零或卸载；且外层Grain继续变化。不能沿用原卡「不留残影」作为已验结论。需要干净交接时应明确归0／条件撤去，并检查下层素材。

抽帧30已接近第二词，60在第二次切换，89第三次，109～129末词清楚，139整体变淡，149基本不可见但非数学0。主体完整后约34帧才开始退场；是否足够要以真实中文读数和下一镜为准。

## 5．原创演绎：在固定句式中逐个识别文件类型

**目标。** 教观众辨认同一集合中的图片、音频和文档。先设计最终态：真实文件列表、扩展名／图标、当前一类的具体对象；下一镜打开一个文件核对其实际内容。不是滚过几个类别名就宣布都能处理。

**美术。** 句干为「当前查看」，词槽是平行类别名；颜色仅指当前讲解项，不冒充软件选择状态。列表保持固定观察距离，裸词放在上沿，与真实文件名有足够间隔；上下邻项低权重，不与实际列表混淆。

1. 先建立真实文件集合和一个文件身份，说明分类依据不只看名称。
2. 主类别滚到中心，同时给真实列表对应区域与一项细节；第一项充分解释，其余简洁跟随，不全部同样长。
3. 类别词颜色随位置集中，实际对象的高亮只在词已可认后出现，避免两个焦点抢读。
4. 最后停在文档，显示实际格式和预览，不把最后词写成没有证据的「所有格式」。
5. 下一镜打开该文件核对内容。退场时词组彻底撤去，真实文件保持，不淡到黑再另开一页。

此演绎未实现。可在三次真正落定处给轻音，短回摆不另加一次音，末词阅读时保持安静；需实际正常速度试听。

## 6．原创文件类别的画面调度

| 状态 | 画面主体 | 词轮的使用 |
|---|---|---|
| 集合全貌 | 少量真实文件、名称和扩展名 | 先建立当前对象范围 |
| 第一类 | 一个代表文件的真实预览 | 词到中心后才强化对象 |
| 半拍 | 列表不整体乱动，只有必要选项切换 | 邻词退弱，不与中心同样彩色 |
| 最后一类 | 文档预览和实际格式清楚 | 停稳后留足解释，不立即淡走 |
| 打开核对 | 同一文件真实内容成为主画面 | 词轮彻底退出，避免微残影 |

尚未实现的草案可用自建的一张图、一段声音和一份文本作为明确示例。图标只帮助定位，格式识别仍需实际属性与内容；不要用更精致的图标掩盖错误扩展名。词轮的固定宽度按最长中文类别加留边，邻词可见性按最终观看尺寸审查，不在四倍放大的设计坐标里误判其清晰。若实际教程没有选择机制，词轮应放在讲解层，避免观众以为它是软件真实存在的分类控件。

## 7．失败与验收

| 失败 | 修正 | 通过时看到 |
|---|---|---|
| 句干随词长晃 | 固定词槽宽、实测最宽词 | 观察轴稳定，变化只在句尾 |
| 邻词像灰色污条 | 保留Y向模糊与足够字形，不滥加全向blur | 可认出邻行是词，但不抢中心 |
| 中途两项都像答案 | 调整颜色／距离权重，延后内容高亮 | 正常速度只有一个清楚当前项 |
| 改时长后模糊不随速度 | 统一当前duration与DT | 速度归零时运动模糊归零 |
| 末帧残影 | 明确归0或卸载，核对合成 | 下一镜无旧字残留，文件身份连续 |
| 只列举无实证 | 接真实文件与打开行为 | 类别判断能由实际内容核对 |

检查最长词、三个半拍、最大过冲、尾词完整、146～149退场和下一镜；再审正常速度、真实内容及声音。与 [自适应胶囊轮换](pill-chip-slot-cycle-handled.md) 的句干位移策略相反，应按内容选择。
