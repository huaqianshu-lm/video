# 扫针自检与滚带定针：仪表身体动作必须服从真实数值

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/data/gauge-readout-moves.md)、[NeedleSweepSelftest](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/data/gauge-readout-moves/NeedleSweepSelftest.tsx)、[TapeScrollFixedPointer](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/data/gauge-readout-moves/TapeScrollFixedPointer.tsx)、[needle-sweep-selftest 官方样片](https://vincentwei1021.github.io/video-shotcraft/media/needle-sweep-selftest.mp4)、[tape-scroll-fixed-pointer 官方样片](https://vincentwei1021.github.io/video-shotcraft/media/tape-scroll-fixed-pointer.mp4)。下文区分原卡给定、准确实现、官方样片抽帧观察和原创制作推导；抽帧每条16幅，未完整正常速度观看、试听、运行上游或实现原创镜头。参数用于解释原例，不能直接作为当前视频默认值。

## 1．自检过程、量程与最终测量是三件事

A指针扫满270°再回真实目标，B固定读数窗让刻度带冲刺回摆。前者适合明确标注的自检演示，后者适合有统一单位的值变化；不能把扫针经过100%误读为测量真的达到100%，也不能用升级上限冒充当前实际吞吐翻倍。源例全是示意目标，实际仪器需要真实数据口径。

## 2．A的美术：盘面有层次，只有针与真值可读

1500×640暗卡内三表，每表占500，半径148、中心Y220。深色表面、外环、0～100刻度、琥珀亮弧、锥形指针和金属轴帽形成统一仪表材质；红区只放在高端，不给整个刻度均匀发光。CPU／GPU／Network和百分比均为示意，87%网络读数具体指什么必须另定，不能用「健康度」掩盖指标含义。

去程扫亮刻度，回程后亮弧收敛，数字与标签在盘下形成阅读区。高速针影沿角向，不用全盘失焦；末态数字比针影重要。若真实产品已有仪表，优先取其可读局部，不为模仿外观另画一套不同口径的表。

## 3．A的真实锁定时间与状态先后

三表start12／16／20，12帧outCubic扫270；随后回程弹簧stiffness120。按超调8°／行程反算阻尼比ζ=−lnp／sqrt(π²+ln²p)，damping=2ζsqrt(120)，目标190／120／235°，最终显示70／44／87%。接近高端时行程小，不能直接复用同一阻尼还声称同8°过冲。

准确函数到start+46才硬锁目标，三表58／62／66；原注释60后全锁不成立。数值却从start+32起9帧弹出，即44／48／52起，最后数字61齐、名字65齐，可能在针仍回摆时就给最终读数。状态done60～68切成Ready，必须判断是否允许「自检未彻底锁定就开始就绪」；真实制作宜用实际完成事件统一确认。

去程outCubic到顶速度0，弹簧回程从0速起，主要接缝可连续；但66等硬锁帧仍要看残差，不能仅凭clamp存在宣布无跳。背景状态灯与颗粒还动，所以全画面不是永久静止。抽帧见扫针、最终百分比和就绪标签，只支持身体语汇，不支持真实硬件健康。

## 4．B的美术：刻度带成为世界，读数窗成为固定焦点

冷白精密台面上右侧贯穿全高的竖带，X1000、宽520；每10单位一刻、每50大刻、64px字。读数窗X970、宽400高150，128px白数字在钴蓝面内，左侧124px标题和后出的结论留足负空间。上下刻度渐隐，不要做成拥挤小仪表盒。

坐标y(u)=540+(v−u)×5，指针固定540，大数在上；value变化带动世界滚动，读数、上限线和新标记共用v。旧上限140，先从60慢爬到122停，56～61退117，61～83冲444，83～110弹回420；110后value常数。这里122是观测路径里的临时值，140是旧容量，不能把「tripled」说成122→420。

420／140=3，即旧上限的300%、增加200%，不是增加300%。字母tripled98起8字符、gap1.6、each14，到123.2，复述114～130才齐；110锁值不等于完整画面已可读。90后主体还推2.5%，所以指针相对容器固定、相对最终屏幕可微移，不称全片屏幕坐标绝对不动。

## 5．原创制作推导：测量、标尺与真实文件结果

**A讲导出前检查。** 先画真实检查项与可核查结果，表针只在解释明确的连续指标时使用，例如实际测得音量或尺寸比例；离散的「字体存在／文件存在」不该硬塞成百分比仪表。先标自检，扫满量程后回真实值，所有项核查完才显示就绪；下一镜打开实际输出或报告验证。三表不是必需，少量信息用一表更清楚。

**B讲标尺定位。** 用真实时间尺或像素尺说明目标位置：固定指针对当前值，刻度滚过，最后标记对齐真实目标。若讲容量升级，先展示真实旧／新上限与条件，当前使用量另列；不能让滚带表演自动生成吞吐结论。下一镜打开实际设置或输出验证单位与范围。

两式先排最终数值、单位、条件和图形的阅读关系，再设计扫满、冲刺或回摆。声音A去程弱扫、最终轻落，B连续滚动短收，不给每个刻度敲击；真实监控不应由动画音效暗示告警。

## 6．原创草图的美术与中段取景

真实检查的美术不一定需要三表并排。只有一个连续指标时，用一只大表与具体单位，旁边列条件和采样时间，比三个含义模糊的百分比更清楚。自检阶段颜色不要同时表达好坏，扫过红区并不等于发生故障；真实值落定后再按明确规则显示状态，阈值依据必须可解释。

滚带定位的数字、刻度与目标标记放在同一视区，单位在读数旁稳定存在。若比较旧新容量，左侧保留旧值与条件，右侧新值落定后再出现增加幅度，别提前把tripled当视觉标题。最终静帧应能分清容量上限、当前使用值和变化比例，任何一项只能靠口播猜，都需重排文字与图形关系。

## 7．关键画面与失败验收

| 状态 | A扫针 | B滚带 |
|---|---|---|
| 开始 | 标明自检，单位和量程清楚 | 旧上限与当前值分开 |
| 最大动作 | 扫满不是实际测量峰 | 刻度和数字同源、指针稳定 |
| 回摆 | 真值标签不误导为已锁定 | 过冲不是新的真实上限 |
| 结果 | 所有检查实际完成后就绪 | 新旧值和百分比能对账 |
| 下一镜 | 打开真实检查依据 | 验证真实参数或文件 |

针乱抖查阻尼与硬锁残差；就绪太早重绑实际完成；数字与刻度不齐查yOf；回摆被当真实变化则标明演示或取消不必要过冲。静帧审仪表层次与口径，正常速度审扫针、刹车与阅读，声音另验，不能用漂亮仪表代替数据证据。
