# 沿时间轴旅行并停在当下

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/data/timeline-travel.md)、[TimelineTravel](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/data/timeline-travel/TimelineTravel.tsx)、[timeline-travel 官方样片](https://vincentwei1021.github.io/video-shotcraft/media/timeline-travel.mp4)。下文区分原卡给定、准确实现、官方样片抽帧观察和原创制作推导；抽帧每条16幅，未完整正常速度观看、试听、运行上游或实现原创镜头。参数用于解释原例，不能直接作为当前视频默认值。

## 1. 这条轴要表达什么

用于表达有依据的先后、积累与当前节点。观众应先知道“正在沿同一条历史前进”，最后知道“为什么停在这里”。仅把三张功能卡横着飞过去，不会自动成为时间叙事。若内容是并列选项或当前步骤而非年代，应改成类别图或操作路径，不能用虚构日期制造成长史。

## 2. 先设计末站和轴的版面

末站是完整海报级画面：上方小眉题负责说明范围，粗无衬线标题负责结论，底部横轴负责日期与顺序，唯一强调色给 Today 节点及其卡片。节点与卡底之间一根细连杆明确归属。原例卡片有版本胶囊、日期、标题、说明和底部指标，字阶不同，不能五行同字号。

背景月份是极浅的大字，位置比前景慢，只作时间环境，不与卡片标题争读。轴附近留出空白让高速运动的参照物显现；主刻度之外的次刻度提供位移尺度。纸白底上的阴影是薄且柔的接触关系，卡片没有厚重黑影；当前卡只稍带冷紫边缘，不能每张都发光。

教程中真正需要阅读的是末站。掠过的历史卡可只辨轮廓和时间，若口播要求比较每版差异，就不能用快速掠过承担阅读任务，须增加局部停留或另拆比较镜头。

## 3. 原卡与准确实现

实现总长 160f，原卡“4–5s”是概述，不能盖掉代码实际时长。f0–12 建立，12–104 行进，104–114 末站推近，114–159 保持。旧工作台曾推断成 104f，直接截掉 Today 和末段，这是明确的时长边界问题。

世界刻度相隔 1400px，四站 x 为 960、2360、3760、5160。相机行程 4200px，由归一化输入 [0,.15,.88,1] 到 [0,.055,.9,1] 并在段内使用 inOutQuad。它是分段变速，不应把注释中“匀加速”误当成整段匀加速定律。

| 关系 | 原例做法 | 实际作用 |
|---|---|---|
| 卡弹起 | 从 camXAt 反查经过该站的帧，再提前 6f | 卡在观众经过时已经立起，而非错过后才入场 |
| 弹立 | 底边为原点的 scaleY，spring damping11/stiffness160/mass.9 | 身份从轴上长出；不是中心缩放的通用弹窗 |
| 急停强调 | 末站 10f 内由 1 放到 1.28 | 距离变化确认“到达”；不必每站重复 |
| 远景 | 月份以约 .35 倍速度移动 | 区分轴与背景的深度，避免整张画布一起滑 |
| 模糊 | 按相机速度的水平拖影 | 静止清零；不能将关键信息持续糊掉 |

反查应查实际单调 camXAt，不能简单按总时长均分四站。改站距后重新求经过时刻；若真实日期间隔不等但刻度等距，须明确这是按事件排列的示意轴，不能让间距冒充准确时间比例。

## 4. 抽帧看到了什么

16 幅官方帧能见第一站纸白卡与浅月份、冲刺时前景拖影、末站冷紫节点和卡片、最终推近后稳定构图。固定页眉提供方向，远处大字没有成为第二主角。中段不少内容已难细读，这正说明该镜头适合概览，不足以证明每项历史被理解。未正常速度观看或试听，不据抽帧断言刹车节奏通过。

## 5. 原创制作推导：同一文件的三个修订点

内容是解释“修改记录怎样帮助找回误删段落”。先做结果：当前文档的一段误删位置与历史版本入口同框，时间轴停在真实的前一版本，卡片内是同段文字的可读局部，而非几张说明卡。

总览里以三次真实保存作为节点。第一站用原始段落缩略图，第二站用确有发生的修改，末站显示恢复前状态。旧节点用中性灰，待恢复的那个节点才上强调色。高速段只让观众感觉记录连续存在，口播不在此逐条解释长句。

相机抵达正确历史点后完全稳住，历史文本与当前缺口并列：相同句子用相同基线与字形，差异只用局部底色。光标点击“恢复”后，段落回到当前文档，时间轴退成细小导航而非继续抢镜。只有真的恢复成功才展示成功状态；演示数据须声明为示意。

下一镜沿同一段文字回到正常编辑视图，指出恢复后哪些新修改需要重新核查。时间旅行由此交给实际工作结果，末站不是一张写着“更高效”的口号卡。

## 6. 失败修正和验收

- 今天卡未出现：核实总长是否覆盖 TRAVEL_END、ZOOM_END 和阅读段，不能只渲染主运动。
- 日期像随机背景：让月份切换与当前位置一致，并压低对比，避免前景是九月、远景还强调七月。
- 弹卡时机落后：反查实际曲线而非线性估算；抽查经过轴点前后几帧，看卡是否已立起。
- 末站推近裁掉日期：连同卡片、节点、日期和页眉计算包络，不能只保护卡片中心。
- 每站都要读却全在冲刺：改叙事容量，保留能读的一站或延长逐站驻留，不靠增大字幕弥补。
- 轴间距误导时长：改真实比例轴，或清楚标识为事件序列；不能用匀距图暗示等时间间隔。

通过证据包括首站方向、运动中段世界连续、末站文字完整及真实内容核对；另需正常速度检查加减速和音效。参数与时间是原例解释，不是本项目通用默认值。
