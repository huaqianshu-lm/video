# 碎片聚合与飞散：先设计一幅值得拼起来的画面

本镜把完整画面分配给多个实体碎片，按空间秩序聚合，供观众读懂后再飞散。内容重点应是“这些局部组成了什么整体”。碎片运动不能替代海报设计；最终只是一行居中文字时，即使三轴旋转准确，也容易成为效果演示。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/opening/fracture.md)、[Fracture.tsx](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/opening/fracture/Fracture.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/fracture.mp4)。另核对 [Motion](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Motion.tsx)、[Polish](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Polish.tsx) 和 [Brand](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Brand.tsx)。固定卡与main实现分别核对，不宣称代码和媒体已同版运行。

本文标明**原卡给定、源码可见、抽帧可见、制作推导**。样片1920×1080、30fps、156帧、5.2秒，无音轨；实际查看16帧。未正常速度完整观看、运行上游或实现原创镜头。案例参数不替代 [质量规则8.6](../../../docs/VIDEO-PRODUCTION-RULES.md)。

## １．适用关系与禁用条件

| 内容 | 是否适合碎片聚合 | 应保留的认识 |
|---|---|---|
| 许多局部共同构成一个整体 | 适合建立整体的概念 | 拼齐后能辨认局部所属的位置 |
| 一幅图像的重建／拼图 | 适合，但需真实内容支持 | 片面采样与整体纹理一致 |
| 文档被删除、数据损坏 | 要谨慎，飞散容易暗示破坏 | 没有删除事实就明确是章节连接 |
| 软件功能演示与逐项说明 | 通常只适合作连接 | 正文必须由真实操作或解释接管 |

**原卡给定**把正放作为开场、倒放或后半作为硬转场。**制作推导**：倒放能改变运动方向，不能自动让观众理解为新材料生成。要从A画面转到B画面，还需要两面纹理、全遮挡时刻或完整的揭示逻辑；当前演示只有一张海报，不包含现成的A／B转场。

## ２．先定完成态的美术，再切网格

### ２．１　海报不是25张小卡

**源码可见**：设计坐标480×270，`DesignStage raster="zoom"`放大4倍到1920×1080。海报380×230、居中，最终基准尺寸1520×920、外边距约200／80。5×5网格的格距76×46，实际每块75.5×45.5，拼缝0.5设计像素，输出约2px。

所有瓦片内部都放同一张380×230海报，并按格位反向偏移。偏移包含半条拼缝，确保连续纹理在正确位置接上。不能每块各用一张缩小海报，也不能让每块渐变以自己中心重新计算，否则完成态变成拼布。

**抽帧可见**：聚合后的冷蓝海报上有横贯下半部的发光弧，左上较明，字标落在弧线上方的暗区；细拼缝仍在，但整体被读作同一幅图像。弧线在多块之间连续，是判断拼合成立的重要证据。

### ２．２　海报中的光与外部环境有分工

**源码可见**：色相常量218派生冷深蓝底、左上柔光、底部地光与明亮圆弧。圆弧中心在海报的64%／168%，亮边在约61.6%径向位置，所以只见弧线的一段，不是完整圆环贴在画上。

海报之外是带同色柔光和暗角的深背景。环境光随拼合程度增强，在退场时减弱；它不随每片单独闪烁。每片有细顶沿高光和极淡内轮廓，朝向越侧越暗，亮度依据`abs(cos(rx)×cos(ry))`近似，不是真实灯光计算。

**制作推导**：改色相时同时检查文字、弧线与深背景的明度差。不能把深蓝换浅黄后仍用白字和同样的白色高光。碎片边缘应支持片状厚薄感，当前没有真实厚度和背面纹理，不要把它描述成有重量的金属板。

### ２．３　字标与拼缝要共同排版

眉题8.5设计px，600字重、0.24em字距，输出约34px；字标22设计px，输出约88px。眉题与字标间距6，整体向上补偿16的底部留白，让字标中心对准第三行瓦片中心y115。标志安放在第二列内部，避免竖缝穿过标志关键结构。

**制作推导**：不能把这一对齐位置套给所有中文标题。先用真实字体测完整字框，再将切缝与关键字形、标志、人物脸部共同审查。可让一般纹理跨缝，但不要让2px缝切断唯一必读汉字的细笔画。若完成态仍需要精确读小字，拼齐后可以换成无缝完整图，但必须在完全重合时交接，不出现锐度或位置跳变。

## ３．每块的物体身份和坐标

**源码可见**：每片固定格位决定终点，不把“当前看起来最近的空位”当目标。初态用确定性种子生成：x约±450、y约±300、z约−210到490设计px，三轴旋转各约±180°。渲染中不重新抽随机值，否则会变成抖动而非飞行。

整幅海报所在父层使用perspective900设计px、保留三维层次；瓦片自身先translate3d再三轴旋转。迁移时先核CSS变换顺序，不能把旋转和平移任意交换后仍沿用同一落点计算。

opacity只由入场进度控制：`min(1, tin×2.5)`；达到tin0.4即实心。退场不淡出。初始0帧全部tin0，因此画面不是已经散布着25个完全可见碎片，而是深场之后碎片陆续变实。

**制作推导**：一片必须始终持有同一块内容和同一格位。不要在飞行中替换纹理来“凑”完整图。如果确需跨素材转场，先定义纹理什么时候在不可见背面或完全遮挡中换掉，并核对它是否会被看见。

## ４．波纹聚合：到位不等于完全安静

时间归一化为`t＝frame／155`，不是frame／156。每片延迟由到中心的曼哈顿距离决定：`d＝(|r−2|＋|c−2|)×0.045`。中心先、四角后，共五圈；每片入场持续0.34，用`bezier(0.42,0,0.3,1)`落位，不是参数表括注的精确inOutCubic。

| 圈距 | 片数 | 开始t | 落位t | 对应落位帧位置 |
|---|---|---|---|---|
| 0 | 1 | 0 | 0.34 | 52.7，整数53到端点 |
| 1 | 4 | 0.045 | 0.385 | 59.675，整数60到端点 |
| 2 | 8 | 0.09 | 0.43 | 66.65，整数67到端点 |
| 3 | 8 | 0.135 | 0.475 | 73.625，整数74到端点 |
| 4 | 4 | 0.18 | 0.52 | 80.6，整数81到端点 |

每片到位后仍有短小rotateX阻尼摆与向内压入：`exp(−since／3.2)×sin(0.75since)`，只在0＜since＜14生效。2.5是乘数，不代表一定达到完整2.5°峰值；z向内压入最多由4×该振幅决定。四角最后一次摆动到约95帧前才终止。

**制作推导**：中心优先不只是好看，意味着观众先认主体再补边界。若中心是空白、重要内容在四角，就应重新安排波纹中心或改变延迟，不机械坚持中心先。要审查最快段是否有背面文字倒映、近片盖住关键字，以及末圈是否还没归位标题就开始要求阅读。

## ５．字、环境光、推近与模糊的重叠

| 通道 | 当前源码 | 设计影响 |
|---|---|---|
| 海报文字亮起 | t0.42→0.52，约65.1→80.6帧 | 文字显露时外圈尚在归位，不能把这段全算阅读 |
| 环境光建立 | t0.28→0.55 | 拼齐之后仍有弱变化 |
| 整体推近 | t0.45→1，1→1.03 | 读字时仍极慢推，不是严格冻结 |
| 聚合模糊 | t＜0.53 | 整数0—82；最后落位后仍有少量采样 |
| 无模糊段 | 0.53≤t≤0.7 | 整数83—108，共26张 |
| 飞散模糊 | t＞0.7 | 整数109—155，170°快门、8样本 |
| 颗粒 | 独立放在模糊之外，0.08透明度 | 避免颗粒被多样本抹平，不证明实际压缩后质感 |

**源码可见**：全局无模糊段83—108仍有四角轻摆到约95；若要求所有瓦片摆动结束且无模糊，真正更稳定的窗口大约只有95—108这14张，且全图仍推近。原卡“hold约1秒”与“t约0.6—0.7唯一读字窗口”不能直接当作成片已满足充分阅读。

**制作推导**：把最后一个物体稳定、文字完整和下一次动作开始分别标记。读一个短品牌名和读十字中文知识结论需要的时间不同。延长总时长若仍用同一归一化时间，只是把全部动作同比拉慢；需要单独延长阅读段时，要重排阶段而非只改duration。

## ６．飞散要真的离开画框

**源码可见**：每片从`0.70＋delay×0.5`起，用0.18归一化时长做inCubic加速。中心108.5帧起，四角122.45起；最后角片在150.35达到完整退场位移，约151帧以后到155只剩5张完整终点画面。

方向按距海报中心的atan2并加入扰动，中心片另给随机方向。x分量乘620—880，y分量乘470—690，二者范围不同，**不是一条等长620—880的径向距离**。同时z回到原平面、rotateZ增加约±150°。退场没有另一次x／y翻转。

**抽帧可见**：120、128附近文字被碎片带走，138后碎片向四边散开，151、155已是暗背景。标题没有先单独淡掉，保留被拆开的物体连续性。

**制作推导**：位移结束不等于全部片已出画，要把带旋转的四角投影、整幅推近和透视一起算边界。不能只检查中心点超过屏幕。若做A／B转场，还要核对B是否在飞片背后可见，A是否因拼缝提前泄漏。

## ７．关键帧怎样审查

实际查看0、12、24、40、53、65、80、94、108、113、120、128、138、145、151、155。

| 画面阶段 | 抽帧支持的观察 | 实现后仍需核对 |
|---|---|---|
| 0—40 | 深场中碎片渐聚，未形成完整文字 | 最快片是否像乱闪，主要方向能否跟住 |
| 53—80 | 中心开始完整，外圈仍有缺口，文字渐亮 | 关键身份是否跨缝／被遮，是否过早读字 |
| 94、108 | 海报读作完整平面，弧光连续 | 极慢推近与最后摆动是否干扰阅读 |
| 113—138 | 多片向外移动，文字随片分离 | 出场是否有清楚的一次主动作 |
| 145—155 | 剩余片离场，深背景接管 | 最后残边、下一镜的实际进入时间 |

静帧能查连续纹理、拼缝与完成构图；不能认证碰撞感、模糊开关手感或声音。源文件没有碰撞检测，也没有真实硬体求解，不应描述为物理仿真。

## ８．原创演绎：局部裁片与原图的关系

以下为**制作推导**，未实现。教程要说明“裁成小块后，每块仍属于同一原图”，准备一张可使用的城市建筑照片。最终画面先设计为横向照片占1200×720、位于360／150，左上小标题“同一原图”，底部一条原图尺寸说明。照片里应有跨越多个网格的楼体竖线、树影和天空，不能选几乎全白的墙面。

使用4×3网格，每格300×240。保留几条可识别的建筑边线作为连续证据，照片不逐块调色。初态只轻微错位与倾斜，近处两三块承担主要运动，其他块简洁跟随；这次任务不是制造高能爆炸，不沿用上游巨大散布和冷蓝弧光。

画面用暖灰`#e9e5de`环境、深墨`#292821`标题与低饱和砖红定位线。照片承担真实光、玻璃反射与树影质感，瓦片只增加克制边缘和接触影；不要给照片每片加独立彩色发光。标题直接排在照片之外，阅读不必等碎片中文字恢复。

| 调度 | 具体画面 | 观众获得的认识 |
|---|---|---|
| 建立局部 | 一块有楼角与树影的裁片稳定，标“左上第2块” | 先认出具体图像局部 |
| 补邻居 | 相邻两块接回，楼体边线连续 | 碎片不是不同照片 |
| 形成整体 | 其余块按空间邻接简洁归位，完成整幅建筑照片 | 每块有固定来源坐标 |
| 阅读核对 | 撤掉辅助阴影，显示一次完整无缝原图与外边界 | 整体纹理和比例没有改变 |
| 接下一镜 | 一块以细砖红框定位，切到原图裁切坐标近景 | 下一步解释如何从原图取这块 |

纹理映射同源：原图3000×1800显示为1200×720，比例0.4，每块对应原图750×600；第二列第一行的源裁片左750、顶0。局部放大到600×480时倍率是源图0.8，不把整幅小图再二次放大。所有块的来源矩形由行列索引计算，完整态应逐边吻合。

本例没有“处理完成”的真实系统事件。归位只是解释关系，不显示软件成功勾。阅读段把临时倾斜和推近全收掉；下一镜通过源图裁切证据继续解释，而不是再次飞散成三张文字卡。需要章节退出时，用整体画面平移或遮挡交棒即可，不为使用技法强加爆炸。

时间先围绕旁白安排“这一块”“相邻位置”“同一张原图”三个认识，不要求每块等长出场。可以只在主要裁片落位用一次轻接触声，其他片共享连续低响；不要25片分别打重音。实际照片、字形、声音与正常速度观看均待验证。

## ９．失败诊断与通过条件

| 失败画面 | 应改什么 | 可观察的通过证据 |
|---|---|---|
| 拼齐后像25张缩略图 | 改为同一大图的固定来源裁片 | 跨片纹理连续，没有重复中心 |
| 拼缝切坏标志或汉字 | 重做文字位置、网格或完成态交接 | 最终关键字形完整可读 |
| 最后角片未稳就开始飞散 | 分离归位、摆动结束、阅读和出场 | 完成后留有实际可读窗口 |
| 运动感只有淡入淡出 | 检查实体位置、朝向与入场透明度 | 观众看见同一片接近固定格位 |
| 模糊撤掉一瞬间锐度跳变 | 先查速度和采样边界，再调整模糊窗口 | 无模糊段从容进入阅读 |
| 已到退场终点但还有残边 | 核旋转后的四角与父层比例 | 下一镜接管前边界已干净 |
| 碎片很热闹，完成画面空洞 | 先重做照片／海报与内容关系 | 静止截帧本身有主体和信息价值 |
| 爆炸被理解成删除资料 | 改隐喻或明确章节连接身份 | 状态没有误导真实产品行为 |

Storyboard需明确完整图像、每块来源、关键连续纹理、排印与缝的关系、先后圈层、稳定阅读段及下一镜。文档细节支持设计和实现，不代表已通过原创镜头的全速、声音或商用验收。
