# 接触阴影与离面抬升：用桌面上的证据点名一个对象

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/ui-entrance/element-body-moves.md)、[ContactShadowLift](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/ui-entrance/element-body-moves/ContactShadowLift.tsx)、[contact-shadow-lift 官方样片](https://vincentwei1021.github.io/video-shotcraft/media/contact-shadow-lift.mp4)。下文区分原卡给定、准确实现、官方样片抽帧观察和原创制作推导；抽帧每条16幅，未完整正常速度观看、试听、运行上游或实现原创镜头。参数用于解释原例，不能直接作为当前视频默认值。

## 1．悬浮不是把卡片放大

本法用卡体离开桌面、影子留在原平面来表示当前关注对象。适合候选比较、点名和最终选择；不适合三张一起升起后让观众猜重点。原例「扫—扫—选」只展示三张配方的状态，不能把第三张对勾当作真实审核通过。教程应让选择对应实际内容结果。

## 2．先画桌面与最终被选中的一张

准确实现卡420×600、间距60，总桌宽1380；注释中的440×580和桌宽1448不是当前常量。三张共同上沿，桌体顶350，perspective2600，原点50%／34%，桌倾24°→20°；上方120px标题留在屏幕平面。大号160px读数、32px说明和底部节拍格各有区域，白面与冷灰桌用细边、顶沿高光分开，避免白卡完全融背景。

主光在左上，影子向右下偏。环境影α.09+.13l、blur14+40l、偏移(10+40l,16+60l)；接触核α.32−.18l、blur3+22l、偏移(2+18l,4+36l)。两影都在桌面附近Z.5／1，卡体Z=2+96lift。卡只保留内高光，外投影不能跟卡一起升空。阴影变软变淡不是随意换box-shadow，而是说明离面距离。

## 3．扫过与选定的身体动作不同

前两卡起点16／50。局部0～10 outCubic抬起，10～24悬停叠小sin，24～32 inCubic回落，31附近开始.99微压，32～34恢复。两次不重叠，一次只有一个主角。其他卡按当前lift加22%弱压暗，仍保留上下文。

第三卡86起弹簧damping16、stiffness120，lift=1.15k加呼吸，所以实际基准高度约110.4px，不是96px；选中描边96～106，勾100起另一条弹簧。不能说所有确认在「100帧落定」瞬间发生。选中后还有呼吸、机位慢推与倾角变化，尾段不是静止。

抬升带scale1.05是辅助，主要位移应由共同桌面法线投影证明。改变倾角时先算屏幕位移，不能把96世界像素当96屏幕像素。原卡对小幅抬升的判断来自其场景，不升级为项目一切镜头的硬性最小数值；当前画幅应实际看得出离面关系。

抽帧能见第一张、第二张轮流离桌，随后第三张描边和勾出现；它支持主次与投影关系，不能证明三项真实比较已经完成。

## 4．原创制作推导：三种裁切方案中选出保留主体的一种

先画结果：同一原图的三种真实裁切，其中一个保留人物头部与视线空间，另两项问题可指认。下一镜进入选中方案的裁切框调整，不落到三张纯文字卡。

1. 三卡展示同一原图、同一输出比例，只改变待比较的裁切位置，避免混入尺寸和滤镜变量。
2. 第一张抬起时放大一个实际问题，例如头顶被切。短标记贴图像，不让整卡小字承担解释。
3. 第一张落回、第二张接棒，桌面与阴影保持共同光向；每项只有一个观察点，不能同时弹出三条评价。
4. 第三张升起停留，确认来自已展示的保留结果。勾只代表本次明确选择，不代表自动完成全部设计审核。
5. 主图进入正视近景，保留其他方案的小索引，下一镜动裁切边界验证主体是否仍完整。

## 5．原创草图的美术与中段取景

三种裁切应共享同一照片、输出比例和容器字阶，让差别确实来自边界选择。首两项的不足可以各只用一个短标记指出，例如头顶或视线空间，标记贴图像对象而非贴卡框。桌面用弱网格或柔光提供平面，卡下阴影有共同右下方向；不要给第一张暖影、第二张冷影，造成三个物体属于不同空间。

第三张悬停时，主图中的人物和预留标题区仍要清楚，不能被大号对勾挡住。选择标记放卡外小角或次级位置，结果判断来自图像。切入正视时先保留主体在屏幕中的大致位置，再撤桌面和旁卡，避免相机转正同时照片主体大幅漂移。最终裁切框和前面主卡应是同一图像范围。

## 6．关键画面与通过条件

| 状态 | 审美与空间要求 | 信息证据 |
|---|---|---|
| 三方案全貌 | 容器统一、重点尚未预判 | 比较条件一致 |
| 第一张抬起 | 影子留桌，图像不糊 | 问题部位清楚 |
| 回落中段 | 卡与影逐渐接近 | 不像透明度退场 |
| 第三张悬停 | 主卡清楚，另两张仍可辨 | 选择理由来自图像 |
| 正视结果 | 真实裁切接管，标签退次级 | 能继续实际调整 |

失败时：只有缩放没有距离，检查独立桌面影和倾角；两卡同起，重排局部窗；影子方向相反，统一主光；勾先于比较结论，延后确认并展示依据；尾部悬浮太久没有解释，进入真实内容。声音可用轻吸与轻放，选中只留一次明确反馈。静帧审阴影与裁切，正常速度审焦点、落地和阅读，两者都需验证。
