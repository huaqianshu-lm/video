# 断笔成字：把“认出来的时刻”设计成一次揭晓

本镜先呈现难以组成词的离散笔段，再补入决定识别的关键段。它与同步描画不同：观众不主要看字怎样写，而是在等待碎段何时组成意义。悬念成立既依赖段序，也依赖观众是否认识这个词；不能仅凭代码标了“钥匙段”就认为识别一定在指定帧发生。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/opening/stroke-segment-build.md)、[StrokeSegmentBuild.tsx](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/opening/stroke-segment-build/StrokeSegmentBuild.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/stroke-segment-build.mp4)。另读 [Look](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Look.tsx)、[Polish](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Polish.tsx) 与 [Brand](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Brand.tsx)。固定卡已核验，当前代码、媒体不冒称同版执行。

本文分**原卡给定、源码可见、抽帧可见、制作推导**。样片1920×1080、30fps、165帧、5.5秒，无音轨；查看16帧，另复算分段启动和直线接缝。未正常速度完整观看、运行上游或实现原创镜头。参数不替代 [质量规则8.6](../../../docs/VIDEO-PRODUCTION-RULES.md)。

## １．先问悬念有没有内容价值

| 内容目标 | 可用条件 | 应避免 |
|---|---|---|
| 揭晓熟悉短词／结果标题 | 观众能在完整态立即识别 | 生造词，拼完仍需解释读音 |
| 表示信息逐渐充分 | 确有不完整到完整的知识关系 | 故意遮住教程必读内容拖时间 |
| 开场气氛与章节停顿 | 后续马上给具体内容 | 全片反复等待标题亮完 |
| 精确演示输入或书写 | 不宜直接采用 | 乱序亮段被误认为真实输入／笔顺 |

**制作推导**：悬念不是默认优于清楚。口播已经说出词时，观众不再猜，只是在看造型；可将设计目标改为“形体建立与通电”，不宣称识别延迟。真正要留谜底，旁白、字幕、文件名、辅助图形都不能提前给出答案。

## ２．完整态美术：一块挂在深场里的霓虹灯牌

### ２．１　字形比例与排印层级

**源码可见**：四字母单线几何词，字面260×400，字间70，总宽1250，左335、顶190。管径30，白热芯9.6；S拆6段、H4段、I2段、P4段，共16段。不是用系统字体的轮廓描边，也没有字块飞入。

四字在完整态保持相同基准高度，但笔画密度不同：S两次转弯，H以中横完成识别，I只需竖直两段，P由碗底闭合。这些差异影响早期可猜程度，段数平均不能等同识别平均。

副题位于y652，32px、600字重，品牌部分窄字距，后半英文宽字距；只在揭晓后出现。主牌本身占宽约65%，周围有足够暗环境，不能把长句硬塞进同样1250宽后仍维持管径30。

**抽帧可见**：完成态粉色管体、浅白芯、紫粉泛光层次明确，字下有较弱地面反射。中间态是孤立弧和竖线，随后变成近似词形；实际何时猜中仍是观看者判断，不能从“前13段”推导所有人都无法识别。

### ２．２　灯管发光有四层，墙面受光另算

管色`#ff5cab`，芯`#fff2f8`。宽泛光使用76px线宽、22px高斯，近泛光42px线宽、6px高斯；本体30px，芯9.6。光晕沿整个字形生成，不在正中央另放一个脏亮点。

墙面环境强度由已亮段数量、揭晓和涌起共同驱动：`0.12＋0.5×亮段占比＋0.35×reveal＋0.3×surge`，最终再钳到1。它按段计数，没有按真实光功率、笔画长度或能量求解，是一致性近似。长短段不同，不能把该公式解释成物理照度。

地面交线y780，下方更深，交界附近有一层低矮受光带。背景暗角较强，主灯牌成为最亮主体。静态完成态应同时看得出管芯、管体和溢光，不能所有层糊成同一团粉白。

### ２．３　“电极缝”要把圆端帽算进去

**源码可见**：每段用`pathLength=1`、dash0.92／1、offset−0.04，意图两端各留4%。但圆端帽会在几何端点外各延长半管径。

**几何复算**：H／I上下竖段长176，原始两段间隔8；两侧修剪后中心线间隔约8＋2×176×0.04＝22.08，小于管径30。按直线与圆帽模型，可见轮廓仍可能相接约7.92。不是所有段都保证有清楚的暗缝。

**制作推导**：真要让每段互不相连，应按屏幕端帽包络决定裁切量，或用适合材质的端面。别仅凭dash比例就写“各管完全分离”。霓虹管可以有轻微接近，但图形若要体现段码结构，暗缝本身必须可见。

## ３．钥匙段先按识别设计，再排时间

**源码可见**：乱序表前13项跨字跳转，最后三项分别补S下脊、H中横、P碗底。所有段位置从开始就固定，亮起时不做平移或缩放；字形的语义变化来自缺段补足。

**制作推导**：换词后重新分析“辨认所需最少线索”。例如两个形似汉字可能只差一横，提前亮出这一横就破坏悬念；反之删除太多后只剩随机棍棒，也没有形体吸引力。应画出约四分之一、二分之一、关键段前、完整态四张草图，再做不看答案的识别检查。

不要借助透明度0的完整底字提供阴影、轮廓或反射，否则观众会提前认出。当前未启动段直接不渲染，主牌与倒影共用同一亮段清单；这是身份与保密一致性，不意味着已经通过感知识别测试。

## ４．节奏复算：当前不是“9帧到3帧”的温和加密

### ４．１　前13段实际高度拥挤在末尾

**源码可见**：启动`12＋stagger(rank,13,60,EASE.out)`，工具把ease直接用于rank／12。EASE.out为`bezier(0.22,1,0.36,1)`，其前快后慢的输出在这里变成后面许多起点挤近72，而不是每段都独立使用该曲线。

用项目已有Remotion同参数贝塞尔纯函数复算，前13个启动约为：

```text
12，32.558，47.852，57.892，64.003，67.602，69.683，
70.859，71.495，71.814，71.951，71.995，72
```

第一间隔约20.56，最后间隔约0.00545。整数采样下最后数段几乎同时开始，不能照抄原卡“间隔9f越来越密到3f”。当前可见效果应按这套实际时序观察，若要温和疏密需要重排启动表或换分布函数。

### ４．２　屏息段没有新增，但仍在起辉

最后一根常规段72开始，用7帧起辉到79。72—86确实没有新段启动，但79前最后几根仍抖闪；只按“无新增”算14帧屏息，不能说这14帧全都已经稳定。若要稳定屏息，应从79之后另留足够的感知停顿。

**制作推导**：将“没有新对象”“旧对象已稳”“听感安静”分开安排。声音如果72立刻只留低嗡，而画面仍多根强抖，视听含义会不同；需要有意设计，而非把注释当同步事实。

## ５．起辉、半亮与揭晓的光强关系

### ５．１　单根的7帧抖闪

**源码可见**：相对启动0、1、2、3、4、5、7帧，亮度依次0、1、0.12、0.95、0.4、1、0.58。稳定后仍有±3.5%左右确定性电流起伏。管体透明度另有0.35基底，而芯与光晕跟亮度走，因此刚渲出的段即使b0，也可能已经有很弱的管体。

**制作推导**：起辉是霓虹材质语言，不等于任何文字都要闪。改成LED段码时可用短建立亮度，改成纸面印刷时应换介质逻辑。也不能把光强参数0.58理解成最终显示的精确58%亮度，图层叠加与钳位会改变观感。

### ５．２　最后一笔与总揭晓有一帧交叠

钥匙段在86、93、99起；最后一段完整7帧到106。总揭晓在105开始，8帧reveal到113；surge105起、108达峰、127回0，同时整牌最大放大2%。所以“105末段起辉已经完”并不精确，105仍处于最后一根的起辉区间。

稳定段亮度从0.58向1过渡，并乘`1＋0.25surge`及电流起伏；层透明度又单独封顶1。1.25是增益上限的设计意图，不是全部像素等亮1.25，也不是瞬时精确的视觉峰值。

**制作推导**：如果希望“最后关键段出现”就是唯一爆点，最好把该段结束、整牌增亮、相机微脉冲与声音重音明确对齐；如果采用一帧提前蓄能，也须解释其视觉理由。知识课不需要强冲击时，保留全词统一增亮而去掉缩放即可。

## ６．倒影、慢推与尾段的实际边界

倒影将整牌沿y780镜像，42%透明、5px模糊，mask在镜像前的本地坐标计算，本地y≥780必须透明，避免反射跑回墙上。远离地面的部分逐渐变淡。主牌与反射使用不同SVG filter ID，防止引用冲突。

整场0→165慢推1→1.035，支点50%／45%，主牌与反射同时经过外层；揭晓脉冲另以字牌中心960／390为支点。不能把两种缩放合成一个任意scale，否则倒影关系和地面交线可能漂移。

副题113→129进入，surge127结束。129—164共36张副题完整帧，但管内hum与整场推近持续；不是全画面严格冻结。原卡165终点不在输出0—164内。

**制作推导**：需要真正安静时，在最后揭晓之后收掉电流变化与相机余动，再留阅读。霓虹持续嗡动可作为材质活性，但不能在审核记录写“无任何变化”。没有倒影载体或暗部空间不足时，删反射比增加一块硬黑地板更合理。

## ７．关键帧：识别和材质都要审

实际查看0、12、22、34、48、60、72、80、86、93、99、105、113、127、129、164。

| 帧组 | 抽帧可见 | 制作审查 |
|---|---|---|
| 0—34 | 深紫墙、少量弧段，大片空白 | 开场有无等待过长，段形是否有吸引力 |
| 48、60 | 部分竖与弧已经具备字形线索 | 不看答案能否过早猜中，不凭作者自信判断 |
| 72、80 | 多段已齐，缺少三处关键连接 | 所谓屏息是稳定等待还是仍闪烁 |
| 86、93、99 | 依次补三处，完整词逐渐可辨 | 识别是否早于预设105，动作是否仍有必要 |
| 105—129 | 总光强上升、完整词与副题建立 | 是否过曝、字芯与辉光是否糊成一片 |
| 164 | 完整霓虹字、反射、副题 | 最终构图与下一镜的明暗接棒 |

## ８．原创演绎：信息补齐之后才能确定字义

以下为**制作推导**，未实现。教程章节要讲“不完整线索可能导致误判”。选择两个确有形态差异、观众认识的简单字作为教学示意，例如“日／目”，最后关键横画决定当前显示的是哪一个；明确只是识别原理示意，不借霓虹伪装软件执行。

### ８．１　先设计结果与美术

改为暖白纸面`#eee8dd`、墨色`#302b24`，主字占420×520，中心稍偏左；右侧保留真实线索说明与最终字义，不做粉色霓虹和地面反射。笔画使用有轻微墨色厚薄的实心形，画面质感来自纸纹、笔触边缘和留白。

初态先给外框与少量不决定字义的短段，最后一横完整进入才确定“目”。要核实际书写结构和骨架比例，避免开始的中横已经足以认成“日”。如果两种读法都可能，旁白明确“现在还不能确定”，不要把错误猜测写成观众一定会发生的反应。

### ８．２　完整导演链

| 阶段 | 画面与动作 | 认识推进 |
|---|---|---|
| 建立问题 | 一份缺失线索的原始示意，右侧不提前写答案 | 线索还不完整 |
| 补外围 | 短段按有意义的空间关系补入 | 形体更清楚，字义仍待关键条件 |
| 稳定等待 | 笔画全部停止，不加随机抖闪 | 给观众察觉信息不足 |
| 关键横画 | 最后一笔一次进入，完成“目” | 新线索改变判断 |
| 结果核对 | 旁边以低权重给“日”的完整对照 | 说明差异具体在哪里 |
| 下一镜 | 切真实资料中“缺一个条件就不同”的例子 | 从字形隐喻进入实际内容 |

字形演示不是结论本身。下一镜要有当前教程确实存在的一项条件差异，例如两条数据适用范围不同；保持原文和实际条件，不能为了对应“多一横”硬造业务结论。

### ８．３　实现与验收先于加装饰

每段有固定路径和语义角色，关键段顺序手工设计，不用随机排序。起止时间直接列成表，检查每一段完整之后的停顿；不再用ease分布意外把后六段挤在同一帧。纸面显形可以采用短遮罩或墨迹建立，不保留7帧霓虹闪烁。

先做缺段、关键段前、关键段后和对照四张静帧，找不看脚本的人判断是否清楚；再正常速度看有无“卡住”等待感。重要判据是观众能指出哪一笔改变判断，而不是是否被作者成功“骗到”。实际字体／自绘路径、盲测、原创实现和声音均未验证。

声音只在关键线索建立时给一次轻提示，等待段不突然完全断人声；按实际旁白留理解时间。下一镜转真实材料时撤掉纸面题字的特殊表现，避免每个条件都变成猜谜游戏。

## ９．失败诊断与通过条件

| 失败 | 修正方向 | 可观察的通过证据 |
|---|---|---|
| 刚亮几段就认出词 | 重选关键词与钥匙段，或改目标为形体建立 | 不再虚报识别时刻；实际观看符合任务 |
| 前面太空、后六段同帧扎堆 | 复算启动表，重排疏密 | 能感到加密，不是长等候后一次跳满 |
| 屏息还在多根抖闪 | 从最后起辉结束倒排 | 稳定与新增动作的边界清楚 |
| 灯管声称分开实际相接 | 计入圆帽半径，重设端点 | 最终暗缝在实际尺度可辨 |
| 总增亮先于末段完成却标同帧 | 调整reveal与strike结束点 | 唯一揭晓点有可核对时序 |
| 光晕糊掉字芯 | 分开管芯、管体、近光与宽光 | 缩小观看仍读得清形体 |
| 倒影穿到墙面 | 先在本地坐标定义mask再镜像 | 地面上有反射，墙上没有倒置重影 |
| 炫技结束没有内容 | 先设计真实例子的接棒 | 下一镜解释一个实际信息差异 |

Storyboard需写清完整词、观众认识基础、钥匙段、真实启动表、材质、揭晓与声音关系，以及从隐喻进入真实内容的路径。文档核对、识别测试、全速观看和原创成片分别验收；当前不宣称商用已验。
