# 先搭骨架，再让文字落位

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/effects/assemble-then-type-flyin.md)、[AssembleThenTypeFlyin](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/effects/assemble-then-type-flyin/AssembleThenTypeFlyin.tsx)、[assemble-then-type-flyin 官方样片](https://vincentwei1021.github.io/video-shotcraft/media/assemble-then-type-flyin.mp4)。下文区分原卡给定、准确实现、官方样片抽帧观察和原创制作推导；抽帧每条16幅，未完整正常速度观看、试听、运行上游或实现原创镜头。参数用于解释原例，不能直接作为当前视频默认值。

## 1. 两阶段必须表达不同认识

这不是把网页所有东西随机飞进来。第一阶段让观众认识版面结构，第二阶段把内容填入各自职责，最后让页面显示一个实际结果。适合讲排版构成、模板填充或页面生成；不适合用飞字代替长篇教程正文，也不能借动画暗示产品具备尚不存在的自动生成能力。

## 2. 最终版面先成立

原例是石墨黑发布页。左侧两行 112px 衬线大标题，一行正体一行斜体，金色只落在关键词和主按钮；右侧竖幅调色台用更大的图像面积平衡标题。上方是低存在感导航，底部三枚指标块与标题左缘对齐。空白不是等宽三栏：标题区和图像区形成大块对照，说明与按钮挤在同一阅读组，微标签则退到次级。

深色卡面由顶亮底暗的细渐变、白色低透明度边缘和接触影构成，不是给所有矩形加霓虹。右侧有可辨暮色山影与色轮，因此静帧自身有内容。换成真实项目时，先设计相同信息层级的原创画面，不搬品牌文案、标志或指标。

## 3. 骨架、文字和定稿三段关系

骨架十件的起点为 f6/10/15/19/23/27/31/35/39/44，每件飞行16f。它们不是 f50 就全部严格静止：末件到 f60 才完成16f位置行程，旋转还要到 f64 才收净，原卡“骨架齐 f50”与这些具体数据存在概述偏差。文字 f58 开始，因此两段在尾部略重叠，换内容不能机械保证“有8f全静空档”。

骨架位移120–420px、旋转±7°、过冲贴合，旋转比位移晚收；按真实速度给方向性拖影。文字改用逐字符三维旋转，维度变化使“结构→内容”可辨。大标题先到，小标签最后到；不能让可读小字先夺走观众注意。

| 通道 | 准确实现关系 | 需要重新设计 |
|---|---|---|
| 字符初姿 | dx±260、dy±200、dz−200至−760；XYZ大角度旋转 | 主标题可保留明显翻转，长正文应减少字符数量或改块级揭示 |
| 透视 | 每字符 transform 内 perspective900 | 这是局部透视，不等于所有字共处同一三维摄影空间 |
| 单字时间 | 16f，块内 step=clamp((128−start−16)/n,.35,1.6) | 下限.35会让长块超过f128；不能声称任何文案都保证按时结束 |
| 字符排版 | inline-block 正常流，空格换不换行空格 | 汉字、组合符号、连字和换行要按实际排版重验，不能按英文逐字结果推断 |
| 落定 | a≥1 transform设none，模糊清零 | 是合成与视觉清理，不是运行性能已实测的证明 |
| 定稿 | CTA118–132通电；图像124–146调色擦除 | f128后并非整页真静止；完整定稿读窗应从最后可见变化后算 |

确定性随机以索引为种子，seek同一帧应给同一姿态。改文案会改变字符序列与种子分配，旧抽帧不再证明新文案安全。

## 4. 官方抽帧观察

16幅可见先无字框体与色轮、后散字拼出两行衬线标题，末段山影由灰转暖且主按钮变金。标题、图像、微标签构成明显主次；不是一屏大小相同的飞字。抽帧不能证明飞字是否令人眩晕，也无法代表阅读时间或音效，未运行原例。

## 5. 原创制作推导：把同一篇短文排成海报

内容目标是“先确定版式职责，再放文字，而不是凭感觉挪字”。先设计成稿：一张真实摄影作品占右侧大幅，左侧是短标题与作者信息，底部用很小但可辨的图注说明拍摄地点。标题笔画、照片明暗与负空间共同形成重心，不用三张流程卡当最终结果。

第一段只出现照片窗口、标题占位区和一条基线；相邻区块从对应边进入，保证运动方向能解释版面分工。第二段只让短标题逐字立体落位，作者和图注用整体揭示，避免每个汉字都成为粒子。落定后显示真实文字对齐，标题与照片边缘形成一个清楚的共同轴。

定稿动作交给照片裁切：同一照片在既定窗口内调整地平线，观众看到先前留白为何必要。若讲排版而非调色，不增加原例色轮和暖金擦除。下一镜从海报右侧照片的同一地平线进入局部，验证构图对主体的影响。

## 6. 失败诊断与合格证据

- 末帧还在掉字：计算 lastStart+(n−1)·step+16，检查clamp下限，调整块起点、句长或总时长；不强行把字符瞬移到终点。
- 所有字一起飞像爆炸：只给主标题表演，副文退后，并限制进入标题阅读区的飞行包络。
- 字落位后间距变：确认空格、字体加载、字距与字符拆分；用静态正常文本叠合末态作几何核对。
- 只有壳体、没有版面设计：暂停动画看最终海报，标题／图像／说明仍应有层级和共同对齐。
- 称有40f静止但图像仍变化：从最后定稿变化重新计读窗，将“缓推”“内容变化”“真静止”分别描述。

提交设计需有骨架态、文字中段与最终成稿的焦点说明，检查动中遮挡与末态阅读；完整正常速度与真实实现仍待具体镜头验证。

## 原创镜头的关键画面调度

下表是上述原创应用的设计草图说明，不是已渲染关键帧，也不代表动态已验。以实际内容、字体与画幅重排，检查每个状态及状态之间的完整运动包络。

| 状态 | 画面安排 | 观看焦点与接棒 |
|---|---|---|
| 骨架 | 原创海报版心、照片窗口、标题区和基线已明确 | 照片窗比指标块更大，空白通向标题 |
| 内容落入 | 短主标题表演，作者与图注整体揭示，避开照片主体 | 最大反差集中在当前标题，不让微字先夺焦 |
| 定稿 | 标题轮廓、照片地平线和图注位置可独立成画 | 撤掉参考线，裁切变化接棒，不继续撒字 |
