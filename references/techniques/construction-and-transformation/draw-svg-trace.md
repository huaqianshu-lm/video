# 带笔头的轮廓描画：一次闭合怎样交给真实内容

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/ui-entrance/draw-svg-trace.md)、[DrawSvgTrace](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/ui-entrance/draw-svg-trace/DrawSvgTrace.tsx)、[draw-svg-trace 官方样片](https://vincentwei1021.github.io/video-shotcraft/media/draw-svg-trace.mp4)。下文区分原卡给定、准确实现、官方样片抽帧观察和原创制作推导；抽帧每条16幅，未完整正常速度观看、试听、运行上游或实现原创镜头。参数用于解释原例，不能直接作为当前视频默认值。

## 1．描边是点名主体，不是等待进度

原例在纸面上画出一张报告卡，闭合加深，内容上墨，再给重点数字画朱红下划线。适合「接下来解释这个对象」的元素级特写；不适合把整段教程变成每页等待边框画完。与整页线框逐区点亮分工：这里一个主体、一条轮廓、一次闭合，之后必须进入对象内部真正的信息。

## 2．无动画时先有出版级版面

原卡1120×660，左400、顶210、圆角28；暖白底、墨色标题、朱红重点。左栏72px短句和188px数字，右栏十二根能量柱，底部签名与细分隔线。数字与柱图各有阅读区，不能为了显大挤成重叠。示例100%和能量柱是演示信息，不是声画同步测量结果。

开场48px点阵网格经中心清晰、边缘渐隐的遮罩控制，四角裁切标记先出现，说明绘图区域。裁切标记不是正文装饰，不应比笔头更黑更粗。底面从贴纸到浮卡由阴影高度4→30渐变完成，白底闭合使用加黑加粗而非无来由霓虹光。

## 3．轮廓、笔头、笔尖共享弧长

主SVG rect设pathLength=1、dasharray=1、dashoffset=1−p，10～50帧inOutCubic画一圈。叠三条短dash：长度.04／.024／.0112，宽6.4／8／9.6；再用实心r7.5圆点作为笔尖，带小落影。短dash与笔尖必须指向同一前沿，不能笔尖转角后线还没到。

笔尖位置用圆角矩形的四直段与四圆弧分段求弧长。总周长=2(w−2r)+2(h−2r)+2πr，当前约3511.93px；起点(x+r,y)，顺时针。**弧长参数化本身不会在每个圆角自动减速**，原源码也明确这一点；速度呼吸来自全段in-out，不能把转角自然弯曲误写成真实手腕停顿。

闭合时50～52线宽6→11且变黑，52～58退；笔头在p.97～.995淡走，避免绕回起点叠一团。56～66描边层退、1.5px自身细边接棒，圆角必须一致。若换真实卡框，要同时更新描画轮廓、笔尖几何、主体圆角与遮罩。

## 4．上墨不是等所有边层退完才开始

卡底50起10帧显，升起50～72；内容第k组52+3k起、每组12帧。末组到79，右侧最后柱56+11×1.5+14=86.5，原卡「50～74上墨」不是所有内容完成点。第二条下划线74～92，与柱图末段重叠，不能说上墨全结束后才强调。

下划线是另一条略弯路径，18帧outCubic，主线12、前沿16，独立强调100%。一屏只强调真正的主词；两条、三条同时画会把重点平均化。原例60～132主体继续推近.9%，Stage颗粒仍动；92后是结构保持，不是像素静止。

抽帧可见前段只有轮廓和裁切标记，闭合时线明显加重，随后卡片内容和柱子出现，最后红线给数字重音。正常速度是否像手绘仍未验证，不能仅凭圆笔头宣布自然。

## 5．原创制作推导：圈出一块真正需要测量的图像

用来解释照片裁切范围时，结果先画为真实照片、裁切边与宽高比例；下一镜拖一条边，让比例变化有实际后果。轮廓不是空卡加载，而是定义作用范围。

1. 原图先存在，裁切区域周边弱化但可见。先定需要保留的主体和画幅，别从一个任意空框开始。
2. 笔头沿实际裁切边界画出范围，主线与真实图像共同坐标。圆角取真实裁切约定，不强套28px报告卡圆角。
3. 闭合时轻加重，裁切工具自身的细线接管，笔头撤去，避免出现两套重边框。
4. 让尺寸与比例以次级信息出现，主图仍是核心。需要强调比例时只划一处，不顺手给全部数值画红线。
5. 下一镜移动边界，看到主体与保留区域如何变化；数字同步真实几何。结果阅读时声音安静，闭合可有一次轻笔触落点。

## 6．原创草图的美术与中段取景

裁切教学里轮廓描画的美术载体应是照片，而非报告卡。照片可先占主要画幅，外部余图略退暗，笔头沿实际边缘画线；宽高读数放在边界外侧的固定读区，避免笔头经过时盖数。若裁切是直角，就用真实直角，不能因源例圆角好看而擅改工具形状。线、尺寸注记和主体只保留一个强调色。

闭合时把重墨退为工具细线，照片本身不应跟着突然变亮或换滤镜。拖边下一镜需保留一个可辨锚点，例如人物眼睛或建筑顶角，让观众看到边界移动但主体没有被换掉。检查四角和线的内外沿：看起来对齐的中心线也可能因stroke宽度让最终裁切少一圈，静态结果应按真正保留像素判断。

## 7．关键画面、失败与验收

| 状态 | 取景要求 | 通过依据 |
|---|---|---|
| 未闭合 | 主图与未画边有清楚关系 | 不是等一个空框加载 |
| 圆角中段 | 笔尖在线前沿，外缘不裁 | 路径、线宽、圆角同源 |
| 闭合峰 | 墨色短暂加重，图像仍清楚 | 画完有句号但不盖主体 |
| 边框交棒 | 粗线退出、工具细边接管 | 不错型、不突然缩一圈 |
| 实际调整 | 一个边界移动、比例跟随 | 范围定义真正影响图像 |

笔头脱线应统一弧长起点与方向；交棒跳边应检查stroke内外沿和box-sizing；轮廓压正文应重设计留白；只有描线没有后续内容则缩短此镜并补真正解释。审核关键静帧后仍需正常速度观看、阅读与声音同步，不能只检查dashoffset从1到0。
