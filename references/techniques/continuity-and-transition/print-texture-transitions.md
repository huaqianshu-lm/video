# 墨渗揭示：让新内容像在纸上显影

## 1．先判断内容是否需要纸墨的观看方式

有效变体为 ink-bleed-reveal。它让新页从一个落墨点逐渐出现，墨边先行、内容随后显影。适合从章节扉页进入资料、书写、阅读或印刷相关内容；它不能替代真实的扫描、识别或生成过程。讲即时反馈时，缓慢洇开的过程反而会拖延因果。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/transition/print-texture-transitions.md)、[InkBleedReveal 实现](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/transition/print-texture-transitions/InkBleedReveal.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/ink-bleed-reveal.mp4)。原卡给定介质隐喻与参数；源码可见遮罩、分层和卸载；抽帧可见纸面、墨边和新页的主次。后文原创应用为制作推导，尚未实现。已核对130帧样片的16幅等距抽帧；未正常速度观看、试听或运行上游。样片中的 Dashboard 是程序示意，不是实测业务数据。

## 2．先把纸面扉页做成立

画幅1920×1080，底不是纯白：中心暖白、外围略灰黄，正文墨色 #2a2620。章号22px等宽、0.32em字距；两行112px衬线大字，第二行斜体；细横线宽120、高1.5，再接34px副题。这里的设计来自字形对照、行间节奏与整块负空间，不来自纸纹有多重。大标题和小章号形成尺度差，避免三段同样粗细的字幕堆叠。

纸纹用固定颗粒，step100000，multiply、0.07；其作用是使底材可感，不能侵蚀细字。新页是冷白界面，和暖纸建立材质反差。若改成真实文档，应先设计最后全页或局部的阅读构图，不能直接铺满一张字小到看不清的截图。

落点为(800,420)，偏左上；它先吸引视线，再把注意范围扩到全屏。点的位置应与新内容的第一观察对象有关。放在空白角落却让关键结果最后出现，会让观众追错方向。

## 3．湿晕、墨边、显影内容是三件事

三层共享固定seed7的空间噪声，但范围和浓度不同。

| 层 | 实际处理 | 视觉职责 |
|---|---|---|
| 湿晕 | 比内容半径领先lead+110，低频噪声、位移×1.3、模糊34，透明度0.12 | 纸先被润湿；不能做成明显灰色光环 |
| 外墨沿 | 领先20～42，位移×1.08、模糊3.2，透明度0.42 | 提供须状软边，打破几何圆的机械感 |
| 内墨芯 | 领先量为lead×0.45，位移×1.03、模糊1，透明度0.86 | 建立浓墨，不让整条边只有一层发虚灰线 |
| 新内容 | 同一噪声圆遮罩，内容本身无置换 | 字和图仍锐利，像被揭示而非被揉碎 |

噪声滤镜挂在遮罩白圆，不能挂在 Dashboard 外层。后者会把文字、图表一起扭曲，变成水波或数字故障。filter范围外扩40%，避免长须边被裁成矩形；多实例使用清洗后的useId，避免不同遮罩相互引用。

`r=baseR×[1+0.08sin(0.32f)×env]`。baseR在20～98以out-quad从0到1450；env在78～98衰减到0。**半径有扰动不等于模拟了真实毛细扩散**，局部可能短暂回缩；若真实内容不适合反复露旧景，可把半径改为单调进度，仅让边缘形状扰动。这是改造建议，并非原例已实现。

落点到最远角的几何距离为1300px，1450还留位移余量。换画幅或落点需重新检查四角，不能只看到中心变满就提前卸载。

## 4．完整动作链与中段构图

| 输出帧 | 动作 | 设计检查 |
|---|---|---|
| 0～13 | 扉页完整建立 | 不播放动画也应有清楚的标题层级与留白 |
| 14～22 | 半径16的小墨点过冲落下 | 只是预告落点，不要像点击按钮或错误提示 |
| 20～98 | 噪声圆扩大，墨边与湿晕领先 | 看旧标题被分割后的残句，避免产生错误读法 |
| 20～100 | 新景1.035收至1，支点同落墨点 | 新页不是大幅冲向镜头；与边界独立保持清楚 |
| 78～98 | 半径扰动退出 | 边缘不要在结束前持续吸引视线 |
| 100～129 | 撤SVG与全部墨层，直接铺新页 | 30帧的结构保持；还要核对新页自身是否有动态 |

抽帧26能看见小块新页与浓边，43左右扩到大半画面，69仍可见角落旧纸，103之后新页完整。粗抽帧不能证明最短全覆盖窗口，卸载前还应补看98～100及四角。若使用可动视频，裸页和遮罩中的页必须读取同一时间，不能卸载时重新从零播放。

中段要当成独立构图审查：一半暖纸、一半新内容时，是否同时出现两句互抢的标题？墨边是否横切人脸、品牌或关键值？可以调整落点和旧页排版，不能只增加黑边宽度掩盖冲突。原例新页是浅色界面，墨边显得强烈；深色素材需重新选择边缘浓度，否则只剩黑洞。

## 5．原创演绎：从「先看原文」进入一页可定位的资料

**内容目标。** 教观众判断一条引文能否在原文中找到。镜头前只知道引文，镜头后能看到真实原句与上下文。洇墨是进入资料的讲解转场，不暗示系统自动验证了真假。

**先设计结果。** 一张真实允许展示的文档局部占主要画幅，原句保留完整行与前后文；页码、标题位于次级位置；只给一个低饱和标记。下一镜回到实际查找或滚动位置，核对句子与来源。最终态不能变成三张「可靠、可信、准确」结论卡。

**美术与调度。** 旧扉页用适合中文的正文／标题字形对照，不机械照搬英文斜体。章题留在墨点之外，落点对准原句附近的空白边；先露出纸面和段落结构，再扩到出处。标记在原句可读后出现，避免渗边与高亮同时争焦。保持前后相同纸色，让变化主要来自观察距离与内容，不用材质反差冒充证据。

1. 展示待核对引文，口播说清要找的是哪句话；保留必要出处，不能只给孤立金句。
2. 字卡站稳后落墨，墨边优先露出目标段落的版式。若边缘会把句子切成含义相反的残句，先露段落区域，再安排独立高亮。
3. 全文局部显影，标记只跟随真实原句的行框。多行标记逐行绘制，不能盖住字形。
4. 去掉转场滤镜，给真实阅读时间。标题、原句、页码的关系清楚后，才解释上下文是否支持引用。
5. 下一镜显示真实搜索结果或原文件定位；存在省略或不一致时明确指出，不强行给通过印章。

声音可选轻微落笔、纸面触感，口播阅读时降低；不能把源样片未验证的声音写成已同步。资料不属于纸墨语境时可完全取消转场，保留定位和阅读方法。

## 6．原创关键画面与取景检查

以下是1920×1080横版的原创排镜草案，尚未实现，尺寸只说明本案例的构图关系。真实原文和字量确定后须重新排，不作为制作默认值。

| 关键画面 | 前、中、后景怎样安排 | 当前唯一阅读任务 |
|---|---|---|
| 引文建立 | 左上小章名；中央偏左大引文；右下出处，纸面大面积留白 | 记住待核对的那句话 |
| 小范围显影 | 墨点放在目标段落旁的空白，不落在字心；新页原句先可见，来源标题暂作弱背景 | 看出正在进入一份具体文档 |
| 半展开 | 新原文占主要左中区；旧引文仅余外侧短块，控制残句不与新段落构成错误拼读 | 视线移到原句，不在两句间来回跳 |
| 完整阅读 | 原句局部放大，完整上下文仍在；页码固定次级位置；转场墨层撤掉 | 判断上下文是否支持引用 |
| 下一镜 | 同一段落保持屏幕位置，实际搜索／滚动接管 | 核实定位真实存在 |

中文原句每行长度先按最终观看尺寸试排，宁可只展示一个完整段落，再用下一镜补上下文。标记的横向范围来自真实行框，不用一个大矩形覆盖整段。渗边最浓处与高亮不同时落在原句上：先完成显影，再明确重点。静帧若只剩一块黑边包围密字，就回到段落取景重做，而不是继续调噪声。

## 7．失败、修正与通过证据

| 失败画面 | 修正 | 通过时应看到 |
|---|---|---|
| 墨边只是完美扩大的圆 | 调整边缘噪声尺度、分层与落点 | 边有浓淡和须状变化，内容内部仍清晰 |
| 整页文字被扭成波浪 | 置换仅作用于遮罩 | 直线、字形和图表在揭露区保持原结构 |
| 像烧纸洞 | 缩窄浓芯，降低黑边和湿晕，核对纸色 | 纸上洇开而非发焦破洞，边不抢原文 |
| 卸载瞬间跳一下 | 同源缩放／时间，末态精确回到1，先查四角 | 99／100前后内容位置与采样连续 |
| 渗完只是密集小字 | 重新选择阅读局部与最终构图 | 观众能指出原句、出处及上下文关系 |
| 读不完就切下一镜 | 按真实字量留时间，另设说明镜头 | 正常速度配口播能完成阅读和定位 |

至少检查完整旧态、落点、半展开、四角覆盖、裸页与下一镜。逐帧无残边只说明技术正确；最终静帧、完整速度、真实内容与声音仍需分别验收。对比 [圆心匹配开圈](circle-match-iris.md)：那篇追踪圆形身份，本篇追踪纸墨介质；不能只换一个噪声滤镜就认定具有相同叙事能力。
