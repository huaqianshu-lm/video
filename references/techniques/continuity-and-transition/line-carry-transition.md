# 线条接力横移：让已有图形引出下一幅内容

## 1．线要有来处，也要有去处

一条进度线完成后继续伸出，镜头沿线横移，线转弯组成结果画框，框内出现对应内容。观众跟踪的是同一根线，旧景与新景属于同一宽世界，没有靠白闪藏一个无关切换。

适合已有图形自然延展到下一关系：测量线进入尺寸图、下划线成为图表轴、流程线围出结果。若线没有语义、目的地只是另一句大标题，就只是让观众追一根装饰线。原卡的招牌使用次数、硬直角和音效选择属于该例的克制方法，不直接变成全项目强制规则。

来源：[line-carry-transition 原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/transition/line-carry-transition.md)、[LineCarryTransition.tsx](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/transition/line-carry-transition/LineCarryTransition.tsx)、[官方演示](https://vincentwei1021.github.io/video-shotcraft/media/line-carry-transition.mp4)。另核对SpeedBlur、velocity、stagger、springAt、Stage和字体辅助。原卡提及《Catch Me If You Can》与Saul Bass风格，本次未观看其原始片头，不将风格类比当直接动态证据。

**原卡给定**线条延伸、相机跟随、收框和海报。**源码可见**下文几何／时序；**抽帧可见**各阶段；原创应用属**制作推导**。已查看190帧／30fps演示的0、20、40、46、56、72、84、92、104、112、124、135、136、142、170、189帧。未正常速度观看、试听或运行上游／原创代码。

## 2．起点与终点的美术应先统一

原例使用米沙纸、墨色几何线、赤陶强调点与海军蓝剪纸山丘。不是把写实进度窗直接接到另一套霓虹结果页：文字、表面、线宽和颜色贯穿全段。

| 部分 | 原例具体设计 | 导演用途 |
|---|---|---|
| A卡 | x280、y300，760×500，圆角28，暖白表面与两层柔影 | 左侧主体足够大，右方为线出发预留空间 |
| A身份 | 120×80小海报、38文件名、28规格；百分比实际170／780 | 来源与结果有共同视觉身份，不只靠一个百分比 |
| 进度线 | 起点336、760，长648，8px墨线，方头 | 线与轨道共用几何，不能从卡片边缘突然长出另一条 |
| 世界纹理 | 60px点阵，低透明，上下遮罩渐隐；线下制图刻度 | 横移中提供参照，不能成为假科学数据 |
| B展签 | 世界x2080、y300，终态屏幕x160；标题与说明在框外 | 可较早出现，让观众知道目的地，不抢框内悬念 |
| B画框 | 世界x2880–3600，y280–760，720×480 | 终态屏幕x960–1680，与左展签组成非对称平衡 |
| B海报 | 奶油纸、赤陶圆日、海军蓝山丘与墨黑前景，72粗标题 | 结果本身具备构图，不能只围一个空白框 |

海报太阳中心x468，最终y226，半径142；后丘和前丘以不同曲率、遮挡与multiply叠印形成深浅。主字左上，太阳偏右，底部墨条接短句。大色形、文字与空白有明确关系，线条转场不是唯一看点。

笔头是r14赤陶实点＋r30低透明晕圈，是跟踪焦点；环境和海报也使用赤陶，因此“全片唯一强调色点”应理解为横移期间的主跟踪点，而不是源码只有它使用强调色。背景Stage在屏幕空间，点阵与卡在世界空间，灯光不随世界横移；这是有意的呈现选择，不是所有层都必须相机绑定。

## 3．一条折线如何同时成为进度与画框

路径为：从(336,760)向右到(2880,760)，向上到(2880,280)，向右到(3600,280)，向下到(3600,760)，最后向左回(2880,760)。五段长度2544、480、720、480、720，总4944。线条通过可见dash长度drawn逐步绘出，笔头用同一分段距离查位置，不单独手调轨迹。

线条方头会在几何终点外多出半线宽，闭合接缝要检查实际渲染，而非只看长度相等。框的左下角是路径连接点，长水平入线会继续留在框下，不是画完就凭空消失。

时间分配：4–40，drawn从0到648，百分比和MB按同一进度计数；40–46短满格；46–56从648伸到1144；56–112随相机继续生长；112–136完成余下收框。

相机cam从0到1920，以EASE.smooth在56f内完成。世界容器3840宽、translateX=−cam；线与世界内容分别放在相同变换的容器里，前者不进模糊层，后者随相机速度做水平SpeedBlur，amount0.28、max16。不能把线留在屏幕坐标而只移动卡，否则跟踪关系断掉。

## 4．笔头“固定1480”只对第一条水平段成立

横移段drawn=1144＋cam。当笔头还在首段，世界x=336＋drawn=1480＋cam，减去相机cam后，屏幕x恒为1480。这正是线生长与相机同步的关键。

但drawn到2544后笔头开始向上，此时cam=1400，世界x固定2880，屏幕x=2880−cam，会由1480向左移动；不能继续说整个横移期笔头永远固定1480。相机到1920时drawn3064，已走完首段2544、竖段480，又在上边走40，笔头世界位置2920、280，屏幕1000、280。

这段向上再向右的运动将焦点从“追线”转为“认出画框”。抽帧84笔头仍在水平线右端，92已经向上，104接近框左上，112开始顶边。中间不是不变的水平扫屏。

所谓“交接速度连续”也要限定：各段标量drawn与相机在时间边界用零速衔接，有助于消除停表；但硬直角处的运动方向仍会瞬间改变。它是几何制图的有意硬转向，不是二维速度向量处处连续。需要柔性绳索或流线物性时，应另设计圆角与弧长，不用同一说法冒充。

## 5．框内内容什么时候开始，什么时候才完整

| 时间 | 实际关系 | 设计含义 |
|---|---|---|
| 40附近 | 进度接近100，done阈值99.95；勾选从40起弹簧 | 圆整百分比可能先显示100，实际done另有阈值 |
| 56–112 | 相机横移，卡／点阵／展签模糊，线与笔头锐利 | 跟踪主焦点不能被背景模糊一起糊掉 |
| 100起 | 展签眉题与两行标题错峰，各20f | 框外身份可先出现；说明到约133.2才完整 |
| 134起／136挂载 | fillIn已开始，closed到136才让海报出现 | 第一次挂载底色已是非零透明度，不是136才从零渐入 |
| 136–142 | 笔头透明度退到0并条件卸载 | 留下完整墨框，撤去“仍在画”的提示 |
| 140–162 | 太阳从画框底外升到最终位置 | 不是整个海报一起淡入 |
| 146–166／152–172 | 两层山丘形成 | 第二层完成比原注释166晚 |
| 152–170 | 海报文字上升到位 | 与后丘重叠；逐项串行会拖慢但不能省略阅读窗口 |
| 172–189 | 主海报几何完整 | 严格满态只有18f，不是注释166后24f全完整；Stage等仍需另查 |

点阵下的“12cm／24cm”等是图形纹理，没有真实测量口径；进度的48MB也是演示数值，随pct线性变化，不是真实渲染日志。若教程要说实际导出完成，必须取得真实文件／结果证据。不能因动画到100就宣称任务已经完成。

海报缩略图与最终海报也不是逐像素相同：mini隐藏文字，主体图形保持最终形状。新案例若要证明同一个文件，应使用同一真实缩略图与输出图，而不是只画一个相似太阳。

## 6．原创演绎：测量线成为图片的尺寸框

**目标。** 解释给图片确定宽高后，比例约束怎样决定另一边。真实输入是一张照片及实际原尺寸；最终结果要让观众看到尺寸关系，不是假进度条推到“成功”。此处为待实现方案。

**先画结果。** 右侧大照片被尺寸框包围，宽、高数字位于框外，不压照片；左侧保留原始尺寸与缩放倍率。下一镜在实际软件输入宽度，观察高度是否按比例改变。

**美术。** 米白背景、墨色测量线与单一蓝色当前读数。照片保持原色，主体位于画面视觉中心；刻度有真实数值和单位时才画，否则只留端点。标题与数字分层，尺寸用等宽字，线宽比照片边界更显但不粗到遮住轮廓。摄影画面无需复制赤陶太阳、山丘和电影口号。

**动作链。**

1. 左侧展示真实原图，先出现一条实际宽度测量线，两端对应图片边缘；读数来自原尺寸，不从零假计数到任意数字。
2. 宽度线右端延长，镜头随之横移。照片与端点暂时保留身份，横移中只跟踪一个主笔头，不再加入飞入标签和相机旋转。
3. 延长线到右侧转向，成为新图下边和右边的尺寸边界。若以固定1480跟随，仅在水平段成立；转角阶段重新规划主焦点，保证笔头不离画。
4. 完整边界形成后，新图显现，来源是同一照片按比例缩放。原图若6000×4000，目标宽1200，高应800，倍率0.2；这个例算只说明关系，实际数值以素材为准。
5. 宽高与倍率共同呈现；把一条细对应线带回原图的身份标记，避免观众以为换了照片。保持完整构图，再接实际输入框操作验证。

**关键取舍。** 线可以从测量构件延展，但不能把测量长度与横移的世界距离混为真实尺度；中段线仅是图形接力，应在视觉上撤去刻度或明确其为连接线。若要表现真实比例，测量只在图像边界段有效。这样既保留流畅转场，又不借制图风格编造物理含义。

**时间与声音。** 横移长短由下一画面距离和口播观察决定，不把1920／56f当默认。线条声音可短而连贯，闭框轻触；未实际配音前不宣称声音节奏已通过。旁白说到比例时，完整宽高都必须已经到位，而不是还在追线。

## 7．可观察诊断与验收

| 失败 | 改哪里 | 怎样确认 |
|---|---|---|
| 笔头逃出画面 | 对同一路径距离和相机求屏幕坐标，分水平段／转角审查 | 全程可跟踪，转弯后没有错误地继续锁1480 |
| 线与卡脱开 | 共用起点、轨道y与世界变换，检查方头半宽 | 最初线就是原构件延长，没有另一条线闪现 |
| 横移中只有空白 | 减少无内容距离，提供低对比参照和明确目的地 | 正常速度始终知道看哪，纹理不伪装数据 |
| 世界糊到没有空间 | 模糊按实际相机速度并限幅，主线独立锐利 | 重点笔头清楚，背景仍可辨运动方向 |
| 框没完内容先出现 | 分清框外身份与框内内容，重排挂载和fillIn | 内部主内容在闭框后建立，前后规则一致 |
| 末态读不完 | 以最后山丘／文字完成时刻重新留停留 | 完整结果与口播有共同阅读窗口，再接下一镜 |
| 好看但测量不真实 | 区分图形连接段与真实测量段，统一单位和比例 | 宽高可从素材复算，画面不暗示虚假尺度 |

审核起点、进度完成、横移中点、首转角、闭框、结果满态及下一镜。代码几何成立后还要正常速度观看与配口播试听；抽帧和公式只证明局部关系，不证明整段已达到商业成片水平。
