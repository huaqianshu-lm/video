# 页卡翻飞与向心收束：让一组对象交出共同焦点

## 1．强动作的职责与限制

三张页卡从侧向展开为一组，持续缓转，然后快速缩向同一中心；中心亮核与一个烟雾环接住能量，巨字成为下一主体。这是高能量的段落收束，原例承担产品口号，不是解释三张页面内容的完整教程镜头。

可学习群组构图、中心统一、运动衔接和材质层级。真实教程只有在一组信息已经解释清楚、确需转向共同结果时才适合改用。页卡消失不会自动证明“信息已融合”，烟雾环也不能代替内容结果。上游原卡中的“不能停”“不加模糊”等裁决针对该示例，不升级为所有视频的审美规则。

来源：[card-flock-tumble 原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/transition/card-flock-tumble.md)、[CardFlockTumble.tsx](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/transition/card-flock-tumble/CardFlockTumble.tsx)、[官方演示](https://vincentwei1021.github.io/video-shotcraft/media/card-flock-tumble.mp4)。同时核对了 Look、Polish、Brand 辅助关系。原卡所指 clickup-30 原片未在本次观看范围内，不宣称与它同质或一致。

**原卡给定**是翻飞、慢转、快速吸入、单环与巨字。**源码可见**是下列参数和层级，**抽帧可见**是对应画面状态，原创段属**制作推导**。已查看 30fps、135 帧演示的 0、10、20、30、46、54、61、62、68、69、70、72、74、88、112、134 帧。未正常速度观看、试听、运行源工程或原创实现。

## 2．先设计两幅主画面与共同中心

前半幅是一叠大页卡，后半幅是一张巨字海报。二者共享画面中心向下30px，即约960、570；卡群、收束目标、亮核、环心、标题共同围绕这一区域。视线不用追到角落再回中间。

| 设计层 | 原例具体美术 | 应保留的关系 |
|---|---|---|
| 背景 | aurora 深紫渐变；中央紫粉柔光；74%高度有低对比地平余辉 | 用亮度承托白卡，背景最亮处不与主字争夺 |
| 字墙 | 两行300px、900粗斜体描边字，2.5px淡紫，透明约0.18／0.12 | 大形状作空间纹理，低对比；不要让观众阅读两组口号 |
| 页卡 | 560×400，16px圆角，浅白紫表面、发丝边、顶部内高光，紫环境辉光与下方暗影 | 亮界面与深环境分离，边缘清晰而非整片乳白发光 |
| 前后层 | Inbox／Shots／Home 阶梯重叠，后两层叠深紫0.2／0.1 | 前卡先读，后卡保留足够页名与边缘证明“一组” |
| 烟环 | 顶奶桃、中粉、下紫，亮暗斑块与破碎絮边，screen叠加 | 一个环形体积感，不做多重同心圆或礼花 |
| 巨字 | 282px、900粗斜体，白到浅紫纵向填充，粉紫双层drop-shadow | 最大文字只给一个主词，其他文字保持克制 |
| 辅助文字 | 上方30px品牌字与50px标志，下方44px短句 | 不是所有字一起发光；保持主次与净空 |

卡内是真正由代码排出的示例UI，不是应用截图。三页有不同内容：收件箱、镜头状态列表、概览；姓名、任务和指标是合成内容，不能视作实际业务记录。原始字号约9–27，卡放大后仍不适合同时读完全部条目，这组镜头主要展示页面身份与规模。

主卡渲染先CSS zoom=1.75，再外层scale=s／1.75，以较高布局尺度生成字形。它帮助代码文字栅格化，不会把低分辨率图片凭空变清。三卡阶梯态比例1.62／1.68／1.74，近似名义宽907／941／974；透视与转角还会改变屏幕包络，实际需看投影，不能仅按这些宽度加起来算占位。

抽帧中0／10是紧窄侧棱，20已经看见三页，30形成紧密阶梯，54–62仍是群组；68–70迅速变小，72环接管，88字横贯，112／134保留主字、品牌、短句与持续扩大的环。没有独立粒子喷散。

## 3．姿态、样条与不能直接信的“连续”

每卡记录x、y、rx、ry、rz、s六个分量。初态ry88°／89°／90°，近乎侧棱；中间态分别向左上／中间／右下散开；末态为阶梯：偏移约(−108,−76)、(−5,−2)、(90,70)，ry13°／11°／9°。固定zIndex10／11／12让第三卡在前，**不是按三维深度实时排序**；改动姿态可能出现遮挡不合空间直觉，必须另查。

10–54的44f先经outCubic，再在三个关键姿态之间用Catmull-Rom。这里要保留一个实现差别：源码将两段分配在u的0–0.55与0.55–1；两段在接点有相同的局部样条切线，但除以不同的0.55／0.45时间长度后，关于u的导数一般不同，后段约为前段的1.22倍。因此“用了Catmull-Rom就保证全程速度连续”不成立。

实际是否显顿需要正常速度观看与速度曲线检查，本次只确认数学关系，不声称已经看出明显卡顿。改造可用统一参数间隔，或给非均匀时间点正确匹配切线，或按弧长重新采样；选哪种取决于是否要恒速以及姿态旋转的节奏，不能机械换一个函数名。

缓转从 `54×0.86=46.44` 后渐起，与翻飞尾段重叠。漂移量用t×角速度再乘14f平方缓入，ry约0.34°／f、rx−0.1°／f、rz0.05°／f；到62取定当时姿态作为收束起点。不是54才突然接一条恒速旋转。

62–72，r=(f−62)／10，姿态按r²向收束目标插值，scale最终0.12；目标并非精确同一点，三卡仍有小偏移与55°／60°／65°角度。透明度在r≤0.55保持1，之后用三次方退去。晚退透明度让观众看见对象被吸近，而不是还没移动就消失。

## 4．能量交接不是“70吸入完成”

| 时段 | 源码关系 | 要防止的误读 |
|---|---|---|
| 6–22 | 字墙渐亮；每帧2.4px反向缓移 | 字墙只作纹理，不是需阅读的新信息 |
| 62–76 | 字墙收至0.7并淡出，中央余辉变弱 | 不与新巨字争主位；其收缩中心还需随设计核对 |
| 62–72 | 卡群快速收束 | 原卡说70到点，实际卡动作到72 |
| 69–84 | CoreFlash已在69预现，70最亮，之后指数退 | “6f衰减”不是6f后卸载，函数持续到t14 |
| 70起 | 烟环从0透明建立，74达到峰值 | 环开始与收束末2f重叠，能量无断档 |
| 74–88 | 巨字1.22→1、字距+0.06→−0.025em；透明度74→79 | 不是从小字慢慢放大，先大后收建立压入感 |
| 82／84起 | 标志框、品牌字依次显露 | 原卡“84眉题”省略了标志较早的动作 |
| 92起 | 英文短句六词，每词16f、间隔3f | 最后一词到123才完成，不是106后全体进入保持 |
| 88–134 | 巨字每帧再长0.0008，环继续长 | 尾段持续运动，不叫静止海报 |

亮核半径由840px径向光容器构成，中心白热、外缘粉紫，全屏微曝峰值约12%。它是交接点的短强调，不是再次新增一条几何描边环。原例卡片无运动模糊与景深模糊，但烟雾层分别有22／9／6／7px柔化；“全程零blur”应理解为卡片运动保持清晰，不能误写为源码没有任何模糊。

## 5．烟环材质的具体构造

环半径 `R=46+330×outCubic(min(t/52,1))+max(0,t−52)×1.6`，t从70起。前52f减速外扩，之后仍持续长大。f134时t64，半径约395.2；线宽从R的0.36逐渐变0.27，尾部约106.7px，已经是明显的厚体积，而非一圈细线。

透明度t0／4／30／60对应0／1／0.94／0.76；60后夹在0.76，所以环不会自动退干净。边缘位移从60→150，噪声分三组：seed11做外絮和主色，seed37做亮斑，seed73做暗斑，频率与octaves各不相同。四个描边图层的半径仅略有差异，共同构成一个环，不是四圈独立扩散。

噪声seed固定，环整体每帧转0.35°；主要变化是半径、线宽、位移强度和整体旋转。它没有真实流体模拟，也没有逐帧演化的三维烟气。制作时若需要近景翻滚烟雾，应另找可支持的材质或模拟证据，不能把静态噪声旋转描述为真实湍流。这里可迁移的是“粗轮廓＋细碎边＋亮暗不均”，不是必须选用某个滤镜数值。

## 6．原创演绎：几份资料进入同一个论证结果

**内容目标。** 已经分别讲解三份真实资料，下一段展示它们共同支持的结构。观众要从“多个来源”理解到“各来源支持哪些论点”，不是只看三页吸入一颗光球。以下是待实现方案，不代表已取得或验证具体资料。

**先设计最终结果。** 中央是一张原创论证结构图：主结论、两条支撑关系与各自引用标记。三份来源保留可回查身份。下一镜直接选一条支撑线，展开真实原文证据。因此收束到的是可读结果，不是仅写“智能汇总”的大字。

**美术。** 深蓝灰底与浅纸页组成两层，引用色只用一种暖金；不用粉紫烟环、巨大英文口号和反向字墙。每张来源页露出实际标题、关键段落位置和编号，正文其他部分退为低对比纹理。结果结构图用明确节点大小表达结论／支撑／引用，细连线不发光，留出足够负空间让关系可读。

**完整动作链。**

1. 三页以轻微阶梯同框，前一段已解释过它们，页名和编号稳定；避免在这里首次要求读三页全文。
2. 第一份资料的真实关键段先成为主焦点，提取一小块可识别的引用标记；其他页用更克制的跟随动作建立各自关系，而非同时翻飞。
3. 页卡向中央缩移，目标是各自真实引用位置。若需要强调群组感，可保留小幅旋转，但不得让页名在运动中完全不可辨；没有叙事需要就取消侧棱开场。
4. 原页退到结果图侧边的来源列，引用标记接到相应支撑节点。主结论在已有关系站稳后出现，不能先生成一句无依据的总结，再把三页当装饰吸入。
5. 完整结果留出阅读。选择一条支撑关系进入下一镜，来源页局部随之展开，原文与结论对应仍可追踪。

**为何不照搬烟环。** 这里需要的是归属和可追溯关系，短亮核或气雾会遮掉关键标记。可以用轻微明暗交接提示中心形成，但“环很好看”不是使用理由。如果另一个视频确实是已解释内容的高能段落结尾，可研究原例单环材质与巨字；也应先证明不会掩盖内容结果。

**参数取舍。** 姿态只服务可辨身份，持续缓转不是硬要求；结果阅读时相机与关键节点可以停稳。运动时长根据真实引用数量和口播确定。坐标映射必须来自每个标记的源框与目标节点，不让三份资料随意熔成一份没有来源边界的页面。

## 7．可观察的失败与修正

| 失败 | 修正方向 | 通过依据 |
|---|---|---|
| 群卡像三张独立海报 | 统一重心、减少间距、建立前后明暗 | 小图仍读作一组，页名／身份没有全被遮挡 |
| 轨迹中途有顿 | 检查样条接点的时间导数和漂移接入，不只看关键点 | 正常速度无意外速度跳变，必要时用速度曲线定位 |
| 卡先消失才开始吸 | 后移透明度退去，先完成可见位移与缩小 | 观众能跟踪原对象到收束位置 |
| 巨字出现前空了一拍 | 让亮核、环、字与收束尾段有明确交接 | 无孤立小环等待；但不提前盖住仍需辨认的来源 |
| 环像塑料霓虹圈 | 建立粗细、破碎边、亮暗斑与色带；控制发光 | 近看有不均匀体积，远看仍只有一个主要环形轮廓 |
| 结果只剩一个口号 | 把结果图、来源归属和下一镜先设计出来 | 无需解释动画参数，也能说清各来源支持什么 |

研究文档的通过范围是原卡、实现和抽帧关系可回查。原创镜头仍需关键帧、正常速度、声音与真实内容验证；尤其看收束中段是否遮挡身份、主字／结果出现时是否已有证据，以及尾段是否给下一镜留下可接的对象。
