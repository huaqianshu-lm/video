# 圆心匹配开圈：从一个对象进入它的展开信息

## 1．同形之外，还要同一对象

旧景有真实圆形主体，新景从它的圆心展开，并以同心圆环继续组织信息。圆形既是注意力锚点，也是对象身份的连接：这个人的头像进入这个人的数据，某个项目图标进入该项目状态。两个无关圆形接起来只能算形状匹配，不能宣称信息关系已成立。

来源：[circle-match-iris 原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/transition/circle-match-iris.md)、[CircleMatchIris.tsx](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/transition/circle-match-iris/CircleMatchIris.tsx)、[官方演示](https://vincentwei1021.github.io/video-shotcraft/media/circle-match-iris.mp4)。相关辅助为 Stage、TextReveal、stagger、字体与缓动。

**原卡给定**圆心共用、脉冲、实心到圆环、开圈和数据生长；**源码可见**下文精确关系，**抽帧可见**关键状态，原创部分为**制作推导**。已查看 30fps、165 帧演示的 0、18、30、40、46、47、48、54、60、68、75、84、104、118、124、164 帧。未正常速度观看、试听或运行上游；原创尚未实现。

## 2．先把榜单与结果分别设计完整

旧景为石墨／橄榄黑底的五行榜单，第三行是唯一醒目的黄绿头像。背景冷白光在上方，右下填光；其他行退弱后，第三行的圆与数字形成主线。新景左侧大圆环、右侧标题与三组数据，圆心仍在540、540，因此不是屏幕居中开圈。

| 部分 | 原例尺寸／层级 | 设计作用 |
|---|---|---|
| 榜单 | 左384，宽1152，行高108，行距124，第三行中心y540 | 五行有节奏但不挤满，重点行有足够上下空间 |
| 头像 | 半径36，行左36内边距＋84名次列＋36半径，圆心x540 | 以真实内容圆心为准，不能取含padding的盒子中心 |
| 行内文字 | 名次等宽、人物名称与副信息分层，末尾大数右对齐 | 动作前先认身份，不让数值抢走对头像的观察 |
| 新圆环 | 路径半径300，线宽44；刻度始于346，长刻度到372 | 大体块撑起左半画面，周围保留净空，不贴画框 |
| 中央数字 | 200／760，百分号另用较小字号和强调色 | 数值、单位与圆弧共同解释比例 |
| 右侧内容 | x1010、y262，宽820；标题、说明、统计、排名回扣 | 新信息有纵向阅读顺序，不与圆环重叠 |
| 环境颜色 | 荧光黄绿为唯一主要强调，深橄榄轨道、近白文字 | 亮色负责对象与进度，背景光保持低层级 |

旧景退弱在代码里主要是其他行 opacity 降到0.32，并非只改亮度；透明会让背景透过，视觉结果与brightness不同。新景是另铺暗底，左侧圆形余辉与右上冷光共同形成空间，不能只把旧背景留着而叠一枚亮圆环。

抽帧可见18／30第三行最突出，46头像缩小，47出现更大的实心黄绿盘，48已镂空，54变暗轨；60圆内数字刚建立，68新景占据更大范围，84右侧标题进入，118有87%与数据，124排名胶囊完整。旧页与新页共存期间，最重要的是圆心、身份与层次，不是开圈边缘越亮越好。

## 3．共用圆心与大小接续要分开检查

头像、涟漪、旧景相机支点、新景圆环、刻度和clip-path共用CX=540、CY=540。旧景相机绕该点从1推向1.03，再在47→81继续放大到约1.22并压暗到0.45；圆心不漂。新景不跟随旧页放大，因此圆环能稳定展开。

头像先有18／30两次脉冲，峰值约1.16，叠各22f扩散环；40→47收至0.9。头像是独立叠在外面的真圆，原行留透明槽；实际截图若不是圆，不能直接替换成一个圆形补丁就声称保留了真实UI。可选择已有真圆，或明确展示一次讲解用的形状转化，避免掩盖产品差异。

**原实现同心，但并非严格等尺寸接续。** 开圈时路径半径从36×0.9=32.4起，描边宽从64.8起。SVG描边以路径为中心，因此外半径是32.4＋32.4=64.8，内半径是0：看起来是半径64.8的实心盘。旧头像缩后加1.03相机的屏幕半径约33.37，两者并不相等，开圈盘约大一倍。f47抽帧也能看到盘比前一帧头像大。

“描边宽等于直径就像实心盘”只说明内孔闭合，**没有说明外轮廓与原头像相等**。若要无跳变地从半径R的实心圆变环，可在交接点取路径半径R／2、线宽R，确保外沿=R、内沿=0，再让路径半径增大、线宽收小。还应计入旧头像当时的脉冲与相机比例。也可直接动画内外半径的遮罩，让两个边界更直观。以上为修正推导，未实际渲染验证。

原卡的圆心偏差阈值是其示例经验，不作通用标准。新素材需实际检查圆形像素轮廓：头像有透明边、阴影、描边时，视觉圆心和盒子圆心未必一致；尺寸连续与圆心连续必须分别通过。

## 4．开圈、旧页退场与进度共用参数

新环47→75从32.4长到300，使用EASE.snappy；线宽47→69从64.8收至44。原卡写r36和expo-out属于概括，实际起点与函数应以实现为准。

光圈半径＝当前环半径＋半线宽＋10＋2400×54→84的bezier(.62,0,.32,1)进度。先允许圆环形成，再额外加速吞没全画面。最远角距圆心约 `sqrt(1380²+540²)=1481.89`，只需光圈达到这个距离就已覆盖，不必等变量到84；不能把84叫作第一张全屏新景而未经计算或抽帧核对。

圈外90px阴影压旧景，初段还挂一圈2px荧光边，49→53显露、70→84撤去。边缘属于临时交接证据，吃满屏后无须保留第二套装饰环。

进度60→118到0.87，bezier(.4,0,.12,1)。弧长=sweep×2π×当前环半径，起点−90°，圆头笔尖位置也由同一sweep求出；中央数字round(sweep×100)。半径仍在生长时用当前周长，避免环大小变了但进度弧比例变错。

这只证明**圆弧与数字同步**，不能证明数字真实。47／54≈87.037%，原例四舍五入为87%；54−47=7，与“7 shots left”一致。但榜单第二名53，47＋6=53是追平，不是严格超过；原胶囊“6 shots to pass”缺少平分排序规则。新教程必须明确追平／超过及实际业务规则，不复制示例措辞。

## 5．阅读窗口与所谓保持

| 时间 | 实际动作 | 应对内容容量的判断 |
|---|---|---|
| 58–74／58–80 | 中央数字淡入／缩放回正 | 不要在刚开圈时要求读取最终百分比 |
| 56–86 | 刻度淡入，按每帧0.06°缓转 | 刻度是空间纹理，不是实时计时器 |
| 72–86 | 右侧身份眉题 | 新景身份需与旧头像一致 |
| 76–101 | 两词标题，每词20f，间隔5f | 第二词不是96就已完整 |
| 86–104 | 说明显露 | 与标题尾段重叠，避免长句抢读 |
| 92起 | 三组数据错峰进入，各18f，延迟来自stagger辅助 | 按实际最后一组计算共同阅读窗口，不能只读卡片注释 |
| 108–124 | 排名胶囊显露 | 晚于sweep完成，118后仍非所有内容已完整 |
| 118–164 | 弧光呼吸、刻度缓转、颗粒等仍存在 | 原卡“静止47f”实际是结果保持，不是全画面静止 |

如果目标是解释一个比例，一组分子／分母可能已经足够。再放人物榜、三统计和排名目标，会把形状匹配镜头扩成整页数据海报；应按口播选择，不默认全部继承。

## 6．原创演绎：由一个项目进入它的完成范围

**输入与目标。** 真实项目列表中，选择某个确有圆形身份图标的项目，解释已完成任务占总任务的比例。先取得实际列表、统计口径和项目身份。本段不预填数字，以下为待实现设计。

**先设计终态。** 左侧圆环只表现完成比例，中央展示“完成数／总数”，右侧展示该项目真实任务列表与未完成项；下一镜选择一个未完成任务展开，而不是以“继续努力”口号结束。

**美术。** 保持实际产品的浅深主题；讲解层只用一个强调色标记同一项目。圆环用哑光实线、淡轨道，不加霓虹发光和类似秒表的120刻度，避免暗示时间指标。文字名称与图标在旧景和新景都出现，环不是唯一身份依据。右侧列表按重要度排，不用装饰性三枚数字补空白。

**镜头链。**

1. 列表先稳定呈现，指针或高亮明确选中项目；邻行适度退弱。若实际项目图标是圆角方形，改选其他连续性手段，不伪造产品图标为圆形。
2. 项目圆心成为开圈原点，按旧图标实际屏幕外半径建立实心盘。原图标内部标识若不能自然转为统计图，应短暂保留项目名和身份徽章，承认这是讲解视图展开，不声称软件真实进行了这种变形。
3. 内孔打开、环扩大，右侧真实任务列表逐步被圆形窗口揭示。内容本身已在新景布局中，不再给每行另加飞入，让光圈承担一次清晰交接。
4. 完成数／总数与进度弧使用同一数据；新景标题明确统计日期及是否包括归档任务。数字从零计数只是展示，不能使任务列表假装现场逐条完成。
5. 结果停留，说明未完成的实际范围。下一镜将一个真实任务带到可读近景，项目名／图标继续在页头保留。

**坐标。** 若图标中心位于列表右侧，不能直接用540、540。先设计终态圆环和右侧列表是否有足够空间，再选择保持圆心还是先以有因的相机移动把它带到合适位置。圆心移动和开圈应分阶段，让观众跟得上；不要一边快速换圆心一边吞屏。

**验内容而非只验形。** 完成率需从相同集合计算，筛选条件变化后分母也要相应更新。环与数字一致而列表显示另一组任务，仍然失败。未取得真实数据时只能标“结构示意”，不能写成实际项目进度。

## 7．失败与合格证据

| 失败 | 修正 | 通过证据 |
|---|---|---|
| 开圈头像突然变大 | 按描边内外沿与相机倍率计算交接，不把路径r当外半径 | 交接前后圆心和外轮廓连续，或放大明确属于有意动作 |
| 圆心看似偏移 | 核对视觉圆、padding、父级变换与clip坐标 | 头像、环和开圈中心共用同一屏幕点 |
| 新景像贴纸 | 检查旧景退弱、边缘阴影与展开节奏 | 新景逐步获得空间与阅读权，旧页不在圈外抢焦 |
| 百分比与弧长不同 | 同源数据与当前周长，圆头视觉补偿另核查 | 任意中间帧比例一致，最终分子分母可复算 |
| 圆接上但人物换了 | 保留同一对象名称与真实数据关联 | 观众能指出新景属于旧景哪个对象 |
| 末态一直嘈杂 | 撤临时边缘光，减少刻度与呼吸，按阅读需要停稳 | 结果可读，下一镜有明确任务可接 |

至少审核锚点、预备、第一开圈帧、半屏、新景满态和下一镜，再正常速度观看、配口播试听。参数对应和抽帧清楚不替代动态感受，更不替代真实数据与原创成片验收。
