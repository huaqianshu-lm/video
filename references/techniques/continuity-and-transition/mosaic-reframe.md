# 同一批内容重排：网格、策展与叠放分别表达什么

## 1．不是换十二张图，而是改变观看关系

十二个内容对象保持身份，从等权网格变成有主图的拼贴，再变成对角叠放。画面改变的是组织方法：全面浏览、突出重点、感知序列。适合图库、作品集与分镜板的组织教学；如果最终叠放遮住关键内容，不能把“有设计感”当作“信息更清楚”。

来源：[mosaic-reframe 原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/transition/mosaic-reframe.md)、[MosaicReframe.tsx](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/transition/mosaic-reframe/MosaicReframe.tsx)、[官方演示](https://vincentwei1021.github.io/video-shotcraft/media/mosaic-reframe.mp4)。辅助核对Stage、TextReveal、stagger、softShadow和缓动。

**原卡给定**三套布局、控件先动、尺寸与位置分开插值、白边与图注；**源码可见**布局表与时间关系；**抽帧可见**状态；原创段属**制作推导**。已查看30fps、214帧演示的0、22、28、52、56、74、92、94、105、128、132、154、176、180、190、213帧。未正常速度观看、试听或运行上游／原创实现。

## 2．三幅静态构图必须各有用途

### A：可扫描的等权网格

内容区x96–1824、y212–984，4列3行，间距24。每片宽414，高约241.33。行列节奏稳定，便于浏览全部对象；页眉和控件在上方同一高度，正文不挤到顶。图片色调集中暖沙、赤陶、蓝灰，避免十二片独立争色。

### B：有主次的策展拼贴

改用6列4行单元格，间距16；单元宽274.67、高181。主图占3×2，即宽856、高378；其他格位包含窄横、竖图、双格等。主图左下压白色衬线图注，太阳偏右，上方暖空色为文字留空间；低处深色海面与暗scrim支持白字，不在亮太阳上硬叠说明。

这张布局的价值是层级，而非不规则本身。主图由内容重要性决定，不默认数组第0张永远最大。图注说明这张图为何值得看，不能只写“精选”装饰词。其他格位应该选适合横竖裁切的图，而非把所有主体裁到中心后称为策展。

### C：序列气氛与留白

每片外框300×372，中心沿(850,214)到(1724,930)展开，相邻中心约差79.45／65.09；旋转从−15°按每片3°增加到18°。14px浅纸白边、圆角从16收至6、带色软影，让图从网页瓦片变成可叠放的相纸。左下留给124px衬线标题，第二行斜体赤陶色，副句32；左上页眉宽度克制，避开第一张。

C并非全面阅读布局：后发卡压前卡，多数图只露一部分。它适合表达“这些内容是一组／一个顺序”，不适合要求逐张对比。末张超出右下边界是原构图的一部分；首张旋转后也可能触及顶边，不能只检查底边裁切。换真实照片时，需明确哪些被裁允许，哪些身份不可丢。

## 3．图片不是实拍，“cover”也不保证主体在

原例十二片来自八类SVG程序插画：落日、沙丘、拱门、山脊、泳池、柑橘、棕榈影、田野，其中部分有色彩变体。暖色天际、简化形状、有限色阶与低对比纹理形成统一“胶片”感觉；它们并不是十二张真实镜头照片，图注中的Crash zoom／4.5s也不是视频证据。

SVG viewBox160×100，以xMidYMid slice填容器，相当于居中cover。重排时不仅尺寸变化，**可见原图范围也变化**。C的照片内框约272×344，宽高比约0.791；1.6横图居中裁成竖框，会舍去大量左右内容。

主图太阳在原坐标x126。C竖框按高度放大时，水平方向可见范围约x40.47–119.53，太阳中心被裁在范围外，最多残留边缘；再加前卡遮挡，不能保证仍认得“Golden Hour”。这与B里故意把太阳放右侧为文字留白是两个条件。一个焦点位置不一定兼容所有布局。

真实图片应为每种布局决定焦点／object-position，且避免重排中跳切焦点：可缓慢调整裁切中心、选用多态都能保留主体的图，或让某些图保持比例并留底。不能只写object-fit:cover就当裁切质量已验。

## 4．运动拆成位置、尺寸、角度与抬起

每片中心cx／cy在A→B→C之间插值，宽高独立插值，最后用cx−w/2、cy−h/2求左上。中心走直线，尺寸变化不会使卡片一边长大一边无意偏移。

| 驱动 | 原例参数 | 为什么这样做 |
|---|---|---|
| 位置 | bezier(.75,0,.15,1)，A→B26f，B→C30f | 慢起、集中移动、尾部收稳；不是全段等速飘 |
| 宽高 | 同曲线但晚2f | 先改变中心关系，再收敛形状，减轻整块橡皮伸缩感 |
| 旋转 | B→C晚4f，bezier(.45,0,.3,1.22) | 只在相纸叠放阶段有轻过冲，网格不随机歪斜 |
| 抬起 | sin(πp)包络，scale最多+3.5%，影子elevation6→40 | 中途暂离底面，落定恢复；不是每片持续浮动 |
| 相纸 | pad14×尺寸进度，圆角16→6，基础影另加8 | 物性变化与尺寸驱动关联，不是末帧突然贴白框 |
| 全局相机 | 0→214缓推1→1.025，支点50%／46% | 尾态仍缓动，不能称绝对静止 |

这里反对用整张图scale代替尺寸变化，是为了保持容器圆角、边框与裁切的正确关系；并非完全禁止scale，源码本身还有入场0.94→1和抬起3.5%。应区分“用scale模拟布局尺寸”与“给物体加整体轻抬”。

移动中会交叠，尤其主图从414扩到856。原例在C前主图z30，其余z10；从132开始切为10+i，后发在上。132时B布局几何已经无重叠，切层不显突跳；若前段时长改变，必须重查切层时机，不能固定132后在交叠中换层。

## 5．控件因果与完整态时间

右上控件三格，每格168×60、padding6，外框516×72；赤陶胶囊12f滑动，途中scaleX最多1.18，选项文字根据位置换明暗。控件只表示演示布局模式，不是本次真实用户点击证据。若教程解释操作，需给明确选择反馈，不靠胶囊自己滑动假装有输入。

| 时间 | 实际关系 | 与原卡概括的区别 |
|---|---|---|
| 0–28 | 开场按对角order错峰，每片16f，最后约28完成 | 原卡0–22不是所有图全稳；f0首张已经部分显露 |
| 52–64 | Grid→Mosaic控件 | 瓦片晚4f，从56开始 |
| 56–92／58–94 | A→B位置／尺寸完成范围 | 严格B尺寸满态最晚94，不是92 |
| 78／82／90起 | Featured／Golden Hour／元信息依次开始 | 不是统一84起；图注约105才全完整 |
| 128–140 | 控件转Cascade，B图注128→138退去 | 后段开始时旧图注尚有短重叠 |
| 132–176／134–178／136–180 | C位置／尺寸／旋转最晚完成 | 176落位只说了位置，旋转还需4f |
| 158–189 | 两行标题逐词显露 | 第二行最后词到189，不是186即全部结束 |
| 172–190 | 副句透明度／位置完成 | 最后共同完整版面约190起，留24f到213 |

抽帧74主图已经长大，其他瓦片仍迁移；92／94版式基本成立；154上半相纸已摊开，下方还有横幅过渡态。这个中间帧最容易出现横图、竖图、文字同时挤成一团，要实际看遮挡与重心。不能用两个满态都漂亮代替整个重排成立。

## 6．原创演绎：同一批照片，浏览与讲述有什么不同

**内容目标。** 教用户先从同一次拍摄的一组真实照片中选择，再组织成有主次的叙事。需要实际照片、稳定编号和明确选择依据；以下为待实现设计，不代表原例软件具有这些真实操作。

**先画结果。** 用一张主图加三张支撑图组成故事：整体环境、主体动作、局部细节、收尾。每张图位置表达其作用，图注是具体内容，而不是四张平均卡片写“第一／第二”。下一镜单独展开主图，解释为什么它承担开场。

**美术。** 中性暖白底，照片保持一致色彩管理；标题用干净黑体，图注用较轻字重，身份编号为小等宽字。主图占约半个主要内容区，三张辅图共用边界与间距。无关照片留在下方窄缩略条，不让所有十二张都抢进故事布局。整套只用一种强调色标选择，不能用给某张加饱和度的方式暗示质量更好。

**动作链。**

1. 网格先展示真实候选，不要在一秒内要求评完十二张。编号稳定，关键主体不被缩略图裁掉。
2. 依据真实内容选主图，先有选择反馈。选中图成为主运动，其余三张被明确指出怎样补充；剩余候选退到缩略条，不凭空消失冒充删掉。
3. 布局控件切到“讲述”，主图先获得大位，辅图按内容关系跟随。位置与尺寸可以稍错开，但重排中要让编号可追踪，不让主图被后发辅图压住。
4. 主图放大时按实际焦点调整裁切。若人物靠边，保留更宽比例或留底，不把脸裁掉再用文字解释。辅图的横竖位置也由素材决定，不能机械套原6×4格位。
5. 结果出现简短角色图注，如“环境”“动作”“细节”；它们对应真实画面。留完整阅读，再切入主图近景，继续解释它的视觉信息。

**是否需要瀑布态。** 如果要教排序，可另用少量真实图片带编号形成可读序列，再逐张展开；原例十二张密叠不适合逐项教学。若只是段落尾的气氛收束，可以保留相纸斜排，但必须承认那时只表达“这一组”，不再承担全图比较。三态不必全部使用。

**实现和信息检查。** 身份用稳定ID，切布局不换图片索引。焦点坐标来自真实素材，各布局记录实际可见区域；中段对照同一ID。主题选择、照片排序和图注依据应先完成，再写位置表；不能先定漂亮模板再硬塞不合适素材。

## 7．失败与合格判据

| 失败 | 修正方向 | 可观察通过证据 |
|---|---|---|
| 重排像换了一组图 | 稳定ID与素材映射，保留可认编号／主体 | 任意重点图能从A追到B与C，不靠猜颜色 |
| 图片在形变中被拉长 | 容器宽高与内部cover分离，不直接scaleX照片 | 人脸、圆形与原图比例不变，只改变可见范围 |
| 太阳／人脸消失 | 审核各态裁切，重设焦点或比例 | 需辨认的主体在结果态仍完整可见 |
| z层突然跳 | 在无重叠阶段切层，或保持符合语义的固定层次 | 中段无无因前后互换，主图焦点稳定 |
| 只有版式美，没有故事 | 用内容决定主图与辅图角色 | 不读操作说明也能看出视觉主次和信息关系 |
| 最后标题还在进就切走 | 按最后旋转、标题、副句完成重排时间 | 完整结果有真实阅读窗口，不用176变量自证 |

审核三种静态版面、两次重排中段、最极端裁切、层级切换和下一镜。之后需正常速度观看及配口播试听，检查主次与连续性；十二张不丢ID只是技术底线，不代表画面已经足以指导真实选片或商用交付。
