# 百叶翻换：让转场几何长在版面网格上

## 1．纯几何转场也需要内容关系

有效变体blinds-slice，把页面按12栏切成160px宽竖叶，逐叶翻到背面B页。它适合刊物、章节或版面切换；并不因为「通用」就适合所有教程操作。观众需要追踪同一控件变化时，分叶会切碎阅读，不宜用来掩盖过程。

## 2．先设计两张真正有版式的页面

A暖白、墨字、朱红句点；B朱红、奶白字、墨色句点。12栏细线贯穿全页，与叶片宽完全同构，转场由版式自然产生。刊头在y92、横线152；右上从第8栏x1120起放28章号与52两行正文；左下400px巨字，底边156；页码在右下。主字、右上解释、页码分工明确，不能把全页内容平均放成三张卡。

字距−0.065em、字重850使巨字形成紧实块面，宽大留白给右上说明；句点用第三色做小焦点。正文换中文后，先排最终行数与主字宽，不照抄字号。两端都要独立好看；高反差使叶波易认，但若是公平比较，不要用暗旧亮新暗示优劣。

纸面颗粒和暗角只画一次，在所有叶片外。若每个切片自带缩小暗角，边缘会重复变黑；若页面中的随机纹理不固定，未翻时就会有接缝。原例共享的Grain仍随时间更新，不能把最终态当像素静止。

## 3．双面叶片怎样避免镜像和错缝

整个叶阵共享1900透视，每叶160×1080、preserve-3d，绕自身竖轴rotateY(−θ)。正面画A，背面预转180°画B，两面均backface hidden。每面内部是完整1920×1080页面，left=−该叶x，仅由外层160宽裁切。B预转后，在叶旋到180时恢复正向，不把文字反读。

叶后暗槽从#1d1712到#120d0a，侧立时自然露出；这比额外画一根跟不上几何的SVG线更一致。角度受光按sinθ变暗，约35°附近有局部screen高光；叶缘2px亮线也随角度变化。它是图形化受光，不是实体厚板或真实灯光模拟。换成其他光向要重算，不能让每面无论转哪边都一律同亮。

## 4．波、弹簧与撤层的实际细节

起跳`24+28(i/11)^0.78`，从左到右先疏后密；第一间隔约4.31帧，最后约2.00帧，**不同于注释3.4→2.1**。总错峰28，末叶52起。每叶弹簧d13／k75，允许过冲；若把θ硬clamp到180会改变拍落手感，若改大弹性则可能出现背面反复闪回。

UNMASK通过检查最后一叶在f、f+1、f+2、f+3均满足|θ−180|≤0.3来选f。它是预先查未来4帧，不是运行时「已经连续稳定4帧再撤」。这没有随机状态，但修改弹簧后仍需检查所有叶和撤层帧的画面差。不能把源码返回值约80当不变常量。

| 阶段 | 内容 | 审查 |
|---|---|---|
| 0～24 | 完整A，缓推1→1.006 | 建立阅读，不是绝对静止 |
| 24～52 | 各叶启动，逐步出现B | 至少看起波、中波、末叶侧立，字块别形成误读 |
| 末叶收敛前 | 正反面、暗槽、受光共同变化 | 叶背不镜像，细线不漂，外层不压平3D |
| UNMASK | 撤全部3D，直接B | 要查同一像素位置与字形采样是否跳动 |
| UNMASK+2～+22 | 刊头线重画 | 原B线在翻面时已经完整；撤层后先归零再重画，是一次重置 |
| 94以后 | 动态缩放项退完 | 相机仍保留1.006，不是注释所说回到1 |

抽帧26首叶变窄，44中部新旧混合，61右端还有暗叶，79以后整体B。最终B相机尺度与制作原图不同，应以输出帧检查安全边；不要仅凭「摘罩」认定所有元素都静止。

## 5．原创演绎：解释同一内容怎样形成有层级的版面

**信息目标。** 同一段文字从未组织的初稿进入实际排版结果。先画最终态：标题、正文、注释各有真实文本和清楚阅读顺序，行宽、基线与留白能被指出；下一镜进入真实编辑器修改一个参数。不是只把「Frame」换成「Craft」。

**美术。** 新旧保持同一纸色与字色，用细栏线展示结构；主标题先对齐稳定支点，正文按真实中文标点排，不为适配12叶强行拆字。转场可以沿版心列而非屏幕12等份，边缘保留固定页边。这属于原创改造，需要重新验证几何。

1. 先展示实际初稿，指出缺少主次的具体位置，而不是故意把旧稿做得难看。
2. 轻显网格并说明组织依据；结束阅读后再启动翻叶。正文最重要句可暂缓到整页完成后高亮，避免在波中被切成残词。
3. 同一文本随叶翻到新布局，保留标题身份与页码；页面重排本身可由对照讲解，不伪称编辑器真的翻叶。
4. 完整B落定后撤临时叶片和网格，把标题、正文、注释按阅读顺序一次指出；不再让全部文字逐个飞入。
5. 下一镜调整真实段落间距或列宽，并看到真实换行变化，使设计结论可验证。

声音可用一条由疏到密的轻薄翻片质感，落定时收尾；不能每叶配等响重击。样片无音轨，实际声画仍需制作试听。

## 6．原创排版前后的关键画面

| 状态 | 应画出的具体关系 | 阅读权 |
|---|---|---|
| 初稿 | 同一标题、正文与注释；保留真实初稿难点 | 先理解现有内容，不急着看效果 |
| 组织依据 | 轻网格标出标题轴、正文列和注释边，文字仍完整 | 观众知道为什么这样分栏 |
| 翻面中段 | 新旧两版共享页码和内容身份；叶缝避开当前强调句 | 波只连接，不要求同时阅读两版 |
| 最终版面 | 主标题、正文与注释形成明确尺度差；网格退弱 | 先看主标题，再读正文，再找说明 |
| 实际调参 | 一个段落参数改变、真实换行和空间随之变化 | 把美术判断落实到可观察结果 |

原创设计尚未实现。两页同一文本可用一条短定义和一段说明作为明确教学材料，按中文标点实际换行，不凭空删字制造简洁。应保留最终页的行间灰度、段间留白与页面边界，百叶片不额外带各自的纸影，否则整页像十二块互不相属的立板。审波中最窄叶和最亮高光，确认文字仍归属于纸面；审撤层前后，确认新页不是突然换了字重或缩放。

## 7．失败诊断与验收

| 失败 | 修正 | 可观察通过 |
|---|---|---|
| 背页字镜像 | 背面预转180、正确backface | 翻完每叶B文字方向一致 |
| 叶间漏列或重复列 | 共享完整源页，按x负偏移，核对总宽 | 静态拼合所有横线、字形连续 |
| 波拖成逐张翻卡 | 重查真实起跳间隔与同时活动数量 | 波连续推进，中途没有无意义空等 |
| 摘层时整页跳动 | 核对角度、世界缩放与裁切，不只看opacity | 撤层前后主体位置一致，字更锐而不跳位 |
| 刊头线突然消失像bug | 若不需要二次画线则保留满态 | 每个重置有明确视觉目的，不打断阅读 |
| 翻完只有色彩变化 | 重做内容结构与后续解释 | 观众能说出排版关系，并看到真实参数影响 |

验收两端静帧、波中构图、最后一叶与撤层前后、全部辅助内容完成和下一镜；再正常速度配口播检查。原卡的同片次数是案例取舍，不覆盖本项目权威数值规则。
