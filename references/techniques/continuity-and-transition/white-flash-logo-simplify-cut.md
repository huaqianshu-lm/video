# 冲白降维：从材质演绎回到清楚识别

## 1．这是定妆连接镜头，不承担教程解释

同一词标先以虹彩金属质感出现，经蓄力与冲白，变成纸面单色版本。观众应读到「同一身份从演出回到正式形象」。适合一次品牌／章节连接；不宜把每个教学标题都做成金属字，也不能用白闪掩盖对象、字号或位置变了的问题。

## 2．金属来自有组织的明暗，不是随便加彩虹

主词标190px／700、全小写、字距0.03em、中心y500。长词按横幅控制宽度，四字短词不能不经重排就照用同一字号。液态层、bloom、倒影、扁平层共享wordStyle和wordText；「ft」连接处单独撤掉f后字距，避免两横笔刚接触时出现抗锯齿亮缝。这种细节应根据自己的字形检查，不能把英文特例搬到中文。

| 质感层 | 原例做法 | 怎样判断是否有效 |
|---|---|---|
| 虹彩底 | 紫、粉、桃、冰蓝，300%背景宽，位置每帧1.1% | 颜色有连续流向，不能每字随机跳色 |
| 体积 | 顶亮底暗的纵向覆盖 | 字体轮廓仍清楚，黑底上不靠粗外描边撑字 |
| 镀铬反光 | 腰部亮带与其下暗带 | 明暗有相邻结构，不是全字平均发光 |
| 斜向高光 | 6～34帧一次扫过，裁在字形内 | 不溢成遮住整词的白雾 |
| bloom | 同色副本blur38、0.42起 | 只托出主体，细字和负空间不被污染 |
| 地面倒影 | 竖向翻转、0.22、渐隐 | 有承托而不出现第二个同等清楚的词标 |

背景极光与浮尘是次级光域，不应比字面更亮。纸面段则撤材质、倒影和强光，留下墨色字标、124标志、96×5琥珀短线与46副句。对比来自视觉语言统一地变化，不只是颜色从彩色切黑色。

## 3．实际时间与配准边界

34～46字面brightness1→1.7，横向眩光34～48拉开。44～50径向白团从80增长到1580，t²加速；50切换场景，50～53直接铺全白；54～76白层退去。**径向阶段不是先已全白**：f49的渐变外围仍透底，真正保证全遮是50开始的整层白。切点必须放在保证窗口内。

扁平字标52～78从1.03收至1。原例两版共享基础字形和中心，但暗段已推至约1.035，亮段早期为1.03，不能说视觉轮廓逐像素完全相同；全白掩护了尺度差。需要严格形态保持时，应在切点统一世界尺度。

72～86短线，74～88取景框，84～96斜切标志；副句78起五词，每词18、gap4，最后**112帧**完整。原卡96起hold仅适用于部分图形，完整短句只余8帧；96～120还缓推1→1.01，颗粒也变化。教程要读副句时应重新留预算，不能照搬4秒总长。

抽帧48看到扩散光团但角落仍暗；56处已纸面且字偏灰，随着曝光退去变清；79标志正在形成，95副句未全出，111附近最后词接近完整。抽帧只能定位阶段，闪光是否舒服仍需正常速度观看。

## 4．原创演绎：让「装饰与识别」成为可解释的排版问题

**目标。** 教观众区分装饰性字效和正式署名。先画最终态：同一个自有教学标题／署名，单色清楚，旁边有真实使用场景，例如封面角标或视频内署名；下一镜在小尺寸环境中检查可辨性。不能使用上游品牌名假冒自己的身份。

**美术。** 选择实际可用的中文字体，保证粗细、内白和连笔在小尺寸不糊。演出段只给主体一次受控反光；正式段沿用相同字形、中心和实际字号，撤掉光效后也能独立成立。底色与下一镜封面统一，避免又加一层无关转场。

1. 大尺寸展示标题的材质方案，口播指出这是演绎效果，不是正式识别标准。
2. 蓄力后短暂冲白，换成同样字形的单色版。若内容没有需要这一重音，可省掉白闪，直接比较。
3. 曝光退去时单色版已在，辅助说明延后，避免字标淡入和白退叠成两次入场。
4. 从正式版连续缩到真实角标位置，展示实际尺寸的识别结果。小字不清就修字形／间距，而不是重新加光。
5. 下一镜在真实封面或页面上看署名与标题主次，说明何时应使用简化版。

声音可用一次克制明亮重音，峰值对应实际冲白窗口，落定后让口播接管。原卡把声效列为必选是其演出偏好；本项目仍应按实际听感与内容判断，不因本参考新增强制声效规则。

## 5．原创定妆画面的关键状态

| 状态 | 具体美术处理 | 重点审查 |
|---|---|---|
| 材质版 | 自有短标题大幅居中，虹彩只在字面，副说明留在低权重区 | 字形内白与字距在最亮时仍可认 |
| 蓄力 | 一次横向反光，背景亮度低于主字，不增加星点 | 焦点集中在同一标题，不是全屏同时炸开 |
| 白峰 | 用真实全遮窗完成风格切换 | 场景替换完全在掩护内，峰前不漏新底 |
| 单色版 | 相同字形与中心，撤倒影和多层光，主字靠轮廓成立 | 无光静帧也有清楚的尺度与留白 |
| 实际角标 | 缩到真实封面／页面的位置，旁边保留主要内容 | 标识可认但不压过视频标题 |

这组原创画面尚未实现。单色版不是把彩色版整体去饱和：应撤去反光带、倒影和体积层，保留纯字形；否则只是灰金属，识别性并未提升。小尺寸审查使用真实输出显示比例，既看有背景的成品，也看单色轮廓，不能只在大画布放大检查漂亮细节。若标题是长中文句，先决定缩略署名或章名的真实内容，不能在白闪中悄悄换成另一个名字。

## 6．失败诊断和证据

| 失败 | 修改 | 通过时看到 |
|---|---|---|
| 彩虹字像塑料贴纸 | 建立腰部明暗与单次定向高光，减平均发光 | 轮廓锐利，明暗能说明表面 |
| 白闪时能看到两版换位 | 统一字形与世界坐标，将切点放全白窗口 | 全白前后仍认得同一身份 |
| 纸面上字又单独淡入 | 撤第二套淡入，让白层退去揭露已在位字 | 一次清楚揭示，无二次浮现 |
| 96以后副句仍在动却被切走 | 按112满态重分时间，或缩短副句 | 完整短句可读，下一镜自然接续 |
| 正式版仍靠光撑质感 | 先审无光静帧，再检查真实小尺寸 | 单色字形和排版本身成立 |

检查暗态、蓄力、49／50／54、曝光回落、完整锁定与下一镜。正常速度、真实中文字体、声音和使用场景需要另验，不能以材质层数证明商用水平。相关 [图标收束与字标落位](../resolution-and-ending/logo-shrink-wordmark-lockup.md) 解决尺寸与组合关系，本篇解决同一身份的材质语气交接。
