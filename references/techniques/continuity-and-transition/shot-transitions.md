# 镜头交棒三式：盖切、甩镜与穿窗怎样交出阅读权

## 1．三种接缝解决三种关系

flash-cut把换页藏进光峰；whip-pan用横向速度把视线带到远处；mask-wipe把一张卡展开为它的详情世界。三者不能只是按「哪个更炫」轮换。教程中先判断前后内容是时间跳转、同一空间远处，还是容器与内部内容，再决定接法。清楚的直接切换同样可以成立，不能把原卡「不裸切」的宣传片偏好升级成全项目禁令。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/transition/shot-transitions.md)、[WhipBrakeReal](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/transition/shot-transitions/WhipBrakeReal.tsx)、[PortalWipeV2](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/transition/shot-transitions/PortalWipeV2.tsx)、[FlashCut](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/assets/lib/FlashCut.tsx)。官方样片：[盖切](https://vincentwei1021.github.io/video-shotcraft/media/flash-cut.mp4)、[甩镜](https://vincentwei1021.github.io/video-shotcraft/media/whip-pan.mp4)、[穿窗](https://vincentwei1021.github.io/video-shotcraft/media/mask-wipe.mp4)。三式均查16幅等距抽帧；原卡给定选型，源码可见机制，抽帧可见美术与阶段，原创为制作推导。未正常速度观看、试听、运行上游或原创实现。

## 2．A：白闪只遮住切点，前后镜仍要独立成立

示例从搜索到的项目卡进入同名详情，卡片高亮与推进先确认对象，白闪跨骑页面替换。可学习的是**同一名称和对象身份在两端保留**，不是把空白当万能胶。详情态应直接呈现需要解释的字段，不能全白后又淡入另一张无关标题卡。

原卡给出切点前5帧、后5帧的使用预算，实际组件默认10帧，在局部第4帧达到0.85峰值。推进支点对准选中对象，光层容器覆盖输出视口，不受卡片overflow裁切；但其径向渐变80%处已透明，**并非全屏不透明白遮挡**。若从切点前5帧调用，峰值反而在切点前1帧；应核对实际调用，不能把「两侧各5帧」当作严格对称的光峰保证。背景在掩护最强时换页，光退去后新页已经在位。不同时叠甩镜、震屏和第二次透明度揭示。

对浅色界面，光峰和原底反差小，点击高亮、空间位置与新页标题承担连续性；对暗页，短白峰更强，要查阅读负担。光没有完全遮住旧标题时，两页的文字突换会暴露切点。不能只核对峰值opacity，还应逐帧查画面实际合成。

## 3．B：索引长廊的美术和运动来自同一位置量

暖纸、墨色衬线大数字与朱红播放头组成画面；460宽卡片、64间隔，pitch524。初始第02张居中，目标第09张，世界位移为7×524＝3668px。下方刻度尺随卡列移动，播放头固定在x960；右上Nº02→09不是独立补间，而是`2+dx/524`的读数。

这种同源关系让观众理解「越过了哪些位置」，而不是看一排贴图被甩走。计数器采用150px衬线数字，个位按索引分数滚动，上下渐隐模拟滚筒，纵向模糊由读数速度驱动；卡列则按横向速度做SpeedBlur。两者方向不可互换。阶段如下：

| 输出帧 | 动作与美术变化 | 要审的内容 |
|---|---|---|
| 0～24 | 第02卡、播放头、索引完整建立 | 卡列并非全要读，当前对象与总体索引必须可认 |
| 24～84 | 60帧积分位移，前三帧平滑起步后指数减速 | 速度连续，不在分段接点再次加速 |
| 80～98 | 第09卡抬高12、放大到1.2；邻卡缩4%、退至45% | 起飞与长尾有4帧重叠，检查目标是否被侧卡盖住 |
| 88～104 | Efficient Models标签升起 | 注释104才完整，不能写98起全部静止 |
| 104～129 | 结果阅读 | 目标卡名、序号、分区对应，下一镜可沿此对象进入 |

位移积分表步长0.05帧，`v∝exp(−6u/60)×smoothstep(u/3)`，归一化到3668。不能把前12帧和后48帧各套ease-out，那会改变接点速度。横向模糊amount0.085、上限64是原例条件；缩短跨度后若机械保留模糊强度，卡片可能只像失焦而非高速通过。

落定卡宽552，原边距64，邻卡也在缩小；审查重叠与阴影不能仅看卡中心。目标用高清纹理；字体读不清时应重取真实局部，不能只增强锐化。抽帧显示高速段文字横向拉成线、索引仍滚动，后段目标凸起并保留左右上下文。

## 4．C：穿窗先设计内外两幅完整画面

外景是瓷白工作台：96px问候标题，3×2卡阵；每卡520×300，封面176高，标题40，元信息32。目标为第二行中卡，蓝色波形封面；内景沿用三条波形，把它们放大为深钴蓝背景地貌。**可迁移的是封面与详情的视觉亲缘**，不是复制预测数字。

内景主体1240×660玻璃面板，64px标题，历史实线／预测虚线／区间带／TODAY标线；两枚浮卡压在面板对角，色彩分别支持主数和辅助置信信息。玻璃有低透明渐变、细亮边和大软影，文字不一起模糊。全部图形和18.4%、94%均为程序示意，不能当真实分析结果。

14～26帧目标抬起10px、scale1.03，邻卡退18%；26～66帧同一t驱动x、y、宽、高、圆角和内景scale0.42→1。卡面在`t≈0.278`时已透明，不是一直把旧标题放大到全屏。34～66画曲线，42～74做两层散开：面板scale1→1.08，近景1→1.3。66之后还有8帧缓停，74～139才是完整内景保持。

内景是1920×1080固定画布在可变窗口内居中裁切，0.42不是对卡尺寸的严格逆矩阵；不能声称全过程封面逐像素配准。原封面与内景沿用wavePath，但尺寸、层次和位移不同。需要严格同图连续时，应另做逆变换与注册验证。

中段尤其检查：卡放大时长宽比在变，标题是否拉伸残留；浮卡是否在狭窗阶段先被切成无意义碎片；远近两层是否遮住同一读数。原例不用深层模糊，正是把复杂度留给内容阅读。

## 5．原创演绎：从照片集合进入同一张照片的裁切

**信息目标与结果。** 观众先在集合中找到照片，后看到它的真实裁切区及保留内容。先画最终编辑界面：主图、裁切边界、比例读数，保留可识别地标；下一镜实际调整比例，证明照片身份未变。不是进入一个与照片无关的炫丽世界。

1. 若集合很长且编号对找图有意义，借B建立同源序号与横向浏览。只让目标照片承担详细阅读，其余缩略图保留存在感。
2. 目标落定后用同一源照片构建C。照片窗口向编辑画布展开，旧卡名尽早退出，主图采用逆变换保持地标，而不是直接套原例0.42。
3. 最终态用克制中性编辑器材质，比例与裁切框是唯一强调；不保留预测浮卡、波形和玻璃。
4. 如果用户真实操作就是一次点击且无需展示空间迁移，可选择A，从点击到同名编辑页，不同时使用三种转场。
5. 展示真实裁切结果，再进入操作；不让转场暗示已经自动优化画面。

声音按所选接法安排：B的速度声随减速收尾，C让展开在口播前结束，A短音点对应盖切。官方37个本批样片均无音轨，以上是待试听的制作建议。

## 6．原创照片镜头的关键画面

以下为未实现的横版导演草案。先选一张主体与边缘都清楚的实际照片，再确定是否真的需要长廊；照片不够多时直接从集合进入编辑，不能复制同图制造数量。

| 状态 | 画面设计 | 保持与改变 |
|---|---|---|
| 浏览建立 | 目标缩略图居中，左右仅露相邻项；上沿小集合名，序号靠近浏览轴 | 真实文件名与图像身份固定 |
| 高速通过 | 缩略图和尺共同横移，标题区保持；重要人脸不在模糊段要求辨认 | 速度变、对象不换皮 |
| 目标落定 | 目标图略大，邻项退弱；先看主体，再看文件名和序号 | 保留集合上下文 |
| 窗口半展开 | 关键地标停在同一屏幕位置，窗口边界扩大；控制区延后 | 原图不拉伸，窗口长宽比可变 |
| 编辑完整 | 照片占主要空间，比例和裁切框在近侧，其他工具低权重 | 真实框边与图像关系成为主内容 |

中段用地标做配准检查，比「中心相同」更可靠：例如同一棵树、眼睛或建筑角点在放大前后可连续跟踪。若目标落定的1.2倍会切掉主体，先改卡内裁切，不以更大阴影掩盖；若内景第一眼已出现无关界面，重新取真实编辑状态。A盖切可用于同一照片的详情跳转，但白闪之外仍要保留名称、缩略图或地标中的至少一个身份线索。

## 7．失败与通过判据

| 失败 | 修改 | 可观察通过 |
|---|---|---|
| 甩到哪张，数字却指另一张 | 卡列、尺和数字共享dx | 播放头下的真实序号与计数器一致 |
| 长尾中突然再次提速 | 查积分速度，撤分段重复ease | 主体方向连续、减速可追，不像二次启动 |
| 穿窗只有一张巨字卡 | 旧卡面提前退出，内景预先存在 | 看得见封面语义进入真实详情，正文不被拉坏 |
| 结果仍在漂，文字读不清 | 视差归零后留阅读段 | 完整态主数和实际内容清楚，能接下一操作 |
| 三种效果叠在一起 | 按关系只选一式 | 接缝有单一清楚的动作，内容目标仍是焦点 |

分别保存前态、掩护峰值、运动中段、最后内容完整态与下一镜；补做正常速度及口播试听。原卡对Linear样片的评论不是本篇重新实测的事实，不据此断言所有优秀片都不能直接切。
