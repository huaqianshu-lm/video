# 字形穿越：把章节标题变成进入内容的门

## 1．先辨认穿的是什么

letterform-zoom不是穿进字母内部封闭的字腔，而是把**字形笔画挖成透明洞**，推进进入其中一条足够宽的笔画。原例选EDITS中央I，暖黑盖板在前，亮页在后。适合章节标题与正文具有明确归属的高能交接；若正文只是另一张标题卡，穿越没有带来新认识。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/transition/transition-travel.md)、[LetterformZoom](https://github.com/Vincentwei1021/video-shotcraft/blob/1266a3ec4831289c4d893d42dd5102723658039a/demos/transition/transition-travel/LetterformZoom.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/letterform-zoom.mp4)。原卡给定空间意图，源码可见遮罩／采样／参数，抽帧可见150帧的16个等距状态。原创为制作推导；未正常速度观看、试听、运行上游或原创实现。发布页数字是程序示意。

## 2．标题构图和洞内明暗先成立

EDITS为560px、900字重、−0.02em字距，SVG基线712；主标题占横向主体，章号在196，副标790，二者较小且低对比。暖黑盖板有顶部微光，洞内橙金渐变是最亮区域；标题边有暖白细切口和橙光，仅落在盖板区域。若字洞后正好是暗色卡，字会像缺笔，不再像窗口。

建立段后景正文完全隐藏，只保留标题区暗形与卡片区奶白柔光。这样观众先读EDITS，不必透过五个字同时阅读另一层小字。64～90才把真实内容由18px失焦转为清晰、透明度0→1。这个延迟关系可迁移，色彩与英文字样无需照搬。

最终页左140px两行标题，右640×600奶白卡，导航更小；暖影和顶部内高光让卡有表面，正文自身不持续发光。后景推至1.08后会裁边，应按最终裁切核对导航和卡片，而非只在1倍时排得下。

## 3．锚点与指数尺度不是凭字体字号猜的

原例实测I的笔画约x920～1026、y316～712，推进支点(973,515)。平面变换`p'=O+s(p−O)`；锚点若落在盖板上，放大的就是黑板，不会自然进入洞。换词、中文字体、字号或渲染器后，必须对渲染字形重新测量。

主尺度不是简单1→30：先有1→1.03慢推，26～34后吸2%，34～86再乘30^u。后吸在34～42恢复，末值为30.9。106宽笔画被放到3275.4，足够横向覆盖，但覆盖是否成立还取决于锚点偏置、笔画上下端和实际轮廓，不能只做宽度乘法。

盖板opacity在**尺度14→26**消失，不是固定76～86帧。它在洞完全覆盖前便可退去，因而实际效果是几何穿越与透明度交接混合；若要求纯几何穿透，应另验遮挡覆盖并调整退出条件。原卡对「洞撑满瞬间」的说法不能代替实帧。

后页1→1.08，主推期完成70%，86～116补完30%；源码两段不同曲线，没有导数匹配计算，不能仅凭注释断言连接处速度严格连续。若实际出现拐点，要测或重建同一位置函数。

## 4．变焦拖尾与时间链

| 阶段 | 实现 | 审查重点 |
|---|---|---|
| 0～26 | 盖板缓推，2～18眉题／副标进入 | 主字第一帧就在，辅助字不抢视觉中心 |
| 26～34 | 后吸2% | 预备克制，不像整个标题突然缩错 |
| 34～86 | 指数主推，u采用bezier(.6,0,.85,.5) | 慢起能认出洞，后段不强求读小字 |
| u>0.35 | 期望模糊增长到20 | 组件内除以s，防止局部blur被尺度放大成糊墙 |
| u>0.5 | 四层过去0.8／1.6／2.4／3.2帧的盖板采样 | 残影来自同一运动函数，不是复制几个任意小字 |
| 64～90 | 后景内容显露合焦 | 转场退场时正文应已可辨，不再二次弹入 |
| 96～126 | 镜头计数0→12 | 示意计数，不是测量渲染进度 |
| 100～140 | 四条时长错峰完成，最后一条118+22=140 | 注释132保持偏早；实际全条完成只余10帧 |

DONE124起仍用弹簧，不因计数到12就全部落定。后景Grain也继续变化。抽帧70见两层内容并存，80仍有盖板边，99后页清楚，139附近最后时长条才接近完整；正常速度是否过急待验。

## 5．原创演绎：从「裁切」标题进入真实照片编辑

**目标。** 观众从知道章节主题，进入能看见画面边界与裁切关系的操作场景。先画最终编辑态：真实照片、裁切框、比例读数、清楚的保留与舍弃区域；下一镜实际改变裁切框，不能停在「轻松裁切」宣传语。

**中文美术。** 选择有足够宽连续笔画的字形，以真实轮廓测量可进入区域。若无法用不夸张倍率铺满，就缩短标题或改用照片窗口；不为了套技法强行把中文笔画拉宽。背景采用中性深灰，洞内是照片色彩，不增加与照片无关的熔金。

1. 两字标题与章号建立，洞后暂时只露照片色块与轮廓；避免洞内字幕与外部标题叠读。
2. 锚点对准实测连续笔画，慢推预告里有内容；正文控制区暂缓进入。
3. 主推时照片按逆变换维持关键地标的屏幕位置，遮罩与内容分别设计，不机械套后景1.08。
4. 字形退去后出现真实裁切框和比例，照片保持身份；只强化当前框边，其余工具低对比。
5. 完整看清后，下一镜拖动裁切框，并展示边界外真实内容；用结果解释构图变化。

此设计尚未实现。声音建议只跟随一次推进建立方向，落定前退去，避免盖住「保留哪一部分」的口播；无音轨样片不能支持已卡点结论。

## 6．原创「裁切」穿越的取景表

未实现的导演草案先用目标中文字体做一次大字静帧，量出能穿过的连续笔画；若需要扭曲字形才能穿，改用照片窗口，比保留技法更符合阅读。

| 状态 | 主体与负空间 | 转入内容的条件 |
|---|---|---|
| 章题 | 两字占主要横向空间，小章号在上；洞内只有照片色块 | 章题读清，目标笔画可辨 |
| 推进预备 | 支点笔画仍完整，辅助说明先退弱 | 不让小注释被放成巨字残影 |
| 半穿越 | 照片主体地标出现，盖板残边仍说明前后层 | 视线从字轮廓移向照片，不突然换对象 |
| 编辑态 | 照片与真实裁切框占主空间，比例读数紧邻框 | 工具字清晰，主体未被无意义裁掉 |
| 操作近景 | 一条框边移动，边外图像仍能看见 | 结果来自真实裁切关系 |

支点只解决穿入方向，不能保证照片主体自动落在好看的位置。最终图像的主体、视线方向和负空间要先设计，再反求洞内取样；必要时让照片轻移而非整体中心推近。若最后全屏只看到照片的天空或一块背景纹理，说明洞内取景选择错了，不是ZOOM_MAX不够大。把标题层和照片层分别单独查看，确认两者都独立成立后再合成。

## 7．失败诊断与验收

| 失败画面 | 修正 | 通过证据 |
|---|---|---|
| 最后被黑板堵住 | 实测锚点与洞轮廓，复算终态覆盖 | 所有屏幕角都落在目标洞内或有明确的交接设计 |
| 字形像杂乱拼贴 | 建立段隐藏后景可读字，只留光形 | 外部章节可读，洞内有内容感但不抢读 |
| 推近后整屏糊 | 模糊按s补偿，只作用于前板 | 后景接管时真实内容清楚 |
| 结果标题很好看但没有内容 | 重做最终操作构图 | 观众能指出操作对象、参数与下一步 |
| 写132保持而条还没满 | 从最后字段完成点重留阅读时间 | 完整结果与说明能在正常速度中被理解 |

保留初始美术、洞的测量、半推进、盖板退出、全部结果完成和下一镜。与 [文字作为观看窗口](../typography/text-as-mask.md) 比较：那篇研究内容配准与文字正向遮罩，本篇以不透明盖板挖洞、前后景尺度差为主；两者遮罩极性不能混用。
