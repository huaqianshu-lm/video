# 单卡魔术登场：先认落点，再让一件东西成为主角

本镜的设计链是短光定位、远处弹射、弧线旋转、正面落稳、内容接管。只有一张卡承担主要动作，右侧文案在落位后获得阅读权。不能把“闪光＋旋转十三圈”当成独立质量标准：卡片本身的排印、材质、正背面和最终画面，决定观众看到的是主视觉还是特效样机。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/opening/magician-card-flourish.md)、[MagicianCardFlourish.tsx](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/opening/magician-card-flourish/MagicianCardFlourish.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/magician-card-flourish.mp4)。另核对 [Look](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Look.tsx)、[Polish](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Polish.tsx) 与 [Brand](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Brand.tsx)。原卡固定版本已核验，main代码与媒体不冒称同版运行。

本文分**原卡给定、源码可见、抽帧可见、制作推导**。样片1920×1080、30fps、156帧、5.2秒，无音轨，查看16帧。未正常速度完整观看、运行上游或实现原创镜头；原卡所述定制参考图未取得，不能认证对该图的还原程度。案例参数不是生产默认，见 [质量规则8.6](../../../docs/VIDEO-PRODUCTION-RULES.md)。

## １．先决定这张卡值得怎样出场

| 内容问题 | 适合的安排 | 不适合的安排 |
|---|---|---|
| 发布一件主产品／封面 | 一次爆点把身份交给完整主视觉 | 同时飞来六张同样重要的卡 |
| 章节介绍一个具体对象 | 短入场，落稳后真实内容接管 | 让炫技占掉解释对象的时间 |
| 教观众如何生成／保存文件 | 必须有真实前后状态 | 光里变出卡就当作操作成功 |
| 多对象比较 | 另设计比较镜头 | 给每个对象重复同样魔术动作 |

**制作推导**：魔术感适合“揭晓”，不天然适合“因果解释”。如果口播正在讲一步操作，先展示实际动作与结果，再考虑用主视觉强调，不用闪光制造不存在的软件能力。原卡中的高能、纯暗场、一次单卡是本例风格条件，不升级为全片通用限制。

## ２．完整静态画面：卡占左侧，文案有独立空间

### ２．１　尺寸与负空间

**源码可见**：卡面设计380×540，定格倍率1.72，显示653.6×928.8；中心700／540，边界x373.2—1026.8、y75.6—1004.4，高度约86%。文案左1130、顶300、宽700；卡右边与文案左边留103.2，右侧到1830，仍留90边距。

这不是一张竖卡放中央再叠标题。卡有近满高的视觉重量，右侧文字靠大字级形成平衡。标题132px／780，眉题24px／700，副文36px／420；眉题前56px细线、18间隔，主标题下40间距。卡与文字不是相同尺寸的两个面板。

**抽帧可见**：落稳后卡在左、标题在右，上下有明确边距；卡面蓝光细节、白色徽记与大字形成三级。右侧文案并不在飞行期间出现，避免卡弧线经过文案位置时互相遮挡。

**制作推导**：先用最长实际标题排好终点，再决定落点。竖卡如果是A4文档，380∶540接近但并不等于A4比例，应以原文件为准，不拉伸。右侧若是教程解释，优先放具体命题／实际结果，别照抄发布会口号。字幕区必须用实际排版检查，不能因卡高86%就认定上下都安全。

### ２．２　卡面美术如何建立物体感

正面从`#16244a→#0d1631→#080d20`形成海军蓝表面，24设计px圆角，细内边和顶边受光。上方品牌行与右侧等宽场次号，下方两行58px标题分别用760与300字重，最底部等宽11px票根信息、虚线分隔。1.72倍后大标题约99.76px，票根仍只有约18.92px，是否能读取决于其职责与最终观看尺寸。

中央徽记不是随便加一个发光标志：三圈细环和四条针线从标志外侧开始，给开口形状留干净空间；底部全息箔通过conic-gradient、screen混合和局部mask形成，透明度0.28。色相随theta变化，定格后theta固定，箔面也固定。它不是实际随视角求解的虹彩材质。

背面另做双向细纹章、内边与中心标志，保持同一色域。代码用cos(theta)判断朝背后时盖背面图；没有建立真实厚度或完整双面几何。若背面文字必须正读，需要另检查背面朝向与180°变换，不能假设一个透明度切换已解决所有背面问题。

**制作推导**：建立三层表面职责：稳定底材、轻微受光、局部装饰。只有重点区域需要箔，不给每行字加虹彩。最终主字在去掉光效后仍应清楚，卡面纹理不能抢徽记或知识信息。

## ３．星芒是空间提示，不是一颗蓝色球

### ３．１　光的形态由多层共同构成

**源码可见**：闪光中心与卡最终中心相同700／540。两条对角针轴初始−38°／52°，各由宽虚晕、主束和细芯构成；中心为26px小亮点、140px蓝色晕及10条短放射刺。蓝渐变的白色主要留在根部，外围仍保留蓝的色相，不是一条全白十字。

针函数向正负两侧各绘一半。代码长针len840，因此完整长轴约1680；短针len420，完整短轴约840。原卡“长轴840／短轴420”若按全轴理解，会把实际范围缩小一半。SVG用3200×3200，避免旋转中的长针端点撞裁切边。

**制作推导**：先看轮廓再看辉光。光线应向外渐弱，不能出现三角形硬边或白色圆球。画面边缘之外的光可以被总画幅自然裁掉，局部SVG却不能先切成直线端头。旋转让形态有一次短促变化，不做持续螺旋桨。

### ３．２　9帧是起飞点，闪光尾部实际到12

grow0→2.5，shrink6→9→12，opacity在12降到0，旋转0→90°也使用0→12。9帧时卡开始起飞，但闪光仍有尾焰；不是原卡字面所说“9帧完成全部90°并完全消失”。首帧透明度约0.35且尺寸0.2，已有小亮点，不是纯黑。

闪光层独立于卡的CameraMotionBlur，避免细针被多样本复制成条纹。卡片可有运动拖尾，针光仍保留独立形态。不能把整场一起套运动模糊后再靠加亮修复分身。

## ４．飞行：行程、弧线、尺度与自旋分别求解

### ４．１　弹射不是一条普通easeOut

**源码可见**：飞行从9到57，48帧。归一化u前0.14只走6%行程，二次加速；之后用cubic减速走余下94%。在转折处行程连续，速度有明显增加，产生“踢出”的节奏。

弧线采用`sin(π×行程)`：中心从700／540向右470、向上230形成单拱，再回到原落点。最高／最右是1170／310，但不一定出现在飞行时间中点，因为行程不是线性。它会经过未来文案区域，因此文字必须延后。

纵深用`z＝14000(1−行程)`，外部缩放`1.72×900／(900＋z)`。起点绝对尺度约0.10389，终点1.72；卡高约56px长到928.8，不是从零尺寸淡出来。卡内另用局部perspective模拟朝向，平移尺度与局部旋转是组合近似，不是完整的同一三维摄影机求解。

### ４．２　自旋要能回到确定的正面

前40%时间，角度进度约1.55u；后60%以2.4次幂衰减，保证结尾进度1。总角度13×360＝4680°，旋转轴由380／540的对角线归一化得到。它不是单纯rotateZ转13圈，也不是匀速转到最后突然夹断。

**制作推导**：圈数只是本例夸张程度。教程如果需要途中辨认卡片身份，十三圈通常太多，应减少圈数、缩短弧线并降低对角倾斜。停止时必须回正，也要看停止前几帧的朝向与速度；整数圈只保证最终姿态，不保证观众觉得落稳自然。

### ４．３　先按终点栅格化，飞行只缩小

卡先按最终653.6×928.8布局，内层zoom1.72生成字形，再将外层缩到飞行比例。相比先把380×540栅格图放大，能避免终点文字被低分辨率放大。若替换成位图封面，仍需要按最大输出尺寸准备真实清晰素材，CSS zoom不会补回图片缺失细节。

## ５．“定格即静”指卡的姿态，不是全场停止

| 通道 | 实际时序 | 审查点 |
|---|---|---|
| 卡姿态夹到终点 | 57起 | 不继续回弹，不改变落点 |
| 卡运动模糊 | 9≤frame≤57，150°／7样本 | 57仍在模糊容器中；清晰交接要看58 |
| 舞台光／背光建立 | 51→81 | 注释53→85不是当前实际值 |
| 外扩脉冲 | 57→79，框扩大14%并消失 | 不是卡本体再次放大 |
| sheen | 65→91 | 斜16°、宽34%，从左外扫到右外 |
| 眉题与细线 | 62／63开始 | 跟在定格之后，不与起飞争焦 |
| 两行标题 | 67／74各22帧 | 末行96完整 |
| 副文 | 86起，7词、每词16、间隔1.6 | 最后约111.6，整数112完整 |
| 背光／浮尘 | 此后仍呼吸／漂移 | 结尾不是全场严格静止 |

**源码可见**：卡落位后换成两层深色投影、淡蓝轮廓和弱泛光；飞行时则是较强蓝尾。sheen局部裁在卡圆角内，不能越过卡边扫到文案。外扩脉冲是独立同形框，不能让真实卡尺寸随着它呼吸。

**制作推导**：读字时要控制叠加动作。当前姿态57稳定，完整文案到112，112—155约44张才是全套内容完整展示；不能把57后的全部3.3秒都说成无新内容的阅读hold。若删掉右文，应重新设计卡的光效与静段，不留空右半屏。

## ６．关键帧观察与审查

实际查看0、3、6、9、12、18、28、38、48、56、57、58、72、91、112、155。

| 帧组 | 抽帧可见 | 制作必须检查 |
|---|---|---|
| 0—9 | 蓝色对角星芒旋转与收缩 | 白芯长度、端点裁切、是否像实体球 |
| 12—38 | 小卡飞行、侧面／背面交替 | 主方向是否清楚，弧线会不会冲出预定区域 |
| 48—58 | 卡迅速接近并回正，外框脉冲起 | 卡边与文字锐度，57／58的采样交接 |
| 72、91 | 卡保持，右侧标题进入，扫光一次经过 | 读字与扫光是否同时抢焦 |
| 112、155 | 完整邀请海报成立 | 静态层级、底部小字、右侧行宽与下一镜 |

抽帧不能证明“魔术感”“硬停有力”或声音卡点。原卡的光效来自定制迭代，不是全行业统一标准；迁移应取短光定位和主次交接，不重复上游品牌与票面。

## ７．原创演绎：揭晓一份完成的教程练习页

以下为**制作推导**，未实现。真实教程已完成一份资料批注练习，要让观众看清最终成果，再检查如何形成。动作表现“现在看成果”，不能代替真实保存／导出确认。

### ７．１　先把成果页设计好

将真实练习页按原比例展示在左侧，最终高约820、中心x670，留更充足上、下边距；右侧x1120起放“批注完成后的阅读结构”，下面只列本页确有的一个关键关系，例如“原句与注释一一对应”，不堆三张说明卡。

背景墨棕`#191613`，纸面米白`#f3eee4`，墨色`#2b2824`，批注为低饱和砖红`#b35c43`。真实纸页的字号、段落与批注才是主视觉，取消全息箔、品牌徽记和霓虹环。页面背面可用同纸色无字面，不编造另一份成果。

主要材料必须是真实完成的练习页，原句与批注文本保持完整。若实际页不够美观，应先调资料版面或选择合理阅读范围，不能靠入场旋转遮掩糊字与失衡排版。

### ７．２　只借一次主角揭晓，随后交还解释

| 阶段 | 画面 | 内容推进 |
|---|---|---|
| 前镜 | 真实最后一步批注已经完成 | 成果有依据 |
| 定位 | 左侧落点有短而克制的暖白边光 | 告诉观众看哪里 |
| 入场 | 页面一次小弧线接近，减少自旋，最终回正 | 看清这就是同一页 |
| 落稳 | 页边轻影固定，右侧命题出现 | 从揭晓转入阅读 |
| 检视 | 一个真实原句与其批注同步定位 | 证明一一对应，而非只看封面 |
| 下一镜 | 在同一页正视推近该原句与批注 | 解释为何这样标注 |

这里不采用十三圈与大星芒。页面内容决定能量：知识正文密时先安静，短封面才可更强。若旁白需要读原句，卡到位后再给一个稳定局部，不要求观众读飞行中的细字。

### ７．３　投影与素材规格先审查

假设原页1600×2260，高820时比例约0.36283、宽约580.53；中心x670时左右约379.73／960.27，与右侧1130留约169.73间隔。原句的源坐标、批注框和截图裁切都用同一比例映射，下一镜推近时保持同一页身份。

若标题36px源字在全页仅显示约13px，就不能让全页承担阅读；全页只建立结构，必读原句交给局部近景。把页面做得再高也不能替代实际缩放计算。渲染前用真实字体与完整批注检查页边、字幕以及下缘裁切。

声音可在落稳时用一次轻纸张触地，之后撤掉动作声让旁白读原句。真实导出成功若要表达，必须另有实际界面或文件证据，不在边光出现时配成功音。素材、配音、原创实现和正常速度观看均待验证。

## ８．失败诊断与通过条件

| 失败画面 | 修正 | 可观察的通过条件 |
|---|---|---|
| 闪光像蓝球／三角片 | 重做细芯、柔晕和根部比例 | 光有渐弱边，不是可触实体 |
| 星芒出现直切端头 | 扩局部SVG扫掠边界 | 全过程没有局部矩形裁切痕迹 |
| 卡飞过文案遮成一团 | 延后文案、缩小弧线或改落点 | 观众一次只追一个主动作 |
| 十三圈后虽正面却突兀 | 改近端角速度与行程 | 正常播放能认到同一对象落稳 |
| 57定格仍有拖影 | 检查采样与58交接，不只查pose | 最终卡字边清晰，无残影 |
| sheen越过圆角污染背景 | 将高光裁在卡面同形蒙版 | 扫光只改变表面，不扫到文字区 |
| 完成页只好看，内容读不到 | 设计全页到局部的阅读接棒 | 必读原句在实际观看尺寸清楚 |
| 魔术被当成生成／保存成功 | 补真实前后状态，改旁白语义 | 动作没有制造不存在的产品结果 |

Storyboard应交代对象身份、完整态美术、落点负空间、闪光与起飞区别、弧线／尺度／自旋关系、最后读字通道与下一镜。静态构图、全速运动、声音和真实成果分开验收；本文未认证原创实现或商用成片。
