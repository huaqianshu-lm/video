# 漫画分格与末格接管：用同一主体的不同观察距离组织节拍

本镜把一个完整主体拆成几个同时存在的观察窗口，再让其中最值得继续看的窗口接管全屏。分格应带来不同认识：形体、操作部件、内部细节，而不是把三个无关画面排成斜格。节拍负责带领视线，材质与内容决定每一格是否值得看。

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/shots/rhythm/panel-grid-moves.md)、[ComicPanelSplit.tsx](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/rhythm/panel-grid-moves/ComicPanelSplit.tsx)、[官方样片](https://vincentwei1021.github.io/video-shotcraft/media/comic-panel-split.mp4)，另核对 [Polish](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Polish.tsx)、[Look](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Look.tsx) 和 [Brand](https://github.com/Vincentwei1021/video-shotcraft/blob/main/demos/_fixtures/Brand.tsx)。固定卡只列当前漫画分格一式，历史网格文件不混称本轮已观看变体。

本文分**原卡给定、源码可见、抽帧可见、制作推导**。样片1920×1080、30fps、156帧、5.2秒，无音轨，查看16帧。未正常速度完整观看、试听、运行上游或实现原创镜头；固定卡与main代码／媒体不冒称同版执行。案例数值不替代 [质量规则8.6](../../../docs/VIDEO-PRODUCTION-RULES.md)。

## １．先为每格安排一个独立观察任务

| 格子角色 | 应提供的内容 | 不应重复的内容 |
|---|---|---|
| 整体 | 主体形状、比例、身份 | 三格都放同一张全景 |
| 部件 | 哪个部件在怎样工作 | 无意义装饰环转动 |
| 细节 | 材质、结构或可检验变化 | 模糊到只剩颜色的微距 |
| 接管格 | 下一镜真正要继续解释的对象 | 为吞屏方便临时挑一个无关区域 |

**制作推导**：如果三格是不同主题，宜明确设计成并列比较或多任务画面，不叫同一主体多机位。对于教程，选择的信息差异比漫画边框更重要。画面必须能说清“这一格比上一格多看懂了什么”。

## ２．三格与最终海报先分别设计

### ２．１　斜格的宽度与观察内容相配

**源码可见**：两条内部分界顶端x750／1405，向下偏左230，约12°；三格形成左窄、中斜、右宽的观察口。每格实际内容铺满整个1920×1080再裁，不先把一张图压扁进斜四边形。

第一格s0.68、中心360／590，展示38°侧向的镜头全身；第二格s2.3、中心1010／300、焦点世界y−240，观察对焦环；第三格s2.2、中心1640／540、焦点0／0，观察镜片。每格不是“同图分别缩小”，而是对同一主体采用不同取景中心与观察方向。

**制作推导**：先把真正要看的细节放到每格最宽的可见区域。斜格上宽下窄，主体脸部、刻度与说明不能只按矩形中心排；对最长文字和最外侧关键轮廓单独检查。真要读操作文字时，局部保持端正，不能为了斜格再把页面做一次斜透视。

### ２．２　墨黑、奶油纸、朱砂红共同形成漫画语言

舞台从`#1c0c0f`到`#070304`，带红相暗环境；分缝深墨边、奶油纸芯，副框奶油底、4px墨边、7px硬影，略歪斜。红色`#ff3346`只给镜筒圈、固定指示与少量图形，主字奶油白，次字偏灰褐。

缝线实际墨边20px、纸芯11px，另外有34px宽8px模糊的深影；不能把所有视觉宽度都统称18px。半调13px网点只在外围渐显，中心主体保留干净，不用满屏圆点覆盖精细玻璃。

**抽帧可见**：分格明显读作同一夜间产品展示，奶油斜缝与盖章式说明把它和普通视频三分屏区分。各格有独立光区，但保持同一墨红色域，没有三套互相冲突背景。

### ２．３　最终海报：细节铺右边，左侧真正可读

最终镜片中心移到1360／540，基准倍率2.45，右侧大幅出画；左侧加由深到透明的暗幕，品牌与两行150px／850标题左120、顶300。副句38px、较弱色，主句先读，不能与巨大的镜片高光争第一焦点。

**制作推导**：接管后不是把第三格简单拉满。要重新安排标题、负空间、主体中心与高光落点；大主体在右侧出画可以产生张力，但被解释的关键部位不能出画。最终海报本身不成立时，先重排，别用更强速度线补救。

## ３．主体质感来自可辨认的构造，而非全屏泛光

**源码可见**：镜头是程序SVG，不是实拍或真实三维模型。侧面通过椭圆、渐变和向左筒身投影构造；黑铝有纵向明暗、橡胶环有120条细纹、刻度围绕环排、红三角固定不转。前镜片由深紫径向底、品红／青绿弧形反光、较细白高光及多层圆边形成。

光圈有11片多边形叶片，按方向给金属明暗，开口由128收至74；它支持“开口变小”的示意，但没有真实光学曝光计算，不能据此认证f/1.2与f/2精确对应。镜筒刻字也是演示设计，不代表上游实际生产了一款镜头。

**制作推导**：迁移到真实物品时，选择能证明材质的局部：金属边缘高光、橡胶细纹、玻璃反射、纸面纤维各不相同。全场只加一团彩色光不能代替这些。若使用照片，三视图须是同一个对象、同一版本，并有足够分辨率支持近景。

## ４．分格节奏：三次画面进入，内部只有两条缝

20／24／28三格分别硬切进入，未到cue不渲染，每格5帧由1.07回1，并有4帧奶油色短闪。底下保留被压暗的完整原画到30附近，让未进入区域有来处，不突然变成黑洞。

原卡称“三刀”，当前更准确是三次格内画面进入、两条内部分缝。第一格20进入时没有第三条额外分界；B1在第二格24附近绘，B2在第三格28附近绘。缝各从cue−1起3帧向下描，首个非零时刻与格进入相近。

**制作推导**：节拍点取自真实音轨或旁白强调，不必机械4帧一格。只在音乐蒙太奇中，133毫秒的间隔才适合“咔咔咔”；教程要辨认三个不同内容，通常需更长建立时间或先后说明。三次切入不能代替每格读懂的时间。

### ４．１　说明框属于格内，不漂在总画面上

三个Caption在27／31／35起，3帧透明度、9帧尺度过冲落位，各有不同左右锚点与轻倾角；最后一个到44才完整。主体仍在动，说明框应被所在格的clip一起遮住；第三格吞屏时，其他格与其说明自然被覆盖。

第三格自己的框65→71退，避免在展开过程中一直挡住镜片。它不是所有说明框统一全局淡出，否则会失去“每格自带旁白”的漫画关系。

## ５．并列期要有内容活动，但不必所有层都动

**源码可见**：对焦环从31起30帧转26°，到61结束；光圈33起30帧收拢，到63结束，随后100→150回开一部分。第一格缓推3.5%，第二格3%，第三格在35→64增加0.06倍率。所谓“35—64定格”是分格布局保持，不是主体与说明全静止。

**制作推导**：有内容的活性可以表现部件工作，但“不能三格全静”不是所有教程的要求。若必须比较三个固定细节，静止并列反而有利；不应捏造物品动作只为避免静图。决定谁动、何时停，依据当前解释任务。

最大取景还叠末段1.5%慢推，最终倍率略超过2.45。位图素材应按实际最大显示尺度准备；SVG矢量可以重绘几何，但嵌入位图仍受源分辨率限制。

## ６．末格吞屏：边界与内部机位要分别控制

### ６．１　边界先回拉，再横扫

64→66，进度先到−0.03，第三格左边界向右缩一点；66→80用snappy推进到1，边界顶端由1410扫到−270，末端已在画外。第三格同时把中心1640滑到1360、尺度从约2.26到2.45。

相机只用max(0,expand)驱动，不跟随负向回拉；回拉只作用在格边，避免镜片先向错误方向抽动。缝线与内容横向速度分别求导再给SpeedBlur，说明“边界扫过”与“世界重新取景”是两条配合通道。

### ６．２　摘罩时仅几何连续，不保证全画面逐像素相同

80起进入独立海报分支，仍调用同一cam3At，主体机位在终点连续。但背景光中心由1640换到1360，左暗幕也在该分支出现，缝线和格内说明撤掉。因此不能把原卡“摘罩逐像素对齐”扩大为整个画面79／80完全一致。

**制作推导**：先核主体与mask覆盖，再看背景、阴影、纹理和注记是否在分支切换时突变。要真正无痕，就让所有共用视觉层以同一终点接续，必要的暗幕提前建立；不能只比较cam数值。

## ７．标题与完整阅读的真实终点

品牌80→90进入，两行标题82／88起、各20，108完整；副句96起、6词、间3、各14，125才完整。125—155共31张完整句展示，不是注释106之后全套海报早已到位。

100—150光圈仍在回开，80—156持续慢推，颗粒也可变化；这是一张有轻微活动的海报，不是全像素冻结。原卡“约50帧hold”可以对应主标题后段，但若副句是必读内容，要从125之后算。

**制作推导**：先分主句与副句职责。副句没有新信息时可以删，留更长的清晰主体；副句承担教学结论时必须读得完。不要为了凑完整海报加一行读不完的小字。

## ８．关键帧观察

实际查看0、19、20、24、28、35、44、61、64、66、70、79、80、108、125、155。

| 阶段 | 抽帧可见 | 审查重点 |
|---|---|---|
| 0、19 | 同一镜头的侧向整体 | 主体和材质是否先被认出 |
| 20—35 | 逐格出现、斜缝与短闪、说明开始 | 两条缝与三次入场关系，是否抢读 |
| 44、61 | 三个观察任务并列 | 整体／对焦环／光圈是否真有差异 |
| 64—79 | 末格边缘回拉后扫过，机位移动 | 途中说明、缝线、主体有无乱遮 |
| 80 | 摘罩为海报 | 主体连续与背景变化分别检查 |
| 108、125、155 | 主句、副句完整，镜片铺右 | 最后阅读和下一镜是否有内容 |

静帧不能认证4帧切点的全速可辨性或声音踩拍。当前没有音轨，不能把三声咔当成已试听；原卡电影风格类比也不等于本轮已研究电影原片。

## ９．原创演绎：用同一只杯子教清整体、握持与釉面

以下为**制作推导**，未实现。教程讲产品观察时应分别看形体、使用部位与材质。准备同一只真实陶杯的三种合法拍摄素材，不把不同杯子拼成一个对象。

### ９．１　先设计三格美术

暖灰背景`#d8d0c3`，杯为灰青釉，光源在左上；整体格展示杯把与杯身比例，近景格展示手握杯把的实际空间，微距格展示釉面高光与细纹。三个机位保留相同物品特征和光向，不给每格完全不同滤镜。

分缝可改为暖白纸芯＋墨绿细边，倾角收至约8°，说明用34px中文“整体”“握持”“釉面”，深墨字、低阴影，避免硬搬漫画重描边。最后让微距接管右侧，左侧只放一句“材质要在细节里看”，不盖住最关键反射区。

### ９．２　完整调度

| 阶段 | 画面 | 新认识 |
|---|---|---|
| 建立整体 | 杯子端正的侧前方视图，足够辨身份 | 先知道观察的是什么 |
| 第二格 | 握持视图进入，整体仍保留 | 使用部位提供另一项判断 |
| 第三格 | 同杯釉面微距进入 | 材质来自真实纹理与高光 |
| 并列读取 | 三格停住，只有必要的真实动作 | 三种观察任务并列成立 |
| 微距接管 | 格边扫开，内部图像到最终细节构图 | 焦点转向材质 |
| 下一镜 | 在真实条件下比较光源位置造成的反射差异 | 用单变量继续解释，不只看美图 |

若握持素材是视频，动作在手真正到位后再留阅读；微距不为保活捏造釉面流动。三格可以分别静止，只保留必要动作。节拍按旁白“整体／握持／材质”三次认识安排，不照用4帧一格。

### ９．３　素材与接管同源

每格先按实际目标范围裁图，再保持等比。假设釉面原图4000×3000，终态截取2000×1125映到1920×1080，倍率0.96；分格与全屏共用同一个裁切世界，接管只改变观看口和中心，不能在80帧突然换另一张更亮的微距。

不同观察机位可以来自不同拍摄，但应核同一对象身份、拍摄条件与所讲结论；要做单变量光源对照时，另保证曝光、角度和后期一致。当前素材尚未取得，不能把三格设计当实测材质结论。

声音每格一次轻提示即可，微距接管后让旁白讲纹理与反射；真实部件声只在实际动作存在时采用。原创素材、中文实排、连续运动、声音和最终成片均待验证。

## １０．失败诊断与合格判据

| 失败 | 修正 | 可观察的通过证据 |
|---|---|---|
| 三格只是三张无关图 | 先定同一对象与不同观察任务 | 能认回主体并指出每格新增内容 |
| 斜格切掉关键文字／部件 | 在实际clip内重排字框与机位 | 必读对象完整处于有效区域 |
| 缝线像普通工具分屏 | 统一纸芯、墨边与说明语言 | 分格风格完整但不抢主体 |
| 所谓定格其实说明还在弹 | 分开布局稳定与内容／注记完成 | 实际阅读起点清楚 |
| 摘罩主体不跳，背景突然变光 | 共用背景与暗幕终点 | 79—81主次和光向连续 |
| 微距只是低清图放大 | 准备足够清晰素材，按最大尺度核 | 最细结构在目标尺寸清楚 |
| 主标题完整却副句读不完 | 按最后必读词倒排 | 正常速度有完整读取窗口 |
| 为保活虚构部件工作 | 用真实动作或允许静止 | 视觉变化有内容与事实依据 |

Storyboard需交代同一主体身份、每格任务、最终海报、斜缝与说明归属、真实活动、边界／机位双通道和下一镜。静态、全速、声音与真实素材分别验收；本文不宣称原创或商用成片已通过。
