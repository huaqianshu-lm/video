# 段落节奏、揭示与声音关系

单镜头有动作，全片还要有理解过程。本页从 Shotcraft 的开场、收束、节奏和声音资料提炼方法；没有在本项目完成连续动态与声音验证。当前口播教程的叙事、真实音频、字幕及 Timeline 按项目规范执行，不采用上游宣传片的固定时长、品牌段位占比或制作流程。

## 用理解任务安排强弱

一段解释可以经过“认出对象 → 看见变化 → 读懂关系 → 核对结果”。运动密度随任务变化：定位可快，观察关键变化要清楚，阅读可静止，结论留出确认时间。全片既可逐步展开，也可先给结果再回看原因；不要求低能量开场或高能量结尾。

把一串镜头放在一起看时，检查每次变化带来了什么新理解。若只是给同一张卡换一种入场，可以合并或改成有内容依据的新状态。相同动作可因教学一致性重复；是否疲劳取决于职责、频率与信息变化，不照搬“同一手法只能一次”。

## 开头与收束的不同职责

| 职责 | 可设计的关键状态 | 适用边界 |
|---|---|---|
| 从局部认识整体 | 认出局部 → 扩展视野 → 全局定位 | 局部须有代表性，不能用一个好看的片段暗示全部能力 |
| 在集合中认识主角 | 整体 → 选定对象 → 检视 → 归属 | 选定理由明确，不以随机聚光代替内容重点 |
| 先立问题再揭示 | 稳定问题 → 必要线索 → 可辨认答案 → 核对 | 延迟揭晓服务理解，不能长期隐藏教程必须先知道的信息 |
| 交代范围与广度 | 先建立集合 → 只突出当前主张 → 必要时展开实例 | 环形陈列和内容墙表达范围，不承担逐项细读 |
| 汇总已解释关系 | 已出现对象回到可比较结构 → 总结 | 不引入未讲过的新组件，汇总不必做发布会合影 |
| 减少复杂度 | 临时工具与旁枝退出 → 结果保留 → 下一内容入口 | 退出不意味着数据被删除，收束与实际业务语义一致 |

当前系列片尾仍按项目规则提供有依据的下一集预告；上游品牌标识演绎不替代这个内容任务。

## 节奏有三种不同变量

**速度**是同一动作行程的快慢；**停留**给观众识别、阅读和判断的时间；**切换间隔**决定多个画面如何接力。三者可分别设计。匀速适合稳定自动滚动、机械扫描或连续传输，缓动适合起停和受力，不以“匀速廉价”概括所有动作。

跳切与突然停顿能强调重点，但要让观众识别这是有意的观看变化。冻结、步进帧与变速是不同方式，复杂重映射叠加会让语义和声音难以对应。当前真实口播不断时，画面也只能在这个时间依据内安排，不能为了制造停顿改写字幕或估算词级切点。

并列画面有两种用途：比较时保持共同尺度、稳定对应；短暂交代同时发生的多件事时，可以安排不同区域的重点接力。四个区域同时各演一整套，通常无法承担细节教学。需要解释某一区域时，就给它主要观看空间。

## 声音如何让动作更可信

学习依据为 [sound-design](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/sound-design.md) 与 [music-beat-sync](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/music-beat-sync.md) 的正文方法，不是音色试听结论。

- 先判断动作和材质：移动、摩擦、接触、锁定和余韵各有声音职责。装饰音不能代替所有动作拟音，也无需每个对象出现都响。
- 重要的是听觉攻击点与画面事件对应。素材文件头可能有空白或蓄力，素材自身峰值与最终输出链路的偏移要分别诊断；不能把上游的偏移常数当作本项目实测值。
- 少量连发可做轻重、远近或样本差异；密集到无法区分个体时，可以简化成整体声音，避免机械复读。两个不同文件名可能是同一个声音，不能只按名称判断差异。
- 口播教程先保障人声清楚、阅读安定。音乐可以辅助段落和少量重音，不把每个鼓点都变成全屏震动，也不强行移动真实 Timeline 去迎合曲子。
- 源文件峰值、混音增益、主观响度和最终输出是不同问题。先听当前画面里的实际效果，再结合适用检查定位；不照抄上游的音量区间、强鼓点曲风或统一片尾句式。

## 原创迁移练习：同一解释的展开与核对

资料提供一个操作及三个有依赖的变化时，可以先明确问题，再让变化依次发生，每次只引入理解所需对象；最后用同尺度的结果画面核对。变化处可用轻反馈，解释和阅读处收静；下一段从仍有作用的结果继续。与“每句一个新卡片”的版本比较，看观众是否更容易追踪对象和复述原因。该练习未实现。
