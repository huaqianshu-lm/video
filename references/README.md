# 视频设计参考

本目录是当前视频项目的设计参考层：从具体表达问题检索方法，再按当前内容设计画面。生产规则仍由 `CLAUDE.md` 路由到 `docs/`；参数默认值以 [质量规则 9.6](../docs/VIDEO-PRODUCTION-RULES.md) 为准。本目录中的案例参数是观察值，不是新的生产默认值。

分镜设计先读索引，选择相关资料；实现时重查对应的布局、运动及失败条件。无需每次读取全部文件。借鉴点和当前内容的调整写进既有设计说明／SQ evidence／note；实际结果写入既有观看证据，不新增资料字段或人工 Gate。

## 使用方法

参考条目围绕表达问题、关键状态、构图、运动、参数关系、适用条件和失败条件组织。案例中的尺寸和秒数用于解释效果，实际制作按当前内容、画幅、风格与真实 Timeline 调整。调校过程可使用 [调校配方骨架](../scaffolds/video-production/tutorial-motion-recipe.md) 留证；只有满足 [视觉模板库](../templates/README.md) 准入标准的可运行实现才进入模板目录。

## 后续案例的更新策略

学习新案例时先读本索引及相关主题文档，比较新增价值，再更新资料。默认按主题合并；不按案例数量扩充文档，也不要求每个案例都产出文件。

1. **先筛选内容**：提取可解释、可迁移的构图、层级、配色、运动或表达方法；仅有表面风格差异、不支持新结论的内容无需收录。没有新增价值时明确说明，不为了记录而扩写。
2. **优先更新现有段落**：已有主题能容纳的方法，补进对应章节。重复方法只在有必要时增加变体或适用条件，不复制整段；新的参数保留其案例条件，不升级为通用默认值。
3. **处理差异与冲突**：不同做法分别写明内容、画幅、文字量和风格条件。没有足够依据时保留适用限制；修正旧结论时说明设计理由，不因新案例出现就直接覆盖旧方法。
4. **按独立主题新增文档**：只有现有主题无法合理容纳、且值得单独检索的内容，才新增方法文档并更新本索引。仅增加一个章节即可表达时，优先加章节。
5. **选择性保留案例解析**：案例有完整、代表性的设计链，值得反复对照时，才在 `examples/` 单独留一份。普通案例将可取方法直接合并到对应段落。
6. **保持内容相关**：正文只保留视频设计和制作可直接使用的内容；沟通记录、研究过程、输入规格、指纹、本地路径和验证履历不放入参考文档。规则变更更新其权威来源，参考文档只引用。

更新完成后简要说明提取了什么、合并到哪里、为何需要新增文件，以及适用限制。检查重复内容、索引和链接，使目录更便于使用。此策略为资料维护约定，不增加每条视频的阶段、产物或 Gate，不要求制作时增加维护步骤。
