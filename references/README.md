# 视频设计参考

本目录是当前视频项目的设计参考层：从具体表达问题检索方法，再按当前内容设计画面。生产规则仍由 `CLAUDE.md` 路由到 `docs/`；参数默认值以 [质量规则 8.6](../docs/VIDEO-PRODUCTION-RULES.md) 为准。本目录中的案例参数注明原文给定或观察依据，不是新的生产默认值。

## 目录分工

根目录主题文档负责表达选型与跨技法比较；`techniques/<设计问题>/` 保留独立技法的完整构图、美术、动作、参数关系、原创演绎和失败修正；`examples/` 保留完整应用及外部案例。`direction/` 保留跨镜头美术、段落、音乐、声音与实际画面评审方法。已有案例与技法相互引用，共用同一份详细解析，不为增加文件数重复写正文。

学习新案例时先读本索引及相关主题文档，比较新增价值，再更新资料。主题用于检索与比较，案例保留足以指导具体画面制作的设计细节；合并不能丢掉独立的动作机制、视觉处理、参数关系和成立条件。不预设最终文档数量，也不要求每个来源机械对应一个文件。

1. **先筛选内容**：提取可解释、可迁移的构图、层级、配色、运动或表达方法；仅有表面风格差异、不支持新结论的内容无需收录。没有新增价值时明确说明，不为了记录而扩写。
2. **保留方法与具体机制**：通用判断进入对应主题；有独立价值的构图、动作阶段、曲线、坐标、材质和交接机制保留完整解释，可在案例中展开。不能把这些压成一句结论或来源表中的一格。重复方法可用链接复用，变体保留其差异；参数注明案例条件，不升级为通用默认值。
3. **处理差异与冲突**：不同做法分别写明内容、画幅、文字量和风格条件。没有足够依据时保留适用限制；修正旧结论时说明设计理由，不因新案例出现就直接覆盖旧方法。
4. **按检索和使用需要组织文档**：跨案例的共性进入主题；具体镜头的连续设计链进入 `examples/`，并从主题链接过去。不以减少文件数量为目标，也不把长篇镜头细节全部塞进通用主题。
5. **案例解析能指导制作**：保留关键状态、构图与阅读顺序、动作触发与重叠、运动曲线及锚点、空间／材质、实现关系、改造条件和失败修正。依据原资料的实际丰富程度展开；没有证据的维度明确留缺口，不为填栏目编造。原文给定、画面观察与原创推导要可区分。
6. **保持内容相关**：正文只保留视频设计和制作可直接使用的内容；沟通记录、研究过程、输入规格、指纹、本地路径和验证履历不放入参考文档。规则变更更新其权威来源，参考文档只引用。

更新完成后简要说明提取了什么、合并到哪里、为何需要新增文件，以及适用限制。检查重复内容、索引和链接，使目录更便于使用。此策略为资料维护约定，不增加每条视频的阶段、产物或 Gate，不要求制作时增加维护步骤。
