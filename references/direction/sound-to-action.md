# 声音怎样解释动作、材质与重点

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/sound-design.md)。以下是原文研究与原创制作推导；不把上游宣传片流程、数值或历史验收结论迁为本项目规范。未试听声音、运行上游或验证原创成片。当前参数及生产边界仍查项目 docs。

## 1. 让耳朵听懂画面发生了什么

声音至少有三项职责：提示事件、建立材质、组织注意。不是每个入场配whoosh、每次落位配impact就叫声音设计。口播教程首先要听清知识，BGM与SFX围绕真实操作与阅读窗口安排。原文产品广告偏强鼓点的音色结论属于片种判断，不是所有教程都要tech-house，也不把无BGM版迁成新增交付要求。

原文把声音集中为时间线事件表，使镜头改动后可追踪。可学习“动作语义、事件锚、素材、裁入、时长、增益”的明确对应，不要求新增某种生成器或复制上游音库。具体TTS、音频路径与渲染仍按本项目docs。

## 2. 根据介质与叙事选音，而非目录名

真实开关可以有机械click，纸页可以有摩擦与轻落，玻璃有脆短接触，金属可以有更密实的敲击；这些是音色方向，不是物理对象必须拟真。连续暗场光斑可以无声，慢阅读通常不需要每次色变都响。

| 动作 | 找什么声音特征 | 避免什么 |
|---|---|---|
| 快速移动 | 短风切、方向感与速度匹配 | 缓慢平移却配巨大喷气声 |
| 接触落位 | 攻击清楚、尾音与重量匹配 | 每张纸卡都电影爆炸 |
| 输入 | 与字符密度相称的键盘或轻书写 | 听写却配连续实体敲键，误导输入方式 |
| 纸面变换 | 轻擦、翻页、压印 | 用电子bleep硬装科技感 |
| 光效 | 可无声，必要时极轻余韵 | 每个高光都叮，盖住口播 |
| 条件确认 | 一次能辨的短反馈 | 未成功也配“success”，声音替事实下结论 |

原文ui目录同时含真实开关与合成tone/bleep，说明类别只是检索入口，不能整目录放行或禁用。data/scifi同样需在成片里试听。文件名、标称用途和曲目好听都不能代替放在实际口播下的听感。

## 3. 事件表如何保留因果

目标写“卡接触槽位”或“按钮松开并出现结果”，不要只写f220。使用shot起点+局部事件偏移，与真实Timeline同源，前镜变长时后续可跟随；镜头内部重新编排时仍须重算偏移，不能误称相对帧能免除所有重对。

长声音区分三类：持续底噪按段落铺、动作音按有效动作段裁、带混响的冲击允许自然余尾。原文把部分长样本统一截断的经验不能机械扩成“音频必须和动作等长”；突然硬切混响可能比留尾更突兀。尾音跨镜时要有意保留，并检查是否掩后镜首句。

连续对象不必逐个配声。前几次可辨落点配轻反馈，密到不能分辨时让位给一条连续风切，或干脆安静。双样本交替的前提是实际不同声音，原文发现多组不同文件名却字节相同，不能拿重命名当变奏。音量渐弱是层级，不等于声音越来越远的真实空间模拟。

## 4. 音量数值不是实际响度

volume是线性增益，振幅乘g相当于20log10(g)dB。g=.34约−9.37dB，这只说明对该音源的增益，不说明它一定给人声留足空间。源文件本来−24dB，给1仍轻；多个近峰值素材叠加，即使各自系数小于1也可能削波。

原文0.2–0.6和BGM .34是模板设置，不迁为默认。先听素材的攻击、频段和底噪，再在实际人声下决定，必要时换更干净素材或合理处理。抬增益会连底噪一起抬；短音效用长节目响度归一目标也可能不合适。峰值、感知响度和遮蔽不同，不能只看max_volume近0就说混音好。

播放环境可能存在传统audio与Web Audio的增益差异，源文关于>1支持与预览钳制是特定实现考察；不保证所有版本与环境相同。最终判断以实际输出试听和测量为准，不通过某个控件值推断成片声音。

## 5. 三个时间坐标和延迟测量

声音的文件起点、内部攻击点、最终输出位置不同。设目标动作在V，音源攻击在Q，裁入C，输出延迟D，素材放置S=V−(Q−C)−D，单位统一为秒或帧，最后再取整。源攻击点可能不是最大峰，需选与动作语义匹配的听觉锚。

输出偏移要用多个探针与实际编码产物核对。源文约1.28f、旧4f只是作者测例，不能预设所有AAC必晚固定帧数。若探针残差随时间增大，查变速或采样时间，不只改全局D；若只有一种素材晚，优先查Q与裁入。音乐源网格保持真值，输出补偿单独记账，避免反复修改源BPM掩盖封装问题。

片头若补偿后S<0，简单clamp0会留下残差，需调整设计或可用预卷，不假称全部对齐。声音时窗整体前移不自动意味着要加长duration；要看实际需保留的攻击与尾音范围。

## 6. 原创制作推导：一次纸面资料归档

目标是“把两份真实资料放进同一主题，同时保留来源”。画面先做最终结构：主资料与补充资料分层，来源标签可读，落位后是有关系的归档结果，不是两张空白卡。

主资料从列表离面时可配很轻纸摩擦，飞行不必大whoosh；接触归档槽时一声短落纸，声音攻击对同一接触事件。第二资料运动更简洁、反馈更轻，避免两次同样响。若资料只是屏幕数字对象，过度纸音会误导介质，可改干净机械短反馈或静音。

归档结束给真实内容阅读，此段只剩口播或很弱环境底。下一镜进入一份原文，声音不再重复飞行，保留一句回查说明。若BGM本身已有强拍，接触SFX只加材质，不与鼓点叠成新爆音。结果状态没有真实完成前不配庆祝音。

## 7. 来源与验收边界

原文列149个SFX、16目录、14个基础文件，其中又区分实际引用、死资产、已删除但模板仍存副本和来源待考。学习的是可追溯与实际接线核对，不把“库里有”当“已用过”或“已获可商用授权”。当前未下载、试听或复核这些音频许可，源文历史归因不构成本项目授权凭证。

通过需实际正常速度合听人声、音乐与SFX，确认关键字清楚、材质一致、事件对齐、尾音自然、无失真；必要时用多个探针测真实输出。文档与波形检查不能代替耳朵。本篇只有声音设计方法研究，没有完成原创混音认证。
