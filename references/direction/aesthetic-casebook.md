# 从审美判例到可执行的画面设计

来源：[固定原卡](https://github.com/Vincentwei1021/video-shotcraft/blob/5a2e98daade313c4f376120f38427eb19a108e8c/references/aesthetic-rules.md)。以下是原文研究与原创制作推导；不把上游宣传片流程、数值或历史验收结论迁为本项目规范。未试听声音、运行上游或验证原创成片。当前参数及生产边界仍查项目 docs。

## 1. 先确定观众看什么，再决定画面怎么动

原文把阅读、群组节奏、真实UI、清晰度、光效、声音和逐镜检查放在同一套返修判例中。可复用的是“为什么这个画面失败、怎样改”，不是把宣传片的次数和秒数变成本项目默认。本项目量化参数仍查[质量规则8.6](../../docs/VIDEO-PRODUCTION-RULES.md)，声音与实际观看另查当前规范。

每个镜头先写一句可观察认识，例如“裁切改变边界，原图仍保留”。接着选主体：真实照片、裁切边界、图层缩略图。它们共同在画面中证明这句话，标题只是定位，不能再用三张解释卡复述一遍旁白。

## 2. 主次不是把其他东西全部删掉

主角有最大的有意义面积、最清楚边缘或最明确变化；次级信息仍提供上下文。六块图表可以同时在场，但当前需要读的那块获得主对比，其他块保持足够身份，不必全糊成灰。若旁白同时讲三项且画面也三处同时动，应先改信息顺序，不只调缓动。

先做三个静态取景：完整环境、关系最复杂的中段、最终证据。暂停时问：最先看哪里，第二眼看哪里，什么内容应暂时不读？如果只能回答“看大标题”，结果画面却没有真实对象，就还没完成视觉导演设计。

| 画面部分 | 具体设计动作 | 失败信号 |
|---|---|---|
| 构图 | 让标题、主体边缘或证据位置共享可见对齐轴 | 每块孤立居中，空间位置不表达关系 |
| 负空间 | 给即将迁移的对象或注记留通道 | 空白只靠粒子填满，动作中段无处落 |
| 字形 | 按实际中文轮廓、笔画密度和字体可用性选择字重 | 英文负字距套中文，粗笔画连成黑块 |
| 明暗 | 一个主光方向，前后层以对比与接触关系区分 | 所有边同时发白，暗部只剩纯黑 |
| 材质 | 纸、玻璃、金属分别使用对应纹理与光响应 | 每张卡都同一大阴影、同一斜扫光 |
| 信息密度 | 保留真实布局的不同尺度与局部细节 | 只剩几个空矩形，却声称复刻真实产品 |

## 3. 字要按输出后的真实形态检查

源码fontSize不等于屏幕上实际字高。祖先scale、透视角、布局zoom和相机都会改变投影；font×scale×cos只适合简单倾斜的粗估，实际透视不同点缩放并不相同。应看最终输出中真正需要读的字、单位和符号，而非把界面所有微字都强行扩大。

原例给出某些字幕、辅助字的像素门槛，是源片语境；这里不建立第二套数值默认。真正要读的正文应有清楚字腔、足够行距和完整读窗；环境UI的小字可以提供密度，但不可同时承担关键教学结论。发现不清楚，优先改变取景和信息容量，不先加锐化。

真实页面要保留它的网格、字体、当前状态与交互依据。截图像素须覆盖最终放大需求；2×/4×是常见来源实例，不是倍数越高越好。CSS zoom可能改变栅格化路径，却不能恢复低清位图里不存在的细节。把纹理、布局重绘、合成缩放与景深分别排查，避免把糊字错误归因于“镜头不够锐”。

## 4. 材质与空间要能解释因果

纸面：暖或冷哑光底、轻微固定纤维、薄边与接触影，文字优先；不默认加镜面高光。玻璃：背后真的有景物或色光，模糊与透色随同一空间关系成立，受光侧边缘有方向。金属：面明暗、侧厚、微纹理与角度响应一起构成，不把一条白色渐变当全部材质。

空间层必须说明前后、包含、组成或流程关系。原位插槽、底板、投影和遮挡是观众判断“同一部件升起”的证据。相机可以绕物体，但读细节时应回正视；把所有信息页统一斜45°会牺牲阅读，而不会自动有摄影感。实体展示适合有空间职责的镜头，教程并非每段都必须出现桌面、侧棱和环绕。

## 5. 节奏、重复与光效的适用范围

原文强调组内非匀速、完整动作弧和先留阅读段，目的是避免所有元素机械滑入。匀速在自动滚屏、扫描、时间刻度等场景有明确意义，不能一律判低级。过冲也只在有重量、接触或弹性隐喻时使用，数据值本身不应被弹簧过冲伪造。

“每技法只当一次主角”是防同质化的提醒，教程中同一操作语法复现、前后受控对照可能必要。判断重复是否增加理解，而非仅凭动作名字相同删除。原文宣传片结尾全家福和高能量峰值不适用于所有教程；结束可以是安静可读的实际结果和适用条件。

单次扫光需要主角、介质动机、轮廓裁切和后续阅读。批量卡一起glint使所有元素同等强调，反而没有重点。全画面闪光、负片和震动属于特殊重音，不能用来掩饰平庸版面。具体频次依当前设计与项目规则，不能复制源例上限建立新制度。

## 6. 原创制作推导：一段裁切教学的完整美术

内容目标是“改变画面边界，不改原始图像”。先选真实照片，主体靠近一边且地平线清楚。结果帧以照片为大色块，裁切框是唯一亮线，图层栏在侧面保留完整缩略图；其他工具降对比，字幕区不与裁切手柄争位。

建立镜头先给整个编辑器和照片身份，随后取景靠近裁切边缘。拖手柄时背景与工具不一起表演；只有边界、保留区与真实尺寸变化。中段既保护主角不被裁出，也保留被排除部分的弱影，让观众看出裁掉哪里。落定后松开手柄，读出真实尺寸；图层缩略图不变，这是非破坏性的证据。

下一镜点恢复边界，原图内容回到视口，保持同一照片与光向。若需展示原图／裁切蒙版／画布关系，另用三层展开并回正视，不把俯冲、爆炸、扫描、霓虹全部塞入同镜。声音只给明确拖动结束或确认，口播始终清楚。

## 7. 把“普通”诊断成具体问题

静帧像PPT时，先看主体是否只是文字卡、空间是否只为均匀排版、图像是否真正参与解释；改真实内容与关系布局，不加更多入场。静帧漂亮但动态难看时，查中段焦点竞争、路径碰撞、视点跳跃和读窗不足。技术无错但美术不统一时，查字体角色、光向、圆角、材质与强调色是否逐镜换了一套。

验收证据需分别回答：静态构图成立吗，正常速度能跟住吗，真实内容能读吗，声音有无盖过口播，下一镜是否接续认识。仅有链接或参数表不算视觉验证；仅有关键帧不算完整观看。本篇是方法研究，没有验证某部原创成片达到商用品质。
