# 多源汇聚

## 表达与关键状态

用于真实合并关系：左侧来源、右侧终点建立 → 曲线接通 → 来源沿各自路径缩小汇入 → 结果反馈 → 旧路径擦除 → 结果居中并静置。来源与结果身份由位置、运动路径及强调色共同说明。

## 案例观察值

以下为 960×540 逻辑画布中的条件，不是生产默认值。

| 条件 | 观察值与作用 |
|---|---|
| 四路来源 | x=200，y=170／230／310／390 |
| 汇聚点 | x=700，y=290；结果用蓝色、输入和路径用中性色 |
| 路径建立 | 0.50 秒起，每路错峰 0.15 秒，各持续 0.50 秒 |
| 来源汇入 | 1.50～3.00 秒，沿曲线弧长取点 |
| 来源缩小 | 前 75％：1→0.34，后 25％：0.34→0 |
| 结果反馈 | 2.85 秒起，最大 scale 约 1.12 |
| 路径清理 | 3.25～3.65 秒，来源消失后再清理 |
| 完成态 | 3.80～4.40 秒终点移至 x=480；4.40～5.80 秒静置 |

## 迁移和失败条件

输入需独立保留时，不能画成被吞并。来源数量增加应重排路径与标签，而非挤入同一布局；胶囊只适合短名称。路线上文字要避开当前阅读区。汇聚后展开成新结构是新的设计，须重新判断其意义，不能只接入一个新效果而省略表达设计。
