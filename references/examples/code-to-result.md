# 代码走读与结果的边界

## 表达与关键状态

代码走读的变化链：代码窗全景 → 推近当前行 → 高亮与相机同步逐行 → 拉回恢复完整结构。走读用于引导阅读；代码与结果的因果演示需要额外展示结果变化。需要「代码到结果」时，结果预览应根据当前资料单独设计。

## 案例观察值

以下为 960×540 逻辑画布中的条件，不是生产默认值。

| 条件 | 观察值与作用 |
|---|---|
| 代码窗 | 600×440，暖褐至墨绿背景、深色玻璃、细描边与阴影 |
| 入场 | 0.55 秒，y：16→0，scale：0.965→1 |
| 推近 | 1.40 秒起，0.55 秒内 zoom：1→1.68 |
| 阅读／换行 | 停留 0.32 秒、换行 0.26 秒，阅读与移动分开 |
| 上下文 | 非当前行最低 opacity=0.30，降低竞争而保留结构 |
| 字号／行高 | 17／26px，空行 14px；随画幅调整 |
| 拉回 | 约 6.89 秒起，0.85 秒内恢复全景 |

## 迁移和失败条件

演示的 0.32 秒停留不代表教程阅读足够。长代码先选取关键片段；保持缩进，检查最长行和首末行在相机移动时的可读区域。背景、玻璃和描边需整体搭配。若增加结果，须有当前资料支持其变化，不能沿用原示例业务文字。
