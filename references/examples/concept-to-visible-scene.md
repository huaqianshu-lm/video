# 从概念解释到可见场景

## 全片各类画面及可取之处

时间为录屏内的近似区间，边界不用于制作时长。

| 区间 | 实际观察 | 设计作用与可迁移方法 |
|---|---|---|
| 0～6.3秒 | 主标题与两项问题；第二项随后出现 | 先交代一个关注点，再增加另一个；问题成为可定位的视觉入口 |
| 6.3～8.3秒 | 三个同类图标及短标签依次出现 | 重复轮廓、间距和进场方向建立组关系；箭头在此表示顺序，不证明因果 |
| 8.3～12秒 | 分散字符归位为章节标题，随后稳定 | 用低密度画面重置注意力；短标题可以有进场表现，阅读期保持完整 |
| 12～20秒 | 组名先出现，三个不同形态的具象对象依次建立，再补解释标签 | 名词获得可辨认的轮廓和材质；标签解释已出现对象，不把所有信息同时抛出 |
| 20～31.5秒 | 旧组保持位置，右侧较大的新对象出现，随后保持比较构图 | 预留空间让新增内容进入；大小、形态和明暗加强主次，但面积不是数据比例 |
| 31.5～33.2秒 | 第二次短章节标题归位、稳定 | 重复章节语言，提供段落边界；没有要求每个画面复用这个转场 |
| 33.2～37.3秒 | 三列等高表格依次建立，同指标同行，名称与数值位置固定 | 比较依靠对齐而非大量颜色；总体密集但整齐，细节阅读仍要考虑时间 |
| 37.3～46.4秒 | 表格退出，低亮资料图上出现较明亮的术语卡 | 从总览切入解释，前后层明度建立焦点；背景资料与术语的语义关系未确认，不作为来源证据 |
| 46.4～50.7秒 | 标题上方定位、左侧条件卡、右侧角色与倾斜操作区域 | 抽象概念被拆成执行者、环境和已知条件；操作区获得主体面积，条件区保持简短 |
| 50.7～54.7秒 | 条件卡转为问号及未知状态，主体场景保留 | 改变理解任务的关键条件，保留已建立空间，减少重新寻找对象的成本 |
| 54.7～57.067秒 | 出现尝试卡及总结流程，操作区域局部亮点变化 | 从条件过渡到行为，视觉语言一致；片段未展示明确完整的操作—反馈—成功链，不能当成闭环范例 |

## 为什么画面能形成整体

**造型参与解释。** 具象对象有轮廓、纹理、体积与不同尺度；交互环境具有角色、操作表面和可辨认的元素。好看的部分包含对象设计，无法用统一矩形加标题代替。迁移时应为当前概念寻找自己的造型理由。

开场容器有切角与轻边缘，两项内部图形分别呼应对象与配置；交互区域的格面、操作块和角色共享透视，块面高光与暗侧提供厚度。这些细节使主体具有具体身份。候选设计方法是先保证形状、材质和受光关系一致，再增加少量装饰；切角、发光和网格本身不成为所有画面的要求。

**视觉一致，表达形式变化。** 暗背景、青绿色强调、白色主文字、轻边缘在多种构图中复用；标题、比较、表格和场景各自承担不同阅读任务。需要学习颜色与材质的角色一致性，不需要固定所有镜头的容器形式。

**新信息有先后，稳定状态有阅读空间。** 同类对象、解释标签和条件变化按时序建立。长停留中可以观察到背景与主体细节变化，但主要文字和比较位置保持稳定。阅读停留和细节运动的强度应在正常速度观看时调整。

**空间关系帮助记忆。** 比较时旧对象没有因新对象出现而全部重排；场景解释时条件变化没有重新建一遍环境。已经理解的对象继续承担上下文，新增信息获得明确区域。

## 按自己的内容使用

### 对象比较段的画面与动画

约14～15秒，三个具象对象依次显露；约16～18秒，下方解释标签逐项补齐。约20.5～21.5秒，右侧较大的网络对象进入已预留的区域，轮廓先显露，内部点线从下部逐渐建立并伴随放大。旧组位置保留，新增对象通过尺寸、细节密度和青绿色亮边获得焦点；大小用于画面主次，不据此推导能力或数值比例。

比较构图稳定后，名称留在固定位置，表面纹理与网络点线继续变化。蓝绿色、灰色对象的亮面和暗面提供体积；橙色对象的纹理、细外沿和柔光提供自发光身份；网络对象的曲面疏密、点线亮度差、轮廓光和弱外晕共同建立科技质感。运动应延续各自材质身份，不把所有对象都做成同样的旋转发光圆。

制作可先检查无文字时对象是否仍有身份、无外晕时是否仍有结构、静止时是否仍有体积，再让表面结构发生连续变化。信息建立、主体运动、解释标签分别安排；阅读时保持名称及比较位置稳定。对应方法见[配色、材质与空间](../color-and-depth.md)和[运动、节奏与转场](../motion-and-transitions.md)。

### 迁移步骤

1. 先写清要理解的是身份、比较、条件还是动作，并列出能看见的对象与差异。
2. 为对象选择有内容理由的形状和材质；再安排主次、留白与字幕区域。
3. 保留全片颜色角色和文字层级的一致，根据问题选择构图，不套原片坐标或容器。
4. 安排先建立什么、改变什么、何时稳定。因果说明必须有可见反馈和依据，不能靠流程文字补足。
5. 真实制作继续使用当前资料、冻结分镜及真实Timeline；画面效果由实际观看和适用人工Gate判断。

例：如果当前内容是说明文件权限，可考虑具有来源依据的文件对象、操作主体、权限边界和允许／拒绝反馈，而非继承原片的天体或角色。具体造型和动作应按当前内容设计。

## 制作时注意

- 背景资料应与当前讲解有关，避免用能读出无关内容的资料图充当装饰。
- 比较对象的大小要说明是视觉主次还是数据比例，箭头要明确表示顺序、连接还是因果。
- 展示交互过程时，需要可辨认的动作和反馈；局部亮点或流程文字不能代替完整状态变化。
