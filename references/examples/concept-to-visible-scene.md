# 从概念解释到可见场景

本页包含两种依据：前部保留既有录屏的画面观察，后部给出原创设计与制作推导。既有录屏原始媒体及出处尚未重新定位，下面时间只作旧记录索引，不能当作当前已重新抽帧核实或可执行 Timeline；没有补造作者、链接、实现技术与声音。可回查的外部造型／材质依据见 [官方设计图研究](external-motion-design.md)，其中已查看的风格图也不等于连续成片。

本页解决的是：怎样把一个概念变成具有身份、条件与行为的场景。图标或术语可以帮助定位，但实际解释应发生在对象、边界、关系或结果上。以下原创应用尚未实现，不作为模板或成片质量基线。

## 全片各类画面及可取之处

时间为录屏内的近似区间，边界不用于制作时长。

| 区间 | 实际观察 | 设计作用与可迁移方法 |
|---|---|---|
| 0～6.3秒 | 主标题与两项问题；第二项随后出现 | 先交代一个关注点，再增加另一个；问题成为可定位的视觉入口 |
| 6.3～8.3秒 | 三个同类图标及短标签依次出现 | 重复轮廓、间距和进场方向建立组关系；箭头在此表示顺序，不证明因果 |
| 8.3～12秒 | 分散字符归位为章节标题，随后稳定 | 用低密度画面重置注意力；短标题可以有进场表现，阅读期保持完整 |
| 12～20秒 | 组名先出现，三个不同形态的具象对象依次建立，再补解释标签 | 名词获得可辨认的轮廓和材质；标签解释已出现对象，不把所有信息同时抛出 |
| 20～31.5秒 | 旧组保持位置，右侧较大的新对象出现，随后保持比较构图 | 预留空间让新增内容进入；大小、形态和明暗加强主次，但面积不是数据比例 |
| 31.5～33.2秒 | 第二次短章节标题归位、稳定 | 重复章节语言，提供段落边界；没有要求每个画面复用这个转场 |
| 33.2～37.3秒 | 三列等高表格依次建立，同指标同行，名称与数值位置固定 | 比较依靠对齐而非大量颜色；总体密集但整齐，细节阅读仍要考虑时间 |
| 37.3～46.4秒 | 表格退出，低亮资料图上出现较明亮的术语卡 | 从总览切入解释，前后层明度建立焦点；背景资料与术语的语义关系未确认，不作为来源证据 |
| 46.4～50.7秒 | 标题上方定位、左侧条件卡、右侧角色与倾斜操作区域 | 抽象概念被拆成执行者、环境和已知条件；操作区获得主体面积，条件区保持简短 |
| 50.7～54.7秒 | 条件卡转为问号及未知状态，主体场景保留 | 改变理解任务的关键条件，保留已建立空间，减少重新寻找对象的成本 |
| 54.7～57.067秒 | 出现尝试卡及总结流程，操作区域局部亮点变化 | 从条件过渡到行为，视觉语言一致；片段未展示明确完整的操作—反馈—成功链，不能当成闭环范例 |

## 为什么画面能形成整体

**造型参与解释。** 具象对象有轮廓、纹理、体积与不同尺度；交互环境具有角色、操作表面和可辨认的元素。好看的部分包含对象设计，无法用统一矩形加标题代替。迁移时应为当前概念寻找自己的造型理由。

开场容器有切角与轻边缘，两项内部图形分别呼应对象与配置；交互区域的格面、操作块和角色共享透视，块面高光与暗侧提供厚度。这些细节使主体具有具体身份。候选设计方法是先保证形状、材质和受光关系一致，再增加少量装饰；切角、发光和网格本身不成为所有画面的要求。

**视觉一致，表达形式变化。** 暗背景、青绿色强调、白色主文字、轻边缘在多种构图中复用；标题、比较、表格和场景各自承担不同阅读任务。需要学习颜色与材质的角色一致性，不需要固定所有镜头的容器形式。

**新信息有先后，稳定状态有阅读空间。** 同类对象、解释标签和条件变化按时序建立。长停留中可以观察到背景与主体细节变化，但主要文字和比较位置保持稳定。阅读停留和细节运动的强度应在正常速度观看时调整。

**空间关系帮助记忆。** 比较时旧对象没有因新对象出现而全部重排；场景解释时条件变化没有重新建一遍环境。已经理解的对象继续承担上下文，新增信息获得明确区域。

## 按自己的内容使用

### 对象比较段的画面与动画

约14～15秒，三个具象对象依次显露；约16～18秒，下方解释标签逐项补齐。约20.5～21.5秒，右侧较大的网络对象进入已预留的区域，轮廓先显露，内部点线从下部逐渐建立并伴随放大。旧组位置保留，新增对象通过尺寸、细节密度和青绿色亮边获得焦点；大小用于画面主次，不据此推导能力或数值比例。

比较构图稳定后，名称留在固定位置，表面纹理与网络点线继续变化。蓝绿色、灰色对象的亮面和暗面提供体积；橙色对象的纹理、细外沿和柔光提供自发光身份；网络对象的曲面疏密、点线亮度差、轮廓光和弱外晕共同建立科技质感。运动应延续各自材质身份，不把所有对象都做成同样的旋转发光圆。

制作可先检查无文字时对象是否仍有身份、无外晕时是否仍有结构、静止时是否仍有体积，再让表面结构发生连续变化。信息建立、主体运动、解释标签分别安排；阅读时保持名称及比较位置稳定。对应方法见[配色、材质与空间](../color-and-depth.md)和[运动、节奏与转场](../motion-and-transitions.md)。

### 迁移步骤

1. 先写清要理解的是身份、比较、条件还是动作，并列出能看见的对象与差异。
2. 为对象选择有内容理由的形状和材质；再安排主次、留白与字幕区域。
3. 保留全片颜色角色和文字层级的一致，根据问题选择构图，不套原片坐标或容器。
4. 安排先建立什么、改变什么、何时稳定。因果说明必须有可见反馈和依据，不能靠流程文字补足。
5. 真实制作继续使用当前资料、冻结分镜及真实Timeline；画面效果由实际观看和适用人工Gate判断。

例：如果当前内容是说明文件权限，可考虑具有来源依据的文件对象、操作主体、权限边界和允许／拒绝反馈，而非继承原片的天体或角色。具体造型和动作应按当前内容设计。

## 原创镜头设计：同一操作在不同条件下怎样变化

### １．先定义认识变化，不先决定画几个卡片

假设当前教程要解释：同一个操作能否继续，取决于资料中明确的一项条件。开始时观众只看到操作名称，结束时应能指出操作主体、作用对象、当前条件和实际结果之间的关系。条件变化不意味着换一套新场景，结果也不能仅由红绿徽章表达。

选具体载体前先核实资料：主体是用户、工具还是一个任务表示？对象是文件、界面区域还是一个输入？条件来自配置、选择还是客观状态？结果是未发生、正在发生还是有证据的完成？这几个身份混在一个“处理器”圆里，后面再精细的动效也讲不清。

### ２．从用途设计轮廓与空间

**原创布局**：操作对象占主要舞台，发起动作的主体在其一侧，条件与实际作用边界就近可见；文字说明只占必要的阅读区。底部先留字幕，操作路径经过中间的清楚通道。未知条件或解释性注记可以出现在同一条件区，不能为了加问号遮掉对象本身。

文件对象保留页边与内容区，工作区保留可操作的区域边界，任务表示保留名称或唯一标记。它们有不同轮廓与内部结构，不需要每个概念都塞进相同圆角卡片。角色图标只在发起者身份对解释有用时使用，不能给任何软件都画一张脸来暗示意图。

**造型与材质**：主体可以采用简洁哑光色面，边界有稳定线宽，支撑面用较低对比环境承托。需要体积时，正面、侧面和接触影遵守同一光向；需要实际界面时保持控件身份和原来的可操作位置。发光仅在表达确有发光性质或临时定位时使用，不把所有对象包成荧光壳。

条件文字与实际边界共享标记，但位置不同：条件负责阅读，边界负责看出作用在哪里。长中文保持完整短句，避免固定药丸；否定与限定条件不能删。标题只是本段的问题定位，不能比当前操作对象与关键反馈更抢眼。

### ３．先画结果，再反推动作通道

完成态需要保留本次操作对象、当前条件和有依据的结果。若结果是操作未发生，对象应仍保持操作前状态；不能让画面已经改完，再盖“未执行”标签。若结果是允许继续，只能表示条件满足，不自动跳到任务成功。具体软件真实完成时再给相应证据。

| 状态 | 主体与环境的变化 | 当前焦点 | 下一状态成立的依据 |
|---|---|---|---|
| 建立任务 | 对象、操作入口和发起者位置清楚，条件区暂保持中性 | 先知道要做什么 | 同一操作具有可追踪身份 |
| 建立条件 | 一项资料支持的条件被呈现，边界同步定位 | 阅读条件与其作用区域 | 不同时改变对象和操作目标 |
| 产生尝试 | 有依据的输入或操作抵达入口，其他对象保持稳定 | 看清是谁发起、作用哪里 | 反馈不能早于尝试 |
| 显示结果 | 对象真的改变、保持原态或停在中间，按资料呈现 | 判断发生了什么 | 状态文字与对象变化一致 |
| 解释原因 | 当前条件和相关对象局部共同获得可读空间 | 结果为什么如此 | 先读完原因，再切换假设 |
| 切换条件 | 结束前一次结果，回到可比较的初态或明确的新情境 | 只比较条件变化 | 不把两次独立假设混作同一次连续执行 |
| 再核对 | 保持同类操作和尺度，再展示有依据的结果 | 新旧差异在哪里 | 变化来自条件而非换对象或换任务 |
| 接下一镜 | 当前结果或相关配置接管，非必要角色和引导退出 | 从结果进入后续解释 | 不为下一节重新建一遍无关卡片 |

假设切换可以清楚重置，不必保留所有物体“永远连续”。要同时比较两条件，就改成同尺度分屏或双轨，两个结果都保持定位；不要一边暗示同一请求还在运行，一边切到另一个独立前提。

### ４．中段构图和动作性格怎样具体检查

取景先覆盖最大主体、条件文字和操作反馈，再检查操作路径中段。主体经过边界时，外框、阴影、引线与标签都可能碰撞，不只看中心点。若目标本来就在阅读区，保持固定机位可以更清楚；只有要揭示新的位置或细节才移动相机。

受限反馈优先局部制动、入口状态或有内容的提示，不让全画面抖动。刚性对象不做大幅软体挤压；纸面或角色的轻次级运动可以有性格，但读取的文字和精确边界保持稳定。临时重点、光线或问号在解释完成后退出，结果获得安静阅读。

实现时由同一当前条件与操作状态派生对象、反馈和说明。教学示意可自行安排可读节奏，但不能把渲染帧数等同真实业务进度；真实素材用实际资料与 Timeline。跨帧求值要能在任意帧重建状态，不依赖已经看过前一帧才有正确结果。

### ５．另一种构图：比较造型或表示时，别强套操作场景

如果内容重点是“几个对象的结构哪里不同”，就不需要发起者、入口与尝试。先给共同尺度和同等视觉尊重，再只突出相关差异。轮廓有共同基础时，内部结构与材质可以不同；同一球形外壳只换颜色，通常不足以表达结构差异。

例如已定义单位的集合与关系网络可以共享元素身份：集合图重在成员与边界，网络图重在真实连接；两种表示中的同一单位用一致标记。网络线的数量和连接规则要有依据，不能用随机发光线暗示复杂能力。需要显示曲面时，点与线遵循同一空间映射，背面遮挡、前后明暗与边缘压缩协调；单纯把平面点阵裁成圆不是完整的球面结构。

立体视角适合辨认形体，比较数值和读取标签通常需要正视。可以用整体轮廓交代差异，再给局部结构近景；名称与比较基准保持稳定。对象面积如果只表示视觉主次，就不把它写成容量、性能或参数量比例。图中示意单位、真实数据单位与艺术轮廓三者必须分清。

## 从场景成立到实际质量判断

| 观察层面 | 能证明成立的具体画面 | 失败时优先修正 |
|---|---|---|
| 对象身份 | 去掉标签仍看得出载体、操作区域或结构差异 | 轮廓、内部用途特征，而非更多装饰 |
| 构图与美术 | 关键静帧有主次、负空间和统一材质，文字完整可读 | 主体尺度、位置、字体与环境关系 |
| 条件与结果 | 同一前提下对象变化与状态说明一致 | 条件、操作、结果的状态链，不仅改颜色 |
| 中段连续性 | 当前主体、边界与引线在移动中仍能对应 | 完整外框、遮挡、路径及并行焦点 |
| 比较真实性 | 对象、尺度或维度可比较，示意与实测身份清楚 | 比较前提及表现语义 |
| 正常速度与衔接 | 观众看清尝试和反馈，读完原因，再进入下一问题 | 减少无用运动、保留实际阅读、重排接管 |

旧录屏不能重新定位前，不把它标记为可复核的成片基线。原创方案也不能仅靠这里的状态表宣称质量通过；需要实际实现、正常速度观看及适用的内容／声音核对。具体镜头方法可沿 [外部造型研究](external-motion-design.md)、[原理解释](external-explanation-design.md) 和 [代码到结果](code-to-result.md) 深入。

## 制作时注意

- 背景资料应与当前讲解有关，避免用能读出无关内容的资料图充当装饰。
- 比较对象的大小要说明是视觉主次还是数据比例，箭头要明确表示顺序、连接还是因果。
- 展示交互过程时，需要可辨认的动作和反馈；局部亮点或流程文字不能代替完整状态变化。
