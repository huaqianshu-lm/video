# 文档到要点：从来源位置建立结论，而不是把摘要排成三张卡

本镜头要让观众看懂“结论由来源中的哪一处支持”。文档先出现、要点再出现，只建立了先后，没有自动建立证据。设计时同时保留来源身份、关键位置、提炼动作和结论适用范围；画面最后应是能核对的认识，而非来源缩成一条边、右侧出现三句旁白。

本文区分 **原卡给定**、**源码可见**、**抽帧可见**、**制作推导**。旧版让位参数的原始样片出处尚未重新确认，保留在末部供追溯，不冒充下列 Shotcraft 样片参数。新增依据是可直接回查的证据接力案例；它与旧版单文档让位是两个方向，不能混成同一个上游实现。

文档整理可以用两种构图：**单来源保留、多个结论建立**，适合同一篇材料；**多个来源逐次接力、论点位置稳定**，适合一项项核对。要完整阅读长段原文时，优先文档近景，不能以缩略页替代阅读。

## ２．完成态先设计成“可核对的论证”

**抽帧可见**：官方片左侧是较大的当前页面，上下露出较暗的邻页；右侧主体名保持，动词与注脚更换。焦点页与词块的中心对应，引线连接二者。页面有正文、栏位或代码等具体结构，不是空白方框加“资料”二字。

**制作推导**：自己的结果画面应让人指出四件事：来源是哪份、依据在哪里、得到什么、结论有没有条件。先把这四件事排成立，再决定页面是否左移。没有来源句支持时，不画引线制造证明感；原文仅支持一个范围，就不把结论写成无条件通用判断。

| 当前内容关系 | 终点如何排 | 空间为什么有意义 |
|---|---|---|
| 一条原文支持一个结论 | 原文可读摘录与结论并列，保留页名和位置 | 观众可在同屏直接核对，不靠记住整页 |
| 同一材料有几条不同要点 | 保留文档定位，当前要点展开，其余已读项收为索引 | 结论有先后与当前重点，不等重堆成三卡 |
| 多份材料分别支持不同论点 | 固定证据窗口，材料逐项换入；论点与来源标记同阶段更新 | 保留阅读位置，换的是证据身份与论述内容 |
| 几份材料共同支持一个结论 | 最终保留必要摘录和共同结论，不让全部材料消失 | 观众看到共同支持关系；若有冲突，先展示冲突再限定结论 |

来源不是终点画面的装饰。要读原文就给予实际字高和停留；只交代资料身份就保留页眉、标题或可靠缩略轮廓，并为关键原文另设可读窗口。不要让半截被裁的正文看起来仍要求阅读。

## ３．字体、页面和背景怎样建立设计感

### ３．１　页面内部先像一份真实文档

**源码可见**：官方 demo 为不同证据分别构造分镜文章、构建界面与代码评审等页面，内部有各自的标题、列、表格、日志与注释。它们属于作者的演示材料，不是本项目可直接采用的真实记录。另有影像查看器等邻页，也不能因它在画面中出现就将其业务语义带入教程。

**制作推导**：保持当前资料的结构特征：技术规范有段落与条件，代码有缩进与语法，表格有行列关系，原文截图有实际页眉。只抽出关键原文时，保留引文边界和来源名，明确它是摘录；不能重排为自写文案后仍声称是原页面截图。省略号不能删掉会改变结论的否定或前提。

### ３．２　正文与论点不能同时争夺海报级重量

**源码可见**：右侧用两行衬线词块，主体名较弱、变化动词较亮，金色小点和引线是少量强调；页面则提供较高细节密度。浅页与暗页交替让一次步进容易辨认。**制作推导**：中文可用适合标题的宋体或清楚的无衬线，不硬套英文斜体。结论采用紧凑短句，解释性长句回到正文层级；来源名可小于主结论，但必须按实际用途决定是否要读。

自己的材料若全部是白页，不为“黑白交替”把截图反相或重画成假深色版。可以通过低对比环境、留白间隔与页边区分当前页；需要读的原文保持原貌及清楚对比。上一条结论继续保留时，降低的是其阅读优先级，不把仍有用的信息压到看不见。

### ３．３　质感来自页面和环境的关系

**源码可见**：页面以细边、上沿内高光及近远软影从石墨舞台分离，邻页通过暗层、缩小和少量模糊退到次级；背景有统一柔光。**制作推导**：温暖编辑风格可用纸面和浅底，精确软件讲解可直接用真实页面边界。只有页面需要表现为独立薄面时才强调厚度；不把每段文字镀玻璃或加一圈霓虹。重点原句的强调与引线使用同一语义色，背景纹理不超过正文笔画的视觉重量。

## ４．图文接力的实际动作与实现关系

### ４．１　证据窗口是步进，不是持续跑马灯

**原卡给定／源码可见**：页面宽９４０、高５３０，间隔１０５，故每次步进距离为６３５；切换起点为第１６／６６／１１４帧，局部窗口１８帧。实际位移由各次单调缓动进度求和：

```text
step(f) = Σ ease(clamp((f-switch_i)/window_i, 0, 1))
scrollY(f) = step(f) × (pageHeight + gap)
pageTop_i(f) = focusTop + i × (pageHeight + gap) - scrollY(f)
```

**制作推导**：每张证据有稳定 ID、当前论点、来源名、关键原文区域。布局可以共享，身份不能只按当时数组索引猜。不同高度页面可放入同高视窗，但页内裁切应提前设计；不要让每次切换连视窗大小与标题位置都跳动。当前证据在阅读时停止滚动，下一条材料有内容理由才换入。

**源码差异**：页面轨道在切换窗口之外停止，但全局仍有１至１．０２的轻推近；所以“静止”指轨道相对位移，不是全部屏幕像素不动。教程需要精读时，可以取消全局推进。切换窗口结束也不等于新词全部字母已完成显露，不能把两个时间当作同一落定帧。

### ４．２　图文对齐是两个阅读组的关系

**原卡给定／源码可见**：焦点页顶部为２７５，页高５３０，中心在５４０；右侧两行各１５４高，从 `540-154` 开始，块中心同在５４０。它校准的是整块，不是任意一行文字的基线。

**制作推导**：中文结论换成两行或三行后，先测实际行盒，再求当前阅读组中心。正文长摘录不必追求与大标题相同中心，应让连接线指向真正的依据。引线起点由页面或摘录矩形边界派生，终点指向结论；不要连接两个容器中心后穿过整段文字。全局缩放同时作用于两端，不能只缩页面、不缩已算好的屏幕引线。

### ４．３　旧词退出、新词进入和证据更换有交接窗口

**源码可见**：旧动词提前１０帧灰化，在切点起８帧向上退出；新词从切点后７帧开始逐字显露，每字１６帧、错峰１．２帧，外层词槽裁切。引线切点起６帧收回，切点后１０帧又开始１６帧重画；此时１８帧滚动未必结束。注释中“新证据落定后重画”是意图，实际表达式有重叠。

**制作推导**：不要从“先出后进”的文字描述推断不存在任何重叠。用实际字形检查是否同时露出两条可读结论；证据尚在换页时，不让引线看似已经证明新结论。可以允许低竞争的交接，但需要明确当前证据与当前论点匹配。长中文宜按语义组显露，不逐字延长到来源早已换走。

### ４．４　邻页退让和模糊只服务当前页

**源码可见**：邻页按相对焦点的距离缩小、压暗并轻模糊；轨道的方向性模糊由步进位移的速度求得，快速时有、停止时归零。固定语法色与页面内部结构不随全局重点高亮胡乱变色。

**制作推导**：重点摘录需要读的时候，可以完全不用邻页，只留可辨的上一份来源名。虚化页不能承担需要精读的前提。模糊仅属于运动或退让对象，不能把当前结论一起糊掉。先做正确遮挡与边界，再决定是否需要速度模糊。

### ４．５　从原文位置到可读摘录，怎样保持准确对应

**制作推导**：用一个稳定标识关联来源、原句区域、摘录和论点。每项至少明确来源身份、原文起止或局部矩形、要显示的摘录、它支持的判断以及必须保留的条件。这里描述的是设计关系，不要求新增生产数据格式或生成器。一个来源支持多条论点时保留各自位置；几份来源支持同一论点时，不能因为显示空间有限就合成一个虚构来源名。

若使用截图原句局部，先从素材坐标映射到展示位置。无旋转、等比缩放的简单条件下：

```text
sourcePoint = 原素材中的点
cropOrigin = 本次裁切左上角在原素材中的位置
displayOrigin = 裁切视窗在画面中的位置
screenPoint = displayOrigin + scale × (sourcePoint - cropOrigin)
```

原句标记、引线锚点与定位框由同一映射派生；页面还要平移时，继续应用同一变换。不能把截图缩小后仍使用原图坐标画高亮，也不能把放大摘录上的线头直接接到未变换的原页面位置。带旋转与透视时用完整变换矩阵，不把此二维式当作现成通解。

摘录以重排文本展示时，它不再是原页面局部的等比图像。连接表达的是来源对应，不能让单个汉字沿路径拉伸成新字。可以先保留原句位置标记，再以相同引文标识在阅读区显露最终排版；必须改写时分清原文引述与提炼结论，不能给自己写的句子套引号冒充原文。

### ４．６　只有一条结论时，不强造接力段

**制作推导**：单条论证可以用较大的原文局部作主体，关键词的对照、限定条件及结果在邻近空区依次建立。结论出现后，原文保持可读，临时运动结束；如果要点已经说完，就沿结论指向实际例子，不再为了凑三次步进添加两份弱证据。

多项逐次解释则先让已读结论收为短索引，新论点获得完整阅读面积。旧索引仍有比较作用时保留，没有作用就退出。要同时比较几个原句时，采用固定对齐摘录而非继续胶片滚动：这样视线用于比较内容，不用于追页。证据接力与并排核对各有用途，不能把某种漂亮换页变成默认段落结构。

## ６．原创演绎：从一段说明中读出调用边界

以下为未实现的原创设计。教学内容是：同一份能力说明的描述可以规定适用任务，正文则说明执行步骤；描述写得宽泛与写清边界，会给读者不同的使用判断。具体原文、改写和例子必须由当前视频资料支持，不把人为示意说成实测命中率。

### ６．１　观众应得到什么认识

开头只有一份说明，观众容易把名称、描述与正文看成同一段介绍。末态应能指出“这句话规定何时使用，那几步规定怎么做”，并看到当前示例请求与描述的对应。结论来自同一文件内的不同区域，不需要飞来三份无关卡片。

### ６．２　先排结果画面与美术

来源文档占主要纵向面积，页眉和文件名始终可辨；当前描述摘录在邻侧较宽的阅读区展开，旁边只留一句短判断。正文步骤保留可辨定位，暂不与描述同时全文阅读。摘录、原位置和解释用同一小标记对应。最后若进入步骤教学，就让同一页的正文成为下一个焦点，而非再生成一套海报。

用清楚的无衬线正文、字段名的等宽角色和少量标题字重形成层级。当前原句的背景强调为薄而低竞争的色带，不盖住标点；引线与页边细线的粗细有主次。浅纸面与稍暗环境保持边缘分离；不需要玻璃厚度、页角卷曲和大范围扫光。对长中文优先增加阅读区或按语义拆段，不缩成药丸。

### ６．３　完整调度与下一镜

| 状态 | 画面与动作 | 观众看懂什么 | 避免什么 |
|---|---|---|---|
| 认来源 | 同一文件正视建立，页眉清楚，内容有真实结构 | 要解释的依据在哪里 | 用不可读乱码充当真实文档 |
| 定位 | 描述区域获得局部标记，其余保持上下文 | 当前关注这段原文 | 原文尚未定位，结论已先飞入 |
| 腾出阅读区 | 文档适度让位或取局部近景，当前摘录在最终排版窗口显露 | 既认得原位置，也读得到句子 | 只保留被裁到半行的来源作为装饰 |
| 建立判断 | 强调触发词与任务范围，旁侧短判断跟随出现 | 结论由哪几个字支持 | 一次整段变色、毫无主次 |
| 对照例子 | 有依据的请求短句出现，与当前范围做同屏核对 | 适用或不适用的理由 | 把可视化判断当成软件已自动选用 |
| 正文接管 | 清理临时引线，沿同一页转向步骤区；描述退为定位 | 从何时用进入怎样做 | 重新淡入三张“步骤”说明卡割断来源 |

来源让位只在能保留身份和可读摘录时采用。若整页是窄长文档，可以保留全页小定位、另给同源局部阅读；如果只有一句来源，直接让引文成为主体即可，不必先做一张假长文档。旧版的固定三要点和等距进入不成为本例结构。

## ７．中段、时间与声音的设计判断

先看文档让位中段：页框、引线、摘录与结论是否挤进同一狭缝，摘录是否覆盖字幕。来源与摘录使用两种比例时，避免观众把它们误读为两份材料；相同名称和位置标记比让文字硬变形更可靠。

时间按实际口播与阅读任务安排。关键原句完整出现且停止运动后才开始计算阅读窗口；一句结论尚在理解，下一条摘录不要同时滚入。长句超出时间就删去无关展示或拆镜头，不删除决定适用范围的条件。无词级证据时不估算逐词高亮时点。

**声音建议，未试听**：材料换入可有轻短翻阅或定位反馈，真正的判断不需要每字发声。页面材质没有表现成纸时，不强加纸张揉动声；摘录阅读保持安静，声效不压过口播。官方媒体中未检测到音轨，不能声称这些是原片音色。

## ８．失败修正与可观察判据

| 失败画面 | 应检查的原因 | 优先修改 |
|---|---|---|
| 来源一闪就缩走，右侧剩三句旁白 | 来源身份与依据没有参加解释 | 先设计原句、结论和位置对应，再重排运动 |
| 文档像空白框加横线 | 只设计外壳，没有原文结构 | 用当前材料建立真实段落、标题与关键摘录 |
| 引线从容器中心穿过字 | 对应只到容器，没有到证据位置 | 从实际原句边界派生锚点，预留通道 |
| 结论换了，证据还是上一页 | 状态和显露时序分离 | 同一语义阶段派生证据、结论、来源标记 |
| 看得到文档，读不到需要的句子 | 将缩略身份与原文阅读混为一件事 | 单独给可读摘录或近景，不仅放大整页 |
| 换页像背景在跑 | 轨道持续运动或停留被装饰吃掉 | 步进后停稳，必要时取消全局推进 |
| 两句结论叠成残字 | 词槽大小或交接窗口不适应中文 | 依据实际字形重排，旧词净退后再给新句阅读 |
| 示意匹配被误认作实测结果 | 使用成功徽章、自动选择与虚构日志 | 清楚保留示意身份，实际证据另行展示 |

通过应能观察到：静态完成态有清楚的来源、依据与结论层级；运动中能认出当前材料；正常速度下读得完关键原文和限定条件；下一镜沿实际内容继续。实际使用当前材料和字体验证这四件事，不能只检查坐标与缓动。本文尚未完成原创镜头实现与正常速度观看，不能据文档宣称商用成片已验。
