# 文档到要点

## 表达与关键状态

用于从来源提炼结论。单文档居中建立来源 → 文档左移让出阅读空间 → 右侧三条要点逐项出现 → 来源及结论收尾退出。来源虽被裁切，身份仍可辨认；观众的阅读重点逐渐转到结论。

## 案例观察值

以下坐标为 960×540 逻辑画布；可按画幅调整，不能直接套为生产默认值。

| 条件 | 观察值与作用 |
|---|---|
| 文档初态 | 700×420，单主体建立来源 |
| 让位 | 0.90～1.70 秒，x 位移 0→−514，缩放 1→0.92 |
| 来源与要点间隔 | 来源右缘约 x=260、要点起点 x=380，约 120px 分隔 |
| 要点进入 | 1.90／3.20／4.50 秒；同左边界、约 100px 行距 |
| 说明补充 | 相对标题延后约 0.30 秒，主次分开 |
| 收尾 | 6.60～7.00 秒清理主体 |

## 迁移和失败条件

长中文不能套不换行的药丸；先确定必要文字、换行和层级，再重算布局。来源裁切适合提炼，不适合全文阅读。让位与要点出现不要同时抢焦点；最后一条说明应读完再退出。真实教程时间取自音频，不套 1.3 秒发牌间隔。
